# LeetCode 刷题

用于找工作前的算法面试刷题练习（Java，建议用 IntelliJ IDEA 打开）。

## 目录结构

- `src/`：每道题一个 Java 文件，推荐用「题号_题名」命名，如 `0001_TwoSum.java`

## 文件约定

- 文件顶部注释写明题目链接和思路要点
- 类内提供题目要求的解法方法，并附 `main` 做简单验证（或使用 JUnit）
- 题目描述较长时，可把题目说明整理成注释，方便复习
