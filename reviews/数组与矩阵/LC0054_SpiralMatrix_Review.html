public List<Integer> spiralOrder(int[][] matrix) {
        List<Integer> ans = new ArrayList<>();
        int l = 0, r = matrix[0].length - 1;
        int u = 0, d = matrix.length - 1;
        while (l <= r && u <= d) {
            for (int i = l; u <= d && i <= r; i++) {
                ans.add(matrix[u][i]);
            }
            u++;
            for (int j = u; l <= r && j <= d; j++) {
                ans.add(matrix[j][r]);
            }
            r--;
            for (int i = r; u <= d && i >= l; i--) {
                ans.add(matrix[d][i]);
            }
            d--;
            for (int j = d; l<= r && j >= u; j--) {
                ans.add(matrix[j][l]);
            }
            l++;
        }
        return ans;
    }

思路拆解

① 问题本质与解法选择

  • 本质是按层（一圈一圈）有方向地遍历矩阵，要求顺时针顺序且每个元素恰好一次。
  • 两种思路：① 状态机 + 方向数组（dirs 右/下/左/上，撞墙或已访问就转向）；② 四边界收缩：用 l/r/u/d 四条边界框住当前圈，依次走 上→右→下→左 四条边，每条边走完把对应边界往里收一圈。
  • 本题选四边界收缩：无需 visited 数组，辅助空间 O(1)，且天然保证每个位置只走一次。

② 关键设计决策

  • 四个边界变量：l=0, r=n-1, u=0, d=m-1（左、右、上、下）。
  • 外层 while (l <= r && u <= d)：只要边界未交叉就还有圈。
  • 每条边用当前边界遍历，走完立即收缩：
  1. 上边：matrix[u][i]，i=l..r，走完 u++；
  2. 右边：matrix[j][r]，j=u..d，走完 r--；
  3. 下边：matrix[d][i]，i=r..l，走完 d--；
  4. 左边：matrix[j][l]，j=d..u，走完 l++。
  • 关键细节：每条边的 for 条件里加边界守卫（如 u <= d && i <= r）。作用是：当只剩单行/单列时，收缩后某些边会「空转」，守卫让空转的边直接跳过，避免重复添加。例如 1x5 走完上边后 u=1 > d=0，右边/下边/左边的循环体全部被守卫拦住。

③ 边界与细节

  • 单行 1x5：上边走完 u++ 后 u>d，后续三条边被守卫拦截，输出恰为整行。
  • 单列 4x1：上边 1 个元素，u++ 后右边走整列，r-- 后 r<l，后续边被拦截。
  • 2x2：一圈走完四个边界全部交叉，while 退出，不会重复。
  • 多圈（4x4）：每圈收缩 1，内圈 2x2 时仍按同一逻辑正确收尾。
  • 值相同 / 负数 / 上下限值：与数值无关，仅位置遍历，天然正确。

④ 复杂度与最优性

  • 每个元素恰好访问一次，O(mn)；返回列表本身 O(mn)，除输出外辅助空间 O(1)（只 4 个边界变量）。
  • 最优性：输出需要包含全部 mn 个元素，下界 Ω(mn)；本解法达到下界且无额外标记数组，为最优。

⑤ 具体 case 推演：2x2 [[1,2],[3,4]]

边边界状态取到的元素收缩后
上l=0,r=1,u=0,d=1matrix[0][0..1] → 1,2u=1
右l=0,r=1,u=1,d=1matrix[1][1] → 4r=0
下l=0,r=0,u=1,d=1matrix[1][0] → 3d=0
左l=0,r=0,u=1,d=0守卫 l<=r 假 → 跳过l=1
  • 结果 [1,2,4,3]，while (l<=r && u<=d) 中 1<=0 假 → 退出。正确（顺序与边界4一致）。

⑥ 具体 case 推演：单行 [[1,2,3,4,5]]（u=d=0）

  • 上边：matrix[0][0..4] → 1,2,3,4,5；u++ → u=1。
  • 右边：守卫 j<=d（j>=1 时 j<=0 假）→ 空转；r-- → r=3。
  • 下边：守卫 u<=d（1<=0 假）→ 空转；d-- → d=-1。
  • 左边：守卫 j>=u（j<=-1 时不可能）→ 空转；l++ → l=1。
  • while 检查 1<=3 && 1<=-1 假 → 退出，结果 [1,2,3,4,5]。正确——若没有守卫，右边会重复取 5。
