34. 在排序数组中查找元素的第一个和最后一个位置 (Find First and Last Position of Element in Sorted Array)

难度：Medium ｜ 分类：数组与矩阵

标签：数组、二分查找

题目描述

给你一个按照非递减顺序排列的整数数组 nums，和一个目标值 target。请你找出给定目标值在数组中的开始位置和结束位置。

如果数组中不存在目标值 target，返回 [-1, -1]。

你必须设计并实现时间复杂度为 O(log n) 的算法解决此问题。

示例 1：

输入：nums = [5,7,7,8,8,10], target = 8

输出：[3,4]

示例 2：

输入：nums = [5,7,7,8,8,10], target = 6

输出：[-1,-1]

示例 3：

输入：nums = [], target = 0

输出：[-1,-1]

public int[] searchRange(int[] nums, int target) {
        if (nums.length == 0) {
            return new int[]{-1, -1};
        }
        int left = findFirstIndex(nums, target);
        int right = findFirstIndex(nums, target + 1);
        if (left >= nums.length || right < left || nums[left] != target ) {
            return new int[]{-1, -1};
        }
        return new int[] {left, right - 1};
    }

	private int findFirstIndex(int[] nums, int target) {
        int left = -1, right = nums.length;
        while (left + 1 < right) {
            int mid = left + (right - left) / 2;
            if (nums[mid] < target) {
                left = mid;
            } else {
                right = mid;
            }
        }
		return right;
	}

排序数组找首尾：两次二分分别找 target 与 target+1 的插入位置，O(log n)/O(1)，一次 Accepted（88/88）

思路拆解

问题本质：有序数组中找 target 的左右边界 = 两个二分：第一个 ≥ target 的位置，与第一个 > target 的位置，右边界 = lowerBound(target+1)-1。

关键设计：只写一个 lowerBound（返回第一个 ≥ x 的下标）：左开右开区间 (left=-1, right=len)，mid 小于 x 时 left=mid（排除左侧），否则 right=mid，循环 left+1<right 结束后 right 即答案。对 target 和 target+1 各调一次，逻辑完全复用，避免两份边界二分不一致。

边界：空数组直接返回 [-1,-1]；target 不存在时 left>=len 或 nums[left]!=target，返回 [-1,-1]；target 是最大元素时 target+1 让 lowerBound 返回 len，right-1 仍正确；全数组等于 target。

复杂度：O(log n) 时间、O(1) 空间，最优。

套路沉淀

二分下界（lower bound）的区间端点：right 取 n 还是 n-1

找「第一个 >= target 的位置」时答案可能是 n（插入点，target 大于所有元素），右端点必须用开区间 n；right=nums.length-1 的闭区间配 while(left<right) 在 target 大于所有元素时停在 n-1 且不验证该元素，返回 n-1 而非 n；空数组时 right=-1 循环不执行返回 0 造成越界

二分 left=mid 收拢必须配 mid 上取整

left=mid 会把区间向右侧收拢，下取整 mid=left+(right-left)/2 在 right==left+1 时等于 left，走 else 分支 left=mid 原地踏步死循环；用 left=mid 时 mid 必须上取整 left+(right-left+1)/2（此时 right=mid-1 仍安全），或改用排除式写法 left=mid+1 配下取整。找第一个 >= target（lower bound）的分支应为 nums[mid] < target 时 left=mid+1 排除 mid，否则 right=mid 保留候选；写成 nums[mid] > target 收 right、else left=mid 实际收敛到最后一个 <= target，两次调用组合结果错位

二分比较符先问等号归属：相等时 mid 是候选还是被排除

写比较符前先问「相等时 mid 是候选还是被排除」，等号必须与保留侧同侧。lower bound（第一个 >= target）：nums[mid]==target 是候选 → nums[mid] < target 排除（left=mid+1）、nums[mid] >= target 保留（right=mid）；若写成 nums[mid] <= target 保留，会把「小于」也当候选，而 > 分支又排除掉真正的候选。等价地 nums[mid] >= target 时 right=mid、else left=mid+1 同样正确——比较符不是关键，等号放哪边才是

二分统一模板：区间定义决定 while 条件，推荐左闭右开

while 条件不是自由选择，它由「区间何时为空」决定：闭区间 [L,R] 里 L==R 还剩一个元素，空区间是 L>R，所以配 while(L<=R)，且 mid 已被检查必须排除（L=mid+1 / R=mid-1），想保留 mid 就得配 mid 上取整；左闭右开 [L,R) 里 L==R 已空（R 不含），配 while(L<R)，排除用 L=mid+1、保留用 R=mid，下取整永远安全。推荐统一用左闭右开 [0,n)：初始 L=0、R=n，循环结束 L==R 即答案（插入点），lower bound 的不变式是 L 左边全 < target、R 右边全 >= target。混用开闭与 while 条件（闭区间写 <、或开区间写 <=）是差一错误的主源

二分全开区间 (L,R) / 红蓝染色模板：while(L+1<R)，答案在边界

全开区间 (L,R) 两端都不含：区间为空当 R<=L+1，循环条件 while(L+1<R)，mid 严格落在内部，排除/保留都收端点（L=mid 或 R=mid），结束时 L 与 R 相邻，答案在边界（lower bound 的答案是 R，L 是最后一个不满足的哨兵）。等价的红蓝染色法：L 标「确定不满足」、R 标「确定满足」，初始可取 L=-1、R=n 当哨兵，mid 染色后收对应端点，最终 R 即第一个满足位置。优点：两种移动对称（都收 mid），没有 +1/-1 纠结；缺点：答案夹在两个哨兵之间，理解门槛略高。日常建议与左闭右开模板二选一，不要混用
