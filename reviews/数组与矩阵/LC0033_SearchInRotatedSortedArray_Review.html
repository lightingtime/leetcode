33. 搜索旋转排序数组 (Search in Rotated Sorted Array)

> https://leetcode.cn/problems/search-in-rotated-sorted-array/

难度：Medium ｜ 分类：数组与矩阵

标签：数组、二分查找

题目描述

整数数组 nums 按升序排列，数组中的值 互不相同 。

在传递给函数之前，nums 在预先未知的某个下标 k（0 ）上进行了 向左旋转，使数组变为 [nums[k], nums[k+1], ..., nums[n-1], nums[0], nums[1], ..., nums[k-1]]（下标 从 0 开始 计数）。例如， [0,1,2,4,5,6,7] 下标 3 上向左旋转后可能变为 [4,5,6,7,0,1,2] 。

给你 旋转后 的数组 nums 和一个整数 target ，如果 nums 中存在这个目标值 target ，则返回它的下标，否则返回 -1 。

你必须设计一个时间复杂度为 O(log n) 的算法解决此问题。

示例 1：

输入：nums = [4,5,6,7,0,1,2], target = 0

输出：4

示例 2：

输入：nums = [4,5,6,7,0,1,2], target = 3

输出：-1

示例 3：

输入：nums = [1], target = 0

输出：-1

public int search(int[] nums, int target) {
        int left = 0, right = nums.length - 1;
        while (left < right) {
            int mid = left + (right - left) / 2;
            if (nums[mid] == target) {
                return mid;
            }
            if (nums[mid] >= nums[left]) {
                if (target >= nums[left] && target < nums[mid]) {
                    right = mid - 1;
                } else {
                    left = mid + 1;
                }
            } else {
                if (nums[mid] < target && target <= nums[right]) {
                    left = mid + 1;
                } else {
                    right = mid - 1;
                }
            }
        }
        return nums[left] == target ? left : -1;
    }

旋转数组二分：有序半段判定用 >=、值域归属 target、mid 命中即返回，O(log n)/O(1) 一次 Accepted（196/196）

思路拆解

问题本质：旋转后的有序数组是「两段各自递增」。二分时不能直接比较 nums[mid] 与 target，必须先判断 mid 落在哪一段，再按段内有序性收窄区间。

关键设计：nums[mid] >= nums[left] 说明左段递增：target 落在 [left, mid) 内则 right=mid-1，否则去右段；否则 mid 在右段：target 落在 (mid, right] 内则 left=mid+1，否则去左段。段内有序保证每步排除一半。

边界：数组长度为 1 时循环不进入，最后统一检查 nums[left]；旋转点恰在 0 处（等价未旋转）走 nums[mid]>=nums[left] 分支仍正确；题目无重复元素，比较不受重复干扰。

复杂度：O(log n) 时间、O(1) 空间，最优。

旋转数组二分只比 nums[mid] 大小、未用有序半段值域判断 target 归属：左半段有序时只有 nums[left] <= target < nums[mid] 才搜左，否则搜右；右半段同理需 nums[mid] < target <= nums[right]，缺值域判断会把 target 错误丢出区间

套路沉淀

旋转有序数组二分：先判有序半段，再用值域归属 target

每次用 nums[left] <= nums[mid] 判断左半段是否有序；左半段有序时仅当 nums[left] <= target < nums[mid] 搜左否则搜右，右半段有序时仅当 nums[mid] < target <= nums[right] 搜右否则搜左；中点用 left + (right-left)/2，循环 left <= right
