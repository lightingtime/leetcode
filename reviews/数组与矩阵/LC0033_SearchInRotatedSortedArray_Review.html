我的解法

思路：旋转数组二分。每次取中点后，用 nums[mid] >= nums[left] 判断左半段是否有序； 左半段有序时仅当 target 落在 [nums[left], nums[mid]) 才搜左，否则搜右； 右半段有序时仅当 target 落在 (nums[mid], nums[right]] 才搜右，否则搜左。 nums[mid] == target 直接返回。

时间 O(log n) 空间 O(1) 满足题目复杂度要求

src/LC0033_SearchInRotatedSortedArray.java提交区
public int search(int[] nums, int target) {
    int left = 0, right = nums.length - 1;
    while (left < right) {
        int mid = left + (right - left) / 2;
        if (nums[mid] == target) {
            return mid;
        }
        if (nums[mid] >= nums[left]) {
            if (target >= nums[left] && target < nums[mid]) {
                right = mid - 1;
            } else {
                left = mid + 1;
            }
        } else {
            if (nums[mid] < target && target <= nums[right]) {
                left = mid + 1;
            } else {
                right = mid - 1;
            }
        }
    }
    return nums[left] == target ? left : -1;
}

边界语义：left、right 是闭区间 [left, right]； 中点 mid = left + (right-left)/2 保证落在区间内；有序半段判定用 >=（两元素区间时 mid == left 也成立）；target 恰好等于 mid 时必须能命中。

套路沉淀

本轮沉淀 1 条套路（lc-analyze/references/patterns.md）：

旋转有序数组二分：中点 left + (right-left)/2；用 nums[left] <= nums[mid] 判有序半段； 左半段有序仅当 nums[left] <= target < nums[mid] 搜左，右半段同理；mid 命中即返回。

旋转数组二分 · 本质梳理

  • 为什么先判有序半段：旋转数组整体只有一个「山谷」（旋转点处大→小掉落）。从任意位置切一刀，最多只有一个半边含山谷，所以必有一半有序；只有有序段才能用值域判断 target 归属，从而确定性丢掉另一半。
  • 端点比较 = 没跨山谷的指纹：左半段 [left, mid] 没跨山谷 ⇔ 严格递增 ⇔ nums[left] < nums[mid]；nums[left] > nums[mid] 说明山谷在左半段内（此时右半段才有序）；== 只在 mid == left（两元素区间、单元素左半段）时发生，天然有序——所以判定用 <=。
  • 为什么 = 不能进 else：else 的前提是「右半段有序」；mid == left 时右半段是整个两元素段（如 [5,1]），可能恰恰无序，前提不成立。
  • 右半段分支：右半段有序时，仅当 nums[mid] < target <= nums[right] 才 left = mid + 1；否则（target ≤ nums[mid] 或 > nums[right]）right = mid - 1。
  • 中点：mid = left + (right - left) / 2，永远是当前区间 [left, right] 的中点；判断有序用的端点是当前区间自己的 left 和 mid，不能混用别的区间的端点。

错误习惯复盘

  • 二分中点公式错：(right-left)/2 在 left > 0 时落在区间外。
  • 旋转数组二分缺值域判断：只比 nums[mid] 大小会把 target 错误丢出区间。
  • 二分丢等号：target == nums[mid] 时严格不等式两边都不进，mid 被丢。
  • 有序半段判定用 > 而非 >=：两元素区间 mid == left 恒 false 进错分支。
