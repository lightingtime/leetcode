162. 寻找峰值 (Find Peak Element)

> https://leetcode.cn/problems/find-peak-element/

难度：Medium ｜ 分类：数组与矩阵

标签：数组、二分查找

题目描述

峰值元素是指其值严格大于左右相邻值的元素。

给你一个整数数组 nums，找到峰值元素并返回其索引。数组可能包含多个峰值，在这种情况下，返回 任何一个峰值 所在位置即可。

你可以假设 nums[-1] = nums[n] = -∞ 。

你必须实现时间复杂度为 O(log n) 的算法来解决此问题。

示例 1：

输入：nums = [1,2,3,1]

输出：2

解释：3 是峰值元素，你的函数应该返回其索引 2。

示例 2：

输入：nums = [1,2,1,3,5,6,4]

输出：1 或 5

解释：你的函数可以返回索引 1，其峰值元素为 2；

或者返回索引 5， 其峰值元素为 6。

我的解法

写法 1 · 二分：比较 nums[mid] 与 nums[mid+1] 沿上升方向收拢

时间 O(log n)空间 O(1)内存 ≈ 42.5 MB用例 76/76

src/数组与矩阵/LC0162_FindPeakElement.java提交区
public int findPeakElement(int[] nums) {
        if (nums.length < 2) return 0;
        int l = 0, r = nums.length - 1;
        while (l < r) {
            int mid = l + (r - l) / 2;
            if (mid == 0) {
                if (nums[mid] > nums[mid + 1]) {
                    return mid;
                }
                l = mid + 1;
            } else if (mid == nums.length - 1) {
                if (nums[mid] > nums[mid - 1]) {
                    return mid;
                }
                r = mid - 1;
            } else if (mid > 0 && mid < nums.length - 1 && nums[mid] > nums[mid - 1] && nums[mid] > nums[mid + 1]) {
                return mid;
            } else {
                if (nums[mid] > nums[mid + 1]) {
                    r = mid - 1;
                } else {
                    l = mid + 1;
                }
            }
        }
        return r;
    }

思路拆解

① 问题本质与解法选择

  • 在无序数组里找任意一个「严格大于左右邻居」的峰值索引，且外侧视为 -∞，要求 O(log n)。
  • 朴素线性扫描是 O(n)，不满足要求 → 必须二分。
  • 关键性质：nums[mid] < nums[mid+1]（上坡）时，沿上升方向走一定能到达某个峰（因为数组右端外侧是 -∞，爬坡不可能永远上升）；nums[mid] > nums[mid+1]（下坡）时，峰在左侧（含 mid）。二分就是反复用这条「局部趋势」决定收缩方向。

② 关键设计决策

  • l=0, r=n-1，while (l < r)，mid = l + (r-l)/2。
  • 判断顺序：
  1. mid==0：nums[0] > nums[1] 则 0 是峰返回；否则 l=mid+1（0 不是峰，峰必在右半）。
  2. mid==n-1：nums[n-1] > nums[n-2] 则返回；否则 r=mid-1。
  3. 中间且 nums[mid] 严格大于两邻居 → 直接返回 mid。
  4. 其余（mid 非峰）：nums[mid] > nums[mid+1] 下坡 → r=mid-1；否则上坡 → l=mid+1。
  • 端点特判里非峰时必须推进指针（l=mid+1 / r=mid-1），否则 l/r 不变会死循环——这是初版代码的死循环根因，已修正。
  • 方向依据必须是 nums[mid] 与相邻元素 nums[mid+1] 比较（局部趋势），不能用与区间远端 nums[r] 比较——初版用后者导致示例 1 返回 0，已修正。

③ 边界与细节

  • 单元素：直接返回 0（两侧 -∞）。
  • 单调递增：峰在末尾；单调递减：峰在开头——由外侧 -∞ 保证。
  • 两元素：递增返回 1、递减返回 0。
  • int 上下限：[MIN, MAX] 峰在 1、[MAX, MIN] 峰在 0，比较运算无溢出风险。
  • 相邻元素互不相等（题目约束），无需处理相等。

④ 复杂度与最优性

  • 每轮区间减半，O(log n)；只用 3 个指针变量，O(1)。
  • 最优性：无序数组中峰值位置无法在 o(log n) 次比较内确定（对抗性论证：任何算法都必须排除掉约一半的候选才能保证找到峰），Ω(log n) 为下界，本解法达到。

套路沉淀

沿上升方向二分找峰

无序数组找峰（外侧 -∞）：二分比较 nums[mid] 与 nums[mid+1]，右邻居更大说明在上坡、峰必在右半（l=mid+1）；右邻居更小说明在下坡、峰在左半含 mid（r=mid）。方向只看局部趋势，不要与区间远端比较。O(log n)。
