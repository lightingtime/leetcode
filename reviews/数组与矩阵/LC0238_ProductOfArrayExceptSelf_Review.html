238. 除了自身以外数组的乘积 (Product of Array Except Self)

> https://leetcode.cn/problems/product-of-array-except-self/

难度：Medium ｜ 分类：数组与矩阵

标签：数组、前缀和

题目描述

给你一个整数数组 nums，返回 数组 answer ，其中 answer[i] 等于 nums 中除了 nums[i] 之外其余各元素的乘积 。

题目数据 保证 数组 nums之中任意元素的全部前缀元素和后缀的乘积都在 32 位 整数范围内。

请 不要使用除法，且在 O(n) 时间复杂度内完成此题。

示例 1:

输入: nums = [1,2,3,4]

输出: [24,12,8,6]

示例 2:

输入: nums = [-1,1,0,-3,3]

输出: [0,0,9,0,0]

提示：

关键点都处理对了：① 全程没有除法，用「左侧积 × 右侧积」替代「总积 ÷ nums[i]」，天然规避 0 的问题；② 第一遍 leftMul[0] = 1 起步，leftMul[i] = leftMul[i-1] * nums[i-1] 写的是「不含 nums[i] 的左侧积」；③ 第二遍从右往左，先 leftMul[i] *= right 再 right *= nums[i]——顺序反过来就会把自身乘进去（因为 right 那时还没包含 nums[i]）；④ 额外空间只有一个滚动变量 right，输出数组不算额外空间，符合 O(1) 要求。本地示例 2 + 边界 8（空输入/单元素/最短长度2/全相同/单个0/多个0/负数/大数）全过，一次提交 Accepted（24/24）。

我的解法

写法 1 · 前缀积×后缀积

时间 O(n)空间 O(n)内存 ≈ 60.9 MB用例 24/24

LC0238_ProductOfArrayExceptSelf.java · 前缀积×后缀积提交区
public int[] productExceptSelf(int[] nums) {
        if (nums.length < 1) {
            return nums;
        }
        int[] leftMul = new int[nums.length];
        leftMul[0] = 1;
        for (int i = 1; i < leftMul.length; i++) {
            leftMul[i] = leftMul[i - 1] * nums[i - 1];
        }
        int[] rightMul = new int[nums.length];
        rightMul[nums.length - 1] = 1;
        for (int i = nums.length - 2; i >= 0; i--) {
            rightMul[i] = rightMul[i + 1] * nums[i + 1];
        }
        for (int i = 0; i < nums.length; i++) {
            nums[i] = leftMul[i] * rightMul[i];
        }
        return nums;
    }

        if (nums.length < 1) return nums;
        int [] leftMul = new int[nums.length];
        leftMul[0] = 1;
        for (int i = 1; i < leftMul.length; i++) {
            leftMul[i] = leftMul[i - 1] * nums[i - 1];
        }
        int right = 1;
        for (int i = nums.length - 1; i >= 0; i--) {
            leftMul[i] = leftMul[i] * right;
            right *= nums[i];
        }
        return leftMul;
    }

思路拆解

问题本质：每个位置输出左边所有数乘积 × 右边所有数乘积。题目禁止用除法（0 会破坏除法），所以用两趟累乘。

关键设计：第一趟从左到右：leftMul[i] = nums[0..i-1] 的累积乘积（leftMul[0]=1）；第二趟从右到左：滚动变量 right 累积 nums[i+1..n-1] 的乘积，leftMul[i] *= right，再 right *= nums[i]。两趟合起来每个位置恰好乘上左右两侧全部元素，且全程不用除法。

边界：数组长度 1 时输出 [1]；含 0 或多个 0 时乘法天然正确处理，这正是不用除法的优势；空数组直接原样返回。

复杂度：O(n) 时间、O(1) 额外空间（复用输出数组，不计入额外空间），最优。
