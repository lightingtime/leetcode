public int[] productExceptSelf(int[] nums) {
        if (nums.length < 1) {
            return nums;
        }
        int[] leftMul = new int[nums.length];
        leftMul[0] = 1;
        for (int i = 1; i < leftMul.length; i++) {
            leftMul[i] = leftMul[i - 1] * nums[i - 1];
        }
        int right = 1;
        for (int i = nums.length - 1; i >= 0; i--) {
            leftMul[i] = leftMul[i] * right;
            right *= nums[i];
        }
        return leftMul;
    }

答案数组存左前缀积+滚动变量累乘右侧，额外空间 O(1)；二次提交均 AC

思路拆解

问题本质：每个位置输出左边所有数乘积 × 右边所有数乘积。题目禁止用除法（0 会破坏除法），所以用两趟累乘。

关键设计：第一趟从左到右：leftMul[i] = nums[0..i-1] 的累积乘积（leftMul[0]=1）；第二趟从右到左：滚动变量 right 累积 nums[i+1..n-1] 的乘积，leftMul[i] *= right，再 right *= nums[i]。两趟合起来每个位置恰好乘上左右两侧全部元素，且全程不用除法。

边界：数组长度 1 时输出 [1]；含 0 或多个 0 时乘法天然正确处理，这正是不用除法的优势；空数组直接原样返回。

复杂度：O(n) 时间、O(1) 额外空间（复用输出数组，不计入额外空间），最优。
