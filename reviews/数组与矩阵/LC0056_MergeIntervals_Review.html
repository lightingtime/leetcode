public int[][] merge(int[][] intervals) {
        Arrays.sort(intervals, Comparator.comparingInt(a -> a[0]));
        List<int[]> list = new ArrayList<>();
        for (int[] interval : intervals) {
            if (list.isEmpty()) {
                list.add(new int[]{interval[0], interval[1]});
            } else {
                int[] last = list.get(list.size() - 1);
                if (last[1] >= interval[0]) {
                    if (last[1] < interval[1]) {
                        last[1] = interval[1];
                    }
                } else {
                    list.add(new int[]{interval[0], interval[1]});
                }
            }
        }
        return list.toArray(new int[0][]);
    }

思路拆解

问题本质：把重叠区间合并。区间按 start 排序后，问题变成顺序扫描：当前区间与上一个合并段重叠就扩展，否则开新段。

关键设计：排序后遍历，用 list 存合并结果；新区间与最后一个重叠（last[1] >= interval[0]，含端点相接）时，end 更新为 max(last[1], interval[1])——必须取 max 而不能直接赋值，因为排序只保证 start 有序，后一个区间可能完全被包含（end 更小）。不重叠则直接追加新区间。

边界：空数组；单个区间；完全包含（如 [1,10] 与 [2,3]）；端点相接 [1,2]+[2,3] 要合并；多个区间同 start 时按 end 正确合并。

复杂度：O(n log n) 时间（排序主导）、O(log n) 排序栈空间（不计输出），最优。
