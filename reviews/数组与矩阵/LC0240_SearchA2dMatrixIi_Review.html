右上角起步：一次移动排除一整行或一整列
✓ Accepted 130/130 难度 Medium 分类 数组与矩阵 提交一次通过 ✓ O(m+n) / O(1) 最优 2026-08-06

我的解法

思路：从右上角出发，利用该角是「行列分界点」的性质逐步排除。 矩阵每行从左到右递增、每列从上到下递增，因此右上角是当前行的最大值、当前列的最小值。 若 target 小于当前值，则当前列从该行往下全部更大，整列排除，左移一列； 若 target 大于当前值，则当前行从该列往左全部更小，整行排除，下移一行。 相等即命中；越界则说明不存在。

时间 O(m+n) 额外空间 O(1) 无需二分、无需排序

src/数组与矩阵/LC0240_SearchA2dMatrixIi.java提交区
public boolean searchMatrix(int[][] matrix, int target) {
    if (matrix.length == 0 || matrix[0].length == 0) {
        return false;
    }
    int m = matrix.length;
    int n = matrix[0].length;

    int x = 0, y = n - 1;
    while (x >= 0 && x < m && y >= 0 && y < n) {
        if (matrix[x][y] == target) {
            return true;
        } else if (matrix[x][y] > target) {
            y--;
        } else {
            x++;
        }
    }
    return false;
}

边界语义：先处理空矩阵/空行避免访问 matrix[0]；循环条件直接用行列下标边界， 越界即代表所有可能位置都已被排除；单行、单列、左上/右上/左下/右下角、负数和重复值都走同一条路径，无需特殊分支。

分类提醒 · 数组与矩阵

矩阵题先想如何用行列信息/排序/原地操作降维。

本题的「降维」在于用行列单调性把二维搜索压成一条折线：不需要在整块矩阵上做复杂的区间判断， 只要找到合适的起点（右上或左下），每步就能确定性地丢掉一行或一列。

右上角消行消列 · 本质梳理

  • 为什么从右上角出发：它同时是当前行最大、当前列最小的「分界角」， 左边都更小、下面都更大，两个方向的单调性都直接可用。
  • 为什么每次能排除一整行/列：target 更小 → 当前列从该行起全部更大，整列可删； target 更大 → 当前行从该列起全部更小，整行可删。
  • 为什么是 O(m+n) 而非 O(log(mn))：矩阵只有「行内、列内分别有序」，没有全局一维有序， 二分无法直接作用于整块矩阵；每次排除一行或一列，最多走 m+n 步，这已是该问题可达到的下限。
  • 左下角对称：从左下角出发同样成立（同行最大、同列最小方向互换），选哪边只是习惯问题。
