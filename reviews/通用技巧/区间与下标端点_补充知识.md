# 补充知识：区间端点、个数与下标 —— 解决 +1 / -1

> 来源：力扣 395 讨论（`dfs` 返回 `end - start`、strStr 返回 `i - j + 1`）沉淀出的通用索引技巧。
> 适用：一切「区间长度」「返回下标」「二分/分治切分」的场景。

## 1. 统一默认姿势：左闭右开 `[l, r)`

区间写 `[l, r)`（含 `l`、不含 `r`）时，三个最常纠结的地方全部免记：

| 问题 | 答案 | 理由 |
|------|------|------|
| 区间里有几个元素 | `r - l` | 不含右端点，个数正好是差值 |
| 怎么遍历 | `for (i = l; i < r; i++)` | `i < r` 天然不含 `r` |
| 怎么切分 | `[l, mid)` 与 `[mid, r)` | 边界 `mid` 不重复计算 |

对应代码：`dfs(start, end)` 里整段合法时直接返回 `end - start`——它不需要 +1。

## 2. 要不要 +1：只问「右端点算不算」

不管区间怎么写，只需问一件事：**右端点算不算在范围内？**

- **算**（闭区间 `[l, r]`，含 `r`）→ 个数 = `r - l + 1`
- **不算**（半开区间 `[l, r)`，不含 `r`）→ 个数 = `r - l`

| 区间 | 包含的下标 | 个数 |
|------|-----------|------|
| 闭 `[2, 5]` | 2, 3, 4, 5 | 4 = 5-2+1 |
| 半开 `[2, 5)` | 2, 3, 4 | 3 = 5-2 |

口诀：**右端点算就 +1，不算就不加**。（左端点通常都算，不用纠结。）

## 3. 反着求起点（strStr / 滑动窗口场景）

知道「窗口长度 `m`、结尾下标 `i`」，求起点 `s`：

- 窗口是闭区间 `[s, i]`（含 `i`，共 `m` 个位置）→ `m = i - s + 1` → `s = i - m + 1`。
- 别背公式，用「右端点算不算」推：`i` 算进去，所以从 `i` 往前数 `m-1` 格（`i` 自己占 1 格）→ 起点 `i - (m-1)`。
- 例：`i = 2, m = 3` → `s = 2 - 3 + 1 = 0` ✓

## 4. 终极兜底：拿「3 个元素」的小例子数一遍

公式记混不可怕，动手数一遍永远对。拿长度 3 的数组 / 3 个字符验证：

- 想验证「区间 `[1, 4)` 几个元素」→ 数 1, 2, 3 → 3 个 → `4 - 1 = 3` ✓
- 想验证「长度 3、结尾下标 5 的窗口起点」→ 数 5, 4, 3 → 起点 3 → `5 - 3 + 1 = 3` ✓

## 5. 常见陷阱

- **把「个数」当「下标」**：个数是差值，下标是位置；`[l, r)` 的个数是 `r-l`，而它的第一个下标是 `l`、最后一个下标是 `r-1`。
- **忘了右端含不含**：先问「右端点算不算」，算就 +1。
- **切分边界算重**：用半开区间切 `[l, mid)` / `[mid, r)`，`mid` 不会出现在两段里。

## 一句话总结

统一 `[l, r)` + 记住「右端点算才算 +1」+ 不确定就数 3 个格子——这三样就够用了。
