171. Excel 表列序号 (Excel Sheet Column Number)

> https://leetcode.cn/problems/excel-sheet-column-number/

难度：Easy ｜ 分类：字符串

标签：数学、字符串

题目描述

给你一个字符串 columnTitle ，表示 Excel 表格中的列名称。返回 该列名称对应的列序号 。

例如：

A -> 1

B -> 2

C -> 3

...

Z -> 26

AA -> 27

AB -> 28

...

示例 1:

输入: columnTitle = "A"

输出: 1

示例 2:

输入: columnTitle = "AB"

输出: 28

示例 3:

输入: columnTitle = "ZY"

输出: 701

提示：

1

columnTitle 仅由大写英文组成

columnTitle 在范围 ["A", "FXSHRXW"] 内

src/字符串/LC0171_ExcelSheetColumnNumber.java提交区
public int titleToNumber(String columnTitle) {
        int ans = 0;
        int mul = 1;
        for (int i = columnTitle.length() - 1; i >= 0; i--) {
            int k = columnTitle.charAt(i) - 'A' + 1;
            ans += k * mul;
            mul *= 26;
        }
        return ans;
    }

思路拆解

① 问题本质与解法选择

  • Excel 列名是无 0 的 26 进制：A=1, ..., Z=26, AA=27。与普通 26 进制（0~25）的区别是这里每一位取值 1~26，且没有表示 0 的字符。
  • 任务就是把这个特殊 26 进制数转成十进制整数。
  • 两种等价写法：从左往右 ans = ans * 26 + k；或从右往左 ans += k * mul, mul *= 26。本题用户采用从右往左按位加权。

② 关键设计决策

  • k = columnTitle.charAt(i) - A + 1：把字母映射到 1~26（A 是 1，不是 0，这是本题和普通 26 进制最大的区别）。
  • mul 从 1 开始，表示当前位的权值（最低位 26^0，向左依次 26^1、26^2 ...）；每处理一位 ans += k * mul，然后 mul *= 26。
  • 从右往左遍历：最低位权值 1，最高位权值 26^(len-1)。

③ 边界与细节

  • 单字符：A=1、Z=26——Z 不是 0，是 26，所以它进位后才是 AA=27。
  • 进位：AZ=52（1×26 + 26）、BA=53、ZZ=702（26×26 + 26）。
  • 三字符：AAA=703（1×676 + 1×26 + 1）。
  • 上限 FXSHRXW=2147483647：中间累加值均小于 int 上限（ans*26 在最后一步前约 8.2e8），无溢出风险；若用 Math.pow 浮点会丢精度，应避免。
  • 长度 1 也正确：mul 只乘一次。

④ 复杂度与最优性

  • 每个字符处理一次，O(n)；只用 ans、mul 两个变量，O(1)。
  • 最优性：必须读取每个字符才能确定其贡献，下界 Ω(n)；本解法达到。

⑤ 具体 case 推演："AB"（期望 28）

套路沉淀

无 0 的 26 进制转十进制

Excel 列名转序号：A=1..Z=26，无 0 位；从右往左 ans += k*mul（k=char-'A'+1，mul 从 1 起每次 *26），或等价从左往右 ans=ans*26+k。O(n) 时间、O(1) 空间，上限 FXSHRXW=2^31-1 无溢出。
