public String longestCommonPrefix(String[] strs) {
        StringBuilder sb = new StringBuilder();
        int index = 0;
        while (index < strs[0].length()) {
            boolean allEquals = true;
            char c = strs[0].charAt(index);
            for (String str : strs) {
                if (index >= str.length()) {
                    allEquals = false;
                    break;
                }
                if (str.charAt(index) != c) {
                    allEquals = false;
                    break;
                }
            }
            index++;
            if (!allEquals) {
                break;
            } else {
                sb.append(c);
            }
        }
        return sb.toString();
    }

思路拆解

① 问题本质与解法选择

  • 求字符串数组的最长公共前缀：一个前缀要同时是每个串的前缀，且长度不能超过最短串。
  • 两种思路：① 横向——拿第一个串作为候选，逐个与后面串取公共前缀逐步缩短；② 纵向——按「列」扫描，所有串同一位置的字符都相等才继续下一列，遇到第一个不等或某个串到头就停。
  • 本题选纵向：逻辑直观（逐位对齐比较），且天然处理「某串较短」——那串到头就是公共前缀的终点。

② 关键设计决策

  • 以 strs[0] 为基准，index 从 0 递增，while (index < strs[0].length())。
  • 每轮取基准串的 c = strs[0].charAt(index)，遍历所有串：
  • 若 index >= str.length()（该串比基准短，此位置已超出其末尾）→ 不相等，停止；
  • 若 str.charAt(index) != c → 不相等，停止。
  • index++ 后判断：allEquals 为真 → sb.append(c)（该列全部相等，纳入公共前缀）；否则 break 结束。
  • 返回 sb.toString()。

③ 边界与细节

  • strs[0] 为空串：while 条件 0 < 0 不成立，直接返回 ""——空串与任何串公共前缀为空。
  • 某串比基准短：index >= str.length() 必须先于 charAt(index) 判断，否则 charAt 越界抛异常。
  • 单元素数组：基准串自身全部列相等，返回它本身。
  • 首字符即不同：第一轮 allEquals=false，sb 为空，返回 ""。

④ 复杂度与最优性

  • 最坏情况（所有串相同且等长）：每个串每个字符都比较一次，O(S)（S = 所有串长度之和）；辅助空间 O(1)（不含返回串）。
  • 最优性：公共前缀的每个字符必须在每个串中被确认一次，最坏（全相同）需读全部字符，下界 Ω(S)；本解法达到。

⑤ 具体 case 推演：示例 1 ["flower","flow","flight"]

index基准字符 c各串该位结果
0fflower=f, flow=f, flight=f全等 → append f
1lflower=l, flow=l, flight=l全等 → append l
2oflower=o, flow=o, flight=iflight 不等 → 停止
  • 返回 "fl"。正确。

⑥ 具体 case 推演：短串截断 ["ab","a"]

index基准字符 c各串该位结果
0aab=a, a=a全等 → append a
1bab=b, "a" 的 1 >= 1（到头）不等 → 停止
  • 返回 "a"。正确——若没有 index >= str.length() 检查，这里会对长度 1 的串 charAt(1) 越界。
