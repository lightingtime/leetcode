写法 1 · 单循环分类：15 倍数优先 FizzBuzz，再 Fizz/Buzz/数字

src/LC0412_FizzBuzz.java提交区
public List<String> fizzBuzz(int n) {
        List<String> ans = new ArrayList<>();
        for (int i = 1; i <= n; i++) {
            if (i % 15 == 0) {
                ans.add("FizzBuzz");
            } else if (i % 3 == 0) {
                ans.add("Fizz");
            } else if (i % 5 == 0) {
                ans.add("Buzz");
            } else {
                ans.add(String.valueOf(i));
            }
        }
        return ans;
    }

思路拆解

① 问题本质与解法选择

  • 对 1..n 每个数做分类映射：15 的倍数 → FizzBuzz，3 的倍数 → Fizz，5 的倍数 → Buzz，否则数字本身。本质是简单的模拟/条件分支题。
  • 核心难点只有一处：判断优先级——同时是 3 和 5 的倍数（即 15 的倍数）必须最先处理，否则会被 Fizz 或 Buzz 抢先。

② 关键设计决策

  • for i = 1..n，按优先级依次判断：
  1. i % 15 == 0 → "FizzBuzz"（等价于 i%3==0 && i%5==0，15 是 3 和 5 的最小公倍数）；
  2. i % 3 == 0 → "Fizz"；
  3. i % 5 == 0 → "Buzz"；
  4. 否则 String.valueOf(i)。
  • 用 if / else if 链保证互斥：每个 i 只命中一个分支。

③ 边界与细节

  • n=1：i%15/3/5 都不成立 → ["1"]。
  • 15 的倍数：15 → FizzBuzz；若把 i%15==0 放后面，15 会先命中 i%3==0 输出 Fizz——顺序错误。
  • 非倍数数字：14 → "14"、16 → "16"。
  • 上限 n=10000：9999 是 3 的倍数非 5 → Fizz；10000 是 5 的倍数非 3 → Buzz；9997 → 数字。

④ 复杂度与最优性

  • 每个数 O(1) 分支判断，总 O(n)；输出列表本身 O(n)，辅助空间 O(1)。
  • 最优性：必须为每个 i 生成一个结果元素，下界 Ω(n)；本解法达到。
