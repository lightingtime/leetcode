38. 外观数列 (Count and Say)

> https://leetcode.cn/problems/count-and-say/

难度：Medium ｜ 分类：字符串

标签：字符串

题目描述

「外观数列」是一个数位字符串序列，由递归公式定义：

countAndSay(1) = "1"

countAndSay(n) 是 countAndSay(n-1) 的行程长度编码。

行程长度编码（RLE）是一种字符串压缩方法，其工作原理是通过将每个最大连续相同字符组替换为该组的长度后加上该字符本身。例如，要压缩字符串 "3322251" ，我们将 "33" 用 "23" 替换，将 "222" 用 "32" 替换，将 "5" 用 "15" 替换并将 "1" 用 "11" 替换。因此压缩后字符串变为 "23321511"。

给定一个整数 n ，返回 外观数列 的第 n 个元素。

示例 1：

输入：n = 4

输出："1211"

解释：

countAndSay(1) = "1"

countAndSay(2) = "1" 的行程长度编码 = "11"

countAndSay(3) = "11" 的行程长度编码 = "21"

countAndSay(4) = "21" 的行程长度编码 = "1211"

示例 2：

输入：n = 1

输出："1"

解释：

这是基本情况。

public String countAndSay(int n) {
        String pre = "1";
        if (n == 1) {
            return pre;
        }
        for (int i = 2; i <= n; i++) {
            pre = getNext(pre);
        }
        return pre;
    }

    private String getNext(String pre) {
        int count = 1;
        char c = pre.charAt(0);
        int l = 1;
        StringBuilder sb = new StringBuilder();
        while (l < pre.length()) {
            if (pre.charAt(l) == c) {
                count++;
            } else {
                sb.append(count).append(c);
                c = pre.charAt(l);
                count = 1;
            }
            l++;
        }
        sb.append(count).append(c);
        return sb.toString();
    }

思路拆解

① 问题本质与解法选择理由

  • 题目按递归定义逐轮生成：countAndSay(1)="1"，第 n 项 = 对第 n-1 项做行程长度编码（RLE）。
  • 核心操作就是「数连续相同字符的个数」，没有隐藏技巧；n ≤ 30 时最长一轮约 4462 字符，直接按定义迭代模拟即可，也不存在更复杂的算法。

② 关键设计决策

  • 用 pre 存当前轮字符串，初始 "1"；对 i=2..n 循环执行 pre = getNext(pre)，最后返回 pre。
  • getNext 内部：c 记录当前组字符，count 记录当前组已累计个数，l 为扫描指针；字符变化时把「count+c」追加进 StringBuilder 并开启新组。
  • 最后一组在循环结束后单独追加：循环里只在「字符变化」时结算，字符串末尾不会再变化，必须补一次，否则漏掉最后一组。

③ 边界与细节

  • n=1 直接返回 "1"，不进循环，也不会对空串做 charAt(0)。
  • 每组至少 1 个字符：c 先取第 0 个字符、count 从 1 起数，不会出现 0 计数。
  • 外观数列只会出现字符 1~3，count 用 int 足够，无溢出。
  • n=30 上限结果长度 4462，StringBuilder 动态扩容无性能问题。

④ 复杂度分析与下限论证

  • 设第 k 轮长度为 L_k，第 k 轮扫描 O(L_k)，总时间 O(ΣL_k)；长度严格单调增长，ΣL_k = O(L_n)，n=30 时约数千字符。
  • 空间 O(L_n)：每轮需要一个 StringBuilder 加上一轮字符串。
  • 最优性：输出本身就有 L_n 个字符，任何解法至少要写出全部输出（下界 Ω(L_n)），且每轮必须完整读一遍上一轮才能编码，因此 O(L_n) 时间、O(L_n) 空间均达下限，模拟就是本题最优解。

⑤ 具体 case 推演：n=4

  • 初始 pre="1"。
  • i=2：扫 "1" → 1 个 1 → pre="11"
  • i=3：扫 "11" → 2 个 1 → pre="21"
  • i=4：扫 "21" → 1 个 2、1 个 1 → pre="1211"
  • 返回 "1211"（与题目示例一致）。

⑥ getNext 内部指针推演：pre="21"

  • 初始化：c=2、count=1、l=1、sb=""
  • l=1：charAt(1)=1 ≠ 2 → sb 追加 "12"；c=1、count=1、l=2
  • l=2 不满足 l<2，循环退出
  • 循环后补最后一组：sb 追加 "11" → sb="1211"
  • 返回 "1211"。"
