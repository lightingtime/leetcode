415. 字符串相加 (Add Strings)

题目描述

给定两个字符串形式的非负整数 num1 和num2 ，计算它们的和并同样以字符串形式返回。

你不能使用任何內建的用于处理大整数的库（比如 BigInteger）， 也不能直接将输入的字符串转换为整数形式。

示例 1：

输入：num1 = "11", num2 = "123"

输出："134"

示例 2：

输入：num1 = "456", num2 = "77"

输出："533"

示例 3：

输入：num1 = "0", num2 = "0"

输出："0"

提示：

1 4

num1 和num2 都只包含数字 0-9

num1 和num2 都不包含任何前导零

我的解法

写法 1 · 逐位相加，尾部追加后反转

时间 O(L)空间 O(L)内存 ≈ 42.4 MB用例 317/317

LC0415_AddStrings.java · 逐位相加，尾部追加后反转提交区
public String addStrings(String num1, String num2) {
        int next = 0;
        StringBuilder ans = new StringBuilder();
        int i = num1.length() - 1;
        int j = num2.length() - 1;
        while (i >= 0 || j >= 0 || next > 0) {
            int a = i >= 0 ? num1.charAt(i) - '0' : 0;
            int b = j >= 0 ? num2.charAt(j) - '0' : 0;
            int sum = a + b + next;
            ans.append(sum % 10);
            next = sum / 10;
            i--;
            j--;
        }
        ans.reverse();
        return ans.toString();
    }

public String addStrings(String num1, String num2) {
        int next = 0;
        StringBuilder ans = new StringBuilder();
        int i = num1.length() - 1;
        int j = num2.length() - 1;
        while (i >= 0 || j >= 0 || next > 0) {
            int a = i >= 0 ? num1.charAt(i) - '0' : 0;
            int b = j >= 0 ? num2.charAt(j) - '0' : 0;
            int sum = a + b + next;
            ans.insert(0, sum % 10);
            next = sum / 10;
            i--;
            j--;
        }
        return ans.toString();
    }

思路拆解

问题本质与解法选择

输入可以长达 10000 位，不能整体转整数或使用大整数库。模拟竖式加法，从个位开始相加，每次只需两位数字和上一位的进位。低位先计算，先按计算顺序尾部追加，最后统一反转，避免头插反复移动已有字符。

关键设计决策

变量语义
i、j两个字符串当前待处理位的下标，从末尾向前移动
a、b当前位数字，下标越界时补 0
next低一位传入当前位的进位，取值 0 或 1
suma+b+next，范围 0～19
ans已计算结果位，按低位到高位存储

循环条件 i>=0 或 j>=0 或 next>0：任何输入还有未处理数字，或者最后还存在进位，都要继续。sum%10 得到当前结果位，sum/10 得到下一轮进位。只要输入下标有效才 charAt，越界补 0 来统一处理长度差异。

推演 num1="99"、num2="1"：

  1. i=1、j=0、next=0，a=9、b=1，sum=10，追加 0；ans="0"、next=1。
  2. i=0、j=-1，a=9、b=0，sum=10，追加 0；ans="00"、next=1。
  3. i=-1、j=-2，两个输入已用完但仍有进位，sum=1，追加 1；ans="001"、next=0。
  4. 三个继续条件均不满足，退出并反转得到 "100"。

边界与细节

"0"+"0" 至少执行一轮，输出 "0"。"2"+"3" 得到 sum=5、next=0，单轮输出 "5"。输入没有前导零，不能把前导零输入当成测试要求。已覆盖两个输入长短交换、内部零、连续进位、超出 int 和 long 范围，以及输入长度 10000 的上限。每轮 sum 至多 19，单轮 int 运算安全。

复杂度与最优性

令 L=max(num1.length,num2.length)。循环至多 L+1 次，StringBuilder 尾部追加摊还 O(1)，统一反转与构造字符串均为 O(L)，总时间 O(L)。结果构造器和返回字符串占用 O(L) 空间，指针及进位为 O(1)。最坏情况需读取 L 位并输出 L 或 L+1 位，因此时间达到线性下限；计入结果构造与返回值时空间为 O(L)。头插版第 k 次插入需搬移 k 个已有字符，总搬移量为 0+1+...+(L-1)，时间 O(L²)。

套路沉淀

竖式加法：低位先算，尾部追加后反转

双下标从末尾开始，越界位补 0；sum=a+b+carry，当前位取 sum%10、进位取 sum/10。循环覆盖残留进位，结果尾部追加并最终反转。例：99+1 依次产生 0、0、1，反转得到 100；避免头插搬移字符造成平方时间。
