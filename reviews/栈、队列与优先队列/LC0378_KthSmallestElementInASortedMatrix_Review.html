378. 有序矩阵中第 K 小的元素 (Kth Smallest Element in a Sorted Matrix)

> https://leetcode.cn/problems/kth-smallest-element-in-a-sorted-matrix/

难度：Medium ｜ 分类：栈、队列与优先队列

标签：数组、二分查找、矩阵、排序、堆（优先队列）

题目描述

给你一个 n x n 矩阵 matrix ，其中每行和每列元素均按升序排序，找到矩阵中第 k 小的元素。

请注意，它是 排序后 的第 k 小元素，而不是第 k 个 不同 的元素。

你必须找到一个内存复杂度优于 O(n2) 的解决方案。

示例 1：

输入：matrix = [[1,5,9],[10,11,13],[12,13,15]], k = 8

输出：13

解释：矩阵中的元素为 [1,5,9,10,11,12,13,13,15]，第 8 小元素是 13

示例 2：

输入：matrix = [[-5]], k = 1

输出：-5

我的解法

写法 1 · 最小堆 k 路归并

时间 O(k log n)空间 O(n)内存 ≈ 49.4 MB用例 87/87

LC0378_KthSmallestElementInASortedMatrix.java · 最小堆 k 路归并提交区
    public int kthSmallest(int[][] matrix, int k) {
        PriorityQueue<Node> queue = new PriorityQueue<>(Comparator.comparingInt(a -> a.val));
        int n = matrix.length;
        for (int i = 0; i < n; i++) {
            queue.offer(new Node(matrix[i][0], i, 0));
        }
        int count = 0;
        while (count < k - 1) {
            Node top = queue.poll();
            if (top.col != n - 1) {
                queue.offer(new Node(matrix[top.row][top.col + 1], top.row, top.col + 1));
            }
            count++;
        }
        return queue.peek().val;
    }
    static class Node {
        int val;
        int row;
        int col;

        public Node(int val, int row, int col) {
            this.val = val;
            this.row = row;
            this.col = col;
        }
    }

写法 2 · 二分答案（值域二分）

时间 O(n·log(值域))空间 O(1)内存 ≈ 50.1 MB用例 87/87

LC0378_KthSmallestElementInASortedMatrix.java · 二分答案（值域二分）提交区
    public int kthSmallest(int[][] matrix, int k) {
        int n = matrix.length;
        int left = matrix[0][0];
        int right = matrix[n - 1][n - 1];
        while (left < right) {
            int mid = left + (right - left) / 2;
            if (check(mid, matrix, n, k)) {
                right = mid;
            } else {
                left = mid + 1;
            }
        }
        return left;
    }

    private boolean check(int target, int[][] matrix, int n, int k) {
        int j = 0;
        int i = n - 1;
        int count = 0;
        while (i >= 0 && j < n) {
            if (matrix[i][j] <= target) {
                count += i + 1;
                j++;
            } else {
                i--;
            }
        }
        return count >= k;
    }

思路拆解

问题本质：n×n 矩阵每行、每列分别升序，但整体拉平并不是有序数组，所以「第 k 小」没有固定坐标、不能按下标直接取。可用的性质是行、列各自的局部序。

两种写法对比：

  • 写法 1（最小堆 k 路归并）：把每行看成一条有序链表，堆里维护每行当前队头（带 row,col 坐标），弹 k 次即第 k 小。时间 O(k log n)，最坏 O(n^2 log n)；空间 O(n)。
  • 写法 2（值域二分，最优）：对数值范围二分，用「≤ mid 的元素个数 ≥ k」判定并收敛。时间 O(n·log(值域))，空间 O(1)，满足进阶「O(1) 内存」要求。

写法 2 关键设计：

  1. 二分对象是值而不是下标：第 k 小的值 v = 满足 count(≤x) ≥ k 的最小 x。count 随 x 单调不减，所以可在 [matrix[0][0], matrix[n-1][n-1]] 上二分。
  2. 统计 count 用左下角游走 O(n) 完成：从 (n-1, 0) 出发，若 matrix[i][j] ≤ mid，则这一列第 0..i 行都 ≤ mid，count += i+1 后 j++；否则这一行右边只会更大，i--。每轮最多走 2n 步。
  3. 判据必须用 ≥ 而不是 ==：count 只在 mid 跨过某些值时恰好等于 k，其余时候都大于 k，用 == 会让二分走错方向（全相同元素时直接错）。

具体 case 推演（示例 1：matrix=[[1,5,9],[10,11,13],[12,13,15]]，k=8，值域 [1,15]）：

midcount(≤mid)与 k=8 比较边界调整
82< 8left=9
126< 8left=13
148≥ 8right=14
138≥ 8right=13

收敛到 13，第 8 小 = 13 ✓

count(≤13) 的游走细节：

  1. (2,0)=12 ≤ 13 → count += 3（列 0 的 1,10,12），j=1
  2. (2,1)=13 ≤ 13 → count += 3（列 1 的 5,11,13），j=2
  3. (2,2)=15 > 13 → i=1
  4. (1,2)=13 ≤ 13 → count += 2（列 2 的 9,13），j=3 结束

合计 8 ✓

边界与细节：

  • k=1：left 初始即 matrix[0][0]，二分直接返回最小值。
  • k=n^2：收敛到 matrix[n-1][n-1]。
  • 全相同元素：count(≤v)=n^2 ≥ k 恒成立，left 停在 matrix[0][0]，正确。
  • 重复元素：≥ 判据让门槛正好落在重复值上（两个 13 凑够第 8 个）。
  • 负数与 ±10^9 值域：mid = left + (right-left)/2 防溢出，int 足够。

复杂度与下限论证：单次判定 O(n)（游走最多 2n 步），二分次数 O(log(值域)) ≤ 31，总 O(n·log(值域)) ≈ 300×31，空间 O(1)。堆写法最坏 O(n^2 log n) 且空间 O(n)；值域二分把判定降到 O(n)、空间降到 O(1)，是本题进阶要求下的最优写法。
