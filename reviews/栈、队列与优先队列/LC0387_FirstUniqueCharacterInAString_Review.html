387. 字符串中的第一个唯一字符 (First Unique Character in a String)

> https://leetcode.cn/problems/first-unique-character-in-a-string/

难度：Easy ｜ 分类：栈、队列与优先队列

标签：队列、哈希表、字符串、计数

题目描述

给定一个字符串 s ，找到 它的第一个不重复的字符，并返回它的索引 。如果不存在，则返回 -1 。

示例 1：

输入: s = "leetcode"

输出: 0

示例 2:

输入: s = "loveleetcode"

输出: 2

示例 3:

输入: s = "aabb"

输出: -1

提示:

1 5

s 只包含小写字母

我的解法

写法 1 · 定长 count[26] 两遍扫描：先统计频次，再找第一个 count==1 的索引

时间 O(n)空间 O(1)内存 ≈ 45.0 MB用例 107/107

src/栈、队列与优先队列/LC0387_FirstUniqueCharacterInAString.java提交区
public int firstUniqChar(String s) {
        int[] count = new int[26];
        for (char c : s.toCharArray()) {
            count[c - 'a']++;
        }
        for (int i = 0; i < s.length(); i++) {
            if (count[s.charAt(i) - 'a'] == 1) {
                return i;
            }
        }
        return -1;
    }

思路拆解

① 问题本质与解法选择理由

  • 找第一个「不重复」字符：不重复 = 该字符在字符串中恰好出现一次。
  • 判定唯一性需要知道每个字符的总出现次数 → 先统计频次；「第一个」要求按原顺序找 → 统计完再从左到右扫一遍。
  • 字符集只有小写字母 26 种，用定长 int[26] 代替 HashMap：空间 O(1) 且比哈希表更省更简洁。

② 关键设计决策

  • 第一遍：count[c - a]++ 统计每个字符出现次数（c - a 把 a~z 映射到 0~25）。
  • 第二遍：count[s.charAt(i) - a] == 1 即为第一个唯一字符，返回 i。
  • 两遍都扫不到 → 返回 -1（无唯一字符）。
  • 为什么两遍而不是一遍：判定「唯一」依赖全局频次，单个字符在遍历中无法预知后面是否还会出现。

③ 边界与细节

  • 单字符 "a"：count[a]=1，第二遍 i=0 命中，返回 0。
  • 全相同 "aaaaa"：count[a]=5，第二遍无 count==1，返回 -1。
  • 唯一字符在末尾/开头：第二遍按索引序扫描，正确返回第一个（索引最小）的唯一字符。
  • 长度上限 10^5：两遍各 O(n)，count 数组固定 26，无性能问题。
  • 输入保证至少 1 个字符（约束 1 <= len），无需处理空串。

④ 复杂度分析与下限论证

  • 时间 O(n)：两遍线性扫描，每遍 O(1) 数组操作。
  • 空间 O(1)：int[26] 与 n 无关。
  • 最优性：判定唯一性至少要读每个字符一次（统计，Ω(n)），找第一个唯一又要按序检查（第二遍，O(n)）；任何解法都要 Ω(n) 时间，且必须把频次记下来，26 定长数组使空间达 Ω(1) 下限——本解为最优。

**⑤ 具体 case 推演："loveleetcode"

  • 第一遍统计：l=2、o=2、v=1、e=4、t=1、c=1、d=1。
  • 第二遍按索引扫：i=0 l(count=2) 跳过；i=1 o(2) 跳过；i=2 v(count=1) 命中 → 返回 2，与示例一致。
  • 对比 "aabb"：a=2、b=2，第二遍无 count==1 → 返回 -1。
