写法 1 · 栈：遇数字 push、遇算符弹两个算完再 push，除向零截断用 Java int 除法

时间 O(n)空间 O(n)内存 ≈ 43.4 MB用例 22/22

src/LC0150_EvaluateReversePolishNotation.java提交区
public int evalRPN(String[] tokens) {
        Deque<Integer> stack = new ArrayDeque<>();
        for (String token : tokens) {
            if (token.equals("+")) {
                int a = stack.pop();
                int b = stack.pop();
                stack.push(a + b);
            } else if (token.equals("-")) {
                int a = stack.pop();
                int b = stack.pop();
                stack.push(b - a);
            } else if (token.equals("*")) {
                int a = stack.pop();
                int b = stack.pop();
                stack.push(a * b);
            } else if (token.equals("/")) {
                int a = stack.pop();
                int b = stack.pop();
                stack.push(b / a);
            } else {
                stack.push(Integer.parseInt(token));
            }
        }
        return stack.pop();
    }

思路拆解

① 问题本质与解法选择理由

  • 后缀表达式：算符跟在操作数后面，天然适合栈——遇数字入栈，遇算符弹栈顶两个操作数计算，结果再入栈，最后栈顶即答案。
  • 除法向零截断：Java 的 int 除法本身向零截断（如 -7/2 = -3），直接 b / a 即可，无需额外处理。

② 关键设计决策

  • Deque<Integer> stack 当栈用：数字 push、算符 pop 两次、算完 push 结果，全部在队头操作。
  • 减/除法操作数顺序：先弹的是后入栈的操作数（a），后弹的是先入栈的（b），表达式是 b - a、b / a（如 13 5 / = 13/5，弹 a=5、b=13）。
  • 判断算符用 token.equals("+") 等，否则 Integer.parseInt(token) 转数字入栈。

③ 边界与细节

  • 单元素 ["42"]：无算符，直接返回 42。
  • 负数除法向零截断：-7/2、7/-2 都等于 -3（Java int 除法向零截断，与题目要求一致）。
  • 大中间结果 200^4=1.6e9：题目保证 32 位整数可表示，int 不溢出。
  • tokens 上限 10^4：栈深最坏 O(n)（如连续入栈 5000 个数字），Deque 动态扩容无问题。
  • 不含除零、表达式一定合法，无需校验栈空。

④ 复杂度分析与下限论证

  • 时间 O(n)：每个 token 处理一次，栈操作 O(1)。
  • 空间 O(n)：栈最坏存 n 个中间操作数（如全部是数字再统一运算），这是求值必需的——后缀表达式的中间结果必须保存，空间 Ω(n) 为下限，O(n) 达到。
  • 最优性：每个 token 至少读一次，时间 Ω(n) 达到；空间必须存全部待计算操作数，Ω(n) 达到——本解为最优。

⑤ 具体 case 推演：["4","13","5","/","+"]（期望 6）

  • "4"：push(4)，栈 [4]。
  • "13"：push(13)，栈 [13,4]（顶 13）。
  • "5"：push(5)，栈 [5,13,4]。
  • "/"：a=pop=5，b=pop=13 → push(13/5=2)，栈 [2,4]。
  • "+"：a=pop=2，b=pop=4 → push(4+2=6)，栈 [6]。
  • 返回 6 ✅。
  • 踩坑对比：若数字用 offerLast 入队尾，"/" 时 pop 到的是 4 和 13 而非 13 和 5，结果错成 8。

套路沉淀

ArrayDeque 当栈用：push/pop 同侧，禁止混 offerLast

ArrayDeque 作栈：push=addFirst、pop=removeFirst 都在队头；数字/元素入栈必须也用 push，混用 offerLast（队尾）会破坏后进先出。后缀表达式求值遇数字 push、遇算符弹两个算完再 push，减/除注意先弹的是后操作数（b-a、b/a）。
