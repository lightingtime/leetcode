public boolean isValid(String s) {
        Deque<Character> stack = new ArrayDeque<>();
        for (char c : s.toCharArray()) {
            if (c == '(') {
                stack.offer(')');
            } else if (c == '{') {
                stack.offer('}');
            } else if (c == '[') {
                stack.offer(']');
            } else {
                if (stack.isEmpty()) {
                    return false;
                }
                if (stack.pollLast() != c) {
                    return false;
                }
            }
        }
        return stack.isEmpty();
    }

思路拆解

问题本质：括号匹配是「后出现的先闭合」，天然用栈：左括号入栈，右括号与栈顶配对。

关键设计：优化写法是左括号入栈时直接压入对应的右括号，这样遇到右括号只需比较是否等于栈顶，省去配对的 switch/if；不匹配或栈空直接 false；遍历结束栈空才是合法串。

边界：空串返回 true；只有左括号（结束栈非空 false）；只有右括号（栈空即 false）；多层嵌套；右括号多余与左括号多余要分别拦截。

复杂度：O(n) 时间、O(n) 空间（栈），最优。
