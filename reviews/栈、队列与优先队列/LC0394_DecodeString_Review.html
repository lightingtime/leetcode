public String decodeString(String s) {
        StringBuilder res = new StringBuilder();
        Deque<Integer> num = new LinkedList<>();
        Deque<String> subStr = new LinkedList<>();
        int multi = 0;
        for (char c : s.toCharArray()) {
            if (c == '[') {
                num.addLast(multi);
                subStr.addLast(res.toString());
                multi = 0;
                res = new StringBuilder();
            } else if (c == ']') {
                StringBuilder temp = new StringBuilder();
                int mul = num.removeLast();
                for (int i = 0; i < mul; i++) {
                    temp.append(res);
                }
                res = new StringBuilder(subStr.removeLast() + temp);
            } else if (Character.isDigit(c)) {
                multi = multi * 10 + Integer.parseInt(c + "");
            } else {
                res.append(c);
            }
        }
        return res.toString();
    }

字符串解码：双栈法（数字栈+字符串栈），]时弹k与前缀拼回当前串，O(n+L)/O(n+L)，一次Accepted（34/34）

思路拆解

问题本质与解法选择

  • 编码规则 k[encoded_string]：方括号内内容重复 k 次，括号可嵌套（如 3[a2[c]]）。
  • 关键难点：嵌套意味着内层展开结果还要被外层倍数重复，且每层 [ 之前还可能有前缀（如 abc3[cd]xyz 的 abc）需要在展开后接回。
  • 解法选择：遇到 ] 时需要把「最近一层」的 k 和前缀取回来拼接，天然符合栈的后进先出结构，因此用双栈：数字栈存 k、字符串栈存前缀。

关键设计决策

  • 两个栈：数字栈 num 存每层的 k；字符串栈 subStr 存每层 [ 之前已拼好的前缀（保护现场）。
  • 当前串 res（StringBuilder）：读入过程中边读边拼的「当前层」内容。
  • 遇到 [：把累计的 k 压数字栈、把 res 当前内容压字符串栈，然后重置 res 与 multi——进入新的一层。
  • 遇到 ]：弹出 k 与前缀，res = 前缀 + res 重复 k 次——拼回当前串而不是最终结果，因为外层可能还有倍数要乘。
  • 数字：多位累计 multi = multi * 10 + digit（如 10[a]）。
  • 普通字母：直接追加到 res。

具体 case 推演（3[a2[c]]）

  • 逐字符处理：
  1. '3'：multi = 3
  2. '['：num=[3]，subStr=[""]，multi=0，res=""
  3. 'a'：res="a"
  4. '2'：multi = 2
  5. '['：num=[3,2]，subStr=["", "a"]，multi=0，res=""
  6. 'c'：res="c"
  7. ']'：弹 k=2、前缀 "a" → res = "a" + "cc" = "acc"
  8. ']'：弹 k=3、前缀 "" → res = "" + "acc"×3 = "accaccacc" ✓
  • 关键：第 7 步的 "acc" 拼回当前串，第 8 步才能被外层 3 重复；若提前拼进最终结果则外层乘不到。

边界与细节

  • 纯字母无括号：不进栈，直接返回原串。
  • k=1：1[a] → "a"，重复 1 次。
  • 多位 k：10[a] → multi 连续累计为 10。
  • 连续嵌套 2[2[a]]：内层 "aa" 后外层再乘 2 → "aaaa"。
  • 相邻块 2[a]2[b]：各自展开后按顺序拼接 → "aabb"。

复杂度与下限论证

  • 时间 O(n+L)：扫描输入 O(n)，字符串重复拼接总代价 = 最终输出长度 L（StringBuilder 摊还），L ≤ 10^5。L 本身必须逐字符生成，故这是时间下限。
  • 空间 O(n+L)：数字栈 + 字符串栈 + 当前串，最坏存下所有前缀与输出。
