155. 最小栈 (Min Stack)

> https://leetcode.cn/problems/min-stack/

难度：Medium ｜ 分类：栈、队列与优先队列

标签：栈、设计

题目描述

设计一个支持 push ，pop ，top 操作，并能在常数时间内检索到最小元素的栈。

实现 MinStack 类:

MinStack() 初始化堆栈对象。

void push(int value) 将元素 value 推入堆栈。

void pop() 删除堆栈顶部的元素。

int top() 获取堆栈顶部的元素。

int getMin() 获取堆栈中的最小元素。

示例 1:

输入：

["MinStack","push","push","push","getMin","pop","top","getMin"]

[[],[-2],[0],[-3],[],[],[],[]]

输出：

[null,null,null,null,-3,null,0,-2]

解释：

MinStack minStack = new MinStack();

minStack.push(-2);

minStack.push(0);

minStack.push(-3);

minStack.getMin(); --> 返回 -3.

minStack.pop();

minStack.top(); --> 返回 0.

minStack.getMin(); --> 返回 -2.

LC0155_MinStack.java · 单栈+Node（值+当前最小）提交区
    static class MinStack {
        Deque<Node> stack;
        public MinStack() {
            stack = new ArrayDeque<>();
        }
        public void push(int value) {
            if (stack.isEmpty()) {
                stack.push(new Node(value, value));
            } else {
                stack.push(new Node(value, Math.min(value, stack.peek().min)));
            }
        }
        public void pop() {
            stack.pop();
        }
        public int top() {
            return stack.peek().cur;
        }
        public int getMin() {
            return stack.peek().min;
        }
    }

    static class Node {
        int cur;
        int min;

        public Node() {
        }

        public Node(int cur, int min) {
            this.cur = cur;
            this.min = min;
        }
    }

static class MinStack {
        Deque<Node> stack;
        public MinStack() {
            stack = new ArrayDeque<>();
        }
        public void push(int value) {
            if (stack.isEmpty()) {
                stack.push(new Node(value, value));
            } else {
                int min = Math.min(value, getMin());
                stack.push(new Node(value, min));
            }
        }
        public void pop() {
            stack.pop();
        }
        public int top() {
            return stack.peek().cur;
        }
        public int getMin() {
            return stack.peek().min;
        }

        class Node {
            int cur;
            int min;

            public Node() {
            }

            public Node(int cur, int min) {
                this.cur = cur;
                this.min = min;
            }
        }
    }

思路拆解

问题本质：O(1) 取最小值。普通栈做不到，做法是让每个元素入栈时记录「当时的栈内最小值」，空间换时间。

关键设计：栈内元素是 (cur, min) 二元组：push 时 min=Math.min(value, 当前栈顶 min)，栈空时 min=value；getMin 直接读栈顶的 min。因为 min 是入栈时刻的快照，元素弹出后历史最小值自然保留，不需要额外结构。

边界：题目约定不会对空栈调用 top/pop/getMin；连续 push 递减序列后逐次 pop，min 要能正确回退到上一状态；重复最小值不影响。

复杂度：push/pop/top/getMin 全部 O(1) 时间、O(n) 空间，满足题目全部要求。
