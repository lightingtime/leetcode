84. 柱状图中最大的矩形 (Largest Rectangle in Histogram)

> https://leetcode.cn/problems/largest-rectangle-in-histogram/

题目描述

给定 n 个非负整数，用来表示柱状图中各个柱子的高度。每个柱子彼此相邻，且宽度为 1 。

求在该柱状图中，能够勾勒出来的矩形的最大面积。

示例 1:

输入：heights = [2,1,5,6,2,3]

输出：10

解释：最大的矩形为图中红色区域，面积为 10

示例 2：

输入： heights = [2,4]

输出： 4

public int largestRectangleArea(int[] heights) {
        int[] newHeights = new int[heights.length + 2];
        System.arraycopy(heights, 0, newHeights, 1, heights.length);
        heights = newHeights;
        int max = 0;
        Deque<Integer> stack = new ArrayDeque<>();
        for (int i = 0; i < heights.length; i++) {
            while (!stack.isEmpty() && heights[stack.peekLast()] > heights[i]) {
                int height = heights[stack.pollLast()];
                int width = i - stack.peekLast() - 1;
                max = Math.max(max, height * width);
            }
            stack.offerLast(i);
        }
        return max;
    }

单调递增栈 + 左右高度0哨兵：弹栈结算（左边界=新栈顶，右边界=i），O(n)。思路从朴素 O(n²)（每根柱子左右扫更矮）引导到单调栈；10 组本地用例一次全过，力扣 99/99 一次 Accepted

思路拆解

问题本质：每个柱子能形成的最大矩形 = 柱高 × 左右第一个更矮柱子之间的宽度。暴力枚举每对边界 O(n²)；单调栈让每个柱子只结算一次。

关键设计：单调递增栈存下标。遇到比栈顶矮的柱子时，栈顶柱子作为高被弹出结算：其左边界是栈内前一个下标、右边界是当前 i，宽度 = i - 栈内前一个 - 1。在数组两端补高度 0 的哨兵，保证所有柱子最终必然出栈、且结算时栈不为空。

边界：全部递增时靠末尾哨兵逐个结算；全部相等（用 > 弹出，相等延后结算但宽度照样覆盖整个区间）；单柱；连续多个可弹出的柱子依次结算。

复杂度：O(n) 时间（每个下标入栈出栈各一次）、O(n) 空间，最优。
