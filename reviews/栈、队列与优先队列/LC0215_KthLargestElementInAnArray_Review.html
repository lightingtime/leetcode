215. 数组中的第K个最大元素 (Kth Largest Element in an Array)

> https://leetcode.cn/problems/kth-largest-element-in-an-array/

难度：Medium ｜ 分类：栈、队列与优先队列

标签：数组、分治、快速选择、排序、堆（优先队列）

题目描述

给定整数数组 nums 和整数 k，请返回数组中第 k 个最大的元素。

请注意，你需要找的是数组排序后的第 k 个最大的元素，而不是第 k 个不同的元素。

你必须设计并实现时间复杂度为 O(n) 的算法解决此问题。

示例 1:

输入: [3,2,1,5,6,4], k = 2

输出: 5

示例 2:

输入: [3,2,3,1,2,4,5,5,6], k = 4

输出: 4

提示：

public int findKthLargest(int[] nums, int k) {
        int n = nums.length;
        return quickSort(nums, 0, n - 1, n - k);
    }

    private int quickSort(int[] nums, int l, int r, int k) {
        if (l == r) {
            return nums[k];
        }
        int x = nums[l], i = l - 1, j = r + 1;
        while (i < j) {
            do {
                i++;
            } while (nums[i] < x);
            do {
                j--;
            } while ( nums[j] > x);
            if (i < j) {
                int temp = nums[j];
                nums[j] = nums[i];
                nums[i] = temp;
            }
        }
        if (k <= j) {
            return quickSort(nums, l, j, k);
        }
        return quickSort(nums, j + 1, r, k);
    }

    public int findKthLargest(int[] nums, int k) {
        return quickSort(nums, 0, nums.length - 1, nums.length - k);
    }

    private int quickSort(int[] nums, int l, int r, int k) {
        if (l == r) {
            return nums[l];
        }
        int p = nums[r];
        int i = l, j = l;
        while (j < r) {
            if (nums[j] < p) {
                swap(nums, i, j);
                i++;
            }
            j++;
        }
        swap(nums, i, r);
        if (i == k) {
            return nums[k];
        } else if (i < k) {
            return quickSort(nums, i + 1, r, k);
        } else {
            return quickSort(nums, l, i - 1, k);
        }
    }

    private void swap(int[] nums, int i, int j) {
        int temp = nums[i];
        nums[i] = nums[j];
        nums[j] = temp;
    }

思路拆解

问题本质与解法选择

  • 求第 k 大 = 求升序下标 target = n-k（0 基）处的元素：第 1 大即升序最后一个。这是「无序数组中按排名取值」问题，不需要完整有序。
  • 候选思路：全排序 O(n log n)；容量 k 的小顶堆 O(n log k)；快速选择 O(n) 平均。本题单次查询，堆的 log k 常数为多余开销，且 k 接近 n 时堆更差；快选原地分区、每层只处理一侧，平均线性，为本题最优档。

关键设计决策

  1. 目标下标固定：target = n-k 是全局 0 基升序下标，递归全程不变、只缩区间——避免上轮「k 语义混用（全局 vs 相对）」的坑。
  2. Lomuto 分区：pivot 取 nums[r]；i 指向小于 pivot 段的下一位置，j 从 l 扫到 r-1，nums[j] < pivot 时与 nums[i] 交换并 i++；扫完把 pivot 换到 i。结果 [l, i) 全 < pivot、nums[i] == pivot、右侧 ≥ pivot。
  3. 只递归一侧：i == target 命中返回；target < i 递归左半 [l, i-1]；否则递归右半 [i+1, r]，保证区间严格缩小，递归基 l == r 直接返回该元素。

具体 case 推演（示例 1：nums=[3,2,1,5,6,4], k=2）

target = 6-2 = 4，初始 l=0, r=5：

  1. pivot = nums[5]=4；i=0, j=0 扫描：
  • j=0：3<4 → 交换 (0,0)（无变化），i=1；
  • j=1：2<4 → 交换 (1,1)，i=2；j=2：1<4 → 交换 (2,2)，i=3；
  • j=3：5≥4 不动；j=4：6≥4 不动。
  1. 扫描结束 swap(i=3, r=5) → 数组 [3,2,1,4,6,5]，pivot 落位 i=3。
  2. target=4 > i=3 → 递归右半 [4,5]：pivot = nums[5]=5，j=4 时 6≥5 不动 → swap(i=4, r=5) → [3,2,1,4,5,6]，i=4 == target → 返回 5。✓

重复值 case 推演（边界：nums=[2,2,2,2], k=2）

target = 4-2 = 2：

  1. 首轮 pivot=2，所有元素都不满足 < 2 → i=0 不动，swap(0,3) 数组不变，pivot 落位 i=0。
  2. target=2 > 0 → 递归右半 [1,3]，同理 pivot 落位 i=1 → 再递归右半 [2,3]。
  3. 此时 l==r==2，返回 nums[2]=2。✓ 等于 pivot 的元素留在右侧（不交换），保证每层区间仍严格缩小、不会因等值元素死循环。

边界与细节

  • 单元素：l == r 直接返回，无需分区。
  • k = n（第 n 大 = 最小）：target = 0，一路向左递归到左端。
  • 全相同数组：等于 pivot 不交换、留在右半，i 停在区间左端并逐层右移——不产生死循环，但属于最坏 O(n²) 退化情形之一。
  • 固定取 nums[r] 作 pivot：对有序/降序输入每层只削掉一个元素 → 退化为 O(n²)；本题 n ≤ 10^4，固定 pivot 平均可接受，随机化 pivot 可进一步摊平最坏概率。

复杂度与下限论证

  • 时间：平均 O(n)——每层期望处理 n/2 规模，n + n/2 + n/4 + ... = O(n)；最坏 O(n²)（pivot 恒为极值）。
  • 空间：原地交换 O(1)，递归栈平均 O(log n)（只递归一侧，最坏 O(n)）。
  • 下限：本题只求第 k 个排名值、不求全序，故不受排序 Ω(n log n) 限制；任何正确算法每个元素至少要参与一次与 pivot 的比较才能被排除，比较下界 Ω(n)，快选平均 O(n) 达到该下界，是本题理论最优档。
