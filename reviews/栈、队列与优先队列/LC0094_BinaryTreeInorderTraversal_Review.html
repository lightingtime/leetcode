    public List<Integer> inorderTraversal(TreeNode root) {
        ans = new ArrayList<>();

    }

    private void dfs(TreeNode root) {
        if (root == null) {
            return;
        }
        dfs(root.left);
        ans.add(root.val);
        dfs(root.right);
    }

LC0094_BinaryTreeInorderTraversal.java · 迭代栈（cur指针）提交区
    public List<Integer> inorderTraversal(TreeNode root) {
        List<Integer> ans = new ArrayList<>();
        if (root == null) {
            return ans;
        }
        Deque<TreeNode> stack = new ArrayDeque<>();
        TreeNode cur = root;
        while (!stack.isEmpty() || cur != null) {
            while (cur != null) {
                stack.push(cur);
                cur = cur.left;
            }
            cur = stack.poll();
            ans.add(cur.val);
                cur = cur.right;
        }
        return ans;
    }

两种写法均 AC：递归 DFS 中序（71/71）+ 迭代栈 cur 指针版（71/71，内存≈41.4MB）。迭代版历经 4 轮修正（重复压栈、当前节点未入栈、右空未移 cur、内层 null 解引用）后通过；analysis.json submissions 含两条不同解法

套路沉淀

递归收集结果：用局部列表+helper 参数，避免实例字段跨调用累积

递归/回溯收集结果的列表如果是实例字段，多次调用（本地多组测试）会串台；正确做法是入口方法内 new 列表并传给递归 helper 收集，或入口先 clear。声明必须放在提交区内。出处：LC0094 binary-tree-inorder-traversal。

迭代中序：cur 指针驱动 + 左链一次压栈，访问后 cur=cur.right

迭代中序遍历用 cur 指针驱动外层 while(cur!=null || !stack.isEmpty())；内层一路压 cur 并 cur=cur.left 到最左，弹栈访问后 cur=cur.right 继续，保证每个节点只压一次。错误写法是每次看栈顶重新走左链（left 不变会重复压栈死循环），且空 root 不能入栈。
