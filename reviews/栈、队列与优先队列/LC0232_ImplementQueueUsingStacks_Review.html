232. 用栈实现队列 (Implement Queue using Stacks)

难度：Easy ｜ 分类：栈、队列与优先队列

题目描述

请你仅使用两个栈实现先入先出队列。队列应当支持一般队列支持的所有操作（push、pop、peek、empty）：

实现 MyQueue 类：

void push(int x) 将元素 x 推到队列的末尾

int pop() 从队列的开头移除并返回元素

int peek() 返回队列开头的元素

boolean empty() 如果队列为空，返回 true ；否则，返回 false

说明：

你 只能 使用标准的栈操作 —— 也就是只有 push to top, peek/pop from top, size, 和 is empty 操作是合法的。

你所使用的语言也许不支持栈。你可以使用 list 或者 deque（双端队列）来模拟一个栈，只要是标准的栈操作即可。

示例 1：

输入：

["MyQueue", "push", "push", "peek", "pop", "empty"]

[[], [1], [2], [], [], []]

输出：

[null, null, null, 1, 1, false]

解释：

MyQueue myQueue = new MyQueue();

myQueue.push(1); // queue is: [1]

myQueue.push(2); // queue is: [1, 2] (leftmost is front of the queue)

myQueue.peek(); // return 1

myQueue.pop(); // return 1, queue is [2]

myQueue.empty(); // return false

LC0232_ImplementQueueUsingStacks.java · 双栈惰性倒序提交区
static class MyQueue {
        Deque<Integer> stack1;
        Deque<Integer> stack2;
        public MyQueue() {
            stack1 = new ArrayDeque<>();
            stack2 = new ArrayDeque<>();
        }
        public void push(int x) {
            stack1.push(x);
        }
        public int pop() {
            if (stack2.isEmpty()) {
                while (!stack1.isEmpty()) {
                    stack2.push(stack1.pop());
                }
            }
            return stack2.pop();
        }
        public int peek() {
            if (stack2.isEmpty()) {
                while (!stack1.isEmpty()) {
                    stack2.push(stack1.pop());
                }
            }
            return stack2.peek();
        }
        public boolean empty() {
            return stack1.isEmpty() && stack2.isEmpty();
        }
    }

思路拆解

问题本质：两个栈各自只能后进先出；用输入栈收集新元素，用输出栈提供队首。只有输出栈为空时才把输入栈逐个弹出并压入输出栈，倒序后最早入队的元素位于栈顶。

关键设计：push 只压入输入栈；pop 与 peek 先检查输出栈，只有它为空才执行搬运。搬运后输入栈为空，输出栈里的已有元素继续排在新元素前面，因此不会打乱队列顺序。empty 只需同时检查两个栈。

具体推演：依次 push(1)、push(2) 后，输入栈从顶到底是 [2,1]，输出栈为空。peek 触发搬运，输出栈从顶到底成为 [1,2]，返回 1；随后 pop 弹出 1。

边界与细节：题目保证 pop/peek 时队列非空，所以不需要定义空队列的返回值。重复 peek 不移除队首；输出栈未空时新 push 不触发搬运，既有队首仍保持优先。

复杂度：每个元素最多从输入栈弹出并压入输出栈一次，之后最多再从输出栈弹出一次，所以 n 次操作总计 O(n)，均摊每次 O(1)；两个栈合计保存队列中的全部元素，空间 O(n)。队列需保存 n 个元素，因此空间量级不可再降。
