    public int calculate(String s) {
        int index = 0;
        Deque<Integer> stack = new ArrayDeque<>();
        int num = 0;
        char sign = '+';
        while (index < s.length()) {
            if (Character.isDigit(s.charAt(index))) {
                num = num * 10 + (s.charAt(index) - '0');
            }
            if (!Character.isDigit(s.charAt(index)) && s.charAt(index) != ' ' || index == s.length() - 1) {
                switch (sign) {
                    case '+' -> {
                        stack.push(num);
                        break;
                    }
                    case '-' -> {
                        stack.push(-num);
                        break;
                    }
                    case '*' -> {
                        stack.push(stack.pop() * num);
                        break;
                    }
                    case '/' -> {
                        stack.push(stack.pop() / num);
                        break;
                    }
                }
                sign = s.charAt(index);
                num = 0;
            }
            index++;
        }
        int ans = 0;
        while (!stack.isEmpty()) {
            ans += stack.pop();
        }
        return ans;
    }

写法 2 · O(1) 空间：sum/last 两变量，乘除合并进 last、加减定稿入 sum（写法2）

时间 O(n)空间 O(1)内存 ≈ 44.6 MB用例 111/111

LC0227_BasicCalculatorIi.java · O(1) 空间：sum/last 两变量，乘除合并进 last、加减定稿入 sum（写法2）提交区
    public int calculate(String s) {
        int num = 0, last = 0, sum = 0;
        char sign = '+';
        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            if (Character.isDigit(c)) {
                num = num * 10 + (c - '0');
            }
            if ((!Character.isDigit(c) && c != ' ') || i == s.length() - 1) {
                switch (sign) {
                    case '+' -> { sum += last; last = num; }
                    case '-' -> { sum += last; last = -num; }
                    case '*' -> { last *= num; }
                    case '/' -> { last /= num; }
                }
                sign = c;
                num = 0;
            }
        }
        return sum + last;
    }

思路拆解

① 问题本质与解法选择理由

  • 无括号中缀表达式（+ - * /），难点在优先级：* / 必须先算，+ - 之间按顺序。
  • 两种做法：① 栈：乘除立即与栈顶算、加减把带符号数字入栈，最后统一求和（直观，空间 O(n)）；② 两个变量：last 存当前累积项、sum 存已定稿项之和，遇加减定稿、遇乘除合并，空间 O(1)。

写法 1（栈，O(n) 空间）

  • 维护 stack，sign 记录当前数字前的运算符。
  • 结算点（非数字非空格或末尾）：+ push(num)、- push(-num)、*// 弹栈顶与新数计算后 push。
  • 最后栈内全部数字相加（带符号）即结果。
  • 时间 O(n)、空间 O(n)。

写法 2（sum/last 两变量，O(1) 空间）

  • last 当前项（乘除原地合并），sum 已定稿项之和，sign 当前数字前的运算符。
  • 结算时：+/-：sum += last; last = ±num（当前项定稿入 sum，开新项）；*//：last *= num / last /= num（乘除合并进当前项）。
  • 最后 return sum + last。
  • 关键：乘除永远作用于 last 内部，sum 只收已定稿的整项，优先级天然正确；空间 O(1)。

③ 边界与细节

  • 单数字 "42"：末尾结算 sign='+' → sum=0、last=42，返回 42。
  • 连续除法左结合：last /= num 每次都用上一个 last 除，等价 (100/10)/2。
  • 负数结果 "1-2"：'-' 把 last=1 定稿入 sum，新 last=-2，返回 -1。
  • 乘除优先级 "1-2*3"：'*' 直接 last=-2*3=-6，sum=1，返回 -5。
  • 除法截断：int 除法向零截断（14-3/2：last=3/2=1，sum=14，返回 13）。
  • 长度上限 3*10^5：单遍扫描，两写法均无性能问题；写法 2 无栈、内存更省。

④ 复杂度分析与下限论证

  • 时间 O(n)：每个字符扫描一次，两种写法都是。
  • 空间：写法 1 O(n)（栈），写法 2 O(1)（两个变量）——写法 2 达空间下限。
  • 最优性：每个字符至少读一次，时间 Ω(n) 达到；表达式求值只需保存「当前项 + 已定稿和」，空间 Ω(1) 即可，写法 2 达到——写法 2 是本题最优解。

**⑤ 具体 case 推演（写法 2）："3+2*2"（期望 7）**

  • '3'：num=3。
  • '+'（结算）：sign='+' → sum+=0、last=3；sign='+'、num=0。
  • '2'：num=2。
  • '*'（结算）：sign='+' → sum+=3、last=2；sign='*'、num=0。
  • '2'（末尾结算）：sign='*' → last=2*2=4。
  • 返回 sum+last = 3+4 = 7 ✅。
