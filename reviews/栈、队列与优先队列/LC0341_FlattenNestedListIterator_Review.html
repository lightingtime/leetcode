src/栈、队列与优先队列/LC0341_FlattenNestedListIterator.java提交区
static class NestedIterator implements Iterator<Integer> {
        Deque<NestedInteger> stack;
        public NestedIterator(List<NestedInteger> nestedList) {
            stack = new ArrayDeque<>();
            for (int i = nestedList.size() - 1; i >= 0; i--) {
                stack.push(nestedList.get(i));
            }
        }

        @Override
        public Integer next() {
            return stack.pop().getInteger();
        }

        @Override
        public boolean hasNext() {
            if (stack.isEmpty()) {
                return false;
            }
            if (stack.peek().isInteger()) {
                return true;
            } else {
                while (!stack.isEmpty() && !stack.peek().isInteger()) {
                    NestedInteger pop = stack.pop();
                    for (int i = pop.getList().size() - 1; i >= 0; i--) {
                        stack.push(pop.getList().get(i));
                    }
                }
            }
            return !stack.isEmpty();
        }
    }

思路拆解

① 问题本质与解法选择理由

  • 嵌套列表按先序（遇到列表先深入）输出全部整数；判题环境提供 NestedInteger（isInteger/getInteger/getList）。
  • 迭代器要求惰性：不预先摊平全部，而是「要一个给一个」。嵌套结构 + 先序 = 栈天然适配：后进先出，逆序压入让最左元素先出。

② 关键设计决策

  • 构造器：把 nestedList 元素逆序压栈（栈顶 = 第一个待输出元素）。
  • hasNext：while (!stack.isEmpty() && !stack.peek().isInteger()) 弹出栈顶列表、逆序压回其元素（getList()），直到栈顶是整数或栈空；返回 !stack.isEmpty()。
  • next：直接 stack.pop().getInteger()（hasNext 已保证栈顶是整数，无需再判断）。
  • 为什么逆序压回：栈 LIFO，正序压会让最后一个元素在栈顶、输出反序；逆序保证最左元素先弹出。

③ 边界与细节

  • 空列表 [[]]：弹出空列表后不压回任何元素，栈变空 → hasNext 返回 false，不会调用 next。
  • 深层嵌套 [[[[1]]]]：hasNext 循环展开多层，直到栈顶是整数 1。
  • 展开循环起点用 size()-1（size() 会越界）。
  • 单整数/值边界 ±10^6：直接走整数分支。
  • 整数值可能为 0，不能用值判断，必须用 isInteger() 判断类型。

④ 复杂度分析与下限论证

  • 构造 O(n)：nestedList 所有元素逆序压栈一次。
  • next/hasNext 均摊 O(1)：每个元素恰好入栈一次、出栈一次；hasNext 的展开循环把「列表节点」也各处理一次，总 O(n)。
  • 空间 O(n)：栈最多存所有待处理元素。
  • 最优性：输出 n 个整数至少要 O(n) 时间、且要保存全部未输出元素 O(n) 空间，均达下限；惰性栈是本题标准最优实现（预先摊平写法同为 O(n)/O(n)，但失去惰性语义）。

⑤ 具体 case 推演：[[1,1],2,[1,1]]（期望 1,1,2,1,1）

  • 构造：逆序压入 [A,2,B]（A=B=[1,1]），栈底→顶 [B,2,A]。
  • hasNext：栈顶 A 是列表 → 弹出，逆序压回 1,1 → 栈 [B,2,1,1]；栈顶 1 是整数 → true。
  • next：弹 1 → 输出 1；next：弹 1 → 1。
  • next：弹 2 → 2。
  • hasNext：栈顶 B 是列表 → 弹出，压回 1,1 → 栈 [1,1]；true。next：1；next：1。
  • hasNext：栈空 → false。输出 1,1,2,1,1 ✅。
