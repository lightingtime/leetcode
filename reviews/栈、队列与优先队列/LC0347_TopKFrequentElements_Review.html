347. 前 K 个高频元素 (Top K Frequent Elements)

> https://leetcode.cn/problems/top-k-frequent-elements/

难度：Medium ｜ 分类：栈、队列与优先队列

标签：数组、哈希表、分治、桶排序、计数、快速选择、排序、堆（优先队列）

题目描述

给你一个整数数组 nums 和一个整数 k ，请你返回其中出现频率前 k 高的元素。你可以按 任意顺序 返回答案。

示例 1：

输入：nums = [1,1,1,2,2,3], k = 2

输出：[1,2]

示例 2：

输入：nums = [1], k = 1

输出：[1]

示例 3：

输入：nums = [1,2,1,2,1,2,3,1,3,2], k = 2

输出：[1,2]

提示：

1 5

-104 4

k 的取值范围是 [1, 数组中不相同的元素的个数]

题目数据保证答案唯一，换句话说，数组中前 k 个高频元素的集合是唯一的

进阶：你所设计算法的时间复杂度 必须 优于 O(n log n) ，其中 n 是数组大小。

LC0347_TopKFrequentElements.java · 哈希表+快速选择提交区
public int[] topKFrequent(int[] nums, int k) {
        Map<Integer, Integer> map = new HashMap<>();
        for (int num : nums) {
            map.merge(num, 1, Integer::sum);
        }
        List<Node> list = new ArrayList<>();
        for (Map.Entry<Integer, Integer> en : map.entrySet()) {
            list.add(new Node(en.getKey(), en.getValue()));
        }
        quickSort(list, 0, list.size() - 1, list.size() - k);
        return list.subList(list.size() - k, list.size()).stream().map(Node::getNum).mapToInt(Integer::intValue).toArray();
    }

    private void quickSort(List<Node> list, int l, int r, int k) {
        if (l == r) {
            return;
        }
        int p = list.get(r).count;
        int i = l, j = l;
        while (j < r) {
            if (list.get(j).count < p) {
                swap(list, i, j);
                i++;
            }
            j++;
        }
        swap(list, i, r);
        if (k == i) {
            return;
        } else if (k < i) {
            quickSort(list, l, i - 1, k);
        } else {
            quickSort(list, i + 1, r, k);
        }
    }

    private void swap(List<Node> list, int i, int j) {
        Node node = list.get(i);
        list.set(i, list.get(j));
        list.set(j, node);
    }

    static class Node {
        int num;
        int count;

        public Node(int num, int count) {
            this.num = num;
            this.count = count;
        }

        public int getNum() {
            return num;
        }
    }

public int[] topKFrequent(int[] nums, int k) {
        Map<Integer, Integer> map = new HashMap<>();
        for (int num : nums) {
            map.merge(num, 1, Integer::sum);
        }
        List<Node> list = new ArrayList<>();
        map.forEach((value, freq) -> {
            list.add(new Node(value, freq));
        });
        quickSelect(list, 0, list.size() - 1, list.size() - k);
        int[] ans = new int[k];
        for (int i = 0; i < k; i++) {
            ans[i] = list.get(list.size() - k + i).value;
        }
        return ans;
    }

    private void quickSelect(List<Node> list, int l, int r, int k) {
        if (l == r) {
            return;
        }
        int x = list.get(l).freq, i = l - 1, j = r + 1;
        while (i < j) {
            do {
                i++;
            } while (x > list.get(i).freq);
            do {
                j--;
            } while (x < list.get(j).freq);
            if (i < j) {
                Node temp = list.get(i);
                list.set(i, list.get(j));
                list.set(j, temp);
            }
        }
        if (k <= j) {
            quickSelect(list, l, j, k);
        } else {
            quickSelect(list, j + 1, r, k);
        }
    }

    class Node {
        Integer value;
        Integer freq;

        public Node(Integer value, Integer freq) {
            this.value = value;
            this.freq = freq;
        }
    }

写法 2 · 桶排序（频次桶倒序收集）

时间 O(n)空间 O(m)内存 ≈ 45.6 MB用例 —

LC0347_TopKFrequentElements.java · 桶排序（频次桶倒序收集）提交区
public int[] topKFrequent(int[] nums, int k) {
        Map<Integer, Integer> map = new HashMap<>();
        int max = 0;
        for (int num : nums) {
            map.merge(num, 1, Integer::sum);
            max = Math.max(max, map.get(num));
        }
        List<Integer>[] counts = new List[max + 1];
        for (Map.Entry<Integer, Integer> entry : map.entrySet()) {
            if (counts[entry.getValue()] == null) {
                counts[entry.getValue()] = new ArrayList<>();
            }
            counts[entry.getValue()].add(entry.getKey());
        }
        int[] ans = new int[k];
        int index = 0;
        for (int i = max; i >= 0; i--) {
            if (counts[i] != null) {
                for (int j = 0; j < counts[i].size(); j++) {
                    ans[index++] = counts[i].get(j);
                    if (index == k) {
                        return ans;
                    }
                }
            }
        }
        return ans;
    }

public int[] topKFrequent(int[] nums, int k) {
        Map<Integer, Integer> map = new HashMap<>();
        int max = 0;
        for (int num : nums) {
            map.merge(num, 1, Integer::sum);
            max = Math.max(max, map.get(num));
        }
        List<Integer>[] counts = new List[max + 1];
        for (Map.Entry<Integer, Integer> entry : map.entrySet()) {
            if (counts[entry.getValue()] == null) {
                counts[entry.getValue()] = new ArrayList<>();
            }
            counts[entry.getValue()].add(entry.getKey());
        }
        int[] ans = new int[k];
        int index = 0;
        for (int i = counts.length - 1; i >= 0; i--) {
            if (counts[i] != null) {
                for (Integer num : counts[i]) {
                    ans[index++] = num;
                    if (index == k) {
                        return ans;
                    }
                }
            }
        }
        return ans;
    }

思路拆解

问题本质与解法选择

统计每个元素出现频次，返回频次前 k 高的元素（答案顺序任意）。先 Map 计数是 O(n) 逃不掉的；难点在「取前 k」：

  • 对频次排序 → O(m log m)，m 为不同元素数，可接受但不是最优；
  • 堆（大小 k 的小顶堆）→ O(n log k)，也常用；
  • 本题没有顺序要求，且频次天然落在 [1, n] 有界区间 → 可以用计数数组当桶：频次作下标，同频次元素放一个桶，从高频往低频收集 k 个，全程线性 O(n)。

选桶排序的理由：无随机退化（快选最坏 O(n²)）、无堆的 log k、实现最直白，是这类「按频次取 top-k」的首选线性写法。

关键设计决策

决策理由
计数时顺手维护 max桶只开到 max+1 而不是 n+1，省空间且收集起点明确
List<Integer>[] counts = new List[max+1]桶下标 = 频次，元素 = 该频次的所有 key
从 counts.length-1 向下收集高频优先，天然满足「前 K 高频」
收集满 k 立即 return避免无谓遍历（也保证桶尾空槽安全）
用 map.merge(num,1,Integer::sum)一行完成计数，语义清晰

具体 case 推演（示例1：nums=[1,1,1,2,2,3], k=2）

阶段状态
计数后map = {1:3, 2:2, 3:1}，max = 3
入桶后counts = [null, [3], [2], [1]]（下标=频次）
i=3counts[3]=[1] → ans[0]=1，index=1
i=2counts[2]=[2] → ans[1]=2，index=2==k → return
结果ans=[1,2]（顺序任意，测试用无序比较）

对照代码：每层 if 判 counts[i]!=null 跳过空桶；内层 for 把同频次的 key 依次写入 ans。若 k=3，则 i=1 时还会把 3 收进来，ans=[1,2,3]。

边界与细节

  • 全相同（[7,7,7,7], k=1）：map 只有 1 个 key、max=4，桶 [null,null,null,null,[7]]，取一个即满。
  • k=不同元素个数：从高到低收完即返回，不会越界（收集总数 = m ≥ k 保证）。
  • 负数 / 极值（-10000、10000）：只作 key 存桶，与频次下标无关，安全。
  • max 初值取 0：nums 非空（题目约束长度 ≥ 1），计数后必 ≥ 1；用 0 无需担心 MIN_VALUE 越界。
  • 答案顺序任意 → 本地与力扣都用无序比较（checkEqUnordered）。

复杂度与下限论证

  • 时间 O(n)：计数 O(n) + 入桶 O(m)（m ≤ n）+ 收集 O(k)，均为线性；必须读完全部 n 个元素才能确定频次，Ω(n) 是下界，已达成。
  • 空间 O(n)：map O(m) + 桶数组 O(max) ≤ O(n)。
  • 对比：快选 O(n) 平均但最坏 O(n²) 且有 partition 细节；堆 O(n log k)。桶排序最坏也线性、实现最简单，是本题满足题意的最优档。

错误习惯复盘

快速选择 top-K：分区比较字段写错（pivot 取 count 却用 num 比较，导致按元素值而非频率分区）；返回区间方向错（subList(k,size) 取反，应取前 k 个或快选把第 size-k 小定位后取后 k 个）（累计 1 次）

快速选择终止分支：应 k==i 返回（pivot 已归位即答案）、k<i 左、k>i 右；写成 k<=i 会把等号情况也递归，pivot 被换到 i 却不在左区间，导致 l>r 非法区间无限递归（栈溢出）或越界（累计 1 次）

桶排序装桶漏 add：if (bucket[f]==null) 创建后必须无条件 add，写成 if/else 导致每个频次桶只装第二个及以后的元素、首个元素丢失；收集时 index==-1 只 break 内层循环，外层继续扫非空桶会 ans[-1] 越界（累计 1 次）
