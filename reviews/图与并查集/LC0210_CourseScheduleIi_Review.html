210. 课程表 II (Course Schedule II)

> https://leetcode.cn/problems/course-schedule-ii/

难度：Medium ｜ 分类：图与并查集

标签：深度优先搜索、广度优先搜索、图、拓扑排序

题目描述

现在你总共有 numCourses 门课需要选，记为 0 到 numCourses - 1。给你一个数组 prerequisites ，其中 prerequisites[i] = [ai, bi] ，表示在选修课程 ai 前 必须 先选修 bi 。

例如，想要学习课程 0 ，你需要先完成课程 1 ，我们用一个匹配来表示：[0,1] 。

返回你为了学完所有课程所安排的学习顺序。可能会有多个正确的顺序，你只要返回 任意一种 就可以了。如果不可能完成所有课程，返回 一个空数组 。

示例 1：

输入：numCourses = 2, prerequisites = [[1,0]]

输出：[0,1]

解释：总共有 2 门课程。要学习课程 1，你需要先完成课程 0。因此，正确的课程顺序为 [0,1] 。

示例 2：

输入：numCourses = 4, prerequisites = [[1,0],[2,0],[3,1],[3,2]]

输出：[0,2,1,3]

解释：总共有 4 门课程。要学习课程 3，你应该先完成课程 1 和课程 2。并且课程 1 和课程 2 都应该排在课程 0 之后。

因此，一个正确的课程顺序是 [0,1,2,3] 。另一个正确的排序是 [0,2,1,3] 。

示例 3：

输入：numCourses = 1, prerequisites = []

输出：[0]

LC0210_CourseScheduleIi.java · Kahn 拓扑排序（入度 + 队列收集出队顺序）提交区
    public int[] findOrder(int numCourses, int[][] prerequisites) {
        List<List<Integer>> graph = new ArrayList<>();
        for (int i = 0; i < numCourses; i++) {
            graph.add(new ArrayList<>());
        }
        int[] inDegree = new int[numCourses];
        for (int[] prerequisite : prerequisites) {
            int before = prerequisite[1];
            int after = prerequisite[0];
            graph.get(before).add(after);
            inDegree[after]++;
        }
        Deque<Integer> deque = new ArrayDeque<>();
        for (int i = 0; i < numCourses; i++) {
            if (inDegree[i] == 0) {
                deque.offerLast(i);
            }
        }
        int[] ans = new int[numCourses];
        int index = 0;
        while (!deque.isEmpty()) {
            int cur = deque.removeFirst();
            ans[index++] = cur;
            for (Integer course : graph.get(cur)) {
                inDegree[course]--;
                if (inDegree[course] == 0) {
                    deque.offerLast(course);
                }
            }
        }
        if (index == numCourses) {
            return ans;
        }
        return new int[0];
    }

思路拆解

问题本质：把课程依赖建模成有向图（边 before→after，先修指向后修），求拓扑排序；存在环则无解（返回空数组）。207 只判「能否完成」，210 额外要求给出一种顺序。

解法选择理由：Kahn 算法（入度 + 队列）天然按「先修在前」的顺序产出——入度为 0 表示所有先修已完成，可以先学。O(V+E) 时间，达到拓扑排序的标准最优（每条边、每个节点访问一次）。

关键设计决策：

  1. 建图：graph.get(before).add(after)，同时 inDegree[after]++。
  2. 初始把所有入度为 0 的课程入队（没有先修，随时可学）。
  3. 出队即「学会」：写入结果数组；对其每个后继 inDegree--，归零就入队（它的先修全学完了）。
  4. 判环：若最终处理数 index != numCourses，说明有节点入度始终 >0（在环里），返回空数组。

具体 case 推演（示例2：numCourses=4，[[1,0],[2,0],[3,1],[3,2]]）：

  1. 入度：0→0，1→1，2→1，3→2；初始队列 [0]
  2. 出队 0 → ans=[0]；后继 1、2 入度减到 0 → 入队 [1,2]
  3. 出队 1 → ans=[0,1]；3 入度 2→1
  4. 出队 2 → ans=[0,1,2]；3 入度 1→0 → 入队 [3]
  5. 出队 3 → ans=[0,1,2,3]，index==4 → 返回 ✓（[0,2,1,3] 也是合法答案，测试用性质校验）

边界与细节：

  • 环（[[0,1],[1,0]]）：1、0 入度都不为 0 → 队列空 → index=0≠2 → 返回空数组。
  • 无先修：所有入度 0，出队顺序即 0..n-1（任意顺序均合法）。
  • 链式依赖：唯一顺序。
  • 大输入 2000 节点链/环：O(V+E) 线性时间通过。
  • 自环/重复边：题目保证 ai!=bi 且所有 [ai,bi] 互不相同。

复杂度与下限论证：建图 O(E)，BFS 每个节点出队一次、每条边处理一次 → O(V+E)；空间 O(V+E)（邻接表 + 入度 + 队列）。拓扑排序必须至少看每条边一次 → 下界 Ω(V+E)，此解达到最优。
