    Map<String, Integer> map;
    List<List<Integer>> edge;
    int nodeNum;
    public int ladderLength(String beginWord, String endWord, List<String> wordList) {
        if (!wordList.contains(endWord)) {
            return 0;
        }
        map = new HashMap<>();
        edge = new ArrayList<>();
        nodeNum = 0;
        for (String word : wordList) {
            addEdge(word);
        }
        addEdge(beginWord);
        Set<Integer> beginSet = new HashSet<>();
        Set<Integer> endSet = new HashSet<>();

        Set<Integer> visitedBegin = new HashSet<>();  // begin 侧已访问
        Set<Integer> visitedEnd = new HashSet<>();    // end 侧已访问
        int levelA = 0;                               // begin 侧当前层的虚拟边数
        int levelB = 0;                               // end 侧当前层的虚拟边数
        beginSet.add(map.get(beginWord));
        endSet.add(map.get(endWord));
        visitedBegin.add(map.get(beginWord));
        visitedEnd.add(map.get(endWord));
        while (!beginSet.isEmpty() && !endSet.isEmpty()) {
            if (beginSet.size() > endSet.size()) {
                Set<Integer> temp = new HashSet<>(beginSet);
                beginSet = endSet;
                endSet = temp;
                temp = new HashSet<>(visitedBegin);
                visitedBegin = visitedEnd;
                visitedEnd = temp;
                int c = levelB;
                levelB = levelA;
                levelA = c;
            }
            Set<Integer> next = new HashSet<>();
            for (Integer u : beginSet) {
                for (Integer v : edge.get(u)) {
                    if (visitedEnd.contains(v)) {
                        return ((levelA + 1) + levelB) / 2 + 1;
                    }
                    if (!visitedBegin.contains(v)) {
                        next.add(v);
                        visitedBegin.add(v);
                    }
                }
            }
            beginSet = next;
            levelA++;
        }
        return 0;
    }

    private void addEdge(String word) {
        addWord(word);
        int id1 = map.get(word);
        char[] charArray = word.toCharArray();
        int len = charArray.length;
        for (int i = 0; i < len; i++) {
            char temp = charArray[i];
            charArray[i] = '*';
            String newWord = new String(charArray);
            addWord(newWord);
            int id2 = map.get(newWord);
            edge.get(id1).add(id2);
            edge.get(id2).add(id1);
            charArray[i] = temp;
        }
    }

    private void addWord(String newWord) {
        if (!map.containsKey(newWord)) {
            map.put(newWord, nodeNum++);
            edge.add(new ArrayList<>());
        }
    }

思路拆解

问题本质：单词接龙 = 无权图最短路。节点是所有单词，边是「只差一个字母」。求 beginWord→endWord 最短序列的单词数，不存在返回 0。

图建模（本次讨论重点）：

  • 图 = 节点（beginWord + wordList 的词）+ 边（差一个字母）。
  • 显式建图：两两比较所有词对、差一个字母就连边存邻接表 → O(n²·L)，n=5000 时约 2500 万次比较，太贵，不用。
  • 隐式建模一（现场生成候选）：BFS 扩到某词时，对每个位置试 25 个字母、查 HashSet 字典 —— O(26L)/步，没有建图步骤。
  • 隐式建模二（本解，通配符虚拟节点）：每个真实词连 L 个「挖一个洞」的模式节点（hit→*it、h*t、hi*），两个真实词共享同一模式节点即「差一个字母」，边长为 2。建图 O(n·L)。addWord 给词/模式分配 id，addEdge 双向连边。

双向 BFS 机制：

  • 两端各维护当前层集合（beginSet / endSet）+ visited + 层号（虚拟边数 levelA/levelB），初始各含 start / target。
  • 每轮扩「当前层节点少」的一侧（交换集合、visited、level 三者一起换），搜索空间最小。
  • 相遇判定：扩 A 侧、u 在虚拟距离 levelA 处，生成邻居 v（levelA+1 处），若 v 已在 end 侧 visited（虚拟距离 levelB）→ 相遇。
  • 返回公式：总虚拟边数 = (levelA+1) + levelB，真实词数 = 总虚拟边数/2 + 1。

相遇公式推导（本次讨论重点）：

  1. 虚拟图每条边是「词↔模式」半程，真实词之间换一个字母 = 2 条虚拟边 → 真实词数 = 虚拟边数/2 + 1（/2 得「换字母次数」，+1 补上起点本身）。
  2. 相遇点 v 离 begin = levelA+1 条虚拟边（v 是 beginSet 里 u 的邻居）；v 离 end = levelB 条（v 在 end 侧 visited）。
  3. 整条链虚拟边数 = (levelA+1)+levelB，代入 1 得 ((levelA+1)+levelB)/2 + 1。
  4. 因为 begin、end 都是真实词，路径必然是「真—模—真—模—…—真」，虚拟边数恒为偶数，/2 可整除。

具体 case 推演（示例 1：hit→cog，答案 5）：

  • 虚拟图路径：hit—h*t—hot—*ot—dot—d*t—dog—d*g—cog（8 条虚拟边）→ 8/2+1 = 5 ✓
  • 最小相遇例子（a→c，字典 ["c"]）：虚拟图 a—*—c。beginSet={a} levelA=0，endSet={c} levelB=0；扩 a→*（levelA=1），扩 *→c ∈ visitedEnd → ((1+1)+0)/2+1 = 2 ✓

边界与细节：

  • endWord 不在字典 → 直接 0。
  • beginWord 可能不在字典 → BFS 前 addEdge(beginWord) 把它连进图（在字典时 addWord 自动去重）。
  • 单词/模式用 int id 表示（map 分配），BFS 在 int 邻接表上跑。
  • 相等值/重复词：wordList 互不相同；begin 与 end 不同。

复杂度：建虚拟图 O(n·L)（每词生成 L 个模式）；双向 BFS 每节点访问一次 O(n·L)；空间 O(n·L)（模式节点数）。这是官方标准最优解。
