138. 随机链表的复制 (Copy List with Random Pointer)

> https://leetcode.cn/problems/copy-list-with-random-pointer/

难度：Medium ｜ 分类：链表

标签：哈希表、链表

题目描述

给你一个长度为 n 的链表，每个节点包含一个额外增加的随机指针 random ，该指针可以指向链表中的任何节点或空节点。

构造这个链表的 深拷贝。 深拷贝应该正好由 n 个 全新 节点组成，其中每个新节点的值都设为其对应的原节点的值。新节点的 next 指针和 random 指针也都应指向复制链表中的新节点，并使原链表和复制链表中的这些指针能够表示相同的链表状态。复制链表中的指针都不应指向原链表中的节点 。

例如，如果原链表中有 X 和 Y 两个节点，其中 X.random --> Y 。那么在复制链表中对应的两个节点 x 和 y ，同样有 x.random --> y 。

返回复制链表的头节点。

用一个由 n 个节点组成的链表来表示输入/输出中的链表。每个节点用一个 [val, random_index] 表示：

val：一个表示 Node.val 的整数。

random_index：随机指针指向的节点索引（范围从 0 到 n-1）；如果不指向任何节点，则为 null 。

你的代码 只 接受原链表的头节点 head 作为传入参数。

示例 1：

输入：head = [[7,null],[13,0],[11,4],[10,2],[1,0]]

输出：[[7,null],[13,0],[11,4],[10,2],[1,0]]

示例 2：

输入：head = [[1,1],[2,1]]

输出：[[1,1],[2,1]]

示例 3：

输入：head = [[3,null],[3,0],[3,null]]

输出：[[3,null],[3,0],[3,null]]

我的解法

写法 1 · 哈希表「一节点一克隆」单遍法（O(n) 空间，写法1）

时间 O(n)空间 O(n)内存 ≈ 44.9 MB用例 19/19

LC0138_CopyListWithRandomPointer.java · 哈希表「一节点一克隆」单遍法（O(n) 空间，写法1）提交区
    public Node copyRandomList(Node head) {
        if (head == null) {
            return head;
        }
        Map<Node, Node> map = new HashMap<>();
        Node p = head;
        while (p != null) {
            Node node = map.getOrDefault(p, new Node(p.val));
            map.put(p, node);
            if (p.next != null) {
                node.next = map.getOrDefault(p.next, new Node(p.next.val));
                map.put(p.next, node.next);
            }
            if (p.random != null) {
                node.random = map.getOrDefault(p.random, new Node(p.random.val));
                map.put(p.random, node.random);
            }
            p = p.next;
        }
        return map.get(head);
    }

写法 2 · 原地穿插三遍：复制节点插入原节点后，设 random，再拆开两链表（O(1) 空间，写法2）

时间 O(n)空间 O(1)内存 ≈ 44.9 MB用例 19/19

LC0138_CopyListWithRandomPointer.java · 原地穿插三遍：复制节点插入原节点后，设 random，再拆开两链表（O(1) 空间，写法2）提交区
    public Node copyRandomList(Node head) {
        if (head == null) {
            return head;
        }
        for (Node node = head; node != null; node = node.next.next) {
            Node nodeNew = new Node(node.val);
            nodeNew.next = node.next;
            node.next = nodeNew;
        }
        for (Node node = head; node != null; node = node.next.next) {
            Node nodeNew = node.next;
            nodeNew.random = node.random != null ? node.random.next : null;
        }
        Node newHead = head.next;
        for (Node node = head; node != null; node = node.next) {
            Node nodeNew = node.next;
            node.next = nodeNew.next;
            nodeNew.next = nodeNew.next != null ? nodeNew.next.next : null;
        }
        return newHead;
    }

思路拆解

问题本质

  • 深拷贝带 random 的链表，难点在 random 映射：克隆节点的 random 必须指向「原 random 节点的克隆」。
  • 两条路线：① 用 Map<原节点,克隆节点> 显式记录映射（空间 O(n)）；② 把克隆节点插到原节点后面，让「原节点的克隆」天然就是「原节点.next」，无需额外映射（空间 O(1)）。

写法 1（哈希表单遍）

  • map：原节点 → 克隆节点，保证一节点一克隆——创建前先 map.getOrDefault(p, new ...)，已存在则复用。
  • 踩坑：最初「无条件 new 再 put」导致同一原节点被创建两次（一次作为被 next/random 引用、一次作为主节点），put 覆盖后旧克隆成孤儿且其 random 未设置（示例 [[1,1],[2,1]] 的 B 被建两次、B₁'.random 为 null）。
  • 单遍完成 next/random 连接，时间 O(n)、空间 O(n)。

写法 2（原地穿插三遍，O(1) 空间）

  • 第一遍：每个原节点后插入克隆：nodeNew.next = node.next; node.next = nodeNew。克隆与其原节点的位置关系即映射。
  • 第二遍：设克隆 random：nodeNew.random = node.random != null ? node.random.next : null（原 random 的克隆 = 原 random.next，因为克隆紧跟在原节点后）。
  • 第三遍：拆开两链表：原链表恢复 node.next = nodeNew.next（步进 node = node.next）；克隆链表连 nodeNew.next = nodeNew.next != null ? nodeNew.next.next : null。
  • 时间 O(n)、空间 O(1)（不含返回值），满足进阶，为该题最优。

具体 case 推演（写法 2）：[[1,1],[2,1]]（A.random=B，B.random=B）

  • 第一遍：A→A'→B→B'（A'.next=B、B'.next=null）。
  • 第二遍：A'.random = A.random(B).next = B'；B'.random = B.random(B).next = B'。
  • 第三遍：A.next=B（恢复原链表）；A'.next = B.next = B'；B.next=null；B'.next = null。
  • 结果：A'→B'，A'.random=B'、B'.random=B'，与原链表状态一致 ✅。

复杂度对比与最优性

| 写法 | 时间 | 空间 |

| 哈希表单遍 | O(n) | O(n) |

| 原地穿插三遍 | O(n) | O(1) |

  • 时间下限：每个节点都必须复制，至少访问全部节点 Ω(n)，两种都达到。
  • 空间下限：除返回的克隆链表外无需额外存储，O(1) 即最优；写法 2 是本题最优解。

套路沉淀

复制带引用结构：一原节点一克隆，先查后建

复制带 next/random 等引用的结构：用 Map<原节点,新节点> 保证一一对应；创建前先 map.get 判存在，已存在则复用、不存在才 new，禁止无条件 new 后 put（会覆盖旧登记、产生孤儿节点且孤儿指针未设置）；或两遍法：第一遍建全量映射、第二遍只连指针。O(n) 时间 O(n) 空间。
