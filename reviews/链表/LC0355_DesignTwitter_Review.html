    static class Twitter {
        Map<Integer, List<Tweet>> tweets;
        Map<Integer, Set<Integer>> followers;
        int uniId;

        static class Tweet {
            int id;
            int time;
            Tweet(int id, int time) {
                this.id = id;
                this.time = time;
            }
        }

        public Twitter() {
            tweets = new HashMap<>();
            followers = new HashMap<>();
            uniId = 0;
        }

        public void postTweet(int userId, int tweetId) {
            uniId++;
            tweets.computeIfAbsent(userId, x -> new LinkedList<>()).add(0, new Tweet(tweetId, uniId));
        }

        public List<Integer> getNewsFeed(int userId) {
            List<List<Tweet>> allNews = new ArrayList<>();
            if (tweets.containsKey(userId)) {
                allNews.add(tweets.get(userId));
            }
            if (followers.containsKey(userId)) {
                for (Integer followeeId : followers.get(userId)) {
                    if (tweets.containsKey(followeeId)) {
                        allNews.add(tweets.get(followeeId));
                    }
                }
            }
            if (allNews.isEmpty()) {
                return new ArrayList<>();
            }
            List<Tweet> sortNews = getSortNews(allNews, 0, allNews.size() - 1);
            List<Integer> res = new ArrayList<>();
            for (int i = 0; i < Math.min(10, sortNews.size()); i++) {
                res.add(sortNews.get(i).id);
            }
            return res;
        }

        private List<Tweet> getSortNews(List<List<Tweet>> allNews, int l, int r) {
            if (l >= r) {
                return allNews.get(l);
            }
            int mid = l + (r - l) / 2;
            List<Tweet> first = getSortNews(allNews, l, mid);
            List<Tweet> second = getSortNews(allNews, mid + 1, r);
            return mergeList(first, second);
        }

        private List<Tweet> mergeList(List<Tweet> first, List<Tweet> second) {
            List<Tweet> list = new ArrayList<>();
            int i = 0, j = 0;
            while (i < first.size() && j < second.size()) {
                if (list.size() == 10) {
                    break;
                }
                if (first.get(i).time > second.get(j).time) {
                    list.add(first.get(i));
                    i++;
                } else {
                    list.add(second.get(j));
                    j++;
                }
            }
            while (i != first.size() && list.size() < 10) {
                list.add(first.get(i));
                i++;
            }
            while (j != second.size() && list.size() < 10) {
                list.add(second.get(j));
                j++;
            }
            return list;
        }

        public void follow(int followerId, int followeeId) {
            followers.computeIfAbsent(followerId, k -> new HashSet<>()).add(followeeId);
        }

        public void unfollow(int followerId, int followeeId) {
            if (followers.containsKey(followerId)) {
                followers.get(followerId).remove(followeeId);
            }
        }
    }

写法 2 · 优先队列多路归并 Top-10

时间 postTweet O(1), getNewsFeed O(k + 10 log k)空间 O(n)内存 ≈ 54.8 MB用例 22/22

LC0355_DesignTwitter.java · 优先队列多路归并 Top-10提交区
    static class Twitter {
        Map<Integer, List<Tweet>> tweets;
        Map<Integer, Set<Integer>> followers;
        int uniId;

        static class Tweet {
            int id;
            int time;
            Tweet(int id, int time) {
                this.id = id;
                this.time = time;
            }
        }

        public Twitter() {
            tweets = new HashMap<>();
            followers = new HashMap<>();
            uniId = 0;
        }

        public void postTweet(int userId, int tweetId) {
            uniId++;
            tweets.computeIfAbsent(userId, x -> new LinkedList<>()).add(0, new Tweet(tweetId, uniId));
        }

        public List<Integer> getNewsFeed(int userId) {
            List<List<Tweet>> flows = new ArrayList<>();
            if (tweets.containsKey(userId)) {
                flows.add(tweets.get(userId));
            }
            if (followers.containsKey(userId)) {
                for (Integer followeeId : followers.get(userId)) {
                    if (tweets.containsKey(followeeId)) {
                        flows.add(tweets.get(followeeId));
                    }
                }
            }
            if (flows.isEmpty()) {
                return new ArrayList<>();
            }

            // 优先队列多路归并：每个流头部进最大堆（按 time），弹最大者后从该流补下一个
            int k = flows.size();
            int[] idx = new int[k]; // 每个流当前游标（默认 0 = 最新）
            PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) ->
                    flows.get(b[0]).get(b[1]).time - flows.get(a[0]).get(a[1]).time);
            for (int i = 0; i < k; i++) {
                pq.offer(new int[]{i, 0});
            }
            List<Integer> res = new ArrayList<>();
            while (!pq.isEmpty() && res.size() < 10) {
                int[] cur = pq.poll();
                res.add(flows.get(cur[0]).get(cur[1]).id);
                cur[1]++;
                if (cur[1] < flows.get(cur[0]).size()) {
                    pq.offer(cur);
                }
            }
            return res;
        }

        public void follow(int followerId, int followeeId) {
            followers.computeIfAbsent(followerId, k -> new HashSet<>()).add(followeeId);
        }

        public void unfollow(int followerId, int followeeId) {
            if (followers.containsKey(followerId)) {
                followers.get(followerId).remove(followeeId);
            }
        }
    }

设计推特：写法1 二分归并；写法2 优先队列多路归并 Top-10 O(k+10logk)，AC 22/22

思路拆解

写法 1（二分归并版）：头插推文流 + 全局时间戳 + 归并 Top-10

1. 问题本质与解法选择

设计 Twitter：发推、关注/取关、取「自己 + 关注人」最近 10 条按时间倒序。核心是 getNewsFeed 的多路合并 Top-10：每个用户推文流是「最近在前」的有序链表，合并多个有序流取最近 10 条。用二分归并逐层合并，每层截断 10。

2. 关键设计决策

  • 推文流头插：tweets: Map<Integer, List<Tweet>>，postTweet 用 add(0, ...) 头插保证「最近在前」——归并正确的前提（尾插会让单用户列表变正序）。
  • 推文存 Tweet { id, time } 对：time 来自全局自增 uniId；排序键是 time 而非 tweetId（tweetId 唯一但不递增）。
  • 关注表：followers: Map<Integer, Set<Integer>>，follow/unfollow O(1)；不用冗余的反向表。
  • 二分归并：getSortNews 递归对半拆，mergeList 双指针比较 time 取大者，输出截断 10。

3. 边界与细节

  • 空 feed（无推文无关注）→ 空列表。
  • 单用户：l >= r 原样返回，靠头插保持倒序。
  • 截断双保险：mergeList 的 size()==10 提前停 + 外层 subList(0, min(10, size))。
  • 排序键是时间戳（本地「先发 100、后发 1」用例验证）。

4. 具体 case 推演

示例流程：

操作tweetsfeed(1)
postTweet(1,5)1:[5][5]
follow(1,2)；postTweet(2,6)1:[5], 2:[6][6,5]
unfollow(1,2)—[5]

多关注人（time：20→1, 10→2, 30→3）：归并 [10] vs [20] → 取 10（t2>t1）→ [10,20]；再 vs [30] → [30,10,20] ✓

5. 复杂度

  • postTweet/follow/unfollow O(1)；getNewsFeed 二分归并 O(L·log k)（L 参与推文总数），每层截断 10 实际 O(10·k·log k) 内。
  • 空间 O(总推文数 + 关注关系)。

---

写法 2（优先队列多路归并版，O(k + 10·log k)）：惰性取 Top-10

1. 问题本质与解法选择

同样是合并「自己 + 关注人」的多个倒序推文流取最近 10 条。写法 1 的二分归并会把参与合并的推文全量归并一遍（即使只要 10 条）；写法 2 用最大堆 + 惰性补位：每个流只把头部（最新一条）进堆，弹出全局最新后，再从该流补下一条——只碰「必要」的条目，复杂度降到 O(k + 10·log k)。

2. 关键设计决策

  • 数据结构与写法 1 相同：tweets: Map<Integer, List<Tweet>>（头插保序）、Tweet { id, time }（全局时间戳 uniId）、followers。
  • 优先队列元素是 int[]{flow, pos}（流编号 + 游标），比较器按 time 降序（b.time - a.time）构造最大堆。
  • 初始化：每个流 pos=0（各自最新）入堆，堆大小 = k。
  • 循环：弹出最大者 → 加入结果 → 该流 pos++，若仍有下一条则重新入堆；结果满 10 或堆空停。
  • idx 数组在写法里用 pos 游标内嵌于堆元素，无需额外状态。

3. 边界与细节

  • 空 feed → 直接返回空列表。
  • 流耗尽：某流弹完最后一条后 pos >= size，不再入堆，堆自动缩小。
  • 截断：res.size() < 10 控制最多取 10。
  • 排序键是 time（先发 100、后发 1 用例验证）；tweetId 唯一但不递增，不能当时间。

4. 具体 case 推演

多关注人（time：20→1, 10→2, 30→3），流：[10](u1), [20](u2), [30](u3)：

步骤堆内容 (flow,time)弹出补位结果
初始(u1,2),(u2,1),(u3,3)——[]
1—(u3,3)=30u3 无下一条[30]
2—(u1,2)=10u1 无下一条[30,10]
3—(u2,1)=20—[30,10,20]

[30,10,20] ✓（与写法 1 一致）

5. 复杂度与最优性

  • getNewsFeed：初始化 k 个入堆 O(k)；最多弹 10 次，每次 O(log k) → O(k + 10·log k)。相比写法 1 的 O(L·log k)（L 为参与推文总数），只处理必要条目，是「多路归并 Top-K」的标准最优形态。
  • postTweet/follow/unfollow 仍 O(1)；空间 O(总推文数 + 关注关系)。
