206. 反转链表 (Reverse Linked List)

题目描述

给你单链表的头节点 head ，请你反转链表，并返回反转后的链表。

示例 1：

输入：head = [1,2,3,4,5]

输出：[5,4,3,2,1]

示例 2：

输入：head = [1,2]

输出：[2,1]

示例 3：

输入：head = []

输出：[]

提示：

链表中节点的数目范围是 [0, 5000]

写法 1 · 递归反转（head.next.next = head）

时间 O(n)空间 O(n)递归栈内存 ≈ 42.6 MB用例 28/28

src/链表/LC0206_ReverseLinkedList.java提交区
public ListNode reverseList(ListNode head) {
        if (head == null || head.next == null) {
            return head;
        }
        ListNode newHead = reverseList(head.next);
        head.next.next = head;
        head.next = null;
        return newHead;
    }

思路拆解

问题本质：单链表反转，让每个节点指向原前驱。递归版本非常简洁：先反转后半段，再把当前节点接到新链末尾。

关键设计：reverseList(head.next) 返回反转后的新头；递归返回后 head.next 已经指向新链的尾节点（即原 head 的后继），于是 head.next.next=head 把 head 挂到末尾，head.next=null 断开旧指向。终止条件：空或单节点直接返回。

边界：空链表/单节点；长度为 2；操作顺序敏感——必须先通过 head.next 访问新尾，再改 head.next.next，顺序写反会丢链。

复杂度：O(n) 时间、O(n) 递归栈空间；若追求严格 O(1) 空间可改迭代三指针，两者时间同为最优。

解题过程

01 · 踩坑已记录

递归反转链表接回错误：把递归返回的「新头」当作 head 的原后继去接（next.next = head），实际新头后面接的是原链表尾，head 被接到新头后面导致中间节点全部丢失；正确是让原后继（现在位于反转后子链表尾部）指回 head，即 head.next.next = head

套路沉淀

递归反转链表：新头 vs 原后继（head.next.next = head）

递归版 reverseList(head.next) 返回的是「反转后子链表的新头」（即原链表尾）；把它接到 head 后面是错的。要让「head 原来的后继」指回 head——该节点在反转后的子链表里位于尾部，即 head.next.next = head，然后 head.next = null。区分两个角色：返回值（新头，最终返回它）与 head.next（原后继，负责接回头部）。
