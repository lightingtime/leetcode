public ListNode mergeTwoLists(ListNode list1, ListNode list2) {
        if (list1 == null) {
            return list2;
        }
        if (list2 == null) {
            return list1;
        }
        ListNode dummy = new ListNode();
        ListNode p1 = list1, p2 = list2, p = dummy;
        while (p1 != null && p2 != null) {
            if (p1.val < p2.val) {
                ListNode node = new ListNode(p1.val);
                p.next = node;
                p1 = p1.next;
            } else {
                ListNode node = new ListNode(p2.val);
                p.next = node;
                p2 = p2.next;
            }
            p = p.next;
        }
        if (p1 != null) {
            p.next = p1;
        }
        if (p2 != null) {
            p.next = p2;
        }
        return dummy.next;
    }

合并两个有序链表：dummy 哨兵 + 双指针迭代，每次接较小节点，剩余部分直接拼接；一次 Accepted（208/208）。

思路拆解

问题本质：两个有序链表合并成一个。归并式双指针：每步取较小节点接在结果链尾。

关键设计：p1、p2 比较取小者接在 p 后并前移；一方走完时把另一方的剩余链整体续接（链表天然 O(1) 续接）。dummy 哑节点避免头节点特判，最后返回 dummy.next。

边界：一方为空时直接返回另一方；两链长度不等；值相等时取哪边都行。

复杂度：O(n+m) 时间、O(1) 额外空间，最优。代码里相等值用 new ListNode 复制节点而非直接续接，正确但可简化——直接续接原节点更省空间。
