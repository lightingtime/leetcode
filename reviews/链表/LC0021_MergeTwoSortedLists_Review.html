题目描述

将两个升序链表合并为一个新的 升序 链表并返回。新链表是通过拼接给定的两个链表的所有节点组成的。

示例 1：

输入：l1 = [1,2,4], l2 = [1,3,4]

输出：[1,1,2,3,4,4]

示例 2：

输入：l1 = [], l2 = []

输出：[]

示例 3：

输入：l1 = [], l2 = [0]

输出：[0]

提示：

两个链表的节点数目范围是 [0, 50]

与一刷对比：算法思路一致（dummy 哨兵 + 双指针迭代合并），但节点处理方式退化了——一刷是原地复用原节点（额外空间 O(1)），这次在交错合并阶段每次都 new ListNode(p1.val) 复制节点，只有最后剩余的那一段是直接拼接，所以额外空间变成 O(m+n)。结果是正确的、Accepted（208/208），但空间没有达最优。

写对的地方：dummy 哨兵 + while (p1 != null && p2 != null) 逐轮接较小节点、每轮接完指针前移；退出循环后剩余链整段拼接（p.next = p1/p2），没有再逐节点接。

可优化点：① 交错阶段直接接原节点（把当前节点挂上、指针后移）就能把额外空间压回 O(1)——本题不要求新链表副本，复用节点是标准写法；② 开头两个 null 判断冗余，dummy 结构本身能兜住空链；③ 拼接剩余段用的两个 if 可以保留其一（两者必有一个为 null）。

掌握度依据：一次提交 Accepted、全程无探讨 → 较强（但写法未达空间最优，已按 optimal=false 记录）。

public ListNode mergeTwoLists(ListNode l1, ListNode l2) {
        if (l1 == null) {
            return l2;
        }
        if (l2 == null) {
            return l1;
        }
        ListNode dummy = new ListNode();
        ListNode pre = dummy;
        while (l1 != null && l2 != null) {
            if (l1.val < l2.val) {
                pre.next = l1;
                l1 = l1.next;
            } else {
                pre.next = l2;
                l2 = l2.next;
            }
            pre = pre.next;
        }
        pre.next = l1 == null ? l2 : l1;
        return dummy.next;
    }

public ListNode mergeTwoLists(ListNode list1, ListNode list2) {
        if (list1 == null) {
            return list2;
        }
        if (list2 == null) {
            return list1;
        }
        ListNode dummy = new ListNode();
        ListNode p1 = list1, p2 = list2, p = dummy;
        while (p1 != null && p2 != null) {
            if (p1.val < p2.val) {
                ListNode node = new ListNode(p1.val);
                p.next = node;
                p1 = p1.next;
            } else {
                ListNode node = new ListNode(p2.val);
                p.next = node;
                p2 = p2.next;
            }
            p = p.next;
        }
        if (p1 != null) {
            p.next = p1;
        }
        if (p2 != null) {
            p.next = p2;
        }
        return dummy.next;
    }

思路拆解

问题本质：两个有序链表合并成一个。归并式双指针：每步取较小节点接在结果链尾。

关键设计：p1、p2 比较取小者接在 p 后并前移；一方走完时把另一方的剩余链整体续接（链表天然 O(1) 续接）。dummy 哑节点避免头节点特判，最后返回 dummy.next。

边界：一方为空时直接返回另一方；两链长度不等；值相等时取哪边都行。

复杂度：O(n+m) 时间、O(1) 额外空间，最优。代码里相等值用 new ListNode 复制节点而非直接续接，正确但可简化——直接续接原节点更省空间。

套路沉淀

dummy 哨兵 + 双指针拼接有序链表

有序链表合并时，用 dummy 哨兵避免单独处理结果头节点，用双指针每次接较小节点，循环结束后把非空剩余段直接整体挂到尾部。关键是直接改 next 指针复用原节点；若每次 new 节点，逻辑直观但会多出 O(m+n) 额外空间。该套路可迁移到 23 合并 K 个链表的分治 merge 与 148 排序链表的归并 merge。
