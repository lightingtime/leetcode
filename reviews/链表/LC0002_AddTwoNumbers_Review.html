题目描述

给你两个 非空 的链表，表示两个非负的整数。它们每位数字都是按照 逆序 的方式存储的，并且每个节点只能存储 一位 数字。

请你将两个数相加，并以相同形式返回一个表示和的链表。

你可以假设除了数字 0 之外，这两个数都不会以 0 开头。

示例 1：

输入：l1 = [2,4,3], l2 = [5,6,4]

输出：[7,0,8]

解释：342 + 465 = 807.

示例 2：

输入：l1 = [0], l2 = [0]

输出：[0]

示例 3：

输入：l1 = [9,9,9,9,9,9,9], l2 = [9,9,9,9]

输出：[8,9,9,9,0,0,0,1]

提示：

每个链表中的节点数在范围 [1, 100] 内

0

题目数据保证列表表示的数字不含前导零

public ListNode addTwoNumbers(ListNode l1, ListNode l2) {
        ListNode dummy = new ListNode();
        ListNode p1 = l1, p2 = l2, p = dummy;
        int next = 0;
        while (p1 != null || p2 != null || next != 0) {
            int a = p1 == null ? 0 : p1.val;
            int b = p2 == null ? 0 : p2.val;
            int sum = a + b + next;
            ListNode node = new ListNode(sum % 10);
            next = sum / 10;
            p.next = node;
            p = p.next;
            p1 = p1 == null ? p1 : p1.next;
            p2 = p2 == null ? p2 : p2.next;
        }
        return dummy.next;
    }

两数相加：dummy 哨兵 + 单循环逐位相加，链表为空按 0 处理，循环条件含 next != 0 统一收尾进位；一次 Accepted（1569/1569），后精简为单循环写法再次提交 Accepted。

思路拆解

问题本质：链表按逆序存数字（头节点是个位），相加就是模拟竖式：逐位求和 + 进位。

关键设计：循环条件 p1!=null || p2!=null || carry!=0 三个都要判断——最高位产生进位时还要再生成一个节点；短链补 0（p1==null ? 0 : p1.val）；每位存 sum%10、进位 sum/10。

边界：两链长度不等；最高位连续进位（如 999+1 结果多一位）；一条链为空；9+9 的进位要带进下一位。

复杂度：O(max(m,n)) 时间、O(1) 额外空间（输出链不算），最优；逆序存储让加法天然从左到右。
