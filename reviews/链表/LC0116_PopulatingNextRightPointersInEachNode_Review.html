写法 1 · BFS 层序遍历，size 控制每层边界，pre 串联同层 next，null 子节点不入队

时间 O(n)空间 O(n)内存 ≈ 44.7 MB用例 59/59

src/LC0116_PopulatingNextRightPointersInEachNode.java提交区
public Node connect(Node root) {
            if (root == null) {
                return root;
            }
            Deque<Node> queue = new ArrayDeque<>();
            queue.offerLast(root);
            while (!queue.isEmpty()) {
                int size = queue.size();
                Node pre = null;
                for (int i = 0; i < size; i++) {
                    Node node = queue.pollFirst();
                    if (pre != null) {
                        pre.next = node;
                    }
                    if (node.left != null) {
                        queue.offerLast(node.left);
                    }
                    if (node.right != null) {
                        queue.offerLast(node.right);
                    }
                    pre = node;
                }
            }
            return root;
        }

思路拆解

① 问题本质与解法选择理由

  • 完美二叉树，要把同一层节点用 next 串成链表，核心操作是「按层处理」。
  • BFS（队列 + size 记录当前层节点数）是最直观的按层手段：队列天然按层存放节点，size 划出本层边界。
  • 选 BFS 而非 DFS：DFS 也能按层号串联，但 BFS 直译「层」的语义；进阶要求 O(1) 额外空间（利用上一层 next 指针），BFS 队列版空间 O(n) 不达进阶，但正确性优先、先写对。

② 关键设计决策

  • 每轮 while 前记录 size = queue.size()，for 循环只处理 size 个节点——这是「不跨层」的保证。
  • pre 指针记本层上一个节点，弹出 node 后 pre.next = node 完成同层串联；每层 pre 初始 null，层首节点的 next 保持 null。
  • null 子节点不入队：叶子节点 left/right 为 null，若直接 offerLast 会把 null 混进队列，下一轮 size 计数错乱、pollFirst 取到 null 后访问 node.left 直接 NPE。这是本题最容易踩的坑。
  • 完美二叉树父节点都有两个子节点，root 非空时只需对左右子判空（叶子层触发）。

③ 边界与细节

  • 空树 root==null 直接返回 root。
  • 单节点：队列 [root]，size=1，无子节点入队，pre 恒为 null，root.next 保持 null，正确。
  • 层尾：每层最后一个节点的 next 保持 null，绝不连到下一层。
  • 节点数上限 2^12-1=4095（12 层满树）：队列最多存一层 2048 个节点，无性能问题。

④ 复杂度分析与下限论证

  • 每个节点恰好入队出队一次，时间 O(n)；队列最坏存最后一层 n/2 个节点，空间 O(n)。
  • 时间下限：每个节点的 next 都必须被设置，至少要访问全部节点，Ω(n)，本解达到。
  • 空间并非最优：进阶的 O(1) 空间解法不存队列，而是利用「上一层已连好的 next」从最左节点一路向右、同时把下一层连好——本轮先保证正确，优化方向明确。

⑤ 具体 case 推演：7 节点树 [1,2,3,4,5,6,7]

  • 第 1 轮：队列 [1]，size=1。弹 1：pre=null，不连；入队 2,3；pre=1。队列 [2,3]。
  • 第 2 轮：size=2。弹 2：pre=null；入队 4,5；pre=2。弹 3：pre=2 → 2.next=3；入队 6,7；pre=3。队列 [4,5,6,7]。得到 "2 3"。
  • 第 3 轮：size=4。弹 4：pre=null，4 的子节点全 null、不入队；pre=4。弹 5：4.next=5…… 依次 5.next=6、6.next=7。得到 "4 5 6 7"。
  • 队列空，结束。按层输出 "1" / "2 3" / "4 5 6 7" 与题目示例一致。

⑥ 踩坑修复（NPE）

  • 最初写法无条件 offerLast(node.left/right)：第 3 轮叶子 4 把两个 null 入队，队列变成 [5,6,7,null,null]；第 4 轮 size 含 null，pollFirst 取出 null 后 node.left 抛 NPE。
  • 修复：入队前判断 node.left != null / node.right != null。这暴露通用套路：BFS 遍历树时，空子节点不要入队。
