写法 1 · BFS 层序遍历，size 控制每层边界，pre 串联同层 next，null 子节点不入队

时间 O(n)空间 O(n)内存 ≈ 44.7 MB用例 59/59

LC0116_PopulatingNextRightPointersInEachNode.java · BFS 层序遍历，size 控制每层边界，pre 串联同层 next，null 子节点不入队提交区
public Node connect(Node root) {
            if (root == null) {
                return root;
            }
            Deque<Node> queue = new ArrayDeque<>();
            queue.offerLast(root);
            while (!queue.isEmpty()) {
                int size = queue.size();
                Node pre = null;
                for (int i = 0; i < size; i++) {
                    Node node = queue.pollFirst();
                    if (pre != null) {
                        pre.next = node;
                    }
                    if (node.left != null) {
                        queue.offerLast(node.left);
                    }
                    if (node.right != null) {
                        queue.offerLast(node.right);
                    }
                    pre = node;
                }
            }
            return root;
        }

写法 2 · O(1) 空间：mostLeft 逐层向下，利用上一层已连好的 next 连接下一层（写法2）

时间 O(n)空间 O(1)内存 ≈ 44.6 MB用例 59/59

LC0116_PopulatingNextRightPointersInEachNode.java · O(1) 空间：mostLeft 逐层向下，利用上一层已连好的 next 连接下一层（写法2）提交区
    public Node connect(Node root) {
        if (root == null) {
            return root;
        }
        Node mostLeft = root;
        while (mostLeft.left != null) {
            Node cur = mostLeft;
            while (cur != null) {
                cur.left.next = cur.right;
                if (cur.next != null) {
                    cur.right.next = cur.next.left;
                }
                cur = cur.next;
            }
            mostLeft = mostLeft.left;
        }
        return root;
    }

LC0116_PopulatingNextRightPointersInEachNode.java · 递归（前序 DFS）：先连左右子与跨父 next，再递归左右子树（写法3）提交区
    public Node connect(Node root) {
        if (root == null) {
            return root;
        }
        if (root.left != null) {
            root.left.next = root.right;
            root.right.next = root.next != null ? root.next.left : null;
            connect(root.left);
            connect(root.right);
        }
        return root;
    }

思路拆解

问题本质

  • 完美二叉树要把同一层节点用 next 串成链表。关键观察：如果某一层的 next 已经连好，处理这一层时能借 cur 与 cur.next 找到下一层所有节点的「右侧邻居」，无需队列。这一观察对迭代与递归都成立。

写法 1（BFS + 队列）

  • 每轮 while 前记 size = queue.size() 划出本层，只处理 size 个节点，pre.next = node 串联同层，层首 next 保持 null。
  • 空子节点不入队：叶子节点的 null 子节点入队会导致 size 计数错乱、pollFirst 取 null 后访问 node.left 抛 NPE（真实踩过）。
  • 时间 O(n)、空间 O(n)。正确但未达进阶空间要求。

写法 2（O(1) 空间迭代，利用上一层 next）

  • mostLeft 指向每层最左节点，外层 while (mostLeft.left != null) 按层向下；cur 遍历当前层（该层 next 已连好）。
  • 对每个 cur：cur.left.next = cur.right（同父相连）；若 cur.next != null 则 cur.right.next = cur.next.left（跨父连接，依赖当前层 next 就绪）。
  • 一层处理完 mostLeft = mostLeft.left 下移；初始化第 1 层只有 root 天然就绪。空间 O(1)。

写法 3（递归 / 前序 DFS）

  • 递归语义：处理当前节点的两个子节点——root.left.next = root.right（同父相连）；root.right.next = root.next != null ? root.next.left : null（跨父，依赖「当前节点所在层的 next 已连好」）。
  • 处理完当前节点后递归 connect(root.left)、connect(root.right)：前序保证进入下一层前，其父层 next 已由上层处理完毕；先左后右保持同层从左到右。
  • 完美二叉树保证 root.left 非空时 root.right 也非空（root.left != null 一个判断覆盖两者）。
  • 空间：递归栈 O(log n)（完美二叉树高度=层数），题目声明递归栈不算额外空间，因此同样满足进阶 O(1) 额外空间。

具体 case 推演（写法 3）：7 节点树 [1,2,3,4,5,6,7]

  • connect(1)：2.next=3；3.next = 1.next(null) → null；递归 connect(2)、connect(3)。
  • connect(2)：4.next=5；5.next = 2.next(3).left = 6；递归 connect(4)、connect(5)。
  • connect(3)：6.next=7；7.next = 3.next(null) → null；递归 connect(6)、connect(7)。
  • 结果：2→3、4→5→6→7，与示例一致。

复杂度与最优性（三写法对比）

| 写法 | 时间 | 额外空间 | 满足进阶 O(1) |

| BFS 队列 | O(n) | O(n) | 否 |

| 迭代利用 next | O(n) | O(1) | 是 |

| 递归 DFS | O(n) | O(1)（递归栈不计） | 是 |

  • 时间下限：每个 next 都必须被设置，至少访问全部节点 Ω(n)，三种写法都达到。
  • 空间下限：除返回值外无需额外存储，写法 2/3 的 O(1) 即最优；写法 2 与写法 3 为该题并列最优解。
