86. 分隔链表 (Partition List)

> https://leetcode.cn/problems/partition-list/

难度：Medium ｜ 分类：双指针与滑动窗口

标签：链表、双指针

题目描述

给你一个链表的头节点 head 和一个特定值 x ，请你对链表进行分隔，使得所有 小于 x 的节点都出现在 大于或等于 x 的节点之前。

你应当 保留 两个分区中每个节点的初始相对位置。

示例 1：

输入：head = [1,4,3,2,5,2], x = 3

输出：[1,2,2,4,3,5]

示例 2：

输入：head = [2,1], x = 2

输出：[1,2]

提示：

链表中节点的数目在范围 [0, 200] 内

LC0086_PartitionList.java · 双指针分链提交区
public ListNode partition(ListNode head, int x) {
        ListNode dummy1 = new ListNode(-1);
        ListNode dummy2 = new ListNode(-1);
        ListNode p1 = dummy1, p2 = dummy2, p = head;
        while (p != null) {
            if (p.val < x) {
                p1.next = p;
                p1 = p1.next;
            } else {
                p2.next = p;
                p2 = p2.next;
            }
            p = p.next;
        }
        p2.next = null;
        p1.next = dummy2.next;
        return dummy1.next;
    }

思路拆解

问题本质：按节点值与 x 的关系稳定划分链表；每个节点都要检查，因此至少需要 O(n) 时间。

设计：用两个哑节点分别构造 < x 和 >= x 两条链，各自尾指针只向后追加当前节点；遍历结束后先将 >= x 链尾置空，再把两条链连接。

边界推演（2, 1, x=2）：读到 2 时追加到 >= 链；读到 1 时追加到 < 链；遍历完把 < 链尾连到 >= 链头，得到 1→2，原分区内顺序不变。若所有值都等于 x，< 链为空，结果直接从 >= 链头开始。空输入时两链均空，返回空。

复杂度：遍历每个节点一次，时间 O(n)；只用固定数量哑节点和指针，额外空间 O(1)。必须查看每个节点才能判断所属分区，所以时间已达下限。

套路沉淀

分区重连前保留后继并隔离节点

原地把链表节点分到多个结果链时，不能边遍历边覆盖 next 后仍依赖旧链推进；先保存待处理节点的原后继，再将当前节点接入对应尾部并断开旧链接，最后拼接各分区，避免遗漏节点或形成环。
