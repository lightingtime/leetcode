114. 二叉树展开为链表 (Flatten Binary Tree to Linked List)

难度：Medium ｜ 分类：链表

标签：栈、树、深度优先搜索、链表、二叉树

题目描述

给你二叉树的根结点 root ，请你将它展开为一个单链表：

展开后的单链表应该同样使用 TreeNode ，其中 right 子指针指向链表中下一个结点，而左子指针始终为 null 。

展开后的单链表应该与二叉树 先序遍历 顺序相同。

示例 1：

输入：root = [1,2,5,3,4,null,6]

输出：[1,null,2,null,3,null,4,null,5,null,6]

示例 2：

输入：root = []

输出：[]

示例 3：

输入：root = [0]

输出：[0]

提示：

树中结点数在范围 [0, 2000] 内

-100

写法 1 · 先序递归+链尾prev

时间 O(n)空间 O(h)内存 ≈ 42.5 MB用例 225/225

LC0114_FlattenBinaryTreeToLinkedList.java · 先序递归+链尾prev提交区
====
    TreeNode pre;
    public void flatten(TreeNode root) {
        if (root == null) {
            return;
        }
        TreeNode left = root.left;
        TreeNode right = root.right;
        if (pre != null) {
            pre.right = root;
        }
        root.left = null;
        pre = root;
        flatten(left);
        flatten(right);
    }
    // ====

二叉树展开为链表：先序递归+链尾prev尾插建链，无条件断开left、递归前暂存左右子树，O(n)/O(h)，一次Accepted（225/225）；进阶可Morris O(1)空间

写法 2 · Morris前驱法

LC0114_FlattenBinaryTreeToLinkedList.java · Morris前驱法提交区
    // ==== 提交代码开始 ====
    public void flatten(TreeNode root) {
        TreeNode cur = root;
        while (cur != null) {
            if (cur.left != null) {
                TreeNode next = cur.left;
                TreeNode pre = next;
                while (pre.right != null) {
                    pre = pre.right;
                }
                pre.right = cur.right;
                cur.left = null;
                cur.right = next;
            }

            cur = cur.right;
        }
    }
    // ==== 提交代码结束 ====

二叉树展开为链表：写法1先序递归+链尾prev（O(n)/O(h)），写法2 Morris前驱原地（O(n)/O(1)），均一次Accepted（225/225）

思路拆解

问题本质与解法选择

  • 题目要求把二叉树按先序遍历顺序展平成一条只用 right 指针串联的链表，所有 left 指针置空。
  • 关键观察：展平结果的顺序恰好就是先序遍历的顺序（根 → 左 → 右），因此可以边遍历边「尾插建链」。
  • 本仓库记录两种 Accepted 写法：写法 1 递归 + 链尾指针 prev（O(n)/O(h)）；写法 2 Morris 前驱原地法（O(n)/O(1)），空间更优。

写法 1：先序递归 + 链尾 prev（O(n)/O(h)）

  • prev 为什么是成员变量：void flatten(TreeNode root) 递归无法把「链尾」通过返回值传回上层；成员变量让所有递归调用共享同一份链尾状态（Java 参数是值传递，局部变量改完带不回去）。
  • prev 的语义：始终指向「已经展平好的链的最后一个节点」，初始为 null。
  • 每访问一个节点 root 做三步：
  1. 若 prev 非空，prev.right = root（把当前节点接到链尾；根节点没有前驱，跳过这一步）；
  2. root.left = null（无条件断开左指针，最终链上所有 left 都必须是 null）；
  3. prev = root（当前节点成为新链尾）。
  • 递归前必须先把 left / right 暂存到局部变量：第 2 步已经置空了 root.left；而展平左子树时 prev.right = 节点 会覆盖 root 原有的 right 指向，不暂存 right 会丢右子树。

写法 1 具体 case 推演（双孩子树 1/2/3）

  • 树：1 左孩子 2、右孩子 3，期望链 1 → 2 → 3，left 全为 null。
  • 初始 prev = null。
  • 访问 1：prev 为 null，跳过「接」；1.left = null；prev = 1。链：1。
  • 递归处理左子树，访问 2：prev=1，1.right = 2；2.left = null；prev = 2。链：1 → 2。
  • 递归处理右子树，访问 3：prev=2，2.right = 3；3.left = null；prev = 3。链：1 → 2 → 3。

写法 2：Morris 前驱原地法（O(n)/O(1)）

  • 核心：不额外用栈/递归，只靠改指针。维护 cur 从左到右扫描；只要 cur.left 非空，就把它搬到右边：
  1. next = cur.left，沿 next 的 right 一路走到「左子树最右节点」pre；
  2. pre.right = cur.right（原右子树整串接到左子树最右节点后面，保证先序顺序）；
  3. cur.left = null、cur.right = next（左子树整体搬到右侧，断开左指针）；
  4. cur = cur.right 继续。
  • 关键设计：把「左子树最右节点」当作桥，把右子树挂过去后左子树整体右移，这样不丢右子树也不需要栈保存。

写法 2 具体 case 推演（双孩子树 1/2/3）

  • 树：1 左孩子 2、右孩子 3。
  • cur = 1，1.left = 2 非空：next = 2，pre 沿 2 的 right 走（2.right 为 null）停在 2；2.right = 3；1.left = null；1.right = 2。结构变为 1 → 2 → 3。
  • cur = 2，2.left 为 null，直接 cur = 3；3.left 为 null，cur = null 结束。
  • 最终链 1 → 2 → 3，left 全为 null。

边界与细节

  • 空树：两个写法都直接结束（递归版 return，Morris 版 while 不进），合法。
  • 单节点：递归版根即链头无「接」动作；Morris 版 cur.left 为 null 直接结束。
  • 根节点 left 必须断开（写法 1 曾踩坑）：若把 root.left = null 放进 if (pre != null)，根会残留左指针，层序输出里 1 后面出现两个 2。
  • 写法 2 的 while 找最右节点：pre.right 必须走到 null 才停，且要先接右子树再断开/搬运，顺序反了会丢子树。

复杂度与下限论证

  • 时间 O(n)：每个节点被访问常数次。写法 1 每个节点递归一次；写法 2 里「找左子树最右节点」的总代价摊还 O(n)（每条边最多被跨过一次）。
  • 空间：写法 1 O(h)（递归栈，最坏单链 O(n)）；写法 2 O(1)（仅几个指针变量），达到空间下限。
  • 时间 O(n) 是下限：重排指针至少要看一遍所有节点。写法 2 同时达到时间与空间下限，为最优解。
