237. 删除链表中的节点 (Delete Node in a Linked List)

> https://leetcode.cn/problems/delete-node-in-a-linked-list/

难度：Medium ｜ 分类：链表

标签：链表

题目描述

有一个单链表的 head，我们想删除它其中的一个节点 node。

给你一个需要删除的节点 node 。你将 无法访问 第一个节点 head。

链表的所有值都是 唯一的，并且保证给定的节点 node 不是链表中的最后一个节点。

删除给定的节点。注意，删除节点并不是指从内存中删除它。这里的意思是：

给定节点的值不应该存在于链表中。

链表中的节点数应该减少 1。

node 前面的所有值顺序相同。

node 后面的所有值顺序相同。

对于输入，你应该提供整个链表 head 和要给出的节点 node。node 不应该是链表的最后一个节点，而应该是链表中的一个实际节点。

我们将构建链表，并将节点传递给你的函数。

输出将是调用你函数后的整个链表。

src/链表/LC0237_DeleteNodeInALinkedList.java提交区
public void deleteNode(ListNode node) {
        node.val = node.next.val;
        node.next = node.next.next;
    }

思路拆解

① 问题本质与解法选择理由

  • 只给要删除的节点 node、不给 head，拿不到前驱，「前驱.next = 后继」的标准删法不可用；node 又保证非末尾（必有后继可借）。
  • 解法核心：不删「当前节点」这个对象，而是让后继顶替它——把后继的值复制给当前节点，再把当前节点指向后继的后继，等效于当前节点消失、节点数减 1。

② 关键设计决策

  • node.val = node.next.val：后继的值顶替当前节点（链表值唯一，无需担心值冲突）。
  • node.next = node.next.next：跳过后继节点，链表长度减 1。
  • 两步缺一不可：只改值不改指针会残留后继节点（节点数不减）；只改指针不改值会让当前值残留。
  • 为什么能成立：题目保证 node 非末尾 → node.next 必非空，两步都不会空指针。

③ 边界与细节

  • 删除头节点：node=head，值覆盖后从原 head 遍历即新链表（无返回值的 void 原地修改）。
  • 删除倒数第二个节点：node.next 是末尾，node.next = null 收尾正确。
  • 两节点链表删头：node.val=后继值，node.next=null，链表剩 1 个节点。
  • 值范围 -1000..1000、节点数 2..1000：int 赋值无溢出，O(1) 操作不受规模影响。

④ 复杂度分析与下限论证

  • 时间 O(1)：只访问 node 与 node.next 两个节点，不遍历链表。
  • 空间 O(1)：无额外存储。
  • 最优性：必须至少修改 node（否则删不掉），一次赋值 + 一次改指针即完成，任何解法都要 Ω(1) 时间，达到下限；空间无额外需求，O(1) 最优。

⑤ 具体 case 推演：链表 [4,5,1,9]，删除 node=值为 5 的节点

  • node(5).val = node.next(1).val → node 变成 4→1→1→9（值 5 被 1 覆盖）。
  • node(1).next = node(1).next.next → 跳过原 1 节点，链表 4→1→9。
  • 结果 [4,1,9]，与示例一致；值 5 不再存在，节点数 4→3，前后顺序 4、1、9 保持不变。
