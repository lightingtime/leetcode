public int singleNumber(int[] nums) {
        int ans = 0;
        for (int num : nums) {
            ans ^= num;
        }
        return ans;
    }

只出现一次的数字：全员 XOR，成对抵消留唯一值，O(n)/O(1)，一次 Accepted（61/61）

思路拆解

### 问题本质与解法选择

  • 数组中除一个元素出现 1 次外，其余每个元素都恰好出现 2 次，目标是找出出现 1 次的那个。
  • 出现偶数次的元素可以互相抵消：异或满足 a ^ a = 0、0 ^ a = a，且交换律、结合律成立。把全部元素异或一遍，成对的元素两两抵消为 0，剩下恰好是唯一出现一次的元素。
  • 该方案同时满足题目的 O(n) 时间与 O(1) 额外空间要求；哈希表/计数方案空间是 O(n)，不符合题目约束。

### 关键设计决策

  • 状态：单个整数 ans，初始为 0（异或单位元）；每读一个元素执行 ans ^= num。
  • 不引入任何容器（数组、哈希表、集合都会破坏常量空间约束）。
  • 遍历完整个数组后 ans 即为答案。

### 具体 case 推演

示例 [2,2,1]：

  1. ans = 0 ^ 2 = 2
  2. ans = 2 ^ 2 = 0（两个 2 抵消）
  3. ans = 0 ^ 1 = 1 → 返回 1

示例 [4,1,2,1,2]：

  1. ans = 0 ^ 4 = 4
  2. ans = 4 ^ 1 = 5
  3. ans = 5 ^ 2 = 7
  4. ans = 7 ^ 1 = 6（与第 2 步的 1 抵消，剩 4 ^ 2）
  5. ans = 6 ^ 2 = 4 → 返回 4

单元素负数 [-7]：ans = 0 ^ (-7) = -7，负数按位异或与符号无关，同样正确。

### 边界与细节

  • 数组非空（约束长度 ≥ 1），无需处理空输入。
  • 目标值为 0 时（如 [0,1,1]），异或结果恰好为 0，与初值一致，不冲突。
  • 数值范围 ±30000，异或是按位运算、不做加法，无溢出风险。
  • 初值必须用 0（单位元）：0 ^ x = x，保证第一轮就能把元素原样纳入。

### 复杂度分析与最优性论证

  • 时间 O(n)：每个元素恰好参与一次异或；下界为 Ω(n)，必须看过每个元素才能确定答案，因此 O(n) 最优。
  • 空间 O(1)：仅一个整数变量；哈希表 O(n) 空间违反题目硬性约束，全员异或是同时达到时间与空间双下限的标准解。
