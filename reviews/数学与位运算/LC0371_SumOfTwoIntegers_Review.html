LC0371_SumOfTwoIntegers.java · XOR+AND 位运算迭代加法提交区
    public int getSum(int a, int b) {
        while (b != 0) {
            int carry = (a & b) << 1;
            a = a ^ b;
            b = carry;
        }
        return a;
    }

思路拆解

1. 问题本质与解法选择

本质：不用 + - 求整数和。二进制加法拆成两步：无进位加（本位）+ 进位，迭代到进位为 0。XOR 恰好是无进位加法（1⊕1=0 正是 1+1 的本位 0），AND 找出需要进位的位（1&1=1），左移一位送到更高位。负数在 Java 里是补码，补码相加就是普通二进制加法，位运算自然处理，无需特判。

2. 关键设计决策

  • 循环不变量：每轮开始时 a = 当前无进位加结果、b = 待传播进位；b == 0 时 a 即答案。
  • 更新顺序（本轮踩坑）：先算进位 carry = (a & b) << 1（用旧 a、旧 b），再 a = a ^ b，最后 b = carry。原则：覆盖某变量前它的旧值必须用完——若先更新 a，进位会拿「新 a」算，结果错误。
  • 最少一个临时变量：两个新值（本位、进位）都依赖旧的一对 (a,b)，至少需要 1 个暂存位；carry 就是唯一暂存位，无法再省。
  • 最多 32 轮（int 32 位），时间常数上界固定。

3. 边界与细节

  • 0+0：b=0 循环不进入，直接返回 a=0。
  • 相反数 -1+1=0：进位传播若干轮后归 0。
  • 进位链 7+9=16、-7-9=-16：多位连续进位由迭代逐轮消化。
  • 约束端点 ±1000 内全组合正确。

4. 具体 case 推演

Case C：1 + 2（01 + 10，1 轮）

5. 复杂度与最优性

  • 时间 O(1)：int 固定 32 位，循环最多 32 轮，每轮常数次位运算——这是位运算加法的标准最优形态（位数是常量，无法低于 O(1) 常数）。
  • 空间 O(1)：只有 a, b, carry 三个局部变量。
  • 下界论证：32 位整数加法至少要处理到最高位的进位，最多 32 轮；本解达到该常数上界，最优。
