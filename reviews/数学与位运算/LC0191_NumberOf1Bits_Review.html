题目描述

给定一个正整数 n，编写一个函数，获取一个正整数的二进制形式并返回其二进制表达式中 设置位 的个数（也被称为汉明重量）。

示例 1：

输入：n = 11

输出：3

解释：输入的二进制串 1011 中，共有 3 个设置位。

示例 2：

输入：n = 128

输出：1

解释：输入的二进制串 10000000 中，共有 1 个设置位。

示例 3：

输入：n = 2147483645

输出：30

解释：输入的二进制串 1111111111111111111111111111101 中，共有 30 个设置位。

public int hammingWeight(int n) {
        int ans = 0;
        while (n != 0) {
            ans++;
            n &= n - 1;
        }
        return ans;
    }

一次AC：n&=n-1 每次清掉最低位1，循环次数=1的个数；比逐位(n&1)+右移的恒32轮更优

思路拆解

问题本质与解法选择理由

统计正整数 n 的二进制中 1 的个数（汉明重量）。最直接是逐位检查：n&1 取最低位累加、n>>>=1 右移，恒跑 32 轮。优化方向：让循环次数与「1 的个数」挂钩而非固定 32 位。

利用位运算技巧 n &= n-1：n-1 会把 n 最低位的 1 变成 0、且把其右侧的所有 0 变成 1，与 n 相与后，最低位的 1 被清除、其余位不变。每次循环清掉一个 1，循环次数 = 1 的个数。

关键设计决策

决策写法理由
清除最低位1n &= n - 1一轮消掉一个 1，循环次数 = 1 的个数
计数ans++每清一个 1 计一次
终止while (n != 0)n 全 0 即所有 1 清完

数学原理（n & (n-1) 为何消最低位 1）：

  • n 二进制最低位的 1 位于位置 p，其右侧全是 0；
  • n-1：位置 p 的 1 变 0，右侧 0 全变 1，p 左侧不变；
  • n & (n-1)：p 位 = 1&0 = 0，右侧 = 0&1 = 0，p 左侧 1&1 不变 → 恰好消掉最低位的 1。

与逐位写法对比

写法循环次数适用
n&1 + >>>=1恒 32实现直观
n &= n-1= 1 的个数稀疏数快得多（如 0x10000000 只 1 轮）

两种均 O(1)（≤32），n&(n-1) 常数更小。

边界与细节

  • 约束 1..2^31-1：正整数，n 最高为 31 个 1（2^31-1）→ 循环 31 次。
  • 2 的幂（16=10000）：只 1 个 1 → 1 轮。
  • 0x55555555 交替位：16 个 1 → 16 轮。

具体 case 逐层推演

n=11（1011，期望 3）：

  • 轮1：n=1011，n-1=1010，n&(n-1)=1010，ans=1
  • 轮2：n=1010，n-1=1001，n&(n-1)=1000，ans=2
  • 轮3：n=1000，n-1=0111，n&(n-1)=0000，ans=3
  • n=0 退出，返回 3 ✓

n=16（10000，期望 1）：

  • 轮1：n=10000，n-1=01111，n&(n-1)=0，ans=1
  • 返回 1 ✓

复杂度与下限论证

  • 时间 O(k)：k = 1 的个数，≤32。每次位运算 O(1)。比逐位法（恒 32 轮）平均更优；SWAR 分治掩码（固定 5 轮无循环）是常数最小的进阶，同属 O(1)。
  • 空间 O(1)：仅一个计数变量。
