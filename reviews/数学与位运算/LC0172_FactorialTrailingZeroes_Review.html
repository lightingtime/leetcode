    public int trailingZeroes(int n) {
        int ans = 0;
        int i = 5;
        while (i <= n) {
            ans += n / i;
            i *= 5;
        }
        return ans;
    }

阶乘后的零：分层计数 n/5+n/25+…，一次 Accepted（500/500），O(log n)/O(1) 达进阶要求且最优

思路拆解

1. 问题本质与解法选择

n! 尾随零 = 因子 10 的个数 = min(因子 2 的个数, 因子 5 的个数)。2 的倍数远多于 5 的倍数，2 永远够用，所以答案 = n! 里因子 5 的个数。绝不能真算 n!（爆炸），要用数论计数：每个数含几个 5，等价于它能被 5、25、125…整除几次；把 1..n 里「5 的倍数个数 + 25 的倍数个数 + 125 的倍数个数 + …」加起来即得 5 的总数。层数每轮除 5，满足进阶要求的 O(log n)。

2. 关键设计决策

  • 状态：ans 累计 5 的个数；i 从 5 开始，每轮 i *= 5 推进到下一层（5、25、125…）。
  • 每层 ans += n / i：n/i 是 1..n 里 i 的倍数个数，每层补记「该层新增的那个 5」。
  • 终止：i > n 时没有 i 的倍数，停。
  • 数学依据：n! 含 5 个数 = Σ_{k≥1} floor(n / 5^k)。

3. 边界与细节

  • n < 5（0..4）：循环不进入，ans=0 ✓。
  • 25/125/625 倍数：多层贡献，靠多层 n/i 逐层补记（如 25 在 5 层记 1、25 层再记 1）。
  • 循环次数：n=10⁴ 时 i 序列 5,25,125,625,3125,15625，共 5 层，不会溢出 int（i 远小于 2³¹）。
  • 整除细节：n/i 是整数除法，天然向下取整。

5. 复杂度与最优性

  • 时间 O(log₅ n)：每层 n 缩小 5 倍，层数 O(log₅ n)，达到进阶「对数时间」要求。
  • 空间 O(1)：只有一个计数器，最优。
  • 下界论证：需要统计 n 中所有 5 的幂次贡献，至少遍历到 5^k ≤ n 的最大 k，层数 Ω(log₅ n)；本解每层常数时间，达到该下界，最优。
