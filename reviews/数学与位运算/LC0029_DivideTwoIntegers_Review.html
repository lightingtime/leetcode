写法 1 · 负数域统一+翻倍减法

时间 O(log^2(x))空间 O(1)内存 ≈ 40.9 MB用例 994/994

LC0029_DivideTwoIntegers.java · 负数域统一+翻倍减法提交区
    public int divide(int dividend, int divisor) {
        if (dividend == Integer.MIN_VALUE && divisor == -1) {
            return Integer.MAX_VALUE;
        }
        if (dividend == Integer.MAX_VALUE && divisor == 1) {
            return Integer.MAX_VALUE;
        }
        boolean negative = (dividend < 0 && divisor > 0) || (dividend > 0 && divisor < 0);
        dividend = dividend < 0 ? dividend : -dividend;
        divisor = divisor < 0 ? divisor : -divisor;
        int ans = 0;
        while (dividend <= divisor && dividend != 0) {
            int num = divisor;
            int time = 1;
            while (num >= (Integer.MIN_VALUE >> 1) && dividend < (num << 1)) {
                num <<= 1;
                time <<= 1;
            }
            ans += time;
            dividend -= num;
        }
        return negative ? -ans : ans;
    }

写法 2 · 预计算 2 幂表 + 从大到小试减

时间 O(log(x))空间 O(log(x))内存 ≈ 41.0 MB用例 994/994

LC0029_DivideTwoIntegers.java · 预计算 2 幂表 + 从大到小试减提交区
    public int divide(int dividend, int divisor) {
        if (dividend == Integer.MIN_VALUE && divisor == -1) {
            return Integer.MAX_VALUE;
        }
        if (dividend == Integer.MAX_VALUE && divisor == 1) {
            return Integer.MAX_VALUE;
        }
        boolean negative = (dividend < 0 && divisor > 0) || (dividend > 0 && divisor < 0);
        dividend = dividend < 0 ? dividend : -dividend;
        divisor = divisor < 0 ? divisor : -divisor;
        int ans = 0;
        List<Integer> list = new ArrayList<>();
        list.add(divisor);
        int num = divisor;
        while (num >= (Integer.MIN_VALUE >> 1) && dividend < (num << 1)) {
            num <<= 1;
            list.add(num);
        }
        while (dividend <= divisor && dividend != 0) {
            int i = list.size() - 1;
            // 处理成负数后，小于不能减，要拿到第一个大于被除数的除数
            while (i >= 0 && list.get(i) < dividend) {
                i--;
            }
            if (i < 0) {
                break;
            }
            dividend -= list.get(i);
            int time = 1 << i;
            ans += time;
        }
        return negative ? -ans : ans;
    }

两数相除：写法1 负数域+翻倍减法 O(log^2)；写法2 预计算 2^k 倍除数表+从大到小试减 O(log)，力扣均一次 Accepted（994/994）

思路拆解

1. 问题本质与解法选择

本质：禁止 * / % 的前提下求向零截断的整数商，且商可能触及 32 位边界。最朴素可行的替代是减法模拟（商 = 能从被除数里减掉多少个除数），但逐次减是 O(商)，商最大 2³¹ 必超时；所以用翻倍（二进制拆分）加速——任意整数都能拆成若干 2 的幂之和，从 1 倍除数开始翻倍找「最大可减块」，正好覆盖商的每一位。统一到负数域：MIN 的绝对值 2³¹ 超出 int 正半轴，取正会溢出；负半轴 [-2³¹, -1] 能装下所有输入取负后的值，除法符号规则不变。

2. 关键设计决策

  • 状态：dividend/divisor 转负数后的剩余被除数；ans 累计商；每轮内 num = divisor × 2^k（当前可减的最大块）、time = 2^k（该块含多少个 divisor）。
  • 翻倍终止条件（两条缺一不可）：① num >= MIN/2——num<<1 不溢出（溢出成正数后「负 < 正」恒真，比较失去意义）；② dividend < num<<1——翻倍后仍减得起才翻。
  • 同步翻倍：num <<= 1 时 time 必须 <<= 1（1→2→4→8…）。time 记录的是「减掉的 divisor 个数」，不是翻倍次数；只 time++ 会把商严重低估（这是本轮调试踩的坑）。
  • 符号：negative 记录原始两数是否异号，最后翻转商。
  • 溢出特判：MIN / -1 是全题唯一商超 int 的输入（= 2³¹），直接返回 MAX。

3. 边界与细节

  • MIN/1 = MIN：不触发特判，负数域正常算；商绝对值 = 2³¹，ans 累计溢出后由「取负溢出」恰好得到 MIN，结果正确但依赖溢出语义。
  • 向零截断：负数域减法自然截断（-7/2 → -3），无需额外处理。
  • |被除数| < |除数| → 0：外层 while 不进入。
  • 整除：dividend 恰好减到 0，dividend != 0 终止。
  • 翻倍安全线：MIN/2（-1073741824）用 Integer.MIN_VALUE >> 1（算术右移）或 / 2；>>> 1（无符号右移）得到的是正数 2³⁰，语义完全不同。

5. 复杂度分析与最优性

  • 时间 O(log²|x|)：外层每轮剩余至少减半，轮数 O(log|x|)；每轮翻倍探索 O(log|x|)。空间 O(1)。
  • 下限论证：任何算法至少读一遍所有位，Ω(log|x|) 是时间下界；O(log²) 可接受但不是最优——可预计算 2^k × divisor 表，从大到小逐位试减，把每轮探索摊平成 O(1)，整体降到 O(log|x|)。空间 O(1) 已达下限。

写法 2（当前最优，O(log x)）：预计算 2^k 倍除数表 + 从大到小试减

1. 问题本质与解法选择

写法 1 慢在每轮都对剩余被除数重新翻倍探索（每轮 O(logx)、共 O(logx) 轮 → O(log²x)）。改进：把 divisor 的翻倍序列一次性建成表 divisor × 2^k，然后从最大块往最小块逐个试减一次——每块只访问一次，总时间 O(logx)，达到时间下界。

2. 关键设计决策

  • 建表：num 从 divisor 开始翻倍，num <<= 1 后 add 进表；终止条件 num >= MIN/2（防 num<<1 溢出成非负数，这是写法 1 踩过的坑）。
  • 试减：从表尾（最大块）往表头，跳过绝对值过大的块（负数域 list[i] < dividend 即 |list[i]| > |dividend|，减不起），选中第一个 list[i] >= dividend 的块；dividend -= list[i]，ans += 1 << i（表下标 i 对应 2^i 倍）。
  • 溢出/符号/截断处理与写法 1 相同：MIN/-1 特判、负数域统一、negative 翻转、减法自然向零截断。

3. 边界与细节

  • 建表终止条件只取决于 divisor（翻到安全线为止）；如果还叠了 dividend < num<<1 的限制，等于按被除数裁剪表——小被除数时表短，试减照样正确，但语义上建表不该依赖 dividend。
  • ans += 1<<i 在 MIN/1（商 = 2³¹）时溢出，靠负数域 + 取负溢出恰好得到 MIN（与写法 1 相同，依赖溢出语义）。
  • 5/5：表 [-5]，i=0，time=1<<0=1，减后 dividend=0 → ans=1 ✓（写法 1 曾因 time 多算一倍在此输出 2）。

  • 时间 O(log|x|)：建表 O(log|x|) + 试减每块一次 O(log|x|)，达到下界（至少读一遍所有位）→ 最优。

套路沉淀

翻倍减法模拟的溢出防护

用翻倍（二进制拆分）做减法除法时，翻倍前必须先确认本次翻倍不会越界：负数域下 num<<1 翻过 MIN/2 后溢出成正数，使『负<正』恒真、减数和商全错；安全翻倍条件是 num*2 不越界且仍减得起。另注意商本身可能等于 2^31（MIN/1），累计商的变量也要做 32 位兜底。
