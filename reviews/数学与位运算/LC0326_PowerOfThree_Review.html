public boolean isPowerOfThree(int n) {
        if (n <= 0) {
            return false;
        }
        int max3 = 1162261467;
        return max3 % n == 0;
    }

一次AC：n>0 且 int 内最大 3 的幂 1162261467 能整除 n 即 3 的幂；注意 Java ^ 是异或不是幂

思路拆解

问题本质与解法选择理由

判断整数 n 是否为 3 的幂次方（n==3^x）。进阶要求不用循环/递归，所以要找 O(1) 判定。

数学观察：所有 3 的幂都是「int 内最大 3 的幂」的因数。int 上限 2^31-1，3^19=1162261467 是范围内最大的 3 的幂（3^20=3486784401 溢出）。任意 3^k(k≤19) 都能整除 3^19：3^19 / 3^k = 3^(19-k) 无余数。反过来，n 若不是 3 的幂（含 3 以外的质因数），就无法整除只有因数 3 的 3^19。因此 max3 % n == 0 ⟺ n 是 3 的幂，充要条件。

关键设计决策

决策写法理由
非正判定n <= 0 → false3^x 恒正；且 n=0 时 0 不能做除数会除零异常
基准常数max3 = 1162261467手算 3^19：从 1 逐次×3，停在再乘就超过 int 上限的那位
整除判定max3 % n == 0被除数 max3、除数 n；余数为 0 ⟺ n 是 3 的幂

易踩的坑

  • Java ^ 是异或不是幂：3 ^ 19 = 16，完全错误；写死常数而非运行时算幂，且 Math.pow 返回 double 有浮点精度问题，都不用。
  • n=0 的除零：必须先用 n<=0 拦截。

边界与细节

  • n=1：3^0，1162261467 % 1 = 0 → true。
  • n=3/9/27/81：1162261467 % 3^k = 0 → true。
  • 上限 3^19 本身：% 自身 = 0 → true。
  • n=45（5×3²）：含质因数 5，除不净 → false。
  • 负数、0、Integer.MIN_VALUE：n<=0 拦截 → false。

具体 case 逐层推演

n=81（3^4）：

  • 1162261467 % 81：3^19 / 3^4 = 3^15 = 14348907 整除 → 余 0 → true ✓

n=45：

  • 45 = 5×9，含因数 5；1162261467 质因数只有 3，除 45 必有余数 → false ✓

复杂度与下限论证

  • 时间 O(1)：一次取模运算，与 n 无关。数学法达到「无循环/递归」的进阶要求，是常数最优。
  • 空间 O(1)：仅一个常数。
