public int hammingDistance(int x, int y) {
        int t = x ^ y;
        int ans = 0;
        while (t != 0) {
            if ((t & 1) == 1) {
                ans++;
            }
            t >>>= 1;
        }
        return ans;
    }

x^y 差异掩码 + 逐位 popcount（&1 判断 + >>> 右移）；O(1)/O(1)，修无条件计数后 Accepted

思路拆解

问题本质：统计两个整数二进制表示中不同位的个数。逐位比较 x 和 y 需要固定 32 次且要处理对齐，而「异或」天然把不同位置 1、相同位置 0，于是问题转化为统计异或结果的 1 的个数（popcount）。

解法选择理由（位运算子类型）：

  • x ^ y 得到差异掩码：某位不同则为 1，相同则为 0。
  • 统计掩码中 1 的个数即汉明距离。
  • 不需要处理符号/对齐，负数的补码也由 ^ 和 popcount 统一处理（但本题约束 x、y 非负）。

关键设计：

  1. t = x ^ y。
  2. 循环统计：while (t != 0) 内先看最低位 (t & 1) == 1 才 ans++，然后 t >>>= 1（必须用逻辑右移 >>>，负数时算术右移 >> 会补 1 死循环）。
  3. 等价做法：Integer.bitCount(x ^ y) 一步完成。

具体 case 推演（x=1, y=4）：

  • t = 1 ^ 4 = 5（二进制 101）。
  • 第 1 轮：5 & 1 = 1，ans=1，t >>>= 1 → 2（10）。
  • 第 2 轮：2 & 1 = 0，不加，t >>>= 1 → 1（1）。
  • 第 3 轮：1 & 1 = 1，ans=2，t >>>= 1 → 0。
  • 返回 2 ✓。

边界与细节：

  • x == y：异或为 0，返回 0。
  • 0 与 Integer.MAX_VALUE（0..2^31-1 范围内最大距离）：31 个 1。
  • MAX 与 MAX-1：只有最低位不同，返回 1。
  • 0 与 2^30：只有最高位不同，返回 1。
  • 全部用例都在题目约束 0 <= x, y <= 2^31-1 内。

复杂度分析：

  • 时间 O(1)：最多循环 32 次（int 固定 32 位），bitCount 也是 O(1)。
  • 空间 O(1)：只有两个局部变量。
  • 已是最优：必须检查每一位是否不同，32 位是常数下界。
