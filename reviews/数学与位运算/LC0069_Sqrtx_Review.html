69. x 的平方根 (Sqrt(x))

题目描述

给你一个非负整数 x ，计算并返回 x 的 算术平方根 。

由于返回类型是整数，结果只保留 整数部分 ，小数部分将被 舍去 。

注意：不允许使用任何内置指数函数和算符，例如 pow(x, 0.5) 或者 x ** 0.5 。

示例 1：

输入：x = 4

输出：2

示例 2：

输入：x = 8

输出：2

解释：8 的算术平方根是 2.82842..., 由于返回类型是整数，小数部分将被舍去。

我的解法

src/数学与位运算/LC0069_Sqrtx.java提交区
public int mySqrt(int x) {
        int l = -1, r = 46341;
        while (l + 1 < r) {
            int mid = l + (r - l) / 2;
            if (mid * mid <= x) {
                // 左边一定满足
                l = mid;
            } else {
                r = mid;
            }
        }
        // 返回谁，上面的 if 里就更新谁
        return l;
    }

思路拆解

问题本质与解法选择理由

求非负整数 x 的平方根整数部分，禁止内置 sqrt/pow。平方根在 [0,x] 上随 x 单调不减，满足「二分判定」的单调性条件：要找最大的 mid 使 mid*mid <= x。这是典型的「求满足条件的最右位置」二分，O(log x) 优于逐个数尝试 O(√x)。

关键设计决策

决策写法理由
搜索区间l=-1, r=46341左哨兵 -1（保证可被替换）、右哨兵 46341（√(2^31-1)≈46340.95，向上取整作不可达边界）
循环条件l+1 < r左闭右开风格，l 指向「最后满足」，r 指向「首个不满足」
判定与移动mid*mid<=x → l=mid，否则 r=midl 始终满足、r 始终不满足，循环结束 l 即答案
防溢出r 取 46341 哨兵mid 最大 = (46339+46341)/2=46340，46340²=2147395600 < 2^31，mid*mid 用 int 安全

防溢出的关键论证

直接 mid*mid 在 int 下，mid 到 46341 时 46341² = 2147488281 溢出 int（>2^31-1）。但本写法 r 固定 46341 且从不把 mid 设成它：l+1<r 时 mid 是 l、r 的中点，l 最大 46340 时 mid=(46339+46341)/2=46340。所以 mid 恒 ≤46340，平方不溢出。这是「用哨兵天然避开溢出」而不是靠类型转换。

边界与细节

  • x=0：l=-1，mid=(−1+46341)/2=23170，23170²>x → r=23170；不断二分，最终 l=0（0²<=0），返回 0。
  • x=1：l 收敛到 1（1²<=1），返回 1。
  • 完全平方 x=16：l 收敛到 4，返回 4。
  • 上限 x=2^31-1：√≈46340.95，l 收敛 46340，返回 46340。

具体 case 逐层推演

x=8（√≈2.828，期望 2）：

  • l=-1, r=46341；mid=23170，23170²>8 → r=23170
  • 二分快速收缩到小区间：…最终 l=2, r=3
  • mid=2，2²=4≤8 → l=2
  • l+1=3=r，循环结束，返回 l=2 ✓

x=15（期望 3）：

  • 收敛到 l=3, r=4：mid=3，3²=9≤15 → l=3
  • l+1=4=r 结束，返回 3 ✓（4²=16>15，r=4 正确排除）

复杂度与下限论证

  • 时间 O(log x)：二分每次区间减半，区间 [−1,46341] 约 2^16 大小，约 16 轮。判定平方根的经典最优（比 O(√x) 的逐个试探快一个量级；牛顿迭代同阶但实现复杂）。
  • 空间 O(1)：仅三个整型变量，理论最低。

套路沉淀

哨兵二分防溢出

求满足条件的最右位置（如 mid*mid<=x）：用 l=-1 可替换哨兵 + r=不可达上界哨兵，l+1<r 循环；把 r 定在答案+1 可让 mid 永远不超过安全值，mid*mid 用 int 也不溢出，省去类型转换
