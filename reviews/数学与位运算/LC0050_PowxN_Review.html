写法 1 · 递归分治快速幂（long 承接）

时间 O(log n)空间 O(log n)内存 ≈ 46.3 MB用例 307/307

LC0050_PowxN.java · 递归分治快速幂（long 承接）提交区
    public double myPow(double x, int n) {
        long N = n;
        return helper(x, N);
    }

    private double helper(double x, long n) {
        if (n == 0) {
            return 1.0;
        }
        if (n < 0) {
            return 1 / helper(x, -n);
        }
        boolean odd = (n & 1) == 1;
        double half = helper(x, n / 2);
        double ans = half * half;
        ans = odd ? ans * x : ans;
        return ans;
    }

写法 2 · 迭代二进制拆分快速幂

时间 O(log n)空间 O(1)内存 ≈ 46.4 MB用例 307/307

LC0050_PowxN.java · 迭代二进制拆分快速幂提交区
    public double myPow(double x, int n) {
        long N = n;
        return N > 0 ? helper(x, N) : 1 / helper(x, -N);
    }

    private double helper(double x, long n) {
        if (n == 0) {
            return 1.0;
        }
        double ans = 1;
        while (n != 0) {
            if ((n & 1) == 1) {
                ans *= x;
            }
            x *= x;
            n >>= 1;
        }

        return ans;
    }

思路拆解

1. 问题本质与解法选择

本质：整数指数幂，n 可达 ±2³¹，O(n) 连乘不可行（21 亿次）。选择分治快速幂：xⁿ 每层把指数减半，层数只有 O(log n)。数学依据：n 偶数时 xⁿ = (x^(n/2))²，n 奇数时再乘一个 x。指数减半意味着任何 n 都能在约 31 层内算完，覆盖 n 的二进制每一位。

2. 关键设计决策

  • long 承接 n：题目签名是 int n，但 n = MIN 时 -n = 2³¹ 超出 int；方法内先 long N = n，取负、除 2 全在 long 域做，递归辅助方法参数也用 long（-MIN = 2147483648L 合法）。
  • half 只算一次：myPow(x, n/2) 是确定性的，先存局部变量再自乘；避免重复计算，也因此不需要 map 缓存——省掉了「缓存键只有 n 不含 x 导致跨输入串数据」的隐患。
  • 奇偶判断 (n & 1) == 1；n / 2 整除向零。
  • 负数指数：n < 0 时 1 / helper(x, -n)，在 long 域取负不溢出。
  • 出口：n == 0 返回 1。

3. 边界与细节

  • n = MIN：-n = 2147483648L 合法；x = 2 时 2^(2³¹) 上溢 double 为 +Infinity，1/Infinity = 0.0，恰好符合结果 0。
  • x = 0, n > 0：0ⁿ = 0（约束保证 x=0 时 n 必为正）。
  • x = ±1：任意大 n 结果恒为 1 或 -1（按 n 奇偶），long 域安全。
  • 精度：double 乘法累积误差在 1e-9 容差内，题目结果范围 [-10⁴, 10⁴]。
  • n = 0：非零底数返回 1。

5. 复杂度与最优性

  • 时间 O(log n)：每层 n 减半。下界论证：n 的二进制表示有 O(log n) 位，任何基于乘法的算法至少要处理每一位 → O(log n) 是下界，已达最优。
  • 空间 O(log n)：递归调用栈（约 31 层）。可优化：迭代二进制拆分（每轮看 n&1 决定是否乘 x^(2^k)，x 自乘、n 右移）→ O(log n) 时间 + O(1) 空间，无调用栈、常数更小。

写法 2（迭代版，O(log n) 时间 / O(1) 空间）：二进制拆分快速幂

1. 数学本质

一条法则打底：同底数幂乘法 x^a · x^b = x^(a+b)。把指数 n 拆成二进制 n = Σ bit_k·2^k，代入幂运算得 x^n = ∏ x^(2^k)（只在 bit_k=1 的 k 上乘）。于是问题变成「n 的哪些二进制位为 1，就把对应的 x^(2^k) 乘起来」。而 x^(2^k) 序列由反复平方得到：x, x², x⁴, x⁸, …，每项 = 前一项的平方。

2. 关键设计决策

  • 状态：ans（累乘结果，初始 1 乘法单位元）；x 每轮自乘推进 x^(2^k)；n 右移逐位查看。
  • 迭代三件套：(n & 1) == 1 查当前位 → ans *= x；无条件 x *= x 推进；n >>= 1 移位。n == 0 终止。
  • long N 承接 n：n = MIN 时 -n = 2³¹ 超出 int，转 long 后取负/移位安全；负数指数最后 1 / helper(x, -N)。
  • 空间 O(1)：无递归栈，比写法 1 的 O(log n) 更优。

3. 边界与细节

  • ans 初始必须为 1（乘法单位元）——写成 0 会导致累乘恒为 0、负数分支出现 Infinity/NaN（本轮调试踩坑）。
  • n = MIN：x = 2 时 2^(2³¹) 上溢 double 为 +Infinity，1/Infinity = 0.0。
  • x = 0, n > 0：位运算循环里 ans *= 0，最终 0 ✓。
  • x = ±1：任意大 n 恒为 ±1。
  • 冗余出口 if (n == 0) return 1.0 无害（while 不执行时返回 ans=1），可留可删。

5. 复杂度与最优性

  • 时间 O(log n)：n 的二进制位数 O(log n)，每位一次乘法；达到下界（任何算法需处理每一位）。
  • 空间 O(1)：只有几个局部变量，比写法 1 的递归栈 O(log n) 更优，是本题最优形态（时间下界 + 常数空间）。
