我的解法

思路：Boyer-Moore 投票算法。维护一个候选值 cur 和一个计数器 cnt； 遍历数组时，遇到与候选相同的元素就 cnt++，不同就 cnt--；计数器归零时换当前元素为新候选。 由于多数元素出现次数超过 ⌊n/2⌋，经过两两抵消后它一定会留在候选位。

时间 O(n) 空间 O(1) 单遍扫描 命中进阶要求

src/LC0169_MajorityElement.java提交区
public int majorityElement(int[] nums) {
    int cnt = 1;
    int cur = nums[0];
    for (int i = 1; i < nums.length; i++) {
        if (cur != nums[i]) {
            cnt--;
            if (cnt <= 0) {
                cur = nums[i];
                cnt = 1;
            }
        } else {
            cnt++;
        }
    }
    return cur;
}

题目保证数组非空且一定存在多数元素，因此从 nums[0] 起步的写法安全；提交区即为上面这一段。

算法判定：Boyer-Moore 投票，已是最优

  • 时间复杂度 O(n)：至少要遍历每个元素一次才能判断多数，O(n) 是本题下限。
  • 空间复杂度 O(1)：只用候选值 + 计数器，不依赖哈希表或排序，正是进阶要求。
  • 正确性：多数元素数量 > ⌊n/2⌋，任意两两抵消后剩余的一定是它；本题保证存在，所以无需再做验证阶段。
