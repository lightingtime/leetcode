169. 多数元素 (Majority Element)

> https://leetcode.cn/problems/majority-element/

难度：Easy ｜ 分类：哈希表

标签：数组、哈希表、分治、计数、排序

题目描述

给定一个大小为 n 的数组 nums ，返回其中的多数元素。多数元素是指在数组中出现次数 大于 ⌊ n/2 ⌋ 的元素。

你可以假设数组是非空的，并且给定的数组总是存在多数元素。

示例 1：

输入：nums = [3,2,3]

输出：3

示例 2：

输入：nums = [2,2,1,1,1,2,2]

输出：2

提示：

n == nums.length

1 4

-109 9

输入保证数组中一定有一个多数元素。

进阶：尝试设计时间复杂度为 O(n)、空间复杂度为 O(1) 的算法解决此问题。

    public int majorityElement(int[] nums) {
        int a = nums[0];
        int count = 1;
        for (int i = 1; i < nums.length; i++) {
            if (nums[i] == a) {
                count++;
            } else {
                count--;
            }
            if (count == 0) {
                a = nums[i];
                count = 1;
            }
        }

        return a;
    }

public int majorityElement(int[] nums) {

        int cnt = 1;
        int cur = nums[0];
        for (int i = 1; i < nums.length; i++) {
            if (cur != nums[i]) {
                cnt--;
                if (cnt <= 0) {
                    cur = nums[i];
                    cnt = 1;
                }
            } else {
                cnt++;
            }
        }
        return cur;
    }

思路拆解

问题本质：找出现次数超过 n/2 的元素。排序后取中位数或哈希计数都能做，但最优是摩尔投票（Boyer-Moore）：O(n) 时间、O(1) 空间。

关键设计：把当前候选记为 cur、计数 cnt。遍历时遇到相同元素 cnt++，不同元素 cnt--；cnt 归零说明候选在已扫描区间内不占优势，放弃它并换当前元素重新计数。因为众数出现超过一半，正负相消之后最后留下的必是众数。

边界：cnt 归零后要立即重置为 1 再换候选（代码里 cnt<=0 时 cur=nums[i]、cnt=1），否则计数起点错一位；结论依赖「严格多数」存在，题目已保证。

复杂度：O(n) 时间、O(1) 空间，是本题下限；不需要任何哈希表或排序。
