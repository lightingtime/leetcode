题目描述

给你四个整数数组 nums1、nums2、nums3 和 nums4 ，数组长度都是 n ，请你计算有多少个元组 (i, j, k, l) 能满足：

0

nums1[i] + nums2[j] + nums3[k] + nums4[l] == 0

示例 1：

输入：nums1 = [1,2], nums2 = [-2,-1], nums3 = [-1,2], nums4 = [0,2]

输出：2

解释：

两个元组如下：

  1. (0, 0, 0, 1) -> nums1[0] + nums2[0] + nums3[0] + nums4[1] = 1 + (-2) + (-1) + 2 = 0
  2. (1, 1, 0, 0) -> nums1[1] + nums2[1] + nums3[0] + nums4[0] = 2 + (-1) + (-1) + 0 = 0

示例 2：

输入：nums1 = [0], nums2 = [0], nums3 = [0], nums4 = [0]

输出：1

public int fourSumCount(int[] nums1, int[] nums2, int[] nums3, int[] nums4) {
        Map<Integer, Integer> map = new HashMap<>();
        int ans = 0;
        for (int i = 0; i < nums1.length; i++) {
            for (int j = 0; j < nums2.length; j++) {
                map.merge(nums1[i] + nums2[j], 1, Integer::sum);
            }
        }
        for (int i = 0; i < nums3.length; i++) {
            for (int j = 0; j < nums4.length; j++) {
                int a = -(nums3[i] + nums4[j]);
                ans += map.getOrDefault(a, 0);
            }
        }
        return ans;
    }

nums1+nums2 全部两两和对存入 map 计数；nums3+nums4 两两求和对取负查 map 累加答案；O(n²)/O(n²)，一次 Accepted

思路拆解

问题本质：统计四个数组中满足 a+b+c+d==0 的下标组合数。朴素四层循环是 O(n⁴)，n=200 时约 16 亿次，不可接受。

解法选择理由（两两分组 + 哈希计数）：

  • 把四个数组拆成两组：A=nums1+nums2 的所有两两和，B=nums3+nums4 的所有两两和。原条件 a+b+c+d==0 等价于 (a+b) == -(c+d)。
  • 第一遍：把 A 中每个和出现的次数登记进 HashMap（值 → 次数）。
  • 第二遍：对 B 中每个和，查询 map 里 -(c+d) 的计数并累加——每个匹配的 B 和对应多少个 A 和，就贡献多少个四元组。
  • 复杂度从 O(n⁴) 降到 O(n²)：每遍都是 n² 个和，哈希查询平均 O(1)。

关键设计决策：

  1. 第一遍用 map.merge(a+b, 1, Integer::sum) 统计每个两两和的出现次数（重复和要累计，因为不同下标组合是不同四元组）。
  2. 第二遍对每个 c+d，用 map.getOrDefault(-(c+d), 0) 累加 ans——不存在时按 0，不用判空。
  3. 顺序：先把 A 全量登记完再查 B，两组独立，不存在「先查后登记」顺序问题（与单数组前缀和不同）。
  4. 溢出安全：a+b 最大 2^28+2^28=2^29，-(c+d) 最小 -(2^29)，都在 int 范围内；答案最大 n⁴=1.6×10⁹ < 2^31-1，int 可容纳。

具体 case 推演：

示例1：nums1=[1,2], nums2=[-2,-1], nums3=[-1,2], nums4=[0,2]（期望 2）

第一遍（登记 nums1+nums2）：

011+(-1)=0{-1:1, 0:1}
102+(-2)=0{-1:1, 0:2}
112+(-1)=1{-1:1, 0:2, 1:1}

第二遍（查询 -(c+d)）：

klc+d查询 -(c+d)ans
00-1+0=-11 → 11

边界5（全 0，n=200）：A 里所有和都是 0，map={0:40000}；B 里 40000 个和都是 0，查询 -0 → 40000，ans = 40000×40000 = 1,600,000,000 ✓（int 不溢出）

边界4（重复组合）：nums1=[1,1], nums2=[-1,-1] → A 中 -... 计算：4 个和都是 0，map={0:4}；B=nums3+nums4=[0] 和 0，查询 4 → ans=4 ✓

边界与细节：

  • n=1：A/B 各 1 个和，直接配对。
  • 无解：map 查询全是 0。
  • 端点值：2^28+2^28 与 -(2^28+2^28) 都在 int 范围。
  • 全 0 上限：答案 16 亿不溢出，但要求用 int 累加即可。

复杂度分析：

  • 时间 O(n²)：两遍各 n² 个和，每步 map 操作均摊 O(1)。
  • 空间 O(n²)：map 最多存 n² 个不同的两两和。
  • 最优性：把 4 个数组分成 2+2 是信息论上的标准分治；O(n²) 时间是最优（任何算法至少要枚举一组两两和才能覆盖所有组合），O(n²) 空间与时间同级，可接受。
