49. 字母异位词分组 (Group Anagrams)

> https://leetcode.cn/problems/group-anagrams/

难度：Medium ｜ 分类：哈希表

标签：数组、哈希表、字符串、排序

题目描述

给你一个字符串数组，请你将 字母异位词 组合在一起。可以按任意顺序返回结果列表。

示例 1:

输入: strs = ["eat", "tea", "tan", "ate", "nat", "bat"]

输出: [["bat"],["nat","tan"],["ate","eat","tea"]]

解释：

在 strs 中没有字符串可以通过重新排列来形成 "bat"。

字符串 "nat" 和 "tan" 是字母异位词，因为它们可以重新排列以形成彼此。

字符串 "ate" ，"eat" 和 "tea" 是字母异位词，因为它们可以重新排列以形成彼此。

示例 2:

输入: strs = [""]

输出: [[""]]

示例 3:

输入: strs = ["a"]

输出: [["a"]]

提示：

LC0049_GroupAnagrams.java · 计数编码键 + 哈希表提交区
public List<List<String>> groupAnagrams(String[] strs) {
    Map<String, List<String>> map = new HashMap<>();
    for (String str : strs) {
        String key = getKey(str);
        map.computeIfAbsent(key, k -> new ArrayList<>()).add(str);
    }
    return map.values().stream().toList();
}

private String getKey(String str) {
    int[] count = new int[26];
    for (char c : str.toCharArray()) {
        count[c - 'a']++;
    }
    StringBuilder sb = new StringBuilder();
    for (int i = 0; i < count.length; i++) {
        sb.append(i + 'a').append(count[i]);
    }
    return sb.toString();
}

思路拆解

问题本质：把「互为字母异位词」的字符串归到同一组。异位词 = 相同字符多重集合（与排列顺序无关），所以核心是把「等价关系」转成「相同键」。

解法选择理由：归组需要 O(1) 查找，用哈希表；键有两条路线——① 排序后的字符串（每串 O(k log k)）；② 字符计数编码（每串 O(k)）。计数编码把 26 个字母计数拼成固定格式，达到线性最优。

关键设计决策：

  • 键 = 逐字符统计次数后拼接「字母+次数」，如 aabbbc → a2b3c1；同字符多重集合必得同键，异位词必然同组。
  • 编码必须带次数：只拼字母会漏次数（aab 与 ab 都变 ab 而撞键）——一刷正是栽在「编码键遗漏次数」。
  • 用 computeIfAbsent(key, k -> new ArrayList<>()).add(str) 一步完成「取组/建组」，避免 containsKey 双查。

具体 case 推演（输入 ["eat","tea","tan","ate","nat","bat"]）：

字符串计数编码 key分组
eata1 e1 t1a1e1t1[eat, tea, ate]
teaa1 e1 t1a1e1t1↑
tana1 n1 t1a1n1t1[tan, nat]
atea1 e1 t1a1e1t1↑
nata1 n1 t1a1n1t1↑
bata1 b1 t1a1b1t1[bat]

边界与细节：空串 "" 计数全 0、编码为空串，仍独立成组（示例2）；全相同字符串同键同组；单字符、长度上限 100、数组上限 10^4 均只需线性时间，编码串长度 ≤ 26×4，不会膨胀。

复杂度下限论证：输出必须包含全部字符串（每个至少写一次），时间下界 Ω(L)；空间上所有分组必须存下所有字符串，Ω(L)。计数编码实现 O(L) 时间 + O(L) 空间，已达到下限，最优。
