166. 分数到小数 (Fraction to Recurring Decimal)

> https://leetcode.cn/problems/fraction-to-recurring-decimal/

难度：Medium ｜ 分类：哈希表

标签：哈希表、数学、字符串

题目描述

给定两个整数，分别表示分数的分子 numerator 和分母 denominator，以 字符串形式返回小数 。

如果小数部分为循环小数，则将循环的部分括在括号内。

如果存在多个答案，只需返回 任意一个 。

对于所有给定的输入，保证 答案字符串的长度小于 104 。

注意，如果分数可以表示为有限长度的字符串，则 必须 返回它。

示例 1：

输入：numerator = 1, denominator = 2

输出："0.5"

示例 2：

输入：numerator = 2, denominator = 1

输出："2"

示例 3：

输入：numerator = 4, denominator = 333

输出："0.(012)"

提示：

-231 31 - 1

denominator != 0

public String fractionToDecimal(int numerator, int denominator) {
        long a = numerator, b = denominator;
        if (a % b == 0) {
            return String.valueOf(a / b);
        }
        StringBuilder sb = new StringBuilder();
        if (a * b < 0) {
            sb.append("-");
        }
        a = Math.abs(a);
        b = Math.abs(b);
        sb.append(a / b).append(".");
        a %= b;
        Map<Long, Integer> map = new HashMap<>();
        while (a != 0) {
            map.put(a, sb.length());
            a *= 10;
            sb.append(a / b);
            a %= b;
            if (map.containsKey(a)) {
                int u = map.get(a);
                return String.format("%s(%s)", sb.substring(0, u), sb.substring(u));
            }
        }
        return sb.toString();
    }

思路拆解

问题本质：把分数 numerator/denominator 转成十进制小数字符串，循环节用括号标出。核心难点不是「算小数」，而是「检测循环节从哪开始、到哪里结束」——浮点数直接算会丢精度、也看不出循环。

解法选择理由（长除法 + HashMap）：

  • 长除法天然逐位产生十进制数字：每次 余数×10 ÷ 分母 得一位商、一个新余数。
  • 关键数学事实：一旦某个余数重复出现，之后的商序列必然完全重复——所以循环节检测 = 检测余数是否重复。
  • HashMap 记录「余数 → 它第一次出现时的小数位下标」，余数重复时，第一次出现的位置就是循环节起点，当前末尾就是终点，插入括号即可。
  • 全程整数运算（long），无精度丢失，还能覆盖 int 溢出。

关键设计决策：

  1. long 防溢出：numerator/denominator 先转 long。经典反例 -2^31 / -1 = 2^31 超出 int；Math.abs(Integer.MIN_VALUE) 在 int 下仍是负数，必须 long。
  2. 整除提前返回：a % b == 0 时结果是整数，不加小数点，直接返回 String.valueOf(a / b)（如 2/1="2"、0/5="0"）。
  3. 符号处理：先判 a * b < 0（异号）就在最前面加 "-"，再对 a、b 取绝对值；这样负号只出现一次。
  4. 整数部分 + "."：sb.append(a/b + ".")，然后 a %= b 进入小数部分模拟。
  5. 长除法循环：map.put(a, sb.length()) 存余数与当前小数位起点（直接用字符串长度当位置，正好是循环节插入点）；a *= 10 放大 10 倍；sb.append(a / b)；a %= b；若新余数已在 map 中，u=map.get(a)，返回 sb[0..u) + "(" + sb[u..] + ")"。
  6. 退出条件：a == 0 表示除尽（有限小数）；余数重复表示循环（提前 return）。

具体 case 推演：

4/333（期望 0.(012)，纯循环）：

轮余数 a（进入时）map 记录a×10商新余数命中?
144→240040否
24040→3400167否
36767→467024是！u=2

sb="0.012"，u=2 → "0." + "(" + "012" + ")" = "0.(012)" ✓

1/6（期望 0.1(6)，混循环）：

轮余数 amap 记录a×10商新余数命中?
111→21014否
244→34064是！u=3

sb="0.16"，u=3 → "0.1" + "(" + "6" + ")" = "0.1(6)" ✓（循环节不是从第一位开始，map 精确记录了起点）

1/8（期望 0.125，有限小数）：a=1 → 商0 余1；×10=10 商1 余2；×10=20 商2 余4；×10=40 商5 余0 → a==0 退出，返回 "0.125" ✓

-4/333（期望 -0.(012)）：a*b<0 → 先 append "-"，abs 后同 4/333 → "-0.(012)" ✓

-2147483648 / -1（期望 2147483648）：a%b==0 → String.valueOf(2147483648L) → "2147483648" ✓（int 会溢出，long 不会）

边界与细节：

  • 0/5：整除分支返回 "0"，不会输出 "0.0"。
  • 分母为 MIN_VALUE：abs 后 2147483648L，long 安全；MIN/MIN=1。
  • a *= 10 后最大约 2^34（abs 后的 a < 2^31），long 无溢出。
  • map value 直接用 sb.length() 而非单独计数器——省一个变量，且正好是插入括号的位置。
  • 题目保证答案长度 < 10^4，循环不会无限跑。

复杂度分析：

  • 时间 O(L)：L 为结果字符串长度，每位小数一次常数操作；L < 10^4。
  • 空间 O(L)：HashMap 存不同余数（最多 L 个）+ StringBuilder。
  • 最优性：每个小数位至少产生一次，O(L) 时间/空间都是下限；长除法是十进制展开的标准最优做法。
