560. 和为 K 的子数组 (Subarray Sum Equals K)

> https://leetcode.cn/problems/subarray-sum-equals-k/

难度：Medium ｜ 分类：哈希表

标签：数组、哈希表、前缀和

题目描述

给你一个整数数组 nums 和一个整数 k ，请你统计并返回 该数组中和为 k 的子数组的个数 。

子数组是数组中元素的连续非空序列。

示例 1：

输入：nums = [1,1,1], k = 2

输出：2

示例 2：

输入：nums = [1,2,3], k = 3

输出：2

LC0560_SubarraySumEqualsK.java · 前缀和 + 哈希计数提交区
int ans = 0;
        int sum = 0;
        Map<Integer, Integer> map = new HashMap<>();
        map.put(0, 1);
        for (int num : nums) {
            sum += num;
            ans += map.getOrDefault(sum - k, 0);
            map.merge(sum, 1, Integer::sum);
        }
        return ans;

和为K的子数组：前缀和之差 + 哈希计已见前缀，先查后登记，O(n)/O(n)，两次 Accepted（93/93），merge 简化版

思路拆解

问题本质与解法选择

  • 连续子数组的和可以用两个前缀和之差表示：sum(nums[i..j]) = prefix[j] - prefix[i-1]（约定 A：prefix[i]=nums[0..i] 的和，虚拟 prefix[-1]=0）。
  • 统计和为 k 的子数组 ⇔ 统计「两个前缀和之差为 k」的有序对。
  • 哈希表把 O(n^2) 枚举降到 O(n)：map 记录「已出现过的前缀和 → 次数」，每轮查 prefix[i]-k、登记 prefix[i]。
  • 数组含负数，滑动窗口的和不单调、会漏/错；前缀和之差公式不依赖单调性，天然适用。

关键设计决策

  • 状态：prefix 数组 + map（已见前缀频次，初始 {0:1} 代表虚拟 prefix[-1]，负责从下标 0 开始的子数组）。
  • 每轮两件事、顺序固定：先查 prefix[i]-k 累加答案，再登记当前 prefix[i]。
  • 顺序不能反：先登记会把「当前前缀自己」当成之前出现过的前缀，k=0 时把空子数组也数进去。
  • 键的语义：查询目标是 prefix[i]-k，登记键永远是当前 prefix[i]，两者不可混（曾因此反复踩坑，见套路 #38）。

具体 case 推演

[1,1,1]、k=2（prefix=[1,2,3]，map 初始 {0:1}）：

  1. i=0：查 1-2=-1 → 0；登记 1:1。
  2. i=1：查 2-2=0 → 命中虚拟 0 → ans=1（子数组 [0,1]）；登记 2:1。
  3. i=2：查 3-2=1 → 命中 prefix[0] → ans=2（子数组 [1,2]）；登记 3:1。
  4. 答案 2 ✓

[1,-1,1,-1]、k=0（prefix=[1,0,1,0]，map 初始 {0:1}）：

  1. i=0：查 1 → 0；登记 1:1。
  2. i=1：查 0 → 命中虚拟 → ans=1（[0,1]）；登记 0:2。
  3. i=2：查 1 → 命中 prefix[0] → ans=2（[1,2]）；登记 1:2。
  4. i=3：查 0 → 命中 2 次（虚拟 + prefix[1]）→ ans=4（[2,3] 和 [0,3]）；登记 0:3。
  5. 答案 4 ✓

边界与细节

  • 单元素 [5]、k=5：初始 {0:1} 让查 prefix[0]-k=0 命中，数到子数组 [0]。
  • k=0：必须严格先查后登记，否则把当前前缀自己数进去（多算空子数组）。
  • 全 0 数组：前缀和大量重复，map 计数正确反映所有组合（n=3 得 6 个子数组）。
  • 无匹配：查不到返回 0，map 照常登记，不影响后续。

复杂度分析与最优性论证

  • 时间 O(n)：一趟前缀构建 + 一趟扫描，每轮常数次哈希操作；下界 Ω(n)，必须读每个元素，故最优。
  • 空间 O(n)：map 最多存 n 个不同前缀和的频次；频次计数没有 O(1) 空间的等价做法（必须记住每种前缀出现过几次），因此 O(n) 空间是前缀和计数题的标准最优。

套路沉淀

子数组和=前缀和之差：map 计已见前缀，先查后登记

map 存「已出现的前缀和 → 次数」；单层循环里先查 prefix[j]-k 累加答案，再登记当前 prefix[j]（顺序不能反，否则会把空子数组或当前前缀算进去）；初始 map 放入空前缀 0（约定 A 是虚拟 prefix[-1]、约定 B 是 prefix[0]），否则漏掉所有从下标 0 开始的子数组；查询目标是 prefix[j]-k，登记键永远是当前前缀 prefix[j]，两者不可混
