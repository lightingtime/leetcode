73. 矩阵置零 (Set Matrix Zeroes)

> https://leetcode.cn/problems/set-matrix-zeroes/

难度：Medium ｜ 分类：哈希表

标签：数组、哈希表、矩阵

题目描述

给定一个 m x n 的矩阵，如果一个元素为 0 ，则将其所在行和列的所有元素都设为 0 。请使用 原地 算法。

示例 1：

输入：matrix = [[1,1,1],[1,0,1],[1,1,1]]

输出：[[1,0,1],[0,0,0],[1,0,1]]

示例 2：

输入：matrix = [[0,1,2,0],[3,4,5,2],[1,3,1,5]]

输出：[[0,0,0,0],[0,4,5,0],[0,3,1,0]]

提示：

m == matrix.length

n == matrix[0].length

public void setZeroes(int[][] matrix) {
        int m = matrix.length;
        int n = matrix[0].length;
        boolean flagCol0 = false, flagRow0 = false;
        for (int i = 0; i < m; i++) {
            if (matrix[i][0] == 0) {
                flagCol0 = true;
                break;
            }
        }
        for (int j = 0; j < n; j++) {
            if (matrix[0][j] == 0) {
                flagRow0 = true;
                break;
            }
        }
        for (int i = 1; i < m; i++) {
            for (int j = 1; j < n; j++) {
                if (matrix[i][j] == 0) {
                    matrix[0][j] = 0;
                    matrix[i][0] = 0;
                }
            }
        }
        for (int i = 1; i < m; i++) {
            for (int j = 1; j < n; j++) {
                if (matrix[i][0] == 0 || matrix[0][j] == 0) {
                    matrix[i][j] = 0;
                }
            }
        }
        if (flagCol0) {
            for (int i = 0; i < m; i++) {
                matrix[i][0] = 0;
            }

        }
        if (flagRow0) {
            for (int j = 0; j < n; j++) {
                matrix[0][j] = 0;
            }
        }
    }

思路拆解

问题本质：矩阵中每个 0 会「传染」它所在的行和列——所有含 0 的行要整行置 0，所有含 0 的列要整列置 0；需要原地完成，不能边扫边改（否则会把「原本非 0 的行/列」误判成含 0）。

解法选择理由（首行首列标记，O(1) 空间）：

  • O(mn) 拷贝太浪费；O(m+n) 用两个 boolean 数组记录「行 i 有 0 / 列 j 有 0」是直观改进，但仍不是进阶要求。
  • 关键观察：标记「哪些行/列有 0」只需要 m+n 个布尔位，而矩阵自己的第 0 行和第 0 列恰好有 m+n 个格子——让首行存「对应列是否有 0」，首列存「对应行是否有 0」，就把额外空间压到 O(1)。
  • 代价：首行/首列本身也会被当作标记区污染，所以必须先用两个布尔提前记住「首行/首列原本有没有 0」，最后再还原。

关键设计决策：

  1. flagCol0 / flagRow0：先单独扫描首列、首行，记录「首列原本有 0 吗」「首行原本有 0 吗」——它们不能被内部标记覆盖掉。
  2. 内部扫描 (i>=1, j>=1)：遇到 matrix[i][j]==0，就在首行 matrix[0][j]=0、首列 matrix[i][0]=0 打标记。
  3. 按标记清内部：对 (i>=1, j>=1)，若 matrix[i][0]==0 或 matrix[0][j]==0 则 matrix[i][j]=0。
  4. 还原首行首列：若 flagCol0 则整列清 0；若 flagRow0 则整行清 0。
  5. 顺序很重要：先清内部、最后才处理首行首列，避免把「标记」和「结果」混在一起。

具体 case 推演：

边界6：[[1,0,3],[4,5,6],[7,8,0]]（0 在 (0,1) 和 (2,2)，期望 [[0,0,0],[4,0,0],[0,0,0]]）

阶段动作矩阵状态
初始-[[1,0,3],[4,5,6],[7,8,0]]
扫首列(0,0)=1≠0 → flagCol0=false不变
扫首行(0,1)=0 → flagRow0=true不变
内部扫描(2,2)=0 → 标记 matrix[0][2]=0、matrix[2][0]=0[[1,0,0],[4,5,6],[0,8,0]]
清内部(1,1): matrix[1][0]=4≠0 且 matrix[0][1]=0 → 清 0；(1,2): matrix[0][2]=0 → 清 0；(2,1): matrix[2][0]=0 → 清 0[[1,0,0],[4,0,0],[0,0,0]]
还原首行flagRow0=true → 第 0 行全 0[[0,0,0],[4,0,0],[0,0,0]] ✓

注意 (1,0)=4 保留：matrix[1][0] 是首列标记位（记录行 1 是否有 0），内部没有 0 落在行 1，所以它保持 4，且它不在任何 0 列，正确。

示例2：[[0,1,2,0],[3,4,5,2],[1,3,1,5]]：首列有 0 → flagCol0=true；首行有 0 → flagRow0=true；内部无 0；清内部时 matrix[i][0] 或 matrix[0][j] 全被标记 → 内部全 0；还原首行首列 → 全 0。期望 [[0,0,0,0],[0,4,5,0],[0,3,1,0]] ✓（内部无 0 时标记区保持 0，逻辑一致）。

边界7（含负数）：[[-1,0],[-2,-3]]：flagRow0=true（(0,1)=0），flagCol0=false；内部 (1,1)=-3 非 0；清内部 (1,1): matrix[1][0]=-2≠0 且 matrix[0][1]=0 → 清 0；还原首行 → [[0,0],[-2,0]] ✓。负数 -1/-2 不会被当成 0 误判，因为判断全部用 ==0。

边界与细节：

  • 单行/单列：内部循环 (i>=1,j>=1) 可能空转，但 flag 逻辑仍覆盖首行/首列。
  • 单元素 [0]：flagRow0/flagCol0 都为 true，最后行列都置 0，结果还是 [0]。
  • 全 0 / 无 0：分别全清 / 完全不变。
  • 值含负数：标记不依赖正负号，只认 ==0，负数安全。
  • 200×200 上限：O(mn) 遍历无压力。

复杂度分析：

  • 时间 O(mn)：两遍内部扫描 + 首行首列扫描，常数倍。
  • 空间 O(1)：只用两个 boolean。
  • 最优性：每个元素至少要读一次（Ω(mn)），时间已达下限；空间 O(1) 满足进阶，是最优解。
