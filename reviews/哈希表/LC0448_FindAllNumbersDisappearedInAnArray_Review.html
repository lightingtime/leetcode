public List<Integer> findDisappearedNumbers(int[] nums) {
        int index = 0;
        while (index < nums.length) {
            if (nums[index] != index + 1) {
                if (nums[index] == nums[nums[index] - 1]) {
                    index++;
                    continue;
                }
                int temp = nums[nums[index] - 1];
                nums[nums[index] - 1] = nums[index];
                nums[index] = temp;
            } else {
                index++;
            }
        }
        List<Integer> list = new ArrayList<>();
        for (int i = 0; i < nums.length; i++) {
            if (nums[i] != i + 1) {
                list.add(i + 1);
            }
        }
        return list;
    }

思路拆解

### 问题本质与解法选择

  • 值域 [1,n] 与下标 [0,n-1] 一一对应：下标 i 的正确住户是 i+1，值 x 的家在下标 x-1。
  • 原地归位（cyclic sort）把每个值送回自己的家；重复值换不进去就留在原位；全部归位后，下标 i 处不是 i+1 的位置，i+1 就是缺失数字。
  • 该方案 O(n) 时间、O(1) 空间，满足进阶要求；哈希集合标记空间 O(n)，不满足进阶。

### 关键设计决策

  • 映射关系：值 → 下标用 x - 1；下标 → 值用 i + 1，两个方向不能混。
  • 就位判断：nums[i] == i + 1。
  • 归位动作：把 nums[i] 与 nums[nums[i] - 1] 交换。
  • 重复守卫：若 nums[nums[i] - 1] == nums[i]，说明目标位已住同值，本位置处理完毕，i 前进。
  • 指针推进规则：只有两种情形前进——已就位、或目标位已有同值；交换后停留原地继续判断，保证每轮必有进展。

### 具体 case 推演

[2,2,1]（n=3）：

  1. i=0：nums[0]=2 != 1；目标位 nums[1]=2 已有同值 → 重复，i=1。
  2. i=1：nums[1]=2 == i+1 → 就位，i=2。
  3. i=2：nums[2]=1 != 3；目标位 nums[0]=2 != 1 → 交换 nums[2] 与 nums[0]，数组变 [1,2,2]，i 停在 2。
  4. i=2 再判断：nums[2]=2 != 3；目标位 nums[1]=2 已有同值 → 重复，i=3，循环结束。
  5. 二次扫描：下标 0、1 就位，下标 2 处是 2 != 3 → 缺失 3。答案 [3]。

[1,1]（n=2）：

  1. i=0：nums[0]=1 == i+1 → 就位，i=1。
  2. i=1：nums[1]=1 != 2；目标位 nums[0]=1 已有同值 → 重复，i=2，循环结束。
  3. 二次扫描：下标 1 处是 1 != 2 → 缺失 2。答案 [2]。

### 边界与细节

  • n=1：[1] 直接就位，返回空列表。
  • 全部相同 [5,5,5,5,5]：第一个 5 归位后其余都是重复，扫描得 [1,2,3,4]。
  • 已有序 [1,2,3]：全程就位推进，零交换。
  • 目标下标恒为 nums[i]-1，落在 [0,n-1]，不会越界（本次曾因写成 x+1 越界并死循环）。

### 复杂度分析与最优性论证

  • 时间 O(n)：每个元素至多被交换常数次（每次交换至少让一个值归位，交换总数 ≤ n），两次遍历各 O(n)；下界 Ω(n)，必须读每个元素，故最优。
  • 空间 O(1)：仅一个临时变量；结果列表由题目约定不算额外空间，满足「不使用额外空间」进阶要求。
