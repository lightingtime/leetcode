LC0448_FindAllNumbersDisappearedInAnArray.java · 原地归位（cyclic sort）提交区
    public List<Integer> findDisappearedNumbers(int[] nums) {
        int index = 0;
        while (index < nums.length) {
            if (nums[index] != index + 1) {
                if (nums[index] == nums[nums[index] - 1]) {
                    index++;
                    continue;
                }
                int temp = nums[nums[index] - 1];
                nums[nums[index] - 1] = nums[index];
                nums[index] = temp;
            } else {
                index++;
            }
        }
        List<Integer> list = new ArrayList<>();
        for (int i = 0; i < nums.length; i++) {
            if (nums[i] != i + 1) {
                list.add(i + 1);
            }
        }
        return list;
    }

思路拆解

### 写法 1：原地归位（cyclic sort）

  • 值域 [1,n] 与下标 [0,n-1] 一一对应：值 x 的家在下标 x-1，下标 i 的正确住户是 i+1。
  • 把每个值送回自己的家；重复值换不进去就留在原位；归位后扫描 nums[i] != i+1 的位置，i+1 即缺失。
  • 关键决策：
  • 就位判断 nums[i] == i+1（下标→值，用 +1）；目标下标 nums[i]-1（值→下标，用 -1）；
  • 重复守卫：目标位已住同值时跳过；
  • 指针推进规则：只有就位或重复两种情形前进，交换后停留原地，保证每轮有进展。
  • 推演 [2,2,1]：i=0 目标位 nums[1] 已有 2 → 重复跳过；i=1 就位；i=2 把 1 换到下标 0 得 [1,2,2]，随后 i=2 处 2 重复跳过；扫描得缺失 3。
  • 复杂度 O(n)/O(1)：每次交换至少让一个值永久归位，交换总数 ≤ n；空间仅一个临时变量。

### 写法 2：负数标记法

  • 思路：借用数组自身的符号位记录「哪个值出现过」——值 x 出现一次，就把下标 x-1 处取负；扫描时仍为正的下标 i，说明 i+1 从未出现，即缺失数字。
  • 关键决策：
  • 读每个数时其值可能已被改负，必须先用 Math.abs 还原成原始值再定位下标；
  • 标记前判断目标位 > 0 才取负：重复出现的值不反复取负，否则符号翻回正号、被误判为缺失。
  • 推演 [4,3,2,7,8,2,3,1]：
  1. i=0 值 4 → 下标 3 处 7 取负为 -7；
  2. i=1 值 3 → 下标 2 处 2 取负为 -2；
  3. i=2 值 -2 → abs=2 → 下标 1 处 3 取负为 -3；
  4. i=3 值 -7 → abs=7 → 下标 6 处 3 取负为 -3；
  5. i=4 值 8 → 下标 7 处 1 取负为 -1；
  6. i=5 值 2 → 下标 1 已是 -3，跳过；i=6 值 -3 → 下标 2 已是 -2，跳过；
  7. i=7 值 -1 → 下标 0 处 4 取负为 -4；
  8. 扫描：下标 4、5 仍为正 → 缺失 5、6。答案 [5,6]。
  • 边界：[1] 标记后全负，返回空；[1,1,1] 只标记一次，下标 1、2 为正 → [2,3]；值域 [1,n] 保证原始值无负数，但标记后数组会出现负数，这正是需要 abs 的原因。
  • 复杂度 O(n)/O(1)：一趟标记 + 一趟扫描；只用几个变量与结果列表（结果列表不算额外空间）。

### 两写法对比

  • 都是 O(n)/O(1)，同时达到时间 Ω(n) 与空间 O(1) 下界，均为最优解。
  • 写法 1 无符号处理，但要维护「指针推进不变量」（就位/重复才前进），写错容易死循环；
  • 写法 2 常数略小、无交换无死循环风险，但需要 abs 还原与重复不取负两个细节。
  • 本题曾因写法 1 的 +1/-1 方向混用与指针推进结构反复死循环，已沉淀为套路 #37（值域 [1,n] 数组原地归位）。
