208. 实现 Trie (前缀树) (Implement Trie (Prefix Tree))

> https://leetcode.cn/problems/implement-trie-prefix-tree/

难度：Medium ｜ 分类：哈希表

标签：设计、字典树、哈希表、字符串

题目描述

Trie（发音类似 "try"）或者说 前缀树 是一种树形数据结构，用于高效地存储和检索字符串数据集中的键。这一数据结构有相当多的应用情景，例如自动补全和拼写检查。

请你实现 Trie 类：

Trie() 初始化前缀树对象。

void insert(String word) 向前缀树中插入字符串 word 。

boolean search(String word) 如果字符串 word 在前缀树中，返回 true（即，在检索之前已经插入）；否则，返回 false 。

boolean startsWith(String prefix) 如果之前已经插入的字符串 word 的前缀之一为 prefix ，返回 true ；否则，返回 false 。

示例：

输入

["Trie", "insert", "search", "search", "startsWith", "insert", "search"]

[[], ["apple"], ["apple"], ["app"], ["app"], ["app"], ["app"]]

输出

[null, null, true, false, true, null, true]

解释

Trie trie = new Trie();

trie.insert("apple");

trie.search("apple"); // 返回 True

trie.search("app"); // 返回 False

trie.startsWith("app"); // 返回 True

trie.insert("app");

trie.search("app"); // 返回 True

提示：

1

word 和 prefix 仅由小写英文字母组成

insert、search 和 startsWith 调用次数 总计 不超过 3 * 104 次

static class Trie {
        Trie[] it;
        boolean end;
        public Trie() {
            this.it = new Trie[26];
            this.end = false;
        }

        public void insert(String word) {
            Trie cur = this;
            for (char c : word.toCharArray()) {
                if (cur.it[c - 'a'] != null) {
                    cur = cur.it[c - 'a'];
                } else {
                    cur.it[c - 'a'] = new Trie();
                    cur = cur.it[c - 'a'];
                }
            }
            cur.end = true;
        }

        public boolean search(String word) {
            Trie cur = this;
            for (char c : word.toCharArray()) {
                if (cur.it[c - 'a'] == null) {
                    return false;
                } else {
                    cur = cur.it[c - 'a'];
                }
            }
            return cur.end;
        }

        public boolean startsWith(String prefix) {
            Trie cur = this;
            for (char c : prefix.toCharArray()) {
                if (cur.it[c - 'a'] == null) {
                    return false;
                } else {
                    cur = cur.it[c - 'a'];
                }
            }
            return cur != null;
        }
    }

static class Trie {
        Trie[] sub;
        boolean end = false;
        public Trie() {
            sub = new Trie[26];
        }
        public void insert(String word) {
            Trie cur = this;
            for (Character c : word.toCharArray()) {
                if (cur.sub[c - 'a'] != null) {
                    cur = cur.sub[c - 'a'];
                } else {
                    cur.sub[c - 'a'] = new Trie();
                    cur = cur.sub[c - 'a'];
                }
            }
            cur.end = true;
        }
        public boolean search(String word) {
            Trie cur = getCur(word);
            if (cur == null) return false;
            return cur.end;
        }

        private Trie getCur(String word) {
            Trie cur = this;
            for (Character c : word.toCharArray()) {
                if (cur.sub[c - 'a'] == null) {
                    return null;
                } else {
                    cur = cur.sub[c - 'a'];
                }
            }
            return cur;
        }

        public boolean startsWith(String prefix) {
            Trie cur = getCur(prefix);
            return cur != null;
        }
    }

思路拆解

问题本质：实现支持 insert / search / startsWith 的字典树。Trie 的价值是把字符串的公共前缀合并存储，查询时按字符逐层走。

关键设计：每个节点是 Trie[26] 子指针数组 + end 结束标记。insert 从根沿字符路径走，缺子节点就 new；search 和 startsWith 共用一个 getCur 沿前缀走到终点，区别是 search 还要检查 end 标记——否则搜 app 会误命中已插入的 apple。

边界：空字符串应作为合法词支持（根节点 end 标记即可）；公共前缀是另一个完整词时必须靠 end 区分；题目限定小写字母，数组固定 26。

复杂度：insert / search / startsWith 均为 O(L)（L 为单词/前缀长度），空间 O(总字符数×26)；比哈希表多支持前缀查询，且共享公共前缀。
