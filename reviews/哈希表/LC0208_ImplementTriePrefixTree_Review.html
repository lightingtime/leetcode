我的解法

思路：数组子节点 + 结束标记。每个节点用 26 格的 Trie[] 存下一层字符的子节点，外加一个 end 标记； insert 用游标从根逐字符走，缺哪层建哪层，最后点亮终点标记；search / startsWith 共用 getCur 沿前缀走，区别只在走完后要不要看 end。

时间 O(L) 空间 O(总字符 × 26) L = 单词长度 游标从根 this 出发

src/LC0208_ImplementTriePrefixTree.java提交区（修复后）
static class Trie {
    Trie[] sub;
    boolean end = false;
    public Trie() {
        sub = new Trie[26];
    }
    public void insert(String word) {
        Trie cur = this;
        for (Character c : word.toCharArray()) {
            if (cur.sub[c - 'a'] != null) {
                cur = cur.sub[c - 'a'];
            } else {
                cur.sub[c - 'a'] = new Trie();
                cur = cur.sub[c - 'a'];
            }
        }
        cur.end = true;
    }
    public boolean search(String word) {
        Trie cur = getCur(word);
        if (cur == null) return false;
        return cur.end;
    }
    private Trie getCur(String word) {
        Trie cur = this;
        for (Character c : word.toCharArray()) {
            if (cur.sub[c - 'a'] == null) {
                return null;
            } else {
                cur = cur.sub[c - 'a'];
            }
        }
        return cur;
    }
    public boolean startsWith(String prefix) {
        Trie cur = getCur(prefix);
        return cur != null;
    }
}

关键点：游标起点是根（this）；「建新节点」和「走过去」两步都做了。

算法判定：标准 Trie，已是最优

  • 时间复杂度 O(L)：每次操作必须读完整个单词，O(L) 是下限；数组定位子节点是 O(1)。
  • 空间复杂度 O(总字符 × 26)：每个插入的字符对应一个节点，节点固定带 26 格数组，是数组实现的标准开销。
  • 正确性：search 要求「走通 + end」，startsWith 只要求「走通」，区分正确。
  • 结论：与题目标准解法一致，无需再优化。
