写法 1 · 三点共线叉积（O(n³)）

时间 O(n³)空间 O(1)内存 ≈ 41.4 MB用例 42/42

src/LC0149_MaxPointsOnALine.java提交区
public int maxPoints(int[][] points) {
        int ans = 1;
        for (int i = 0; i < points.length; i++) {
            int[] p1 = points[i];
            for (int j = i + 1; j < points.length; j++) {
                int[] p2 = points[j];
                int count = 2;
                for (int k = j + 1; k < points.length; k++) {
                    int[] p = points[k];
                    // p1 -> p2 (p2[1] - p1[1], p2[0] - p1[0])
                    // p -> p2 (p[1] - p2[1], p[0] - p2[0])
                    // 三点共线 ⇔ 这两个向量平行 ⇔ 叉积为 0：
                    // P1P2 × P2P = (p2[1] - p1[1])*(p[0] - p2[0]) − (p[1] - p2[1])*(p2[0] - p1[0]) == 0
                    int s1 = (p2[1] - p1[1]) * (p[0] - p2[0]);
                    int s2 = (p[1] - p2[1]) * (p2[0] - p1[0]);
                    if (s1 == s2) {
                        count++;
                    }
                }
                ans = Math.max(ans, count);
            }
        }
        return ans;
    }

枚举每对点 p1,p2 定直线，第三点 p 用向量叉积判共线（s1==s2）；n=300 时约 445 万次可过；非最优，O(n²) 斜率哈希更优

思路拆解

问题本质：求共线点数最大值。点 i 与点 j 确定一条直线，统计「有多少个点也在这条直线上」的最大值。

解法选择理由（三点共线叉积，O(n³)）：

  • 枚举每一对点 (p1, p2) 作为直线的两个基准点，再扫描第三个点 p 是否与它们共线。
  • 共线判定用向量叉积：向量 p1→p2 与向量 p2→p 平行 ⇔ 叉积为 0，写成整数比较 s1 == s2，避免浮点斜率精度问题，也无需约分。
  • n ≤ 300，三重循环 C(300,3) ≈ 445 万次，Java 完全可过。

关键设计决策：

  1. 外层 i、j 枚举点对 p1、p2，count 从 2 起（p1、p2 本身两点）。
  2. 内层 k 枚举第三个点 p，判断是否共线：
  • s1 = (p2[1]-p1[1]) * (p[0]-p2[0]) = dy(p1→p2) × dx(p2→p)
  • s2 = (p[1]-p2[1]) * (p2[0]-p1[0]) = dy(p2→p) × dx(p1→p2)
  • s1 == s2 ⇔ dy12·dx2p − dy2p·dx12 == 0 ⇔ 叉积为 0 ⇔ 三点共线。
  1. ans 初始 1：n≥1 时至少 1 个点；内层可能不执行（单点/无第三点时）也要正确。
  2. 每对 (p1,p2) 更新全局最大 count。
  3. 坐标 ±10^4，差值乘积最大 4×10^8，int 不溢出。

具体 case 推演：

示例1 [[1,1],[2,2],[3,3]]（期望 3）：

  • i=0 p1=(1,1), j=1 p2=(2,2), k=2 p=(3,3)：
  • s1 = (2-1)×(3-2) = 1；s2 = (3-2)×(2-1) = 1 → 相等 → count=3 → ans=3 ✓

边界5 [[0,0],[2,4],[4,8],[1,2]]（期望 4，斜率 2 的线）：

  • (0,0),(2,4) 与 (4,8)：s1=(4-0)×(4-2)=8，s2=(8-4)×(2-0)=8 → 共线；
  • (0,0),(2,4) 与 (1,2)：s1=(4-0)×(1-2)=-4，s2=(2-4)×(2-0)=-4 → 共线 → count=4 ✓

边界1 单点 [[0,0]]：内层不执行，ans 保持 1 ✓

边界与细节：

  • 单点/两点：ans 初始 1，两点时 count=2。
  • 水平线/垂直线：dx 或 dy 为 0 时叉积式仍正确。
  • 重复点：题目保证互不相同，无需处理。
  • 300 点共线：最内层 4.45M 次整数运算，无性能问题。

复杂度分析：

  • 时间 O(n³)：三重组合枚举；n=300 时约 4.45M 次，可接受但不是最优。
  • 空间 O(1)：只用常数变量。
  • 最优性：本题最优是 O(n²)：固定一个基准点，用 HashMap<归一化斜率, 计数> 统计「与基准点斜率相同的点数」，取 count+1 最大值；叉积法省空间但多一重循环。当前写法复杂度未达最优（optimal=false），但 n 上限小、能 AC。
