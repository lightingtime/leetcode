149. 直线上最多的点数 (Max Points on a Line)

题目描述

给你一个数组 points ，其中 points[i] = [xi, yi] 表示 X-Y 平面上的一个点。求最多有多少个点在同一条直线上。

示例 1：

输入：points = [[1,1],[2,2],[3,3]]

输出：3

示例 2：

输入：points = [[1,1],[3,2],[5,3],[4,1],[2,3],[1,4]]

输出：4

提示：

1

points[i].length == 2

-104 i, yi 4

points 中的所有点 互不相同

写法 1 · 三点共线叉积（O(n³)）

时间 O(n³)空间 O(1)内存 ≈ 41.4 MB用例 42/42

LC0149_MaxPointsOnALine.java · 三点共线叉积（O(n³)）提交区
public int maxPoints(int[][] points) {
        int ans = 1;
        for (int i = 0; i < points.length; i++) {
            int[] p1 = points[i];
            for (int j = i + 1; j < points.length; j++) {
                int[] p2 = points[j];
                int count = 2;
                for (int k = j + 1; k < points.length; k++) {
                    int[] p = points[k];
                    // p1 -> p2 (p2[1] - p1[1], p2[0] - p1[0])
                    // p -> p2 (p[1] - p2[1], p[0] - p2[0])
                    // 三点共线 ⇔ 这两个向量平行 ⇔ 叉积为 0：
                    // P1P2 × P2P = (p2[1] - p1[1])*(p[0] - p2[0]) − (p[1] - p2[1])*(p2[0] - p1[0]) == 0
                    int s1 = (p2[1] - p1[1]) * (p[0] - p2[0]);
                    int s2 = (p[1] - p2[1]) * (p2[0] - p1[0]);
                    if (s1 == s2) {
                        count++;
                    }
                }
                ans = Math.max(ans, count);
            }
        }
        return ans;
    }

写法 2 · 固定锚点 + 归一化斜率哈希（O(n²)）

时间 O(n^2)空间 O(n)内存 ≈ 45.2 MB用例 42/42

LC0149_MaxPointsOnALine.java · 固定锚点 + 归一化斜率哈希（O(n²)）提交区
    public int maxPoints(int[][] points) {
        int max = 0;
        for (int i = 0; i < points.length; i++) {
            Map<Integer, Integer> map = new HashMap<>();
            int[] a = points[i];
            for (int j = 0; j < points.length; j++) {
                if (i == j) continue;
                int[] b = points[j];
                int dx = b[0] - a[0];
                int dy = b[1] - a[1];
                if (dx < 0 || (dx == 0 && dy < 0)) {
                    dx = -dx;
                    dy = -dy;
                }
                int gcd = getGcd(Math.abs(dx), Math.abs(dy));
                dx /= gcd;
                dy /= gcd;
                int key = dx * 400001 + dy;
                map.merge(key, 1, Integer::sum);
                max = Math.max(max, map.get(key));
            }
        }
        return max + 1;
    }

    private int getGcd(int x, int y) {
        while (y != 0) {
            int t = x % y;
            x = y;
            y = t;
        }
        return x;
    }

    public int maxPoints(int[][] points) {
        int max = 0;
        for (int i = 0; i < points.length; i++) {
            Map<String, Integer> map = new HashMap<>();
            int[] a = points[i];
            int curMax = 0;
            int same = 0;
            for (int j = 0; j < points.length; j++) {
                if (i == j) {
                    continue;
                }
                int[] b = points[j];
                int dx = a[0] - b[0];
                int dy = a[1] - b[1];
                if (dx == 0 && dy == 0) {
                    same++;
                    continue;
                }
                if (dx < 0 || (dx == 0 && dy < 0)) {
                    dx = -dx;
                    dy = -dy;
                }
                int g = gcd(Math.abs(dx), Math.abs(dy));
                dx = dx / g;
                dy = dy / g;
                String key = dx + "," + dy;
                map.merge(key, 1, Integer::sum);
                curMax = Math.max(curMax, map.get(key));
            }
            max = Math.max(max, curMax + 1 + same);
        }
        return max;
    }

    private int gcd(int dx, int dy) {
        while (dy != 0) {
            int n = dx % dy;
            dx = dy;
            dy = n;
        }
        return dx;
    }

思路拆解

问题本质与解法选择理由

给 n 个点找「共线最多」的直线。朴素思路（一刷 O(n³)）是枚举每对点定一条直线，再扫第三点判共线——慢在每条线都把第三点重算一遍。

关键转化：一条直线可由「一个点 + 一个方向」唯一确定。固定锚点 i 后，点 j 与 i 共线 ⟺ 方向 (dx,dy) 相同；方向从「锚点指向点」计算，且 (d) 与 (−d) 是同一条线要合并。于是问题变成对每个锚点统计「每个方向出现次数」，取最大次数 + 锚点自己。整体 O(n²)。

关键设计决策

  1. 方向归一化（key）：(dx,dy) 先除以 gcd(|dx|,|dy|) 得最简方向，再符号统一（dx<0，或 dx==0 且 dy<0 时整体取反），保证 dx≥0、dy 的符号保留斜率正负。
  • 为什么不能 abs 两个：abs 会把 (1,1)（斜率+1）与 (1,−1)（斜率−1）并成同 key，两条不同直线被合并而虚高。
  • key 用字符串 dx+","+dy（或 long 编码），不能用 int[]：Java 数组 equals/hashCode 是引用相等，每次都查不到。
  1. 每轮锚点新建 HashMap：斜率相对各自锚点，跨锚点累计会污染计数（典型错误：map 建在循环外导致答案膨胀）。
  2. 聚合取峰值：curMax = max(curMax, count)，不是直接取当前斜率计数——主导斜率不连续出现时会丢峰值。
  3. 重复坐标：j 与锚点 i 重合（dx==dy==0）时 gcd(0,0) 会除零，单独用 same 计数，答案 = curMax + 1 + same（重合副本在过锚点的任意直线上都算）。

具体 case 推演：A=(0,0), B=(1,1), C=(−1,−1), D=(1,−1)

锚点 A=(0,0)：

  • B：dx=1, dy=1 → gcd=1 → key (1,1) → 计数 1
  • C：dx=−1, dy=−1 → 符号统一 → (1,1) → 计数 2
  • D：dx=1, dy=−1 → 符号不动 → (1,−1) → 计数 1
  • 收尾：max(2)+1 = 3（A,B,C 在斜率 +1 线上）✓；若用 abs，B/C/D 全变 (1,1) 会错算成 4

边界与细节

  • 单点：内层空转，max=0+1=1 ✓
  • 垂直 dx=0：符号统一保证 dy>0 → key (0,1)；水平 dy=0 → (1,0)，两者不混淆
  • 300 点全共线：每锚点计数 299，答案 299+1=300
  • 重复坐标隐藏用例：same 计数兜底，避免 gcd(0,0) 除零

复杂度与下限论证

时间 O(n²)（外层锚点 n × 内层 n，每次 gcd O(logC)，C 为坐标范围）——因为「共线关系」必须比较所有点对方向，任两点都要检查是否同线，比较点对已是 Ω(n²)；空间 O(n)（每轮一张斜率表）。相对一刷 O(n³) 去掉的正是「每条线重扫第三点」的冗余层，故 O(n²) 为该问题可达的最优复杂度。
