1. 两数之和 (Two Sum)

题目描述

给定一个整数数组 nums 和一个整数目标值 target，请你在该数组中找出 和为目标值 target 的那 两个 整数，并返回它们的数组下标。

你可以假设每种输入只会对应一个答案，并且你不能使用两次相同的元素。

你可以按任意顺序返回答案。

示例 1：

输入：nums = [2,7,11,15], target = 9

输出：[0,1]

解释：因为 nums[0] + nums[1] == 9 ，返回 [0, 1] 。

示例 2：

输入：nums = [3,2,4], target = 6

输出：[1,2]

示例 3：

输入：nums = [3,3], target = 6

输出：[0,1]

LC0001_TwoSum.java · 单遍哈希表（边查边存）提交区
    public int[] twoSum(int[] nums, int target) {
        Map<Integer, Integer> map = new HashMap<>();
        for (int i = 0; i < nums.length; i++) {
            // 先查后存：配对必须是更早出现的下标；若先 put，num * 2 == target 时会拿自己的下标配自己
            if (map.containsKey(target - nums[i])) {
                return new int[]{i, map.get(target - nums[i])};
            }
            map.put(nums[i], i);
        }
        return new int[] {};
    }

LC0001_TwoSum.java · 单遍哈希表（边查边存） · 上一版提交区
public int[] twoSum(int[] nums, int target) {
        Map<Integer, Integer> map = new HashMap<>();
        for (int i = 0; i < nums.length; i++) {
            if (map.containsKey(target - nums[i])) {
                return new int[]{map.get(target - nums[i]), i};
            } else {
                map.put(nums[i], i);
            }
        }
        return null;
    }

思路拆解

问题本质：在数组中找两个下标使元素之和等于 target。暴力枚举两两组合是 O(n²)；把「查补数」优化为哈希表 O(1) 查询，本质是空间换时间。

关键设计：边遍历边把 nums[i] → i 存入 HashMap；对每个元素先查 target-nums[i] 是否已存在，存在即返回 [已存下标, 当前下标]。顺序很重要：先查再存，保证同一个元素不会和自己配对（例如 target=6、数组只有一个 3，先查时 map 还没有 3，不会误返回 [i,i]）。

边界：题目保证恰好一个解，但实现仍返回 null 兜底；元素值重复时后存的下标覆盖先存的下标，先查后存确保返回的是靠前的那一对。

复杂度：O(n) 时间、O(n) 空间。相比 O(n²) 暴力是时间最优；空间是 O(1) 查询的必要代价，题目没有限制额外空间。

套路沉淀

单遍哈希：边查补数边存下标，先查后存天然处理重复值

求「两数之和 = target」：map 存「已见过的值 → 下标」；单层循环里先用 map.containsKey(target - num) 查补数，命中即返回当前下标与补数下标，再登记当前值。先查后存保证不会用同一下标和自己配对，重复值 [3,3] 也能取到两个不同下标；写成先存后查时，num*2 == target 的情形会错用自己的下标。空间换时间，把暴力 O(n²) 降到 O(n)。出处：LC0001 两数之和。
