205. 同构字符串 (Isomorphic Strings)

> https://leetcode.cn/problems/isomorphic-strings/

难度：Easy ｜ 分类：哈希表

标签：哈希表、字符串

题目描述

给定两个字符串 s 和 t ，判断它们是否是同构的。

如果 s 中的字符可以按某种映射关系替换得到 t ，那么这两个字符串是同构的。

每个出现的字符都应当映射到另一个字符，同时不改变字符的顺序。不同字符不能映射到同一个字符上，相同字符只能映射到同一个字符上，字符可以映射到自己本身。

示例 1：

输入：s = "egg", t = "add"

输出：true

解释：

字符串 s 和 t 可以通过以下方式变得相同：

将 'e' 映射为 'a'。

将 'g' 映射为 'd'。

示例 2：

输入：s = "f11", t = "b23"

输出：false

解释：

字符串 s 和 t 无法变得相同，因为 '1' 需要同时映射到 '2' 和 '3'。

示例 3：

输入：s = "paper", t = "title"

输出：true

提示：

1 4

t.length == s.length

s 和 t 由任意有效的 ASCII 字符组成

LC0205_IsomorphicStrings.java · 双向哈希映射提交区
public boolean isIsomorphic(String s, String t) {
        Map<Character, Character> map = new HashMap<>();
        Map<Character, Character> reverseMap = new HashMap<>();
        for (int i = 0; i < s.length(); i++) {
            if (map.containsKey(s.charAt(i))) {
                if (map.get(s.charAt(i)) != t.charAt(i)) return false;
            } else {
                map.put(s.charAt(i), t.charAt(i));
            }
            if (reverseMap.containsKey(t.charAt(i))) {
                if (reverseMap.get(t.charAt(i)) != s.charAt(i)) return false;
            } else {
                reverseMap.put(t.charAt(i), s.charAt(i));
            }
        }
        return true;
    }

思路拆解

问题本质与解法选择理由：需要检查每种源字符始终对应同一种目标字符，同时不同源字符不能共用目标字符。按位置扫描，分别维护源到目标、目标到源的映射，能在每个字符处立即发现冲突。

关键设计决策：

  • 保存源字符到目标字符，检查同一源字符后续是否仍映射到原目标。
  • 保存目标字符到源字符，检查映射是否一对一。
  • 新字符对两边都登记；已见字符必须与两张表中的关系同时一致。

具体推演：输入 、：

  1. 下标 0：登记 和 。
  2. 下标 1：登记 和 。
  3. 下标 2：再次看到 与 ，两张表的映射都一致，返回 true。

若输入 、，下标 0 登记 ；下标 1 的目标 已反向映射到 ，但当前源字符是 ，因此返回 false。

边界与复杂度：长度为 1 时正常登记一对字符；非字母 ASCII 字符也可作为哈希键。扫描 n 个位置，时间 O(n)。ASCII 字符总数固定，最多记录 128 种字符映射，额外空间 O(1)。最坏情况下必须检查到末尾才能确认所有位置关系一致，因此时间下界为 Ω(n)。
