写法 1 · 原地交换（cyclic sort）

时间 O(n)空间 O(1)内存 ≈ 45.4 MB用例 122/122

LC0268_MissingNumber.java · 原地交换（cyclic sort）提交区
public int missingNumber(int[] nums) {
        for (int i = 0; i < nums.length; i++) {
            if (nums[i] == nums.length) {
                continue;
            }
            while (nums[i] != i) {
                int temp = nums[nums[i]];
                nums[nums[i]] = nums[i];
                nums[i] = temp;
                if (nums[i] == nums.length) {
                    break;
                }
            }
        }
        for (int i = 0; i < nums.length; i++) {
            if (nums[i] != i) {
                return i;
            }
        }
        return nums.length;
    }

cyclic sort：每个 v 换到 nums[v]，n 是哨兵；同一 i 上 while 连环交换直到归位或遇 n，扫描 nums[i]!=i 即缺失；O(n)/O(1)，满足进阶，本地两轮修正后一次提交 AC

写法 2 · 求和（差值累加）

时间 O(n)空间 O(1)内存 ≈ 45.6 MB用例 122/122

LC0268_MissingNumber.java · 求和（差值累加）提交区
public int missingNumber(int[] nums) {
        long ans = nums.length;
        for (int i = 0; i < nums.length; i++) {
            ans = ans + i - nums[i];
        }
        return Math.toIntExact(ans);
    }

求和差分累加：ans 从 n 起步，每轮 ans += i - nums[i]，用 long+Math.toIntExact 防溢出；O(n)/O(1)，第二种写法再次 Accepted

思路拆解

问题本质：在 [0,n] 共 n+1 个数中缺一个，数组给 n 个（每个独一无二）。缺失值 = 0..n 的总和 - 数组总和。

解法选择理由（求和 + 差值累加）：

  • 数学恒等式：∑0..n - ∑nums = 缺失值。每个数只读一次，O(n) 时间、O(1) 空间，满足进阶要求。
  • 不用「先算总和再减」而是「边加边减」，是因为差分累加的中间值量级始终贴近 [−n, n]，不会像 n(n+1)/2 那样先堆出大数；再用 long 兜底、Math.toIntExact 收尾，通用场景也不怕溢出（本题 n≤10^4 时 n(n+1)/2≈5×10^7，int 本就安全）。

关键设计决策：

  1. ans 从 nums.length 起步：0..n 的和 = n + ∑(0..n−1)，循环里 i 贡献 0..n−1，nums[i] 减去实际值，正好等于「期望总和 − 实际总和」。
  2. 循环 i=0..n−1：ans += i − nums[i]，把每个位置的「期望值 − 实际值」累加。
  3. long 累加 + Math.toIntExact(ans)：防中间溢出，并在结果超 int 时抛异常（本题不会）。
  4. 与异或的关系：异或也能达到同样复杂度且完全无溢出；求和的优点是直观，缺点是必须处理大数，差分 + long 就是它的防溢出手段。

边界与细节：

  • n=1：[0] → ans=1+0−0=1 ✓；[1] → ans=1+0−1=0 ✓。
  • 缺 0 / 缺 n / 缺中间、10^4 上限全覆盖，与 cyclic sort 同一套边界用例。
  • 不会误判：即使缺失位置存 0，也只需算术，不依赖数组内容符号。

复杂度分析：

  • 时间 O(n)：单次遍历，每步 O(1)，达到下限 Ω(n)（至少要读完数组）。
  • 空间 O(1)：只用一个 long。
  • 最优性：与异或同为 O(n)/O(1) 且代码极简；cyclic sort 复杂度同级但实现重、交换多，不是本题的首选最优写法。求和与异或二选一即可。

写法对比（本题两种 Accepted 写法）：

  • 写法 1 cyclic sort：原地交换把每个 v 换到 nums[v]，n 当哨兵；O(n)/O(1)，思路通用但代码长。
  • 写法 2 求和差分累加：∑0..n − ∑nums；O(n)/O(1)，3~4 行，防溢出用 long/差分。

套路沉淀

取负标记法

取负标记法的前提是「每个可标记位置的值都非 0」或「0 能表达已标记」：-0 仍是 0，缺失位置恰好存 0 时无法被标记成负，扫描用 nums[i]>0 判未标记会漏掉该位置；对策是把值平移（v+1）再标记，或换 cyclic sort / 异或 / 求和。
