public int firstMissingPositive(int[] nums) {
        for (int i = 0; i < nums.length; i++) {
            if (nums[i] > nums.length || nums[i] <= 0) {
                continue;
            }
            while (nums[i] > 0 && nums[i] <= nums.length && nums[nums[i] - 1] != nums[i]) {
                int temp = nums[nums[i] - 1];
                nums[nums[i] - 1] = nums[i];
                nums[i] = temp;
            }
        }
        for (int i = 0; i < nums.length; i++) {
            if (nums[i] != i + 1) {
                return i + 1;
            }
        }
        return nums.length + 1;
    }

答案在 [1,n+1]：v 归位到 v-1；while 条件= v 有效(1..n) && 目标位!=v，无效值占位也交换、重复值停止；扫描 nums[i]!=i+1 返回 i+1，全对返回 n+1；本地多轮修正+力扣一次 WA 后 AC

思路拆解

问题本质：找出数组中没有出现的最小正整数，答案必在 [1, n+1] 内（n 个位置最多覆盖 1..n）。要求 O(n) 时间 + O(1) 空间，不能排序、不能开额外集合。

解法选择理由（cyclic sort 值域偏移）：

  • 与 268 同一套路：把「值 v 放到它该待的位置」，扫描位置与值是否一致，第一个不一致的位置就是答案。
  • 关键差异：268 值域 [0,n-1] 用「值 v 放下标 v」；本题答案从 1 开始，值 v 应放下标 v-1（1→0、2→1、…、n→n-1），位置 i 的正确值是 i+1。
  • 只有 1..n 的值值得归位；v<=0 或 v>n 是无效值，不参与归位但可能占位——需要被交换出来。

关键设计决策：

  1. 外层 for 遍历每个位置；内层 while 把当前位置的有效值 v 连环交换到正确位置 v-1。
  2. while 条件三合一（&&）：nums[i] > 0 && nums[i] <= nums.length && nums[nums[i]-1] != nums[i]。
  • 前两个保证 v 有效，无效值一到当前位置就退出 → 永不拿无效值当下标（防越界）；
  • 第三个保证目标位没放着同样的 v，重复值不交换 → 防死循环（41 允许重复，268 无此问题）；
  • 目标位是无效值或别的值时都交换——无效值占位时更要换，把无效值挤出来（这是本地踩过的坑：break 会让有效值换不进被无效值占的位置）。
  1. 扫描 i=0..n-1：nums[i] != i+1 返回 i+1；全部归位返回 n+1（1..n 全在时缺 n+1）。

关键在第 5 步：位置 0 被无效值 100000 占着，但 1 有效、目标位≠1 → 照样交换，把无效值换出来。

[1,1]（n=2，期望 2，重复值防死循环）：i=0 nums[0]=1 已在目标位；i=1 nums[1]=1 有效，目标 nums[0]=1==1 → while 第三个条件不满足 → 不交换、不死循环；扫描 i=0 通过、i=1 nums[1]=1≠2 → 返回 2 ✓

[3,1,2]（n=3，期望 4）：3 有效（3≤3）→ 归位到下标 2；1→0；2→1；扫描全对 → 返回 n+1=4 ✓（v==n 必须保留处理，不能跳过）

边界与细节：

  • 单元素 [1]→2、[0]/[-1]/[2]→1。
  • 全非正 → 扫描 i=0 即返回 1。
  • 重复值 [1,1]→2、[1,2,2]→3。
  • 值超范围/负数 → 无效值被交换到后方，扫描时自然暴露空位。
  • n 上限 5×10^5：while 总交换次数 O(n)（每个元素最多被换走一次），无性能问题。

复杂度分析：

  • 时间 O(n)：每个元素至多被交换一次到正确位置，扫描 O(n)，均摊 O(n)。
  • 空间 O(1)：完全原地。
  • 最优性：必须至少读每个元素一次（Ω(n)），O(1) 空间满足题目硬性要求，是标准最优解。
