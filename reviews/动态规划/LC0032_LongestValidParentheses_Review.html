public int longestValidParentheses(String s) {
        int n = s.length();
        int[] dp = new int[n];
        int max = 0;
        for (int i = 0; i < n; i++) {
            if (s.charAt(i) == ')') {
                if (i > 0 && s.charAt(i - 1) == '(') {
                    if (i - 2 >= 0) {
                        dp[i] = dp[i - 2] + 2;
                    } else {
                        dp[i] = 2;
                    }
                } else if (i > 0 && s.charAt(i - 1) == ')') {
                    int j = i - dp[i-1] - 1;
                    if (j >= 0) {
                        if (s.charAt(j) == '(') {
                            if (j - 1 >= 0) {
                                dp[i] = dp[i - 1] + 2 + dp[j - 1];
                            } else {
                                dp[i] = dp[i - 1] + 2;
                            }
                        }
                    }
                }
                max = Math.max(max, dp[i]);
            }
        }
        return max;
    }

一维 DP：dp[i] 以 i 结尾的最长有效长度；遇 ) 分直接配对与跳段配对+向前拼接；O(n)/O(n)，本地修 3 处边界后力扣一次 Accepted

思路拆解

问题本质：求字符串中最长连续有效括号子串长度。暴力枚举每个子串再校验是 O(n^3)，不可行；观察到一个关键性质：有效串必须以 ) 闭合，且当前 ) 只能闭合「最近的未配对左括号」，因此可以定义「以当前位置结尾」的一维状态递推。

解法选择理由：

  • 定义 dp[i] = 以 s[i] 结尾的最长有效括号子串长度；s[i] == '(' 时它不可能结尾，dp[i] = 0。
  • 只有遇到 ) 才可能让 dp[i] > 0，按前一个字符分成两类：直接配对 () 和跳段配对 ...))。

关键设计：

  1. 情况一：s[i-1] == '('，末尾形成 ()，长度为 2，前面 s[i-2] 结尾的有效段可以拼接，所以 dp[i] = dp[i-2] + 2（i-2 < 0 时就是 2）。
  2. 情况二：s[i-1] == ')'，以 i-1 结尾有一段长度 dp[i-1] 的已闭合有效串，配对的左括号在 j = i - dp[i-1] - 1；只有 j >= 0 且 s[j] == '(' 时配对成立，dp[i] = dp[i-1] + 2，并且 j-1 >= 0 时还能再拼接前面的 dp[j-1]。
  3. 全程用 max 记录最大值，答案不是 dp[n-1]（最优段不一定以末尾结尾）。

具体 case 推演（s = "()(())"，期望 6）：

i字符dp[i]说明
0(0左括号不能结尾
1)2s[0] == '(' 直接配对
2(0左括号不能结尾
3(0左括号不能结尾
4)2s[3] == '(' 直接配对，dp[2]+2 = 2
5)6j = 5-2-1 = 2，s[2] == '(' 配对；dp[5] = dp[4]+2+dp[1] = 2+2+2 = 6

再推演 s = "())"（下标 2 的 ) 无配对）：

  • i = 2，dp[1] = 2，j = 2-2-1 = -1 < 0，不配对，dp[2] 保持 0，而不是 dp[1]+2 = 4。

边界与细节：

  • 空串、全左括号、全右括号、")(" 都返回 0。
  • "())(()" 中间断开：i=2 时 j<0 不能错误延长。
  • "(())"：i=3 时 j=0 配对成立，但前面没有可拼接段，dp[j-1] 越界按 0 处理，结果为 4。
  • "()(())" 验证配对后必须拼接 dp[j-1] 而不是 dp[j]。

复杂度分析：

  • 时间复杂度 O(n)：单次遍历，每步 O(1)，已达下界（每个字符至少要检查一次）。
  • 空间复杂度 O(n)：dp 数组；可进一步用双指针/计数法做到 O(1)，所以本题标记为可进阶。
