LC0140_WordBreakIi.java · 后缀可拆预判+回溯提交区
public List<String> wordBreak(String s, List<String> wordDict) {
        set = new HashSet<>(wordDict);
        ans = new ArrayList<>();
        int n = s.length();

        suffixOK = new boolean[n + 1];
        suffixOK[n] = true;
        for (int i = n - 1; i >= 0; i--) {
            for (String word : set) {
                if (i + word.length() <= n && suffixOK[i + word.length()] && s.startsWith(word, i)) {
                    suffixOK[i] = true;
                    break;
                }
            }
        }

        dfs(s, 0, new ArrayList<>());
        return ans;
    }

    private void dfs(String s, int start, List<String> path) {
        if (start == s.length()) {
            ans.add(String.join(" ", path));
            return;
        }
        if (!suffixOK[start]) {
            return;
        }
        for (int i = start; i <= s.length(); i++) {
            String temp = s.substring(start, i);
            if (set.contains(temp)) {
                path.add(temp);
                dfs(s, i, path);
                path.remove(path.size() - 1);
            }
        }
    }

后缀可拆预判 suffixOK（右往左）+回溯：DFS入口 !suffixOK[start] 剪到不了终点的子树，set.contains 保证段合法，path+String.join 拼句子

思路拆解

## ① 问题本质与解法选择

  • 本质：枚举所有能把 s 拆成字典词的句子，词可重复使用。两层结构：回溯负责枚举，预判负责剪枝。
  • 解法选择：后缀可拆预判 suffixOK（右往左的线性 DP）+ 回溯。set.contains 保证每段是合法词；suffixOK 在 DFS 入口剪掉「从 start 到不了终点」的整棵子树。

## ② 关键设计决策

设计点决策理由
预判数组suffixOK[i] = s[i..n) 能否拼完，suffixOK[n]=true，从右往左算剪枝要问「未来」能否到终点，不是「过去」前缀
剪枝位置DFS 入口 if (!suffixOK[start]) return到不了终点直接整棵剪，不试词
段合法性set.contains(temp)与 dp 无关，前缀本来就一路真拆出来的
句子拼接List path + 出口 String.join(" ", path)回溯只需 add/remove，避开 StringBuilder 下标手抖
前缀 dp完全不需要前缀可拆在 DFS 里恒 true（被真拆过），冗余

## ③ 具体 case 推演

示例3 catsandog / [cat,cats,and,sand,dog] 的 suffixOK（期望 []）：

位置剩余判定
10空true（基）
7og无词匹配 → false
3sandogsand→suffixOK[7]=false；and→s[3..6)=san 不匹配 → false
0catsandogcat→suffixOK[3]=false；cats→suffixOK[4] 也 false → false

dfs(0) 入口 !suffixOK[0] → 一步不进直接返回 []，省掉整棵死树的遍历。

示例1 catsanddog 的 DFS 两条路径（suffixOK[3]、[7] 均为 true）：

starttemppath出口
0cat → dfs(3)[cat]—
3sand → dfs(7)[cat,sand]—
7dog → dfs(10)[cat,sand,dog]cat sand dog
0cats → dfs(4) → and → dog[cats,and,dog]cats and dog

## ④ 边界与细节

  • 单字符命中 / 完全无法拆分 / 整词+细分并存 / 词重复使用（aaa={a,aa} 三种）/ 剩余不可拼（abcd 只有 ab cd）
  • 长度 20 上限：20 个 a 用 {a,aa} 拼 → 方案数 F(21)=10946，验证枚举不漏不重
  • StringBuilder 出口删空格不恢复是乱码根因 → 用 List path + join 根治

## ⑤ 复杂度与下限论证

  • 预判 O(n·|dict|)；枚举阶段总开销 = 输出方案数 × 每句拼接 O(n)
  • 空间 O(n)（suffixOK+path）+ 输出结果
  • 枚举类题目下限就是 Ω(方案数)，不可再低；suffixOK 让不可达分支 O(1) 跳过，是可实现的剪枝上限
