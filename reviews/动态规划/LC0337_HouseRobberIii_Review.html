public int rob(TreeNode root) {
        int[] res = dfs(root);
        return Math.max(res[0], res[1]);
    }

    // 返回 int[]{偷当前节点, 不偷当前节点} 的最大金额，子问题只算一次
    private int[] dfs(TreeNode node) {
        if (node == null) {
            return new int[]{0, 0};
        }
        int[] left = dfs(node.left);
        int[] right = dfs(node.right);
        int robThis = node.val + left[1] + right[1];                              // 偷它：孩子被迫不偷
        int skipThis = Math.max(left[0], left[1]) + Math.max(right[0], right[1]); // 不偷它：孩子自由
        return new int[]{robThis, skipThis};
    }

一次 AC；树形 DP 自底向上返回 [偷,不偷] 两值，每节点 O(1) 转移；O(n)/O(n) 已达下界

思路拆解

问题本质与解法选择理由

  • 本质：带权二叉树上的最大独立集——「父子不能同时偷」，求能偷到的最大权和。
  • 为什么树形 DP：每个节点的决策只影响自己的子树，且左右子树互不约束（最优子结构 + 无后效性）。暴力枚举所有选法是指数级；树形 DP 让每个节点只算一次、O(1) 转移，总 O(n)。

关键设计决策

  • 状态定义：对每个节点返回两个值 [偷它, 不偷它] 的子树最大金额：
  • 偷它 = node.val + 左子「不偷」 + 右子「不偷」（孩子被迫不偷）
  • 不偷它 = 左子 max(偷,不偷) + 右子 max(偷,不偷)（孩子自由）
  • 为什么返回两值而不是 boolean 传参：自底向上每个节点恰好算一次，天然 O(n)；之前 boolean 传参版同一子树会被「父被偷/父没偷」两种状态反复进入，链状树指数级。
  • 出口：null 节点返回 [0, 0]。
  • 答案：根的两个值取 max（根可偷可不偷）。

具体 case 推演 1：[3,2,4]（期望 6）

  • 叶子 2：→ [2, 0]；叶子 4：→ [4, 0]
  • 根 3：偷 = 3+0+0 = 3；不偷 = max(2,0)+max(4,0) = 6 → [3, 6]
  • 答案 max(3,6) = 6 ✓（不偷根、偷两个子）

具体 case 推演 2：[5,2,7,9,8]（期望 24）

  • 9 → [9,0]；8 → [8,0]；7 → [7,0]
  • 节点 2：偷 = 2+0+0 = 2；不偷 = 9+8 = 17 → [2, 17]
  • 根 5：偷 = 5 + 17 + 0 = 22；不偷 = max(2,17) + max(7,0) = 24 → [5, 24]
  • 答案 24 ✓（跳过根，偷 9+8+7，三者互不相邻）

边界与细节

  • 空树：dfs(null) = [0,0]，返回 0。
  • 单节点：max(val, 0) = val。
  • 全零树：偷不偷都 0。
  • 链状树：递归深度 O(n)，n=10^4 栈内可承受。

复杂度与下限论证

  • 时间 O(n)：每节点一次 dfs + O(1) 转移；必须遍历全部节点才能知道所有值，Ω(n) 是下界，已达。
  • 空间 O(n)：递归栈最深 O(height)，链状树 height=n；无额外缓存，是树形递归的标准空间。
