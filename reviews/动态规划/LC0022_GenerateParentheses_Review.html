题目描述

数字 n 代表生成括号的对数，请你设计一个函数，用于能够生成所有可能的并且 有效的 括号组合。

示例 1：

输入：n = 3

输出：["((()))","(()())","(())()","()(())","()()()"]

示例 2：

输入：n = 1

输出：["()"]

List<String> ans;
    public List<String> generateParenthesis(int n) {
        ans = new ArrayList<>();
        dfs(n, n, new StringBuilder());
        return ans;
    }

    private void dfs(int left, int right, StringBuilder sb) {
        if (left < 0 || right < 0) {
            return;
        }

        if (left == right  && left == 0) {
            ans.add(sb.toString());
            return;
        }

        if (left > right) {
            return;
        }

        sb.append("(");
        dfs(left - 1, right, sb);
        sb.deleteCharAt(sb.length() - 1);

        sb.append(")");
        dfs(left, right - 1, sb);
        sb.deleteCharAt(sb.length() - 1);
    }

List<String> ans;
    public List<String> generateParenthesis(int n) {
        ans = new ArrayList<>();
        dfs(n, n, "");
        return ans;
    }

    private void dfs(int left, int right, String sb) {
        if (left < 0 || right < 0) {
            return;
        }
        if (left == right && left == 0) {
            ans.add(sb);
            return;
        }
        if (right < left) {
            return;
        }
        dfs(left - 1, right, sb + "(");

        dfs(left, right - 1, sb + ")");
    }

思路拆解

问题本质：生成 n 对括号的所有合法组合，数量是卡特兰数 C_n = (2n)!/((n+1)!·n!)。枚举每个位置放 ( 还是 )，用「已用右括号 ≤ 已用左括号」保证每一步前缀都合法。

为什么用回溯：

  • 每个位置只有两种选择，但 () 的合法组合不能靠排列硬凑，必须边生成边校验；
  • 回溯天然支持「生成一条路径 → 到底 → 撤销 → 换分支」的完整枚举。

关键设计：

  1. 状态：剩余左括号数 left、剩余右括号数 right、当前串 sb；
  2. 终止条件：left==0 && right==0 时当前串完整，加入答案；
  3. 剪枝：right < left 时说明已用右括号超过已用左括号，前缀已非法，直接返回；负数守卫防止 left 为 0 时仍递归减成 -1；
  4. 两条分支对称：加 ( → dfs(left-1, right)，加 ) → dfs(left, right-1)，各自递归后删除末尾字符撤销。

具体 case 推演（n=2，dfs(2,2)）：

  • 加 ( → (1,2)：加 ( → (0,2)：只能加 ) → (0,1) → 加 ) → (0,0) → 得到 (())；
  • 回溯回 (1,2)：改加 ) → (1,1)：加 ( → (0,1) → 加 ) → (0,0) → 得到 ()()；
  • 从 (2,2) 直接加 ) 的分支变成 (2,1)，right<left 剪枝，非法分支不产生。

边界与细节：

  • n=1 只有 ()；n=2 两个；n=4 14 个；n=8 1430 个（本地测试逐个校验合法性并检查去重）；
  • StringBuilder 加入答案时必须 toString 复制，否则后续撤销会改坏已存结果；
  • 题目约束 n >= 1，无需处理空输入。

复杂度分析：

  • 时间 O(C_n · n)：C_n 个合法串，每个长 2n；剪枝后的递归树只含合法前缀；
  • 空间 O(n)：递归深度 2n + 当前串（不含输出）。

为什么是最优：答案数量本身就是卡特兰数，任何算法至少要输出 C_n 个长度为 2n 的串；回溯让每个合法串恰好生成一次、无重复枚举，已达下限。

套路沉淀

括号生成回溯：剩余计数 + 前缀合法性剪枝

适用信号：列出所有受前缀约束的串（括号、表达式、路径），答案数本身指数级。用「还剩多少」代替「已用多少」：l/r 为剩余左/右括号数，剪枝条件就写成 l > r（已放下的 ) 已多于 (，前缀非法）。两种分支各带前提：放 ( 需 l>0，放 ) 需 r>l；共享 StringBuilder 在递归返回后立刻撤销末字符。终止在 l==r==0 收结果，剪枝放在终止判断之后，已完整的合法串不会被误剪。复杂度下限：答案 C_n 个、每个长 2n，输出开销本身 Ω(C_n·n)。对照 LC0301：那题先算最小删除预算再删，本题构造时维护剩余计数，共同点是把非法前缀的整棵子树砍掉。
