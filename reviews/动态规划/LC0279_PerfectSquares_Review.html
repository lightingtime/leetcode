279. 完全平方数 (Perfect Squares)

> https://leetcode.cn/problems/perfect-squares/

难度：Medium ｜ 分类：动态规划

标签：广度优先搜索、数学、动态规划、背包问题、完全背包

题目描述

给你一个整数 n ，返回 和为 n 的完全平方数的最少数量 。

完全平方数 是一个整数，其值等于另一个整数的平方；换句话说，其值等于一个整数自乘的积。例如，1、4、9 和 16 都是完全平方数，而 3 和 11 不是。

示例 1：

输入：n = 12

输出：3

解释：12 = 4 + 4 + 4

示例 2：

输入：n = 13

输出：2

解释：13 = 4 + 9

思路拆解（状态与转移）

  • 状态：dp[i] = 恰好凑成 i 的最少完全平方数个数；容量维度就是 i 本身，物品是 1²、2²、3²…，每件可无限次使用，属完全背包（DP 子类型：背包DP）。
  • 转移：dp[i] = min(dp[i - j²] + 1)，j 取 1..√i；正序枚举平方数保证同一件可重复使用。
  • 结束：返回 dp[n]；dp[0]=0，其余初值 Integer.MAX_VALUE。

用具体输入逐层走一遍

  • 从 dp[0]=0 出发：i=1 时只有 j=1，dp[1]=dp[0]+1=1。
  • i=4：j=1 得 dp[3]+1=4，j=2 得 dp[0]+1=1，取较小值 dp[4]=1，对应 4=2²。
  • i=12：j=1 得 dp[11]+1=4，j=2 得 dp[8]+1=3，j=3 得 dp[3]+1=4，最小 3，对应 12=4+4+4。
  • i=13：j=1 得 dp[12]+1=4，j=2 得 dp[9]+1=2，j=3 得 dp[4]+1=2，最小 2，对应 13=4+9。

LC0279_PerfectSquares.java · 一维DP（枚举最后一块平方数）提交区
public int numSquares(int n) {
        int[] dp = new int[n + 1];
        Arrays.fill(dp, Integer.MAX_VALUE);
        dp[0] = 0;
        for (int i = 1; i <= n; i++) {
            for (int j = 1; j <= Math.sqrt(i); j++) {
                dp[i] = Math.min(dp[i], dp[i - j * j] + 1);
            }
        }
        return dp[n];
    }

思路拆解

问题本质与解法选择

求 n 的完全平方数最少数量，本质是「物品无限可用、凑总和最小化物品数」的完全背包/最短路问题：物品是 1、4、9、16…，要凑出总和 n 使个数最少。任何合法拆法都可以看成「最后一块 j² + 剩余 n−j² 的最优拆法」，剩余部分与整体同构且更小，满足最优子结构；枚举所有组合是指数级，DP 自底向上填表避免重复计算。

关键设计决策

  1. 状态：dp[i] = 和为 i 所需的最少平方数个数；dp[0]=0（和为 0 用 0 个），dp[1..n] 初始化成一个足够大的值（如 n+1），防止 min 把未计算的 0 当成候选。
  2. 转移：dp[i] = min over j=1..⌊√i⌋ (dp[i−j²] + 1)：枚举最后一块 j²，前面部分用已算好的最优子解，+1 数上这一块本身。
  3. 填表顺序：i 从小到大，保证任何候选 dp[i−j²]（下标更小）先就绪——自底向上原则。
  4. 答案：dp[n]。

边界与细节

  • n=1：内层只试 1²，dp[1]=dp[0]+1=1。
  • n 本身是平方数：如 4，试到 2² 时 dp[0]+1=1。
  • 上限大数：n=10000=100²，答案 1；O(n·√n) 约 10^6 次操作，很快。
  • 溢出安全：dp[i−j²] 下标更小、必已算好，不会拿 MAX_VALUE 参与加法。
  • 推演 case：n=13。
  1. dp[0]=0；i=1：j=1 → dp[0]+1=1。
  2. i=4：j=1 → dp[3]+1=4；j=2 → dp[0]+1=1 → dp[4]=1。
  3. i=8：j=1 → dp[7]+1=4；j=2 → dp[4]+1=2 → dp[8]=2（4+4）。
  4. i=13：j=1 → dp[12]+1=4；j=2 → dp[9]+1=2；j=3 → dp[4]+1=2 → dp[13]=2（4+9 或 9+4）✓。

复杂度与下限论证

  • 时间 O(n·√n)：外层 n 个 i，内层最多 ⌊√i⌋ 个候选，Σ√i = O(n·√n)；n≤10^4 时约百万次，可接受。
  • 空间 O(n)：dp 数组长度 n+1。
  • 为什么可接受/下限：每个 i 必须比较其全部可用平方数候选才能保证不漏最优（贪心取最大块会错，如 12 取 9 得 4 个而最优 3 个），「枚举最后一块取 min」是这类拆分数 DP 的自然复杂度；另有四平方和定理的数学解法可常数级判定（答案为 1/2/4 的判断），属于特例延伸，DP 是通用可迁移的做法。

套路沉淀

完全背包一维压缩（正序枚举）

物品可无限次使用时，一维 dp 按容量从小到大正序填表，dp[c] 才能复用本轮刚更新的 dp[c-w]；改成倒序就退化成 0-1 背包。本题 w=j²、每件代价 1，求恰好装满容量 n 的最小代价。
