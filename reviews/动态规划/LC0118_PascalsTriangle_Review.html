public List<List<Integer>> generate(int numRows) {
        List<List<Integer>> ans = new ArrayList<>();
        List<Integer> list = new ArrayList<>();
        list.add(1);
        ans.add(list);
        if (numRows == 1) {
            return ans;
        }
        for (int i = 2; i <= numRows; i++) {
            List<Integer> temp = generateHelper(ans.get(ans.size() - 1));
            ans.add(temp);
        }
        return ans;
    }

    private List<Integer> generateHelper(List<Integer> list) {
        int[] cur = new int[list.size() + 1];
        cur[0] = 1;
        for (int i = 1; i < cur.length - 1; i++) {
            cur[i] = list.get(i - 1) + list.get(i);
        }
        cur[cur.length - 1] = 1;
        return Arrays.stream(cur).boxed().toList();
    }

线性递推逐行生成：ans[i][j]=ans[i-1][j-1]+ans[i-1][j]，首尾置 1，从 [1] 滚动推进

思路拆解

## ① 问题本质与解法选择

  • 本质：按规则构造二维三角形数组，不求最值——属于「递推生成」型线性 DP：状态天然就是「第 i 行第 j 列」，转移关系由题目定义直接给出。
  • 解法选择：逐行递推。第 i 行只依赖第 i-1 行，拿着上一行滚动前进即可，不需要额外数据结构。

## ② 关键设计决策

设计点决策说明
状态ans[i][j] = 第 i 行第 j 列的值（0 起）即二项式系数 C(i,j)
转移内部位置 ans[i][j] = ans[i-1][j-1] + ans[i-1][j]左上 + 右上
边界每行首尾 = 1；第 1 行整体 [1]对应 C(i,0)=C(i,i)=1
填表顺序从 [1] 出发，i 从 2 到 numRows 逐行派生numRows=1 时循环体自然不执行

具体 case 推演（numRows=5）逐行状态变化：

行 i长度内部位置的逐个计算
01初值 [1]
12只有首尾 → [1,1]
23cur[1]=prev[0]+prev[1]=1+1=2 → [1,2,1]
34cur[1]=1+2=3；cur[2]=2+1=3 → [1,3,3,1]
45cur[1]=1+3=4；cur[2]=3+3=6；cur[3]=3+1=4 → [1,4,6,4,1]

细节：第 i 行内部下标 j 的有效范围是 1..len-2（开区间，不含首尾），写循环边界时最容易在这里差一。

## ③ 边界与细节

  • numRows=1：直接返回 [[1]]；主循环 i<=numRows 条件天然覆盖，无需单独特判 return
  • numRows=2：第一次从上一行派生且没有内部位置，验证首尾分支
  • numRows=30 上限：最大值 C(29,14)=77558760 < 2^31-1，int 不会溢出；总元素 30×31÷2=465
  • 数值锚点：第 10 行等于 C(9,k) 序列 [1,9,36,84,126,126,84,36,9,1]

## ④ 复杂度与下限论证

  • 时间 O(n²)：n(n+1)/2 个元素每个恰好计算一次。
  • 空间：输出 O(n²)；辅助只有当前行的临时数组 O(行长)。
  • 下限论证：答案本身就含 Θ(n²) 个数字，任何算法都至少要把它们写出来一遍，因此 O(n²) 是硬下限，本题不存在更快做法。

杨辉恒等式递推
