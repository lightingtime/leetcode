public int minPathSum(int[][] grid) {
        int[] dp = new int[grid[0].length];
        for (int i = 0; i < dp.length; i++) {
            if (i == 0) {
                dp[i] = grid[0][i];
            } else {
                dp[i] = dp[i - 1] + grid[0][i];
            }
        }
        for (int i = 1; i < grid.length; i++) {
            for (int j = 0; j < grid[0].length; j++) {
                if (j == 0) {
                    dp[j] = dp[j] + grid[i][0];
                } else {
                    dp[j] = Math.min(dp[j], dp[j - 1]) + grid[i][j];
                }
            }
        }
        return dp[grid[0].length - 1];
    }

dp[i][j]=grid[i][j]+min(上,左)，一维 dp[j] 滚动：先铺第一行，主循环从 i=1 起，j 必须用列变量；66/66 一次 Accepted

思路拆解

问题本质

从左上角到右下角只能向下/向右，求路径数字总和最小 = 每个格子的最小和只依赖「上边」和「左边」两个格子，经典二维 DP。

为什么用 DP + 一维滚动数组

  • 状态：dp[i][j] = 到达 (i,j) 的最小路径和；转移：dp[i][j] = grid[i][j] + min(dp[i-1][j], dp[i][j-1])。
  • 观察依赖：填第 i 行只需要上一行整行 + 本行左边已算好的部分，更早的行不再使用 → 用一维数组 dp[j] 滚动，空间从 O(m·n) 压到 O(n)。
  • 更新顺序必须从左到右：dp[j] 更新前存「上一行第 j 列」（正上方），dp[j-1] 已被本行覆盖成「本行左边」。

关键设计决策

  • 初始化第一行：只能从左往右累加（dp[j] = dp[j-1] + grid[0][j]）。
  • 主循环从第 1 行开始（第一行已铺好，不能从 0 重滚，否则重复累加）。
  • 每行第一列：dp[0] = dp[0] + grid[i][0]（只能从上边来）。
  • 普通列：dp[j] = min(dp[j], dp[j-1]) + grid[i][j]。
  • 下标必须用列变量 j：dp 长度 = 列数，用行变量 i 当下标会越界/算错。

小 case 推演

示例1 grid = [[1,3,1],[1,5,1],[4,2,1]]：

  1. 铺第一行：dp = [1, 4, 5]
  2. i=1：dp[0] = 1+1 = 2；j=1: min(4,2)+5 = 7；j=2: min(5,7)+1 = 6 → dp = [2,7,6]
  3. i=2：dp[0] = 2+4 = 6；j=1: min(7,6)+2 = 8；j=2: min(6,8)+1 = 7 → 答案 7 ✅

边界与细节

  • 单行/单列：只有一条路，按方向累加即可（滚动数组天然处理）。
  • 单元素：答案就是 grid[0][0]。
  • 全零矩阵：最小和 0。
  • 大矩阵 200×200 全 1：必须走 200+200-1 = 399 格，验证不越界与长度计算。

复杂度与下限论证

  • 时间 O(m·n)：每个格子恰好访问一次，任何解法都必须看遍所有格子 → O(m·n) 是下界，已达最优。
  • 空间 O(n)：一维滚动数组（若按较短维度滚动可到 O(min(m,n))）；答案只有一个数，无需额外输出空间。
  • 结论：二维 DP + 一维滚动是本题标准最优解。
