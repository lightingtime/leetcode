src/动态规划/LC0042_TrappingRainWater.java提交区
public int trap(int[] height) {
        int left = 0, right = height.length - 1;
        int leftMax = 0, rightMax = 0;
        int water = 0;
        while (left < right) {
            leftMax = Math.max(leftMax, height[left]);
            rightMax = Math.max(rightMax, height[right]);
            if (leftMax < rightMax) {
                water += leftMax - height[left];
                left++;
            } else {
                water += rightMax - height[right];
                right--;
            }
        }
        return water;
    }

left数组+滚动右最大值，O(n) 一次通过

思路拆解

问题本质与解法选择

每格能存的水由「左右两侧最高柱子的较矮者」决定：water[i] = max(0, min(左侧最高, 右侧最高) − height[i])，其中左右最高都不含自身。暴力对每格左右各扫一遍是 O(n²)；把「左侧最高」「右侧最高」预计算成数组就是前缀/后缀递推（leftMax[i]=max(leftMax[i-1], height[i])），这正是本题归入 DP 的形态——子问题（到 i 为止的最高值）被反复复用，每格查表 O(1)，总 O(n)。本题实现进一步把右侧最高改成滚动变量，只留 left 一个数组。

关键设计决策（按用户实际写法）

  1. left[i] = height[0..i−1] 的最大值（不含 i 本身）：left[i]=max(left[i−1], height[i−1])，从左到右一次填好；left[0]=0（左侧无柱子）。
  2. 从右往左第二次扫描：pre 滚动表示「当前 i 右侧的最大值」= max(height[i+1..n−1])，初始 i=n−1 时 pre=0。
  3. 每格累加 ans += max(0, min(left[i], pre) − height[i])，随后 pre = max(pre, height[i])，保证下一轮（i−1）的右侧最大值包含当前高度。
  4. 返回 ans。

边界与细节

  • 单元素/两元素：每格 min(左,右) 至多等于自身高度，差 ≤0，ans=0。
  • 两端：left[0]=0、pre 初始 0，公式天然给出 0。
  • 全相等/递增/递减：存水为 0，公式自动处理。
  • int 溢出安全：每格水 ≤10⁵、n≤2×10⁴，总量 ≤2×10⁹ < int 上限，用 int 安全。
  • 推演 case：height=[4,2,0,3,2,5]。
  1. left=[0,4,4,4,4,4]。
  2. 从右往左：i=5：min(4,0)−5<0→0，pre=5；i=4：min(4,5)−2=2；i=3：min(4,5)−3=1；i=2：min(4,5)−0=4；i=1：min(4,5)−2=2；i=0：min(0,5)−4<0→0。
  3. ans=0+2+1+4+2+0=9 ✓。
  • 推演 case：height=[2,0,2]：left=[0,2,2]；i=2→0、pre=2；i=1：min(2,2)−0=2；i=0→0 → ans=2 ✓。

复杂度与下限论证

  • 时间 O(n)：两次线性扫描，每格常数工作；每个位置的水量依赖两侧全局信息，至少需要线性时间，O(n) 已达下限。
  • 空间 O(n)：left 数组；改用双指针可进一步降到 O(1) 空间，属同一思路的常数优化。
  • 与暴力对比：暴力每格 O(n) 重复找两侧最高，DP 把「两侧最高」变成可复用状态，正是 DP 消除重复计算的价值所在。
