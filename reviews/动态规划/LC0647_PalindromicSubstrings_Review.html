public int countSubstrings(String s) {
        int ans = 0;
        int n = s.length();
        for (int i = 0; i < 2 * n - 1; i++) {
            int l = i / 2, r = (i + 1) / 2;
            while (l >= 0 && r < n && s.charAt(l) == s.charAt(r)) {
                l--;
                r++;
                ans++;
            }
        }
        return ans;
    }

中心扩散：枚举 2n-1 个奇数/偶数中心，向两侧扩展；每次成功扩展计数，O(n^2)/O(1)，一次 Accepted

思路拆解

问题本质：统计字符串中所有回文子串。与其枚举每个区间再判断，不如利用每个回文串都有唯一中心的性质，直接枚举中心并向两侧验证，因此不需要保存二维 DP 表。

解法选择理由：

  • 奇数长度回文有一个字符作为中心，例如 aba 的中心是 b。
  • 偶数长度回文有两个字符之间的间隙作为中心，例如 abba 的中心是 bb 之间的间隙。
  • 长度为 n 的字符串共有 n 个字符中心和 n-1 个间隙中心，共 2n-1 个中心。

关键设计：

  1. 用 i 枚举中心编号，范围是 0 <= i < 2*n-1。这里的 i 不是子串长度，而是把字符中心和间隙中心统一编号后的中心编号。
  2. 用 l = i/2、r = (i+1)/2 把中心编号映射为左右指针。以 s = "abc"、n = 3 为例：
il = i/2r = (i+1)/2实际中心类型
000下标 0 的 a字符中心，奇数回文
101a 与 b 之间间隙中心，偶数回文
211下标 1 的 b字符中心，奇数回文
312b 与 c 之间间隙中心，偶数回文
422下标 2 的 c字符中心，奇数回文

因此循环写成 i < 2*n-1：当 n=3 时，i 依次为 0,1,2,3,4，刚好覆盖 3 个字符中心和 2 个间隙中心；如果再取 i=5，映射会得到 l=2、r=3，右指针已经越界。

  1. 只要 l、r 没越界且两端字符相等，s[l..r] 就是一个新的回文子串，计数加一，然后继续向外扩展。
  2. 单字符回文由 l==r 的第一次检查自然统计；长度为二及以上的回文由后续扩展统计。
  3. 扩展停止条件是越界或两端字符不相等。

具体 case 推演（s = "aaa"）：

  • 字符中心 a（下标 0）：先统计 a，向外越界，贡献 1。
  • 间隙中心（下标 0 和 1 之间）：统计 aa，继续扩展得到 aaa，贡献 2。
  • 字符中心 a（下标 1）：统计 a，向外得到 aaa，再扩展越界，贡献 2。
  • 间隙中心（下标 1 和 2 之间）：统计 aa，贡献 1。
  • 字符中心 a（下标 2）：统计 a，贡献 1。
  • 总数为 1+2+2+1+1=6。

边界与细节：

  • 空串：n=0 时循环范围为空，返回 0。
  • 单字符：只有一个字符中心，返回 1。
  • 两个不同字符：两个字符中心各贡献 1，间隙中心第一次比较失败，不会错误统计长度 2 回文。
  • 全相同字符串会触发最深扩展，能够覆盖最坏情况。

复杂度分析：

  • 时间复杂度 O(n^2)：共有 2n-1 个中心，最坏情况下每个中心都可能向两边扩展 O(n) 次。
  • 空间复杂度 O(1)：只使用计数器、字符串长度和左右指针，没有额外 DP 数组。
  • 这是本题常规解法中空间最优、实现简洁且足够高效的方案；虽然 Manacher 可以把时间降到 O(n)，但复杂度和实现成本都明显更高，本题无需使用。
