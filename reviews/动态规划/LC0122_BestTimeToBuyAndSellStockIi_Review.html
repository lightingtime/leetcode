122. 买卖股票的最佳时机 II (Best Time to Buy and Sell Stock II)

> https://leetcode.cn/problems/best-time-to-buy-and-sell-stock-ii/

难度：Medium ｜ 分类：动态规划

标签：贪心、数组、动态规划

题目描述

给你一个整数数组 prices ，其中 prices[i] 表示某支股票第 i 天的价格。

在每一天，你可以决定是否购买和/或出售股票。你在任何时候 最多 只能持有 一股 股票。然而，你可以在 同一天 多次买卖该股票，但要确保你持有的股票不超过一股。

返回 你能获得的 最大 利润 。

示例 1：

输入：prices = [7,1,5,3,6,4]

输出：7

解释：在第 2 天（股票价格 = 1）的时候买入，在第 3 天（股票价格 = 5）的时候卖出, 这笔交易所能获得利润 = 5 - 1 = 4。

随后，在第 4 天（股票价格 = 3）的时候买入，在第 5 天（股票价格 = 6）的时候卖出, 这笔交易所能获得利润 = 6 - 3 = 3。

最大总利润为 4 + 3 = 7 。

示例 2：

输入：prices = [1,2,3,4,5]

输出：4

解释：在第 1 天（股票价格 = 1）的时候买入，在第 5 天 （股票价格 = 5）的时候卖出, 这笔交易所能获得利润 = 5 - 1 = 4。

最大总利润为 4 。

示例 3：

输入：prices = [7,6,4,3,1]

输出：0

解释：在这种情况下, 交易无法获得正利润，所以不参与交易可以获得最大利润，最大利润为 0。

我的解法

写法 1 · 状态机DP

时间 O(n)空间 O(n)可滚动O(1)内存 ≈ 44.7 MB用例 203/203

LC0122_BestTimeToBuyAndSellStockIi.java · 状态机DP提交区
public int maxProfit(int[] prices) {
    int[][] dp = new int[prices.length][2];
    dp[0][1] = -prices[0];
    for (int i = 1; i < prices.length; i++) {
        dp[i][0] = Math.max(dp[i - 1][0], dp[i - 1][1] + prices[i]);
        dp[i][1] = Math.max(dp[i - 1][0] - prices[i], dp[i - 1][1]);
    }
    return dp[prices.length - 1][0];
}

写法 2 · 贪心累加正差价

时间 O(n)空间 O(1)内存 ≈ 44.4 MB用例 203/203

LC0122_BestTimeToBuyAndSellStockIi.java · 贪心累加正差价提交区
public int maxProfit(int[] prices) {
    int max = 0;
    for (int i = 1; i < prices.length; i++) {
        if (prices[i] > prices[i - 1]) {
            max += (prices[i] - prices[i - 1]);
        }
    }
    return max;
}

思路拆解

① 问题本质与解法选择

  • 本质：交易次数不限、每次至多持有一股，最大化累计利润。两个等价建模视角：状态机 DP（空仓/持有两状态逐天转移）与贪心（累加所有正相邻差价）。
  • 关系：贪心是状态机的极限简化——不限次数时，「每个上涨相邻差值都兑现」等价于「每个局部低点买入、高点卖出」，两者利润一致。

② 关键设计决策（两写法对照）

写法状态机 DP贪心
状态dp[i][0] 空仓 / dp[i][1] 持有无状态，单变量累加
转移空仓=max(昨空, 昨持+今天价)；持有=max(昨空-今天价, 昨持)profit += max(0, prices[i]-prices[i-1])
初值dp[0][1]=-prices[0]（第 0 天买入）profit=0
答案dp[n-1][0]profit
复杂度O(n)/O(n)O(n)/O(1)

③ 具体 case 推演

边界4 [1,2,1,2] 贪心逐差：

iprices[i]差价累计 profit
122-1=1>0 → +11
211-2=-1<0 → +01
322-1=1>0 → +12

结果 2 ✓（买1卖2 + 买1卖2）。单调增 [1,2,3,4,5]：1+1+1+1=4，等于第 1 天买第 5 天卖——证明逐差相加与整段持有等价。单调减 [7,6,4,3,1]：无正差价 → 0 ✓。

④ 边界与细节

  • 单日：循环不执行 → 0
  • 全相同：差价全 0 → 0
  • 含 0 价（约束允许）：0 买 1 卖赚 1
  • 长度 30000 上限交替 1,2：15000 个 +1 → 15000
  • 溢出：答案上界约 1.5×10^8 < 2^31-1，int 安全（题目亦保证）

⑤ 复杂度与下限论证

  • 时间 O(n)：必须读一遍所有差价，Ω(n) 是下限
  • 空间 O(1)：贪心无额外数组，已达下限；状态机 DP 的 O(n) 可滚动到 O(1)
  • 贪心正确性：任意交易收益 = Σ(卖出-买入)，可展开为一串相邻差值的带符号和；正差价互不重叠地对应各段上涨，负差价（下跌段）跳过即等价于不参与。取每个正差价构成全局最优。
