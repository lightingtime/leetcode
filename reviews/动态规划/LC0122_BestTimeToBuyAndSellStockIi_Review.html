写法 1 · 状态机DP

时间 O(n)空间 O(n)可滚动O(1)内存 ≈ 44.7 MB用例 203/203

LC0122_BestTimeToBuyAndSellStockIi.java · 状态机DP提交区
public int maxProfit(int[] prices) {
    int[][] dp = new int[prices.length][2];
    dp[0][1] = -prices[0];
    for (int i = 1; i < prices.length; i++) {
        dp[i][0] = Math.max(dp[i - 1][0], dp[i - 1][1] + prices[i]);
        dp[i][1] = Math.max(dp[i - 1][0] - prices[i], dp[i - 1][1]);
    }
    return dp[prices.length - 1][0];
}

写法 2 · 贪心累加正差价

时间 O(n)空间 O(1)内存 ≈ 44.4 MB用例 203/203

LC0122_BestTimeToBuyAndSellStockIi.java · 贪心累加正差价提交区
public int maxProfit(int[] prices) {
    int max = 0;
    for (int i = 1; i < prices.length; i++) {
        if (prices[i] > prices[i - 1]) {
            max += (prices[i] - prices[i - 1]);
        }
    }
    return max;
}

写法2：贪心累加所有正相邻差价，O(n)/O(1)，已达空间下限

思路拆解

## ① 问题本质与解法选择

  • 本质：交易次数不限、每次至多持有一股，最大化累计利润。两个等价建模视角：状态机 DP（空仓/持有两状态逐天转移）与贪心（累加所有正相邻差价）。
  • 关系：贪心是状态机的极限简化——不限次数时，「每个上涨相邻差值都兑现」等价于「每个局部低点买入、高点卖出」，两者利润一致。

## ② 关键设计决策（两写法对照）

写法状态机 DP贪心
状态dp[i][0] 空仓 / dp[i][1] 持有无状态，单变量累加
转移空仓=max(昨空, 昨持+今天价)；持有=max(昨空-今天价, 昨持)profit += max(0, prices[i]-prices[i-1])
初值dp[0][1]=-prices[0]（第 0 天买入）profit=0
答案dp[n-1][0]profit
复杂度O(n)/O(n)O(n)/O(1)

## ④ 边界与细节

  • 单日：循环不执行 → 0
  • 全相同：差价全 0 → 0
  • 含 0 价（约束允许）：0 买 1 卖赚 1
  • 长度 30000 上限交替 1,2：15000 个 +1 → 15000
  • 溢出：答案上界约 1.5×10^8 < 2^31-1，int 安全（题目亦保证）

## ⑤ 复杂度与下限论证

  • 时间 O(n)：必须读一遍所有差价，Ω(n) 是下限
  • 空间 O(1)：贪心无额外数组，已达下限；状态机 DP 的 O(n) 可滚动到 O(1)
  • 贪心正确性：任意交易收益 = Σ(卖出-买入)，可展开为一串相邻差值的带符号和；正差价互不重叠地对应各段上涨，负差价（下跌段）跳过即等价于不参与。取每个正差价构成全局最优。
