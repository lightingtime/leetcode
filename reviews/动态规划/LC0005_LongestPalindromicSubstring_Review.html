5. 最长回文子串 (Longest Palindromic Substring)

> https://leetcode.cn/problems/longest-palindromic-substring/

难度：Medium ｜ 分类：动态规划

标签：双指针、字符串、动态规划、Manacher 算法

题目描述

给你一个字符串 s，找到 s 中最长的 回文 子串。

示例 1：

输入：s = "babad"

输出："bab"

解释："aba" 同样是符合题意的答案。

示例 2：

输入：s = "cbbd"

输出："bb"

提示：

s 仅由数字和英文字母组成

与上一轮对比

具体推演与错误规避

  • 输入 cbbd。扫描到 i=1 时，偶数中心调用 getLen(1,2)：b 与 b 相等，于是 l=0、r=3；接着比较 c 与 d 不相等，返回 3-0-1=2。
  • 此时 max 从 1 更新为 2，start 计算为 1-(2-1)/2=1，最终截取 s.substring(1,3) 得到 bb。
  • 输入 babad 时，i=1 的奇数中心先得到回文 bab；i=2 的奇数中心继续得到 aba，长度同样是 3，因此保留先记录的 bab。两种答案都合法。
  • 本次没有把偶数中心和奇数中心漏掉，也没有在失配后错误截取长度；这避开了此前全相同长串因冗余扫描导致的 TLE 问题。

① 与上一轮对比：仍是中心扩散，单层枚举 2n-1 个中心；每个中心分别测奇中心 (i,i) 和偶中心 (i,i+1)，没有额外套长度循环。复杂度保持 O(n^2) / O(1)，最多同时只有一个最长结果需要保存。

我的解法

写法 1 · 区间 DP（boolean 表）

时间 O(n^2)空间 O(n^2)内存 ≈ 46.9 MB用例 144/144

LC0005_LongestPalindromicSubstring.java · 区间 DP（boolean 表）提交区
public String longestPalindrome(String s) {
        int n = s.length();
        boolean[][] dp = new boolean[n][n];
        for (int i = 0; i < n; i++) {
            dp[i][i] = true;
            if (i < n - 1 && s.charAt(i) == s.charAt(i + 1)) {
                dp[i][i + 1] = true;
            }
        }
        String ans = "";
        for (int i = n - 1; i >= 0; i--) {
            for (int j = 0; j < n; j++) {
                if (j - i >= 2 && s.charAt(i) == s.charAt(j)) {
                    dp[i][j] = dp[i + 1][j - 1];
                }
                if (dp[i][j] && j - i >= ans.length()) {
                    ans = s.substring(i, j + 1);
                }
            }
        }
        return ans;
    }

写法 2 · 中心扩散

时间 O(n²)空间 O(1)内存 ≈ 41.8 MB用例 144/144

LC0005_LongestPalindromicSubstring.java · 中心扩散提交区
public String longestPalindrome(String s) {
        int max = 0;
        int start = 0;
        for (int i = 0; i < s.length(); i++) {
            int len1 = getLen(s, i, i);
            int len2 = getLen(s, i, i + 1);
            int len = Math.max(len1, len2);
            if (len > max) {
                max = len;
                start = i - (max - 1) / 2;
            }
        }
        return s.substring(start, start + max);
    }

    private int getLen(String s, int l, int r) {
        while (l >= 0 && r < s.length() && s.charAt(l) == s.charAt(r)) {
            l--;
            r++;
        }
        return r - l - 1;
    }

public String longestPalindrome(String s) {
        int n = s.length();
        if (n < 2) return s;
        int maxLen = 0;
        int start = -1;
        for (int i = 0; i < n; i++) {
            int len1 = getLen(s, i, i);
            int len2 = getLen(s, i, i + 1);
            int len = Math.max(len1, len2);
            if (len > maxLen) {
                maxLen = len;
                start = i - (maxLen - 1) / 2;
            }
        }
        return s.substring(start, start + maxLen);
    }

    private int getLen(String s, int l, int r) {
        while (l >= 0 && r < s.length() && s.charAt(l) == s.charAt(r)) {
            l--;
            r++;
        }
        return r - l - 1;
    }

思路拆解

问题本质：找最长回文子串。本题有 DP 与中心扩散两种常规解法，均已提交记录。

写法 1 · 区间 DP（已提交）：

  • dp[i][j] = s[i..j] 是否为回文，转移 dp[i][j] = (s[i]==s[j]) && dp[i+1][j-1]（j-i >= 2）；
  • base：长度 1 恒真、长度 2 两端相等；填表用 i 倒序满足依赖方向；答案更新必须校验 dp[i][j]==true；
  • 复杂度 O(n^2) 时间、O(n^2) 空间。

写法 2 · 中心扩散（已提交）：

  • 每个回文有唯一中心：奇数长度中心是字符本身，偶数长度中心是两个字符之间，共 2n-1 个中心；
  • 对每个中心向两边扩散直到两端不等，返回半径长度；
  • 主循环对每个 i 分别以 (i,i) 和 (i,i+1) 为起点扩散，取更长者更新答案；
  • 起点换算：start = i - (maxLen-1)/2；
  • 复杂度 O(n^2) 时间（每个中心最多扩 O(n)）、O(1) 空间。

具体 case 推演（s=babad）：

  • 中心 = 下标 1 的 a：b==b → bab（长 3），越界停；
  • 中心 = 下标 2 的 b：a==a → aba（长 3），再外 b!=d 停；
  • 空隙中心（a 与 b 之间）：a!=b，长 0；
  • 最长 3，bab / aba 任取。

两种写法对比：

  • DP 状态定义更「正统」，方便扩展（如回文子序列）；中心扩散代码更简洁、空间 O(1)；
  • 时间同为 O(n^2)；Manacher 可到 O(n) 是进阶。

为什么是最优/可接受：O(n^2) 是本题常规最优解（暴力 O(n^3) 不可接受）；中心扩散的空间 O(1) 是两种常规解法里最优的。

套路沉淀

DP 填表顺序满足依赖方向 + 答案更新必须校验状态

出处：LC0005 最长回文子串

  • dp[i][j] 依赖 dp[i+1][j-1]（左下方），按 i 正序、j 内层正序填会读到未计算的格子，必须按子串长度从小到大填（或 i 倒序）；
  • 记录答案/最优解前必须确认 dp[i][j] 为 true：只看两端字符相等就更新会把非回文（如 abca）当成答案；
  • 具体 case：abca 的 dp[0][3]=dp[1][2]=false，但若 ans 更新不看 dp，会错误返回 abca。

要点：写 DP 先画依赖图确定填表顺序；从 dp 取值更新答案时，先校验状态本身成立。

  • 长度 2 的 base 不能走转移：dp[i][i+1] 已在初始化置位，主循环再执行 dp[i][j]=dp[i+1][j-1] 会读到无效下三角把 true 覆盖，偶数长度回文全断；长度 2 直接判两端相等或排除 j==i+1。
