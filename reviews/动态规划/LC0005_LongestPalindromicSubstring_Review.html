public String longestPalindrome(String s) {
        int n = s.length();
        boolean[][] dp = new boolean[n][n];
        for (int i = 0; i < n; i++) {
            dp[i][i] = true;
            if (i < n - 1 && s.charAt(i) == s.charAt(i + 1)) {
                dp[i][i + 1] = true;
            }
        }
        String ans = "";
        for (int i = n - 1; i >= 0; i--) {
            for (int j = 0; j < n; j++) {
                if (j - i >= 2 && s.charAt(i) == s.charAt(j)) {
                    dp[i][j] = dp[i + 1][j - 1];
                }
                if (dp[i][j] && j - i >= ans.length()) {
                    ans = s.substring(i, j + 1);
                }
            }
        }
        return ans;
    }

区间 DP，长度 2 base 与填表顺序是两处关键坑

思路拆解

问题本质：找最长回文子串。回文的判定可以按「内部是回文 + 两端字符相等」递推，适合区间 DP。

状态与转移：

  • dp[i][j] = s[i..j] 是否为回文；
  • 转移：dp[i][j] = (s[i]==s[j]) && dp[i+1][j-1]，只对 j-i >= 2 有效（内部子串非空）；
  • base case：长度 1 恒为回文；长度 2 直接判两端相等。

关键设计（本轮踩过的三个坑）：

  1. 长度 2 的 base 不能走转移：相邻格 j==i+1 时 dp[i+1][j-1] 指向无效下三角（恒 false），会把初始化好的 true 覆盖掉，所有偶数长度回文断链——转移前先排除 j-i < 2；
  2. 填表顺序必须满足依赖：dp[i][j] 依赖 dp[i+1][j-1]（左下方），用 i 倒序（或按子串长度从小到大）填，保证依赖格子已计算；
  3. 记录答案必须校验 dp[i][j]==true：只看两端相等就更新会把非回文（abca）当成答案。

具体 case 推演：

  • s=babad：单字符 dp[i][i]=true；dp[0][2]：b==b 且 dp[1][1]=true → bab 成立；dp[1][3]：a==a 且 dp[2][2]=true → aba 成立，两者同长任取一个；
  • s=cbbd：dp[1][2] 长度 2 base（b==b）→ bb；dp[0][3]：c!=d 不成立，最长 bb；
  • 反例 abca：dp[0][3]=dp[1][2]=false（b!=c），若答案更新不看 dp 会错误返回 abca——所以校验必须加；
  • 反例 aa：dp[0][1] 初始化 true，若被转移 dp[1][0]=false 覆盖，返回会退化成单字符。

边界与细节：

  • 单字符返回自身；双字符相同/不同；全相同字符串应返回整串（长度 1000 测试覆盖）；
  • 两端相等但内部非回文（abca）必须返回单字符；
  • 奇数/偶数长度中心都要能扩张（cbbd 偶数、babad 奇数）。

复杂度分析：

  • 时间 O(n^2)：n^2 个状态各算一次；
  • 空间 O(n^2)：boolean 表（可滚动优化到 O(n)，本题不必须）。

为什么是可接受/最优：O(n^2) 区间 DP 是本题标准解法，每个子串恰好判定一次；进阶可用 Manacher 达到 O(n)，但对刷题/面试而言 DP 已是常规最优。

套路沉淀

DP 填表顺序满足依赖方向 + 答案更新必须校验状态

出处：LC0005 最长回文子串

  • dp[i][j] 依赖 dp[i+1][j-1]（左下方），按 i 正序、j 内层正序填会读到未计算的格子，必须按子串长度从小到大填（或 i 倒序）；
  • 记录答案/最优解前必须确认 dp[i][j] 为 true：只看两端字符相等就更新会把非回文（如 abca）当成答案；
  • 具体 case：abca 的 dp[0][3]=dp[1][2]=false，但若 ans 更新不看 dp，会错误返回 abca。

要点：写 DP 先画依赖图确定填表顺序；从 dp 取值更新答案时，先校验状态本身成立。

  • 长度 2 的 base 不能走转移：dp[i][i+1] 已在初始化置位，主循环再执行 dp[i][j]=dp[i+1][j-1] 会读到无效下三角把 true 覆盖，偶数长度回文全断；长度 2 直接判两端相等或排除 j==i+1。
