62. 不同路径 (Unique Paths)

> https://leetcode.cn/problems/unique-paths/

难度：Medium ｜ 分类：动态规划

标签：数学、动态规划、组合数学

题目描述

一个机器人位于一个 m x n 网格的左上角 （起始点在下图中标记为 “Start” ）。

机器人每次只能向下或者向右移动一步。机器人试图达到网格的右下角（在下图中标记为 “Finish” ）。

问总共有多少条不同的路径？

示例 1：

输入：m = 3, n = 7

输出：28

示例 2：

输入：m = 3, n = 2

输出：3

解释：

从左上角开始，总共有 3 条路径可以到达右下角。

  1. 向右 -> 向下 -> 向下
  2. 向下 -> 向下 -> 向右
  3. 向下 -> 向右 -> 向下

示例 3：

输入：m = 7, n = 3

输出：28

示例 4：

输入：m = 3, n = 3

输出：6

LC0062_UniquePaths.java · 一维滚动 DP提交区
public int uniquePaths(int m, int n) {
        int[] dp = new int[n];
        Arrays.fill(dp, 1);
        for (int i = 1; i < m; i++) {
            for (int j = 1; j < n; j++) {
                dp[j] = dp[j - 1] + dp[j];
            }
        }
        return dp[n - 1];
    }

public int uniquePaths(int m, int n) {

        dp[0] = 1;
        for (int i = 0; i < m; i++) {

思路拆解

问题本质：m×n 网格，只能向右/向下，到右下角有多少条路径。到达 (i,j) 的上一步来自上方或左边，所以 dp[i][j] = dp[i-1][j] + dp[i][j-1]；组合视角答案是 C(m+n-2, m-1)，可作扩展理解。

为什么用一维滚动：

  • 转移只用上一行同列（上方）与本行左边（左方），二维表可滚动为一行；
  • 空间从 O(m·n) 降到 O(n)，时间保持 O(m·n) 不变。

关键设计：

  1. 状态：dp[j] 表示当前行第 j 列的路径数；更新式 dp[j] = dp[j-1] + dp[j]（dp[j] 旧值=上方，dp[j-1] 新值=左边）；
  2. 内层从左到右，保证左边用本行已更新的值；
  3. 初始化与循环统一写法：只置 dp[0]=1（第一列永远 1），循环 i=0..m-1、j=1..n-1，第一行由第一趟自然生成——省去 Arrays.fill 与循环起点偏移，规避「多算一行」类 off-by-one；
  4. 第一列 dp[0] 全程保持 1。

具体 case 推演（3×2，统一写法）：

  • 初始 dp=[1,0]；i=0：j=1 → dp[1]=0+1=1 → [1,1]（第一行）；
  • i=1：j=1 → dp[1]=1+1=2 → [1,2]；
  • i=2：j=1 → dp[1]=2+1=3 → [1,3]；
  • 答案 dp[1]=3。

边界与细节：

  • m=1 或 n=1：只有一条直线路径，返回 1（1×1 也是 1）；
  • 17×17 答案 601080390 不溢出 int（题目保证答案 ≤ 2×10^9）；
  • 本轮的坑：初始 fill 全 1 已代表第一行，循环若从 i=0 开始会多算一行（m=1,n=10 得 10）；统一写法消除了「初始化行」的语义，天然规避。

复杂度分析：

  • 时间 O(m·n)：每个格子算一次；
  • 空间 O(n)：滚动一行。

为什么是最优：每个格子至少算一次，O(m·n) 是时间下限；转移只依赖上一行，O(n) 空间是 DP 内最优（组合公式可 O(min(m,n)) 时间，但 DP 是标准解）。

套路沉淀

滚动数组：初始化已代表第 0 行，循环起点要偏移到 1

出处：LC0062 不同路径

  • Arrays.fill(dp, 1) 已代表第一行（一路向右只有 1 条路径），外层循环应只处理第 2..m 行，即从 i=1 开始共 m-1 次；
  • 若循环仍从 i=0 开始，第一行会被额外更新一遍，等于多算一行：m=1,n=10 应得 1 却得 10，3x2 应得 3 却得 4；
  • 通用检查：写出初始化语义后，确认循环覆盖的区间与之不重叠；滚动数组常见错误就是「初始化一行 + 再跑 m 行」= m+1 行。

要点：状态初始化与循环起点的行数要对齐：init 占一行，循环只跑剩余 m-1 行。
