List<List<String>> ans;
    boolean[][] isPal;
    public List<List<String>> partition(String s) {
        ans = new ArrayList<>();
        if (s.isEmpty()) {
            return ans;
        }
        isPal = new boolean[s.length()][s.length()];
        for (int i = 0; i < s.length(); i++) {
            isPal[i][i] = true;
        }
        for (int len = 1; len < s.length(); len++) {
            for (int i = 0; i < s.length() - len; i++) {
                int j = i + len;
                if (len == 1) {
                    isPal[i][j] = s.charAt(i) == s.charAt(j);
                } else {
                    isPal[i][j] = s.charAt(i) == s.charAt(j) && isPal[i + 1][j - 1];
                }
            }
        }
        dfs(s, 0, new ArrayList<>());
        return ans;
    }

    private void dfs(String s, int start, ArrayList<String> list) {
        if (start == isPal.length) {
            ans.add(new ArrayList<>(list));
            return;
        }
        for (int i = start; i < s.length(); i++) {
            if (!isPal[start][i]) {
                continue;
            }
            list.add(s.substring(start, i + 1));
            dfs(s, i + 1, list);
            list.remove(list.size() - 1);
        }
    }

区间DP回文预判表+回溯枚举：按长度填 isPal（len==1 特判双字符），回溯查表 O(1) 判段、切段递归、返回撤销

思路拆解

## ① 问题本质与解法选择

  • 本质：枚举所有切割方案使每段回文。切点的选择是回溯问题；但「子串是否回文」会被反复询问，若每次现算就是重复劳动。
  • 解法选择：区间 DP 先把回文表 O(n²) 一次算完，回溯时 O(1) 查表；回溯负责枚举所有可行切割。

## ② 关键设计决策

设计点决策理由
isPal[i][j]闭区间 [i,j] 是否回文，只填上三角区间 DP 状态定义
填表顺序按区间长度 len 从小到大isPal[i][j] 依赖更短的 isPal[i+1][j-1]
len==1 双字符直接判 s[i]==s[j]，不查表查 isPal[i+1][i] 落在下三角默认 false，会误杀所有双字符回文
回溯参数(start, path)start=下一段起点；path=已收集的段
出口start==n 时复制 path 入 anspath 之后还要复用，必须拷贝副本

## ③ 具体 case 推演

示例1 "aab" 的回溯树（表：单字符全真，[0,1]="aa" 真，[0,2]="aab" 假）：

调用枚举 end段动作
dfs(0,[])0"a" 回文收 [a]，进 dfs(1,[a])
dfs(1,[a])1"a" 回文收 [a,a]，进 dfs(2,[a,a])
dfs(2,[a,a])2"b" 回文收 [a,a,b]，dfs(3) 出口入 ans
dfs(2,[a,a])2 循环结束—撤销回 dfs(1)
dfs(1,[a])2"ab" 非回文跳过
dfs(0,[])1"aa" 回文收 [aa]，进 dfs(2,[aa]) → "b" → 入 ans
dfs(0,[])2"aab" 非回文跳过

结果 [["a","a","b"],["aa","b"]] ✓。边界3 "abba" 验证查表：整串 [0,3] 直接查 isPal[1][2]("bb") 是否为真，两格均已预判好，O(1) 完成。

## ④ 边界与细节

  • 空输入：约束 n>=1，s.isEmpty() 分支永不执行，属冗余代码
  • 双字符 "aa"/"bb"：len==1 特判保证不会误杀
  • 偶回文 "abba"：内核对 "bb" 若被误判则整串连锁错误（这是 len==1 特判缺失的典型后果）
  • 16 全同字符：任意切割都回文 → 2^15=32768 方案，验证枚举不漏
  • 16 全不同：仅全拆一种，验证不误报

## ⑤ 复杂度与下限论证

  • 预判：O(n²) 时间 / O(n²) 空间
  • 回溯：方案数本身可能指数（全同串 2^(n-1)），输出全部方案的算法下界就是 Ω(方案数)，无法再低；n≤16 时上界 32768 完全可接受
  • 空间：isPal 表 O(n²) + 递归栈 O(n) + path O(n)，无额外浪费
