题目描述

你是一个专业的小偷，计划偷窃沿街的房屋。每间房内都藏有一定的现金，影响你偷窃的唯一制约因素就是相邻的房屋装有相互连通的防盗系统，如果两间相邻的房屋在同一晚上被小偷闯入，系统会自动报警。

给定一个代表每个房屋存放金额的非负整数数组，计算你 不触动警报装置的情况下 ，一夜之内能够偷窃到的最高金额。

示例 1：

输入：[1,2,3,1]

输出：4

解释：偷窃 1 号房屋 (金额 = 1) ，然后偷窃 3 号房屋 (金额 = 3)。

偷窃到的最高金额 = 1 + 3 = 4 。

示例 2：

输入：[2,7,9,3,1]

输出：12

解释：偷窃 1 号房屋 (金额 = 2), 偷窃 3 号房屋 (金额 = 9)，接着偷窃 5 号房屋 (金额 = 1)。

偷窃到的最高金额 = 2 + 9 + 1 = 12 。

public int rob(int[] nums) {
        if (nums.length < 2) return nums[0];
        int[][] dp = new int[nums.length][2];
        // 第 1 行两列要覆盖前两间的全部决策：dp[1][0]=nums[1]（偷 1 号）、dp[1][1]=nums[0]（只偷 0 号）
        dp[0][0] = dp[1][1] = nums[0];
        dp[1][0] = nums[1];
        for (int i = 2; i < nums.length; i++) {
            dp[i][0] = Math.max(dp[i - 2][1] + nums[i], dp[i - 1][1]);
            dp[i][1] = Math.max(dp[i - 2][0] + nums[i], dp[i - 1][0]);
        }
        return Math.max(dp[nums.length - 1][0], dp[nums.length - 1][1]);
    }

public int rob(int[] nums) {
        if (nums.length < 2) return nums[0];
        int[] dp = new int[nums.length];
        dp[0] = nums[0];
        dp[1] = Math.max(nums[0], nums[1]);
        for (int i = 2; i < nums.length; i++) {
            dp[i] = Math.max(dp[i - 1], dp[i - 2] + nums[i]);
        }
        return dp[nums.length - 1];
    }

思路拆解

问题本质与解法选择

在「相邻房屋不能同时偷」的约束下选择若干下标，使金额和最大。每间房子只有偷/不偷两种决策，且合法方案存在明显的重叠子结构（前缀最优可复用到更长前缀），适合 DP；贪心不可行，因为局部金额大不代表全局最优，例如 [2,1,1,2] 先偷金额 2 会丢掉「偷 0 号和 3 号得 4」的全局最优。

关键设计决策（按用户实际写法）

  1. 状态：dp[i][0] 与 dp[i][1] 是两条交替推进的链——列 0 只能由列 1 的旧值推进，列 1 只能由列 0 的旧值推进，把「相邻不可同偷」编码进交替结构。
  2. 转移：dp[i][0] = max(dp[i-2][1] + nums[i], dp[i-1][1])：偷第 i 间从两行前的另一列跳接（直接跳过 i-1，天然保证不触发警报），不偷则从上一行另一列继承；dp[i][1] 对称地由列 0 推进。
  3. 初始化：dp[0][0]=nums[0]（只偷 0 号）、dp[0][1]=0（默认，不偷）、dp[1][0]=nums[1]、dp[1][1]=nums[0]；n<2 直接返回 nums[0] 避免越界。
  4. 答案：最后一行的两列取大，覆盖「最后偷在奇/偶相位」两种模式。

边界与细节

  • 单元素：n<2 提前返回，dp[1] 不存在。
  • 两元素：初始化即答案 max(nums[0], nums[1])。
  • 含 0：金额非负，继承不偷的候选不会变差。
  • 全相同：如 [3,3,3,3]，交替结构只能隔间取，得 3+3=6。
  • 推演 case：nums=[2,1,1,2]。
  1. 初始化：dp[0][0]=2，dp[0][1]=0，dp[1][0]=1，dp[1][1]=2。
  2. i=2：dp[2][0]=max(dp[0][1]+1=1, dp[1][1]=2)=2（不偷 2 号，继承偷 0 号的 2）；dp[2][1]=max(dp[0][0]+1=3, dp[1][0]=1)=3（偷 2 号：2+1，跳过 1 号）。
  3. i=3：dp[3][0]=max(dp[1][1]+2=4, dp[2][1]=3)=4（偷 3 号：偷 0 号的 2 再 +2）；dp[3][1]=max(dp[1][0]+2=3, dp[2][0]=2)=3。
  4. 答案 = max(4,3) = 4 ✓（偷 0 号和 3 号）。

复杂度与下限论证

  • 时间 O(n)：每个下标常数次比较与加法，单遍扫描；任何解法都必须读一遍所有房屋（Ω(n)），已达下限。
  • 空间 O(n)：dp 数组两列；转移只依赖前两行的两列，可滚动为 4 个变量降到 O(1)。
  • 信息量下限：相邻约束下每间房子只需知道「前两间的最优」，本结构与标准一维 dp[i]=max(dp[i-1], dp[i-2]+nums[i]) 等价，没有引入多余维度。

套路沉淀

DP 初始化必须覆盖该下标全部合法决策，不能只取一种

递推起点状态要完整：dp[1] 表示前两间的最优，应同时包含「偷第 1 间」与「只偷第 0 间」两种候选（max(nums[0], nums[1])），只存 nums[1] 等于强制第 1 间必偷。case：[2,1,1,2] 正确起点 dp[1]=2 才能让 i=3 得到 2+2=4；起点只存 1 时最终只算到 3。修复后一维 dp 单调不减，答案直接取 dp[n-1] 即可，末尾再 max(dp[n-1], dp[n-2]) 是冗余。要点：写 DP 时把「下标 x 的状态语义」写出来，初始化时逐项核对它该包含哪些候选。
