44. 通配符匹配 (Wildcard Matching)

> https://leetcode.cn/problems/wildcard-matching/

难度：Hard ｜ 分类：动态规划

标签：贪心、递归、字符串、动态规划

题目描述

给你一个输入字符串 (s) 和一个字符模式 (p) ，请你实现一个支持 '?' 和 '*' 匹配规则的通配符匹配：

'?' 可以匹配任何单个字符。

'*' 可以匹配任意字符序列（包括空字符序列）。

判定匹配成功的充要条件是：字符模式必须能够 完全匹配 输入字符串（而不是部分匹配）。

示例 1：

输入：s = "aa", p = "a"

输出：false

解释："a" 无法匹配 "aa" 整个字符串。

示例 2：

输入：s = "aa", p = "*"

输出：true

解释：'*' 可以匹配任意字符串。

示例 3：

输入：s = "cb", p = "?a"

输出：false

解释：'?' 可以匹配 'c', 但第二个 'a' 无法匹配 'b'。

提示：

0

s 仅由小写英文字母组成

p 仅由小写英文字母、'?' 或 '*' 组成

② 这次写对的关键（状态只有两个变量 + 一个 case）

  • start：最近一个 * 目前吃到 s 的下标；matchIdx：该 * 之后第一个待匹配的模式下标。两者在「遇 *」时更新一次，此后只被回溯用到——这就是整个贪心的全部状态（O(1) 空间）。

  • 收尾比较的是 j == n（模式是否走完）而不是 s 是否走完，并先跳过尾部剩下的 *——这两处正是上次翻车的点。

写法 1 · 线性DP双序列

时间 O(nm)空间 O(nm)内存 ≈ 45.8 MB用例 1812/1812

LC0044_WildcardMatching.java · 线性DP双序列提交区
public boolean isMatch(String s, String p) {
        boolean[][] dp = new boolean[s.length() + 1][p.length() + 1];
        dp[0][0] = true;
        for (int j = 1; j <= p.length(); j++) {
            if (p.charAt(j - 1) == '*') {
                dp[0][j] = dp[0][j - 1];
            }
        }
        for (int i = 1; i <= s.length(); i++) {
            for (int j = 1; j <= p.length(); j++) {
                if (p.charAt(j - 1) == '?' || s.charAt(i - 1) == p.charAt(j - 1)) {
                    dp[i][j] = dp[i - 1][j - 1];
                } else if (p.charAt(j - 1) == '*') {
                    dp[i][j] = dp[i - 1][j] || dp[i][j - 1];
                }
            }
        }
        return dp[s.length()][p.length()];
    }

public boolean isMatch(String s, String p) {
        boolean[][] dp = new boolean[s.length() + 1][p.length()+ 1];
        dp[0][0] = true;
        for (int i = 0; i <= s.length(); i++) {
            for (int j = 1; j <= p.length(); j++) {
                if (p.charAt(j - 1) == '?') {
                    dp[i][j] = i > 0 && dp[i - 1][j - 1];
                } else if (p.charAt(j - 1) == '*') {
                    dp[i][j] = (i > 0 && dp[i - 1][j]) || dp[i][j - 1];
                } else {
                    dp[i][j] = (i > 0 && dp[i - 1][j - 1]) && p.charAt(j - 1) == s.charAt(i - 1);
                }
            }
        }
        return dp[s.length()][p.length()];
    }

写法 2 · 贪心双指针+星号回溯

时间 最坏 O(nm)空间 O(1)内存 ≈ 43.3 MB用例 1812/1812

LC0044_WildcardMatching.java · 贪心双指针+星号回溯提交区
    // ==== 提交代码开始 ====
    // 参数 s：待匹配字符串；参数 p：模式串（`?` 配任意单字符、`*` 配任意长度含空串）；返回整体是否匹配
    public boolean isMatch(String s, String p) {
        int m = s.length();
        int n = p.length();
        // start：最近那个 `*` 目前吃到 s 的下标（回溯时 ++ 表示多吃一个字符）；matchIdx：该 `*` 之后第一个待匹配的模式下标
        int start = -1, matchIdx = -1;
        int i = 0, j = 0;
        while (i < m) {
            if (j < n && p.charAt(j) == '*') {
                start = i;
                matchIdx = j + 1;
                j++;
            } else if (j < n && (s.charAt(i) == p.charAt(j) || p.charAt(j) == '?')) {
                i++;
                j++;
            } else {
                if (start > -1) {
                    start++;
                    i = start;
                    j = matchIdx;
                } else {
                    return false;
                }
            }
        }
        // 收尾：模式可能还剩尾部的 `*`（匹配空串），所以比较方向是「模式是否走到头」而不是「s 是否走到头」
        while (j < n && p.charAt(j) == '*') {
            j++;
        }
        return j == n;
    }
    // ==== 提交代码结束 ====

LC0044_WildcardMatching.java · 贪心双指针+星号回溯 · 上一版提交区
public boolean isMatch(String s, String p) {
        int i = 0, j = 0, starIdx = -1, match = 0;
        while (i < s.length()) {
            if (j < p.length() && (p.charAt(j) == '?' || p.charAt(j) == s.charAt(i))) {
                // 普通字符或 ?：对上就双指针前进
                i++;
                j++;
            } else if (j < p.length() && p.charAt(j) == '*') {
                // 当作 * 先不存在（吞空），记住位置，i 不动
                starIdx = j++;
                match = i;
            } else if (starIdx != -1) {
                // 失配或模式走完：让最近的 * 多吞一个字符，回到 * 之后重新开始
                i = ++match;
                j = starIdx + 1;
            } else {
                return false;
            }
        }
        while (j < p.length() && p.charAt(j) == '*') {
            j++;
        }
        return j == p.length();
    }

思路拆解

① 问题本质与解法选择

  • 本质：通配符全串匹配。? 占一位、* 任意序列（含空）。主流两解法：双序列线性 DP 与贪心回溯。
  • DP：dp[i][j]=s 前 i 个能否匹配 p 前 j 个，按 p[j-1] 是字母/?/* 三种转移，稳健直观。
  • 贪心：双指针 + 最近星号回溯，O(1) 空间、常数小；两者时间同为 O(n·m)。

② 关键设计决策

DP 转移表：

当前 p[j-1]转移
?dp[i-1][j-1]
*dp[i-1][j]（吃一字符）或 dp[i][j-1]（吃空）
字母dp[i-1][j-1] 且 s[i-1]==p[j-1]

空串行 i==0 的三分支：? 与字母直接 false；* 只有吃空方向 dp[0][j-1]，吃字符方向在空串行不存在必须短路 false——写 true 会让星号无视前面压着的字面字符凭空成立，这是 WA 用例 c*a*b 误匹配 aab 的根。

贪心变量：i/j 双指针；starIdx=最近星号位置；match=该星号已吞到的 s 位置。规则：对上→双进；遇*→记位吞空；失配→回溯让星号多吞一个（i=++match, j=starIdx+1）；无星→false；收尾跳过尾部星号。

③ 具体 case 推演

DP 回归用例 aab / c*a*b：dp[0][2]（空串 vs c*）正确应为 false——c 必须吃掉一个字符，空串给不了。错误写法（空串行星号吃字符恒 true）让它成 true，之后 a、b 在错误真值上叠加，最终误判匹配。

贪心 adceb / *a*b 逐步回溯：

i/j动作
0/0* → starIdx=0, match=0, j=1
0/1a==a → i=1,j=2
1/2* → starIdx=2, match=1, j=3
1/3b vs d 失配 → 星号2 吞 d
2/3b vs c 失配 → 吞 c
3/3b vs e 失配 → 吞 e
4/3b==b → i=5,j=4 → true

④ 边界与细节

  • 双空 true；空串配 * true、配 ?/字母 false
  • 多星号吞空（空串/****）；星号吞中段（abc/a*c）；吞后接不上（abcd/a*c 必须 false）
  • 长度 2000 上限：精确匹配、单星万能、全不匹配
  • DP 空串行三分支短路；贪心主循环以 i 扫完为准、j 触底靠星号回溯

⑤ 复杂度与下限论证

  • DP：O(n·m) 时间 O(n·m) 空间（可滚动 O(m)）
  • 贪心：最坏 O(n·m)（反复回溯）但空间 O(1)，常数小
  • 双序列比对两个串的下标组合都要遍历，O(n·m) 是该类问题公认可接受上限
