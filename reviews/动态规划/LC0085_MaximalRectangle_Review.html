public int maximalRectangle(char[][] matrix) {
        int m = matrix.length;
        int n = matrix[0].length;
        int[] heights = new int[n + 2];
        int max = 0;
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (i == 0) {
                    heights[j + 1] = matrix[i][j] == '1' ? 1 : 0;
                } else {
                    heights[j + 1] = matrix[i][j] == '1' ? (1 + heights[j + 1]): 0;
                }
            }
            Deque<Integer> stack = new ArrayDeque<>();
            for (int j = 0; j < heights.length; j++) {
                while (!stack.isEmpty() && heights[stack.peekLast()] > heights[j]) {
                    int height = heights[stack.pollLast()];
                    int width = j - stack.peekLast() - 1;
                    int area = height * width;
                    max = Math.max(max, area);
                }
                stack.offerLast(j);
            }
        }
        return max;
    }

逐行高度 + 单调栈直方图：heights 递推每列向上连续 1，每行单调栈求最大矩形；O(mn)/O(n)，修压栈下标后 Accepted

思路拆解

问题本质：在 0/1 矩阵中找只含 1 的最大矩形面积。直接枚举矩形四个边界再验证是 O(R^3*C) 不可行；关键转化是把它拆成「逐行维护高度 + 一维直方图最大矩形」两个子问题。

解法选择理由：

  • 固定某一行作为矩形的底边时，每一列能向上延伸的连续 1 的个数就是该列的高度，所有列拼成一个直方图；原问题变成「这个直方图里面积最大的矩形」。
  • 直方图最大矩形用单调栈可在 O(C) 内求出：每个柱子作为高度时，向左右第一个比它矮的柱子之间就是它能撑起的最大宽度。
  • 逐行扫描时高度可以 O(1) 递推：当前格是 '1' 则高度 = 上一行高度 + 1，是 '0' 则清零，不需要重新扫描整列。

关键设计：

  1. heights[j+1] 表示第 j 列当前行的高度，数组开 n+2 长度，heights[0] 与 heights[n+1] 都是 0 哨兵，避免弹栈后空栈特判。
  2. 每行结束后对 heights 跑一次单调栈：栈存列下标，遇到比栈顶矮的柱子就弹出，弹出时高度 = 该柱子高度，宽度 = 当前下标 - 新栈顶 - 1。
  3. 每行都新建栈；全程用 max 累计全局最大值。

具体 case 推演（示例 1 矩阵）：

行处理后 heights该行直方图最大
0[0,1,0,1,0,0,0]1
1[0,2,0,2,1,1,0]2（高 2 宽 1 或高 1 宽 2）
2[0,3,1,3,2,2,0]6（高 2 宽 3，列 2~4）
3[0,4,0,0,3,0,0]3

最大面积 = 6。

再推演单行直方图 [2,1,2]（单调栈过程）：

  • 下标 0（高 2）入栈；下标 1（高 1）比栈顶矮，弹出下标 0：宽度 = 1-(-1)-1 = 1，面积 2×1 = 2。
  • 下标 1 入栈；下标 2（高 2）不入栈？高度相等用 > 不弹，先入栈。
  • 右哨兵 0 到达：弹出下标 2（宽度 1，面积 2），再弹下标 1（宽度 3，面积 3）。
  • 最大 3，对应整个直方图横跨。

边界与细节：

  • 全 0 矩阵：高度全 0，单调栈不产生任何面积，返回 0。
  • 单行/单列：高度递推与哨兵同样生效。
  • 全 1 大矩阵（如 30x30）：每行直方图都是 [0,30,...,30,0]，单调栈一次弹出算出 900。
  • 上下两段被全 0 行隔开：0 行会把高度清零，两段不会错误合并。
  • 栈内必须存列下标 j，存行号会导致 heights 错位访问与空栈 NPE（本地测试曾暴露）。

复杂度分析：

  • 时间 O(R*C)：每格 O(1) 更新高度，每行单调栈 O(C)，总 O(R*C)，已达下界（每个格子至少要看一次）。
  • 空间 O(C)：heights 数组 + 栈，与行数无关。
  • 这是本题最优解；相比 DP 记录每行左/右边界再 O(C) 扫描的写法，单调栈思路更统一且常数更小。
