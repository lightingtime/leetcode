int max;
    public int maxPathSum(TreeNode root) {
        max = Integer.MIN_VALUE;
        dfs(root);
        return max;
    }

    private int dfs(TreeNode root) {
        if (root == null) {
            return 0;
        }
        int maxLeft = Math.max(0, dfs(root.left));
        int maxRight = Math.max(0, dfs(root.right));
        max = Math.max(max, root.val + maxLeft + maxRight);
        return Math.max(maxLeft, maxRight) + root.val;
    }

二叉树最大路径和：后序 DFS，子树贡献与 0 取 max，全局拼两侧、向上返单链，入口重置 max 后一次 Accepted（96/96）

思路拆解

### 问题本质与解法选择

  • 路径是一条链：树上任意两点间唯一路径，或退化为单个节点；同一节点至多出现一次、不一定经过根。
  • 对任意一条路径，存在唯一一个「最高点」（离根最近，路径在该处从左右两个方向汇合，或只从一侧下来）。按每个节点作为最高点枚举所有候选路径即可覆盖全部路径——这是树形 DP / 后序 DFS 的天然选择。
  • 每个节点需要区分两类值：
  1. 向上提供的单链贡献：以该节点为端点、只朝一个方向向下延伸的最大和，供父节点拼接；
  2. 以该节点为最高点的完整路径：左单链 + 节点 + 右单链，直接更新全局答案。
  • 负数子树贡献直接丢弃（与 0 取 max），因为路径可以选择不接那一侧。

### 关键设计决策

  • 状态定义：dfs(node) 返回从 node 出发向下只走一条链能得到的最大贡献；全局 max 记录所有「以某节点为最高点的完整路径」的最大值。
  • 转移：
  • maxLeft = max(0, dfs(node.left))，maxRight = max(0, dfs(node.right))：负贡献截断为 0；
  • 更新 max = max(max, node.val + maxLeft + maxRight)；
  • 返回 node.val + max(maxLeft, maxRight)——只能带一侧，不能两侧都往上带。
  • 终止条件：node == null 返回 0，空子树贡献为 0，由上层决定是否采纳。
  • 状态重置：max 作为实例字段时，每次 maxPathSum 入口必须重置为 Integer.MIN_VALUE，否则同实例多次调用会残留上一次答案。

### 具体 case 推演

示例 [1, 2, 3]（root=1，左=2，右=3）：

  1. dfs(2)：叶子，两侧贡献都为 0；更新 max = max(MIN_VALUE, 2) = 2；返回 2 + 0 = 2。
  2. dfs(3)：同样逻辑；max 仍为 2；返回 3。
  3. dfs(1)：maxLeft = max(0, 2) = 2，maxRight = max(0, 3) = 3；更新 max = max(2, 1 + 2 + 3) = 6；返回 1 + max(2, 3) = 4（向上只能带 3 这一侧）。
  4. 结果 max = 6，对应路径 2 -> 1 -> 3。

全负例 [-2, -1, -3]（root=-2，左=-1，右=-3）：

  1. dfs(-1)：两侧 0；更新 max = max(MIN_VALUE, -1) = -1；返回 -1。
  2. dfs(-3)：更新 max = max(-1, -3) = -1；返回 -3。
  3. dfs(-2)：maxLeft = max(0, -1) = 0，maxRight = max(0, -3) = 0；更新 max = max(-1, -2) = -1。
  4. 结果 -1：全负时最优就是最大的单点，负贡献被 0 截断，避免把路径拉得更低。

### 边界与细节

  • max 初值必须是 Integer.MIN_VALUE 而非 0：节点值可全为负，0 起步会把答案错算成 0。
  • 入口重置 max：本次曾踩坑——实例字段跨多次调用残留，后续用例返回上一次的最大值（如把 42 串到单元素用例）。
  • 返回值语义：给父节点的必须是单侧链，不能在父节点处「既分叉又向上」。
  • 空输入不在约束内（节点数 ≥ 1），但 dfs(null) = 0 让递归统一覆盖空子树。

### 复杂度分析与最优性论证

  • 时间 O(n)：每个节点恰好后序遍历一次，每次常数次比较与加法；下界同为 Ω(n)，必须看过每个节点才能确定全局最大路径，因此 O(n) 是最优。
  • 空间 O(height)，最坏退化为链时为 O(n)：递归栈深度等于树高；本题需要在子树聚合完成后才能更新答案，沿树高保留调用栈是最小必要开销，与时间下界一样属于可接受最优。
