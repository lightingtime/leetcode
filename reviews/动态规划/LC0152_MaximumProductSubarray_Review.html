152. 乘积最大子数组 (Maximum Product Subarray)

难度：Medium ｜ 分类：动态规划

题目描述

给你一个整数数组 nums ，请你找出数组中乘积最大的非空连续 子数组（该子数组中至少包含一个数字），并返回该子数组所对应的乘积。

测试用例的答案是一个 32-位 整数。

请注意，一个只包含一个元素的数组的乘积是这个元素的值。

示例 1:

输入: nums = [2,3,-2,4]

输出: 6

解释: 子数组 [2,3] 有最大乘积 6。

示例 2:

输入: nums = [-2,0,-1]

输出: 0

解释: 结果不能为 2, 因为 [-2,-1] 不是子数组。

public int maxProduct(int[] nums) {
        int max = nums[0], min = nums[0];
        int ans = nums[0];
        for (int i = 1; i < nums.length; i++) {
            int temp = max;
            max = Math.max(nums[i], Math.max(max * nums[i], min * nums[i]));
            min = Math.min(nums[i], Math.min(temp * nums[i], min * nums[i]));
            ans = Math.max(max, ans);
        }
        return ans;
    }

思路拆解

问题本质与解法选择

在连续子数组中找乘积最大值。乘积与加法最大的区别是符号会反转：负数×负数得正数，且遇到 0 会归零重来，所以「以 i 结尾的最大乘积」不能只由一个状态决定——最大值可能来自上一轮的最小值（负负得正）。这正好构成最优子结构：以 i 结尾的连续子数组要么只有 nums[i]，要么由「以 i-1 结尾的某个子数组」接上 nums[i]，因此双状态一维 DP 能覆盖全部情况，无需回溯或枚举所有子数组。

关键设计决策

  1. 状态定义：dpMax[i] = 以 i 结尾的连续子数组的最大乘积；dpMin[i] = 以 i 结尾的最小乘积。初始 dpMax[0]=dpMin[0]=nums[0]。
  2. 转移：每个位置有三种候选——nums[i]（重新开始）、nums[i]×dpMax[i-1]、nums[i]×dpMin[i-1]；dpMax 取三者最大、dpMin 取三者最小。必须同时维护两个状态，因为当前 nums[i] 为负时，乘以更负的上一轮值反而得到最大。
  3. 答案：所有 dpMax[i] 的最大值，初始化取 nums[0]，不能从 0 开始，否则全负数组会错。
  4. 实现用 int[n][2] 存两列；每轮只依赖 i-1，实际可以滚动成两个变量把空间降到 O(1)。

边界与细节

  • 单元素：直接返回 nums[0]，正负都适用。
  • 全负：如 [-2,-3,-1] 答案是 6（子数组 [-2,-3]），靠负负得正；若答案初始化为 0 会错。
  • 含 0：0 会切断子数组，「重新开始」的候选 nums[i] 保证 0 之后能重来，单个 0 也是合法答案。
  • 32 位保证：乘积不溢出 int，直接用 int 即可。
  • 推演 case：nums=[2,-5,-2,-4,3]。
  1. i=0：max=min=2，ans=2。
  2. i=1(-5)：候选 -5、-10、-10 → max=-5，min=-10，ans=2。
  3. i=2(-2)：候选 -2、10、20 → max=20，min=-2，ans=20。
  4. i=3(-4)：候选 -4、-80、8 → max=8，min=-80，ans=20（此处必须用 i=2 的 min=-2，若错用更早的 -10 会拼出非连续子数组）。
  5. i=4(3)：候选 3、24、-240 → max=24，min=-240，ans=24 ✓。

复杂度与下限论证

  • 时间 O(n)：每个位置常数次运算，一次扫描完成；任何解法都至少要读一遍数组（Ω(n)），已达下限。
  • 空间：本实现 O(n)（dp 数组）；转移只依赖 i-1，可滚动为两个变量达到 O(1)，是该问题的最优空间。
  • 无法更优的论证：答案依赖每个元素，且负号传播要求同时知道最大与最小，单状态（只记 max）无法处理负负得正，双状态是最小的必要信息集。

套路沉淀

滚动变量原地更新：先存旧快照再整体替换，答案跟踪对象与状态语义一致

把二维 dp 压成滚动变量时，转移输入必须是「上一轮」的两个旧值：先更新 max 再算 min，min 的候选就混进本轮新 max（状态污染）；应先保存旧快照或用临时变量，新旧值整体替换。答案变量也要跟对对象：dpMax 的滚动结果才对应最大，ans 与 min 比较会丢掉已出现的最大值。case：[-2,-3,-1] 正确过程 i=1 得 max=6、min=-3、ans=6；原地更新+跟 min 比较会算出 min=-18，最终返回 -2 而非 6。要点：滚动只改存储、不改转移语义。
