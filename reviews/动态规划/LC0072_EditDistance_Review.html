72. 编辑距离 (Edit Distance)

> https://leetcode.cn/problems/edit-distance/

难度：Medium ｜ 分类：动态规划

标签：字符串、动态规划

题目描述

给你两个单词 word1 和 word2， 请返回将 word1 转换成 word2 所使用的最少操作数 。

你可以对一个单词进行如下三种操作：

插入一个字符

删除一个字符

替换一个字符

示例 1：

输入：word1 = "horse", word2 = "ros"

输出：3

解释：

horse -> rorse (将 'h' 替换为 'r')

rorse -> rose (删除 'r')

rose -> ros (删除 'e')

示例 2：

输入：word1 = "intention", word2 = "execution"

输出：5

解释：

intention -> inention (删除 't')

inention -> enention (将 'i' 替换为 'e')

enention -> exention (将 'n' 替换为 'x')

exention -> exection (将 'n' 替换为 'c')

exection -> execution (插入 'u')

提示：

0

word1 和 word2 由小写英文字母组成

写法 1 · DP 二维表格

LC0072_EditDistance.java · DP 二维表格提交区
public int minDistance(String word1, String word2) {
        int m = word1.length();
        int n = word2.length();
        if (m == 0) return n;
        if (n == 0) return m;
        // 滚动数组：dp[j] 存当前行 dp[i][j]，覆盖前先取旧值当 dp[i-1][j]；diag 存斜对角 dp[i-1][j-1]
        int[] dp = new int[n + 1];
        for (int j = 0; j <= n; j++) {
            dp[j] = j; // 第 0 行：dp[0][j] = j
        }
        for (int i = 1; i <= m; i++) {
            int diag = dp[0]; // 进第 1 列前，diag = dp[i-1][0]
            dp[0] = i;        // 第 0 列：dp[i][0] = i
            for (int j = 1; j <= n; j++) {
                int prevRowSame = dp[j]; // 覆盖前保存 dp[i-1][j]
                if (word1.charAt(i - 1) == word2.charAt(j - 1)) {
                    dp[j] = diag;
                } else {
                    dp[j] = Math.min(Math.min(prevRowSame, dp[j - 1]), diag) + 1;
                }
                diag = prevRowSame; // 下一列的斜对角 = dp[i-1][j]
            }
        }
        return dp[n];
    }

写法 2 · 一维滚动 DP

时间 O(mn)空间 O(n)内存 ≈ 42.8 MB用例 1149/1149

LC0072_EditDistance.java · 一维滚动 DP提交区
public int minDistance(String word1, String word2) {
        int m = word1.length();
        int n = word2.length();
        if (m == 0) {
            return n;
        }
        if (n == 0) {
            return m;
        }
        int[] dp = new int[n];
        // 永远记住此时的dp是带着空串行列的
        for (int i = 0; i < n; i++) {
            dp[i] = i + 1;
        }
        for (int i = 0; i < m; i++) {
            // leftTop，表示上一行的编辑距离
            int dig = i;
            for (int j = 0; j < n; j++) {
                int pre = dp[j];
                if (word1.charAt(i) == word2.charAt(j)) {
                    dp[j] = dig;
                } else {
                    //
                    dp[j] = Math.min(j == 0? i + 1 : dp[j - 1], Math.min(pre, dig)) + 1;
                }
                dig = pre;
            }
        }
        return dp[n - 1];
    }

LC0072_EditDistance.java · 一维滚动 DP · 上一版提交区
    public int minDistance(String word1, String word2) {
        int m = word1.length();
        int n = word2.length();
        if (m == 0) {
            return n;
        }
        if (n == 0) {
            return m;
        }
        int[] dp = new int[n];
        // dp初始化表示当word1为0时，处理到word2的前缀长度为j个字符需要的操作步骤
        // j 从 0 开始，所以步骤 = j + 1
        for (int j = 0; j < n; j++) {
            dp[j] = j + 1;
        }
        for (int i = 0; i < m; i++) {
            // leftTop 是每行开头 j = 0 那个格子的左上角（虚的，不存在的）：word1 前 i 个 -> word2 前 j 个 的步数
            // j=0 时它是 "前 i 个 -> 空串" = i（数组没存 word2 为空的那一列，需手动补）
            int leftTop = i;
            for (int j = 0; j < n; j++) {
                // 防止 dp[j] 被更新，记录一下
                int pre = dp[j];
                if (word1.charAt(i) == word2.charAt(j)) {
                    dp[j] = leftTop;
                } else {
                    dp[j] = Math.min(j == 0 ? i + 1 : dp[j - 1], Math.min(pre, leftTop)) + 1;
                }
                // 下一列的左上角 = 本列覆盖前的 dp[j]（word1 前 i 个 -> word2 前 j+1 个）
                leftTop = pre;
            }
        }
        return dp[n - 1];
    }

思路拆解

问题本质与解法选择

  • 双序列对齐类 DP：目标是把 word1 前 i 个字符变成 word2 前 j 个字符，每次只能增/删/改一个字符，问最少步数。三个操作作用在「最后一对字符」上互斥，天然有重叠子问题；朴素枚举是指数级，用 DP 表格把每个 (i,j) 前缀对只算一次。
  • 状态定义：F(i,j) = word1 前 i 个字符 → word2 前 j 个字符的最少操作数（i、j 是前缀长度，范围 0..m / 0..n），答案 F(m,n)。
  • 转移（看 word1 第 i 个与 word2 第 j 个字符）：
  • 相同：F(i,j)=F(i-1,j-1)，两字符直接对齐、不动。
  • 不同：取三种操作最小值 +1：替换 F(i-1,j-1)+1；删除 word1 侧字符 F(i-1,j)+1；插入 word2 侧字符（等价消掉 word2 第 j 个）F(i,j-1)+1。
  • 边界：F(0,j)=j（空串插入 j 次）、F(i,0)=i（删光 i 个字符）。
  • 为什么可压到 O(n)：每格只依赖上一行 F(i-1,*) 与本行左侧，更早的行永不回看 → 只保留一行即可；唯一难点是「左上角」没有数组位，需要一个接力变量。

关键设计决策（一维滚动实现）

  • 数组砍掉 word2 为空的第 0 列：dp[j] 实际存「word2 前缀长度 j+1」的值（下标与列号差 1），所以初始化 dp[j]=F(0,j+1)=j+1，不是 j。
  • 算 F(i+1,j+1) 需要的三个邻居与来源：

| 邻居 | 二维值 | 本实现来源 |

| 上 | F(i,j+1) | pre = dp[j]（更新前原值） |

| 左 | F(i+1,j) | j=0 时为 i+1（第 0 列公式，没存）；否则为刚更新的 dp[j-1] |

| 左上 | F(i,j) | leftTop：行首 =i（=F(i,0) 手补），每算完一列 leftTop=pre |

  • leftTop=pre 为什么成立：pre 是覆盖前的 dp[j]=F(i,j+1)，而下一列 j+1 格子的左上角恰好是 F(i,j+1)，接力无缝隙。
  • 字符相同走 dp[j]=leftTop（继承左上、不加 1）；不同才做 min(左,上,左上)+1。

边界与细节

  • m==0 / n==0 提前返回，避免空数组与循环空转；空串→abc 全插入、abc→空全删除分别验证第 0 行/第 0 列语义。
  • main 测试覆盖：双空、单字符相同/不同、全相同、只差尾部一个字符、等长全替换、交换两字符（ab→ba 需 2 步）、kitten/sunday 经典回归例。
  • 约束内 m,n ≤ 500，O(mn) 时间安全；不存在负长度等越界输入。

复杂度与下限论证

  • 时间 O(mn)：m×n 个格子每格 O(1) 转移。任何算法要算清两串全部前缀对的最优对齐，至少要读 O(mn) 个状态，因此 O(mn) 是渐进最优。
  • 空间 O(n)：只保留一行，从二维 O(mn) 降到线性；按短串方向滚动可再降到 O(min(m,n))，但 O(n) 已达标。
  • 判题：一次提交 Accepted，1149/1149，内存约 44.8MB，属最优档。

小输入逐格推演（word1="ab", word2="xy"）

  • 完整二维表（对照）：

| F(i,j) | j=0 空 | j=1 x | j=2 xy |

| i=0 空 | 0 | 1 | 2 |

| i=1 a | 1 | 1 | 2 |

| i=2 ab | 2 | 2 | 2 |

  • 滚动数组实际只留一行：
  1. 初始化 dp=[1,2]（=F(0,1)、F(0,2)）。
  2. i=0 轮（word1 前缀 0→1，算 F(1,*)）：行首 leftTop=0(=F(0,0))。
  • j=0：pre=1(=F(0,1))；a≠x → dp[0]=min(左 i+1=1, 上 1, 左上 0)+1=1=F(1,1)；leftTop←pre=1。
  • j=1：pre=2(=F(0,2))；a≠y → dp[1]=min(dp[0]=1, 上 2, 左上 1)+1=2=F(1,2)；leftTop←2。
  1. i=1 轮（word1 前缀 1→2，算 F(2,*)）：行首 leftTop=1(=F(1,0))。
  • j=0：pre=1(=F(1,1))；b≠x → dp[0]=min(左 i+1=2, 上 1, 左上 1)+1=2=F(2,1)；leftTop←pre=1。
  • j=1：pre=2(=F(1,2))；b≠y → dp[1]=min(dp[0]=2, 上 2, 左上 1)+1=2=F(2,2)。
  • 返回 dp[1]=2，即 "ab"→"xy" 全替换 2 次 ✓。
  • 补一个「字符相同」的格子看 leftTop 直传：word1="a", word2="a" 时 i=0 轮 j=0，leftTop=0(=F(0,0))，a==a → dp[0]=0=F(1,1)（不用操作）✓。

本轮复盘重点（为什么 weak）

  • 滚动数组的「下标 j 对应列 j+1」偏移与 leftTop 语义互相纠缠是卡点：leftTop 不是从数组读 dp[i-1][j-1]，而是行首手补 F(i,0)=i + 列末取「覆盖前的 dp[j]」接力。把这两件事拆开记，比背代码可靠。
