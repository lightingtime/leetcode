72. 编辑距离 (Edit Distance)

> https://leetcode.cn/problems/edit-distance/

难度：Medium ｜ 分类：动态规划

标签：字符串、动态规划

题目描述

给你两个单词 word1 和 word2， 请返回将 word1 转换成 word2 所使用的最少操作数 。

你可以对一个单词进行如下三种操作：

插入一个字符

删除一个字符

替换一个字符

示例 1：

输入：word1 = "horse", word2 = "ros"

输出：3

解释：

horse -> rorse (将 'h' 替换为 'r')

rorse -> rose (删除 'r')

rose -> ros (删除 'e')

示例 2：

输入：word1 = "intention", word2 = "execution"

输出：5

解释：

intention -> inention (删除 't')

inention -> enention (将 'i' 替换为 'e')

enention -> exention (将 'n' 替换为 'x')

exention -> exection (将 'n' 替换为 'c')

exection -> execution (插入 'u')

提示：

0

word1 和 word2 由小写英文字母组成

输出：3

public int minDistance(String word1, String word2) {
        int m = word1.length();
        int n = word2.length();
        if (m == 0) return n;
        if (n == 0) return m;
        // 滚动数组：dp[j] 存当前行 dp[i][j]，覆盖前先取旧值当 dp[i-1][j]；diag 存斜对角 dp[i-1][j-1]
        int[] dp = new int[n + 1];
        for (int j = 0; j <= n; j++) {
            dp[j] = j; // 第 0 行：dp[0][j] = j
        }
        for (int i = 1; i <= m; i++) {
            int diag = dp[0]; // 进第 1 列前，diag = dp[i-1][0]
            dp[0] = i;        // 第 0 列：dp[i][0] = i
            for (int j = 1; j <= n; j++) {
                int prevRowSame = dp[j]; // 覆盖前保存 dp[i-1][j]
                if (word1.charAt(i - 1) == word2.charAt(j - 1)) {
                    dp[j] = diag;
                } else {
                    dp[j] = Math.min(Math.min(prevRowSame, dp[j - 1]), diag) + 1;
                }
                diag = prevRowSame; // 下一列的斜对角 = dp[i-1][j]
            }
        }
        return dp[n];
    }

一次 AC；二维 DP 时间最优，空间 O(mn) 可优化为滚动数组 O(n)

思路拆解

问题本质与解法选择

  • 本质：求两个字符串的最小编辑距离，是典型的最优化问题；word1 前缀转 word2 前缀的过程有大量重叠子问题（如转 "abc" 时反复用到 "ab"、"a" 等更短前缀的结果），因此用动态规划。
  • 为什么不暴力：每次操作有插入/删除/替换 3 种选择，递归枚举是指数级；DP 把每个 (i,j) 前缀对的结果只算一次，共 O(mn) 个状态。

关键设计决策

  • 状态定义：dp[i][j] = word1 前 i 个字符转成 word2 前 j 个字符所需的最小操作数（i、j 是前缀长度，不是下标，所以表是 (m+1)x(n+1)）。
  • 转移（看末尾字符 word1[i-1] 与 word2[j-1]）：
  • 相等：dp[i][j] = dp[i-1][j-1]（末尾天然匹配，无需操作）
  • 不等：三种操作取最小再 +1
  1. 删除 word1 末尾字符：dp[i-1][j] + 1
  2. word1 末尾插入 word2[j-1]：dp[i][j-1] + 1
  3. 替换末尾为 word2[j-1]：dp[i-1][j-1] + 1
  • 初始化：dp[0][j]=j（空串转非空只能靠插入），dp[i][0]=i（非空转空只能靠删除）。
  • 返回 dp[m][n]。

具体 case 推演：word1="ab"，word2="abc"（期望答案 1）

  • 初始化后：dp[0][0..3] = 0,1,2,3；dp[0..2][0] = 0,1,2
  • i=1, j=1：a==a → dp[1][1]=dp[0][0]=0
  • i=1, j=2：a vs b 不等 → min(dp[0][2]=2, dp[1][1]=0, dp[0][1]=1)+1 = 1（插入 b，"a"→"ab"）
  • i=1, j=3：a vs c 不等 → min(dp[0][3]=3, dp[1][2]=1, dp[0][2]=2)+1 = 2
  • i=2, j=1：b vs a 不等 → min(dp[1][1]=0, dp[2][0]=2, dp[1][0]=1)+1 = 1（替换 b→a）
  • i=2, j=2：b==b → dp[2][2]=dp[1][1]=0
  • i=2, j=3：b vs c 不等 → min(dp[1][3]=2, dp[2][2]=0, dp[1][2]=1)+1 = 1（插入 c）
  • 答案 dp[2][3]=1 ✓

边界与细节

  • 双空：dp[0][0]=0。
  • 一边为空：全插入 / 全删除，直接被初始化行/列覆盖。
  • 单字符相同 / 不同、全相同、等长全替换（结果=长度）、交换两字符（2 步，替换或删+插）均已在本地测试覆盖。
  • 下标对齐：charAt(i-1) / charAt(j-1) 对应前缀长度 i / j，避免越界。

复杂度与下限论证

  • 时间 O(mn)：两层循环填表，每格 O(1) 转移；两个串的所有前缀组合都要比较，O(mn) 是问题本身的下限。
  • 空间 O(mn)：完整二维表；每格只依赖上一行同列、当前行左邻、上一行左邻，可滚动压缩到 O(n)。
