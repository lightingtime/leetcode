309. 买卖股票的最佳时机含冷冻期 (Best Time to Buy and Sell Stock with Cooldown)

> https://leetcode.cn/problems/best-time-to-buy-and-sell-stock-with-cooldown/

难度：Medium ｜ 分类：动态规划

标签：数组、动态规划

题目描述

给定一个整数数组prices，其中第 prices[i] 表示第 i 天的股票价格 。​

设计一个算法计算出最大利润。在满足以下约束条件下，你可以尽可能地完成更多的交易（多次买卖一支股票）:

卖出股票后，你无法在第二天买入股票 (即冷冻期为 1 天)。

注意：你不能同时参与多笔交易（你必须在再次购买前出售掉之前的股票）。

示例 1:

输入: prices = [1,2,3,0,2]

输出: 3

解释: 对应的交易状态为: [买入, 卖出, 冷冻期, 买入, 卖出]

示例 2:

输入: prices = [1]

输出: 0

LC0309_BestTimeToBuyAndSellStockWithCooldown.java · 三状态机 DP（含冷冻期）提交区
public int maxProfit(int[] prices) {
        int hold = -prices[0];
        int empty = 0;
        int cold = 0;
        for (int i = 1; i < prices.length; i++) {
            int preHold = hold;
            int preEmpty = empty;
            // hold -> hold, cold -> hold
            hold = Math.max(hold, cold - prices[i]);
            // hold -> empty, empty -> empty, cold -> empty
            empty = Math.max(preEmpty, preHold + prices[i]);
            // cold -> cold, empty -> cold
            cold = Math.max(preEmpty, cold);
        }
        return Math.max(empty, cold);
    }

    public int maxProfit(int[] prices, int k) {
        int[][] dp = new int[prices.length][3];
        dp[0][0] = -prices[0];
        for (int i = 1; i < prices.length; i++) {
            dp[i][0] = Math.max(dp[i - 1][0], dp[i - 1][2] - prices[i]);
            dp[i][1] = dp[i - 1][0] + prices[i];
            dp[i][2] = Math.max(dp[i-1][2], i-k >= 0 ? dp[i-k][1] : 0);
        }
        return Math.max(dp[prices.length - 1][1], dp[prices.length - 1][2]);
    }

思路拆解

问题本质与解法选择理由

  • 本质：每日价格序列允许多次买卖，但「卖出后下一天不能买入（冷冻期）」，求最大利润。相对无限次交易的 122，多了一条时序约束：昨天刚卖 与 今天可买 不能同时成立，必须显式建模。
  • 为什么 DP：明天的最优只依赖今天收盘时「是否持有、是否刚卖」，有最优子结构与无后效性，是标准状态机 DP；暴力枚举所有买卖组合是指数级。

关键设计决策

  • 状态定义（第 i 天收盘，三种互斥状态）：
  1. dp[i][0] 持有：手里有股票（今天买入或一直拿着都落这里）
  2. dp[i][1] 刚卖：今天卖出，明天是冷冻期
  3. dp[i][2] 自由空仓：没股票且今天没卖，明天可以买
  • 转移（都从第 i-1 天推来）：
  • dp[i][0] = max(dp[i-1][0], dp[i-1][2] - prices[i])：继续持有，或从自由空仓买入。买入只允许从状态 2 来，堵死「昨天刚卖、今天买」——这就是冷冻期约束。
  • dp[i][1] = dp[i-1][0] + prices[i]：昨天持有，今天卖出。
  • dp[i][2] = max(dp[i-1][2], dp[i-1][1])：继续空仓，或昨天刚卖、今天歇完回归自由。
  • 初始化：dp[0][0] = -prices[0]；dp[0][1] = 0（逻辑上第 0 天不可能刚卖，占位值，只参与 max 且利润下界为 0，无副作用）；dp[0][2] = 0。
  • 答案：max(dp[n-1][1], dp[n-1][2])。最后一天持有不参与：最后一天买入必不优于空仓（价格非负），卖出则落入刚卖已被覆盖。

具体 case 推演：prices = [1,2,3,0,2]（期望 3）

  • 第 0 天（价 1）：dp[0] = [-1, 0, 0]
  • 第 1 天（价 2）：dp[1][0]=max(-1, 0-2)=-1；dp[1][1]=-1+2=1（天0买天1卖）；dp[1][2]=max(0,0)=0
  • 第 2 天（价 3，冷冻期）：dp[2][0]=max(-1, 0-3)=-1；dp[2][1]=-1+3=2；dp[2][2]=max(0,1)=1（天1刚卖→天2回归自由）
  • 第 3 天（价 0）：dp[3][0]=max(-1, 1-0)=1（天3买 0）；dp[3][1]=-1+0=-1；dp[3][2]=max(1,2)=2
  • 第 4 天（价 2）：dp[4][0]=max(1, 2-2)=1；dp[4][1]=1+2=3（天3买0天4卖2，累计3）；dp[4][2]=max(2,-1)=2
  • 答案 max(3,2)=3 ✓。关键：天 2 是冷冻期不能买 3，转移靠「买入只从 rest 来」自动保证。

边界与细节

  • n=1：答案 max(0,0)=0。
  • 全相同 / 单调递减：无利可图，hold 恒 ≤0、rest 保持 0，答案 0。
  • 单调递增：一直持有到最后卖最优（中途卖出引入冷冻期反而错过），hold 走 max 正确。
  • 交替 1,2,1,2,1,2：每笔交易后强制隔一天，最多 2 笔，不会错算成 3 笔。

复杂度与下限论证

  • 时间 O(n)：每天 3 个 O(1) 转移；至少得读一遍全部价格才知道收益，Ω(n) 是下界，已达。
  • 空间 O(n)（dp[n][3]）：每格只依赖 i-1 的三个值，可滚动成 3 个变量压到 O(1)，当前实现用数组更直观但空间未达最优。
