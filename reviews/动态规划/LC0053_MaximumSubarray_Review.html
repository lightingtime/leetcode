public int maxSubArray(int[] nums) {
        int max = Integer.MIN_VALUE;
        int preMax = Integer.MIN_VALUE;
        for (int i = 0; i < nums.length; i++) {
            if (i == 0) {
                preMax = nums[i];
            } else {
                preMax = Math.max(preMax + nums[i], nums[i]);
            }
            max = Math.max(max, preMax);
        }
        return max;
    }

Kadane：以 i 结尾的最大子数组和 + 全局最大值

思路拆解

问题本质：找和最大的连续子数组。暴力枚举所有起止点 O(n²)；Kadane 用「以 i 结尾的最大子数组和」这个状态把每个元素只处理一次，O(n)。

为什么状态定义成「以 i 结尾」：

  • 连续子数组的边界一旦固定（右端必须是 i），组合规则就唯一：要么 nums[i] 单独开一段，要么接在以 i-1 结尾的那段后面；
  • 「区间内最大和」不能由子区间直接拼（两个子数组可能不相邻），所以不能用二维区间 DP。

关键设计：

  1. dp[i] = 以 nums[i] 结尾的最大连续子数组和，转移 dp[i] = max(nums[i], dp[i-1] + nums[i])；
  2. 只依赖前一个状态，滚动为两个变量：preMax（当前结尾最大和）与 max（历史最大值）；
  3. max 初始化为最小整数，保证全负数数组也能取到最大单元素。

具体 case 推演（nums = [-2,1,-3,4,-1,2,1,-5,4]）：

  • i=0：-2 单独开段 → preMax=-2，max=-2；
  • i=1：max(-2+1, 1)=1 → preMax=1，max=1；
  • i=2：max(1-3, -3)=-2 → preMax=-2，max=1；
  • i=3：max(-2+4, 4)=4 → max=4；
  • i=4：max(4-1, -1)=3；
  • i=5：max(3+2, 2)=5；
  • i=6：max(5+1, 1)=6 → max=6（对应子数组 [4,-1,2,1]）；
  • i=7：max(6-5, -5)=1；i=8：max(1+4, 4)=5；
  • 答案 6。

边界与细节：

  • 全负数：每个位置都是「自己开段」，返回最大单元素（如 [-1,-2,-3] → -1）；
  • 单元素直接返回自身；含 0 不影响结果；
  • 10^5 个 10^4 的和是 10^9，恰好不溢出 int（本地测试已覆盖）。

复杂度分析：

  • 时间 O(n)：一趟；
  • 空间 O(1)：两个变量。

为什么是最优：每个元素至少要读一次才能确定答案，O(n) 是下限；转移只依赖前一个状态，O(1) 空间也是下限。进阶分治解法 O(n log n) 不如 Kadane，本题 Kadane 即最优。
