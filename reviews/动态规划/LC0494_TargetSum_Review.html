494. 目标和 (Target Sum)

> https://leetcode.cn/problems/target-sum/

难度：Medium ｜ 分类：动态规划

标签：数组、动态规划、回溯、背包问题、0-1 背包

题目描述

给你一个非负整数数组 nums 和一个整数 target 。

向数组中的每个整数前添加 '+' 或 '-' ，然后串联起所有整数，可以构造一个 表达式 ：

例如，nums = [2, 1] ，可以在 2 之前添加 '+' ，在 1 之前添加 '-' ，然后串联起来得到表达式 "+2-1" 。

返回可以通过上述方法构造的、运算结果等于 target 的不同 表达式 的数目。

示例 1：

输入：nums = [1,1,1,1,1], target = 3

输出：5

解释：一共有 5 种方法让最终目标和为 3 。

-1 + 1 + 1 + 1 + 1 = 3

+1 - 1 + 1 + 1 + 1 = 3

+1 + 1 - 1 + 1 + 1 = 3

+1 + 1 + 1 - 1 + 1 = 3

+1 + 1 + 1 + 1 - 1 = 3

示例 2：

输入：nums = [1], target = 1

输出：1

public int findTargetSumWays(int[] nums, int target) {
        int sum = 0;
        for (int num : nums) {
            sum += num;
        }
        if (sum < target || sum + target < 0) {
            return 0;
        }
        if (((sum + target) & 1) == 1) {
            return 0;
        }
        sum = (sum + target) / 2;
        int[] dp = new int[sum + 1];
        dp[0] = 1;

        for (int num : nums) {
            for (int i = sum; i >= num; i--) {
                dp[i] = dp[i] + dp[i - num];
            }
        }
        return dp[sum];
    }

一次 AC；加减号→选 P 子集和=(sum+target)/2 的 0-1 背包计数 DP，倒序防元素复用，上下界+奇偶剪枝；O(n·total)/O(total)

思路拆解

问题本质与解法选择理由

  • 本质：给每个数分配 + 或 -，求表达式结果等于 target 的个数。二选一分配 + 计数 → 0-1 背包的计数版。
  • 转化：P=加号集合、N=减号集合。sum(P)-sum(N)=target，sum(P)+sum(N)=total，相加得 sum(P)=(total+target)/2——问题变成「选一个子集和等于 sum(P) 有几种方式」，直接复用 416 的子集和思路，只把 boolean 换成计数。

关键设计决策

  • 前置剪枝：① total+target 为奇数 → 0；② sum(P) 越界（target>total 或 target<-total）→ 0（第二个防数组长度变负）。
  • 状态：dp[s] = 用已处理元素凑出和 s 的方式数；dp[0]=1（空子集 1 种）。
  • 转移：每处理 num，dp[s] += dp[s-num]，s 从 target 倒序到 num——倒序保证 dp[s-num] 读的是上一轮旧值，每个元素只用一次；正序会让一个元素被重复使用（1 个当 2 个用）。
  • 答案：dp[sum(P)]。

具体 case 推演：[1,1,1]，target=1（期望 3）

  • total=3，sum(P)=(3+1)/2=2；dp=[1,0,0]
  • num=1：s=2→1：dp[2]+=dp[1]=0；dp[1]+=dp[0]=1 → [1,1,0]
  • num=1：dp[2]+=dp[1]=1；dp[1]+=dp[0]=2 → [1,2,1]
  • num=1：dp[2]+=dp[1]=3；dp[1]+=dp[0]=3 → [1,3,3]
  • dp[2]=3 ✓（对应 +-+、-++、++- 三种符号组合）

具体 case 推演：[0,0]，target=0（期望 4）

  • total=0，sum(P)=0，dp[0]=1
  • 每个 0 处理时 s=0：dp[0] += dp[0] → 每轮翻倍：1→2→4 ✓（每个 0 可 +0 或 -0，共 2² 种）

边界与细节

  • 单零/双零：0 的 + 与 - 是不同表达式，dp[0] 累加正确处理。
  • 负 target：target<-total 时 sum(P)<0，必须先返回 0 否则数组越界。
  • 大数组 20×1000 target=0：sum(P)=10000，dp 长度 10001，C(20,10)=184756 验证计数。
  • 倒序是 0-1 背包防元素复用的关键，不可省。

复杂度与下限论证

  • 时间 O(n·sum(P)) ≤ O(n·total)：每元素倒序遍历 dp 数组。n≤20、total≤20000，完全可行。这是子集和计数（NP 完全问题的计数版）的标准伪多项式 DP，本约束下即最优。
  • 空间 O(sum(P)) ≤ O(total)。
