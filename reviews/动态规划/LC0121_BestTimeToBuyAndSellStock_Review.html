121. 买卖股票的最佳时机 (Best Time to Buy and Sell Stock)

题目描述

给定一个数组 prices ，它的第 i 个元素 prices[i] 表示一支给定股票第 i 天的价格。

你只能选择 某一天 买入这只股票，并选择在 未来的某一个不同的日子 卖出该股票。设计一个算法来计算你所能获取的最大利润。

返回你可以从这笔交易中获取的最大利润。如果你不能获取任何利润，返回 0 。

示例 1：

输入：[7,1,5,3,6,4]

输出：5

解释：在第 2 天（股票价格 = 1）的时候买入，在第 5 天（股票价格 = 6）的时候卖出，最大利润 = 6-1 = 5 。

注意利润不能是 7-1 = 6, 因为卖出价格需要大于买入价格；同时，你不能在买入前卖出股票。

示例 2：

输入：prices = [7,6,4,3,1]

输出：0

解释：在这种情况下, 没有交易完成, 所以最大利润为 0。

我的解法

写法 1 · 单趟扫描维护历史最低

时间 O(n)空间 O(1)内存 ≈ 90.5 MB用例 212/212

src/动态规划/LC0121_BestTimeToBuyAndSellStock.java提交区
public int maxProfit(int[] prices) {
        int max = 0;
        int minPrice = prices[0];
        for (int i = 0; i < prices.length; i++) {
            max = Math.max(max, prices[i] - minPrice);
            minPrice = Math.min(prices[i], minPrice);
        }
        return max;
    }

单趟扫描维护历史最低买入价

思路拆解

问题本质：只能买卖一次，最大利润 = max(某天卖出价 − 之前某天买入价)。暴力枚举所有买卖日组合是 O(n²)；因为「买入必须在卖出前」，一趟扫描维护历史最低买入价即可 O(n) 解决。

为什么用单趟扫描：

  • 对第 i 天，最优卖出策略一定是「在 0..i-1 天里的最低价买入、第 i 天卖出」；
  • 更高的旧买入价永远不会比历史最低更好，可以放心丢弃，所以只需滚动维护一个 minPrice。

具体 case 推演（prices = [7,1,5,3,6,4]）：

  • 第 1 天 7：历史最低 7，利润 7-7=0，max=0；
  • 第 2 天 1：历史最低更新为 1，利润 0，max=0；
  • 第 3 天 5：利润 5-1=4，max=4；
  • 第 4 天 3：利润 3-1=2，max=4；
  • 第 5 天 6：利润 6-1=5，max=5；
  • 第 6 天 4：利润 4-1=3，max=5，答案 5。

关键设计：

  1. 两个滚动变量：minPrice 记录到当前为止的最低买入价，max 记录到当前为止的最大利润；
  2. 每步先算「今天卖出」的利润更新 max，再考虑是否把今天更新为新的历史最低；
  3. max 初始 0：全程下跌时不允许亏损，返回 0。

边界与细节：

  • 单元素数组：无法完成买卖，返回 0；
  • 全递增：最低点买入、最高点卖出；全递减/全相同：返回 0；
  • 10 万元素长数组也要一趟通过（本地边界测试已覆盖）。

复杂度分析：

  • 时间 O(n)：一趟扫描；
  • 空间 O(1)：两个变量。

为什么是最优：每个价格至少要读一次才能确定答案，O(n) 是下限；只需要历史最低这一个信息，O(1) 空间也是下限。
