题目描述

假设你正在爬楼梯。需要 n 阶你才能到达楼顶。

每次你可以爬 1 或 2 个台阶。你有多少种不同的方法可以爬到楼顶呢？

示例 1：

输入：n = 2

输出：2

解释：有两种方法可以爬到楼顶。

  1. 1 阶 + 1 阶
  2. 2 阶

示例 2：

输入：n = 3

输出：3

解释：有三种方法可以爬到楼顶。

  1. 1 阶 + 1 阶 + 1 阶
  2. 1 阶 + 2 阶
  3. 2 阶 + 1 阶

写法 1 · 滚动变量斐波那契

时间 O(n)空间 O(1)内存 ≈ 40.6 MB用例 45/45

src/动态规划/LC0070_ClimbingStairs.java提交区
public int climbStairs(int n) {
        if (n <= 2) {
            return n;
        }
        int f1 = 1, f2 = 2, fn = 2;
        for (int i = 2; i < n; i++) {
            fn = f1 + f2;
            f1 = f2;
            f2 = fn;
        }
        return fn;
    }

滚动变量斐波那契，O(1) 空间

思路拆解

问题本质：到第 n 阶的方法数 = 最后一步从第 n-1 阶跨 1 阶 + 从第 n-2 阶跨 2 阶，所以 f(n) = f(n-1) + f(n-2)，就是斐波那契数列（f(1)=1, f(2)=2）。

为什么用 DP/滚动变量：

  • 状态定义：f(i) = 爬到第 i 阶的方法数；
  • 转移方程：f(i) = f(i-1) + f(i-2)，只依赖前两个状态；
  • 因此不需要存整个数组，两个滚动变量即可，空间 O(1)。

具体 case 推演（n=4）：

  • f(1)=1：只能走 1 阶，方法 [1]；
  • f(2)=2：方法 [1,1]、[2]；
  • f(3)=f(1)+f(2)=3：方法 [1,1,1]、[1,2]、[2,1]；
  • f(4)=f(2)+f(3)=5：方法 [1,1,1,1]、[1,1,2]、[1,2,1]、[2,1,1]、[2,2]。

关键设计：

  1. 循环从 i=2 到 n-1 共 n-2 轮，每轮 fn=f1+f2 后滚动 f1=f2、f2=fn；
  2. n<=2 提前返回，避免 f1/f2 的初值问题。

边界与细节：

  • n=1 → 1、n=2 → 2 直接返回；
  • 题目约束 1 <= n <= 45，f(45)=1836311903 不溢出 int（再大一位 F47 就会溢出，约束恰好卡在安全范围内），本地边界测试已覆盖 n=45。

复杂度分析：

  • 时间 O(n)：n-2 轮转移；
  • 空间 O(1)：只保留前两个状态。

为什么是最优：状态转移只依赖前两项，常规做法 O(n)/O(1) 已到 DP 最优；进阶可用矩阵快速幂做到 O(log n)，但对 n<=45 没有实际收益，面试/刷题场景滚动变量就是标准答案。
