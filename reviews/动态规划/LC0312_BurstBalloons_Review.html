312. 戳气球 (Burst Balloons)

> https://leetcode.cn/problems/burst-balloons/

难度：Hard ｜ 分类：动态规划

标签：数组、动态规划

题目描述

有 n 个气球，编号为0 到 n - 1，每个气球上都标有一个数字，这些数字存在数组 nums 中。

现在要求你戳破所有的气球。戳破第 i 个气球，你可以获得 nums[i - 1] * nums[i] * nums[i + 1] 枚硬币。 这里的 i - 1 和 i + 1 代表和 i 相邻的两个气球的序号。如果 i - 1或 i + 1 超出了数组的边界，那么就当它是一个数字为 1 的气球。

求所能获得硬币的最大数量。

示例 1：

输入：nums = [3,1,5,8]

输出：167

解释：

nums = [3,1,5,8] --> [3,5,8] --> [3,8] --> [8] --> []

coins = 3*1*5 + 3*5*8 + 1*3*8 + 1*8*1 = 167

示例 2：

输入：nums = [1,5]

输出：10

提示：

LC0312_BurstBalloons.java · 区间 DP提交区
    public int maxCoins(int[] nums) {
        int n = nums.length;
        int[] array = new int[n + 2];
        System.arraycopy(nums, 0, array, 1, n);
        array[0] = array[array.length - 1] = 1;
        int[][] dp = new int[array.length][array.length];
        for (int len = 2; len < array.length; len++) {
            for (int i = 0; i + len < array.length; i++) {
                int j = i + len;
                for (int k = i + 1; k < j; k++) {
                    dp[i][j] = Math.max(dp[i][j], dp[i][k] + array[i] * array[k] * array[j] + dp[k][j]);
                }
            }
        }
        return dp[0][array.length - 1];
    }

思路拆解

问题本质：n 个气球按某个顺序全部戳破，每次得分依赖「当前相邻气球」，求最大总得分。直接枚举顺序是 O(n!)，不可行；正着做会不断改变相邻关系，所以倒过来想「最后一个戳谁」——最后一个被戳的气球左右邻居固定，且把问题切成两个互不影响的子区间。

解法选择理由（区间 DP）：

  • 在数组两端补 1 哨兵，val = [1] + nums + [1]，下标 0..n+1。
  • 定义 dp[i][j] = 戳破开区间 (i, j) 内所有气球（端点 i、j 不戳，只当边界）能拿到的最大硬币。
  • 最后戳 k（i < k < j）时，(i,k) 和 (k,j) 已戳完，k 的左右邻居就是 i 和 j，得分 = val[i] * val[k] * val[j]；左右子区间互不影响。
  • 答案 = dp[0][n+1]（0 和 n+1 是哨兵，戳完中间全部真实气球）。

关键设计：

  1. 转移：dp[i][j] = max(dp[i][k] + val[i]*val[k]*val[j] + dp[k][j])，枚举所有 i < k < j。
  2. 填表顺序：三层循环，外层按区间长度 len 从小到大（2..n+1），中层左端点 i（j = i+len），内层枚举 k。长度小的区间先算完，dp[i][k]、dp[k][j] 才可用。
  3. 哨兵数组创建后必须把 val[0]、val[n+1] 设为 1；转移里所有取值都用 val，不能用原 nums（否则越界且边界不是 1）。

具体 case 推演（nums = [3,1,5]，val = [1,3,1,5,1]，期望 35）：

lenijk 候选dp
202k=1: 0+1×3×1+03
213k=2: 0+3×1×5+015
224k=3: 0+1×5×1+05
303k=1: 0+1×3×5+15=30；k=2: 3+1×1×5+0=830
314k=2: 0+3×1×1+5=8；k=3: 15+3×5×1+0=3030
404k=1: 0+1×3×1+30=33；k=2: 3+1×1×1+5=9；k=3: 30+1×5×1+0=3535

答案 = dp[0][4] = 35。

边界与细节：

  • 单元素 [5]：val=[1,5,1]，dp[0][2] = 1×5×1 = 5。
  • 全 0：所有乘积为 0，返回 0。
  • 全 1：每个气球得分 1，n 个气球共 n。
  • 0 在中间（[1,0,1]）：0 只会在某次乘积中贡献 0，最优把 1 的气球各拿 1 分，共 2。
  • 300 个全 1：int 范围内 300，验证大输入不溢出。

复杂度分析：

  • 时间 O(n^3)：len 有 n 种、i 有 O(n) 种、k 有 O(n) 种。
  • 空间 O(n^2)：dp 表。
  • 这是本题的标准最优解：每个子区间都要枚举分界点，O(n^3) 是区间 DP 的下限形态；n<=300 时完全可接受。

套路沉淀

区间 DP：最后一步切分 + 补哨兵

正着操作会破坏相邻关系时，倒过来想最后一步处理谁：最后处理的对象把区间切成两个独立子区间。dp[i][j] 表示开区间 (i,j)（端点当边界不处理），转移枚举最后处理的 k：dp[i][k] + 边界代价 + dp[k][j]；数组两端补哨兵简化边界；填表按区间长度从小到大。
