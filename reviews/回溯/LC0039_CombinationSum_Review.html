39. 组合总和 (Combination Sum)

> https://leetcode.cn/problems/combination-sum/

难度：Medium ｜ 分类：回溯

标签：数组、回溯

题目描述

给你一个 无重复元素 的整数数组 candidates 和一个目标整数 target ，找出 candidates 中可以使数字和为目标数 target 的 所有 不同组合 ，并以列表形式返回。你可以按 任意顺序 返回这些组合。

candidates 中的 同一个 数字可以 无限制重复被选取 。如果至少一个数字的被选数量不同，则两种组合是不同的。

对于给定的输入，保证和为 target 的不同组合数少于 150 个。

示例 1：

输入：candidates = [2,3,6,7], target = 7

输出：[[2,2,3],[7]]

解释：

2 和 3 可以形成一组候选，2 + 2 + 3 = 7 。注意 2 可以使用多次。

7 也是一个候选， 7 = 7 。

仅有这两种组合。

示例 2：

输入: candidates = [2,3,5], target = 8

输出: [[2,2,2,2],[2,3,3],[3,5]]

示例 3：

输入: candidates = [2], target = 1

输出: []

List<List<Integer>> ans;
    public List<List<Integer>> combinationSum(int[] candidates, int target) {
        ans = new ArrayList<>();
        Arrays.sort(candidates);
        dfs(candidates, 0, target, new ArrayList<>());
        return ans;
    }

    private void dfs(int[] candidates, int index, int remain, List<Integer> path) {
        if (remain == 0) {
            ans.add(new ArrayList<>(path));
            return;
        }

        for (int i = index; i < candidates.length; i++) {
            if (candidates[i] > remain) {
                break;
            }
            path.add(candidates[i]);
            dfs(candidates, i, remain - candidates[i], path);
            path.remove(path.size() - 1);
        }
    }

思路拆解

问题本质

无重复候选、每数可无限取，找所有和为 target 的组合 = 枚举「每个候选取多少个」的非负整数解；组合无序（[2,2,3] 与 [2,3,2] 相同），必须避免排列重复。

为什么用 回溯（排序 + start 去重 + 剪枝）

  • 本质是组合枚举：递归树每层决定「取哪个候选」；因为可无限取，选择空间没有明确上限，只能靠剩余值约束剪枝。
  • 去重靠「start 下标」：下一层只能从当前下标（含）开始取，保证组合内元素按下标非降，从根上杜绝 [2,3,2] 这类排列重复。
  • 排序的价值：遍历时一旦 candidates[i] > remain，后面只会更大全部无效，直接 break 剪枝；顺带让输出天然有序。

关键设计决策

  • 状态：index（当前可取的起始下标，同时管去重与重复取）、remain（还差多少）、path（已选组合）。
  • 终止：remain == 0 → 把 path 拷贝加入结果（必须 new 一份，否则引用会被后续撤销污染）；取数前已保证 candidates[i] <= remain，所以不会出现 remain < 0。
  • 选择/撤销：path.add(candidates[i]) → 递归（传同一个 i，允许再取同一个数）→ path.remove(last) 撤销，回到上一层继续试别的选择。
  • 剪枝：if (candidates[i] > remain) break;——排序保证其后所有候选都大于 remain，整段不必再试。

小 case 推演

candidates=[2,3,6,7]（已排序），target=7：

  1. 第一层取 2（i=0）：remain=5 → 再取 2：remain=3 → 再取 2：remain=1，2>1 break 回溯；改取 3（i=1）：remain=0 → 记录 [2,2,3]
  2. 回到第一层取 3（i=1）：remain=4 → 取 3：remain=1，3>1 break；取 6：6>4 break
  3. 第一层取 6（i=2）：remain=1，6>1 break
  4. 第一层取 7（i=3）：remain=0 → 记录 [7]

结果 [[2,2,3],[7]] ✅，且全程不会出现 [2,3,2] 这类排列重复。

边界与细节

  • 全 1：[1] 凑 3 → [1,1,1]，验证同一数无限重复取。
  • 无解：全偶数凑奇数 → 空列表，循环里全部 break/超限。
  • 候选恰等于 target：[3] 直接命中 remain=0，无需继续递归。
  • 单元素整除：[5] 凑 10 → [5,5]，两个 5。
  • 小 target / 无候选可用：for 循环可能一次都不进，直接返回空。

复杂度与下限论证

  • 时间：指数级，上界 O(n^(target/min))（每层最多 n 个选择、深度 ≤ target/min）；但题目保证组合总数 < 150，输出规模本身受控，排序剪枝后实际遍历远小于上界。
  • 空间：递归深度 ≤ target/min（最坏全取最小值），path 与调用栈 O(target/min)；答案空间不计入。
  • 下限论证：任何解法都必须把全部有效组合输出出来，输出规模就是下界；回溯 + 剪枝在本题约束下已是标准最优取舍。
