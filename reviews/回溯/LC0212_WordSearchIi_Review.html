List<String> ans;
    boolean[][] visited;
    public List<String> findWords(char[][] board, String[] words) {
        ans = new ArrayList<>();
        visited = new boolean[board.length][board[0].length];
        Trie trie = new Trie();
        for (String word : words) {
            Trie p = trie;
            for (char c : word.toCharArray()) {
                if (p.children[c - 'a'] == null) {
                    p.children[c - 'a'] = new Trie();
                }
                p = p.children[c - 'a'];
            }
            p.word = word;
        }
        for (int i = 0; i < board.length; i++) {
            for (int j = 0; j < board[0].length; j++) {
                dfs(board, i, j, trie);
            }
        }
        return ans;
    }

    private void dfs(char[][] board, int i, int j, Trie trie) {
        if (i < 0 || i >= board.length || j < 0 || j >= board[0].length || visited[i][j]) {
            return;
        }
        if (trie.children[board[i][j] - 'a'] == null) {
            return;
        }
        trie = trie.children[board[i][j] - 'a'];
        if (trie.word != null) {
            ans.add(trie.word);
            trie.word = null;
        }
        visited[i][j] = true;
        dfs(board, i - 1, j, trie);
        dfs(board, i + 1, j, trie);
        dfs(board, i, j - 1, trie);
        dfs(board, i, j + 1, trie);
        visited[i][j] = false;
    }

    static class Trie {
        Trie[] children;
        String word;

        public Trie() {
            this.children = new Trie[26];
        }

        public Trie(Trie[] children, String word) {
            this.children = children;
            this.word = word;
        }
    }

Trie 建树词尾存整词便于收集与清空去重；DFS 携带树上当前节点同步前进，children 查不到即整枝剪枝；visited 进栈标记回溯撤销

思路拆解

## ① 问题本质与解法选择

  • 本质：在棋盘的全部路径中，找出恰好等于字典中某个单词的路径。朴素做法是逐词 DFS：每个词都从 m·n 个起点各搜一遍，words 可达 3×10^4 个，重复扫描量爆炸必超时。
  • 解法选择：Trie + 回溯。把全部单词压进共享前缀的字典树后，「往这个方向走还有没有词活着」从查 3 万次变成查 1 次 children 槽位；棋盘每走一格、树上同步走一层，死前缀整枝剪掉。

## ② 关键设计决策

设计点决策理由
词尾标记存完整单词 String 而非 boolean命中直接收集不用回拼路径字符串；置回 null 即天然去重
dfs 的树参数每层递归传当前节点的孩子树上位置随路径推进；Java 引用按值传，形参换指向不影响外层 root
去重机制trie.word = null 改对象内容改的是节点本体，全局可见，任何路径二次走到同一词尾不会重复收录
回溯现场visited 进栈标记、返回前撤销当前路径用过的格子释放给兄弟分支复用

dfs 单帧五步顺序：守卫(越界或已访问直接 return) → 剪枝(children[idx]==null return) → 前进+命中(word!=null 则收集并清空) → 标记 visited → 四方向递归 → 撤销 visited。

## ③ 具体 case 推演（边界5）

board=[a,b,c] 单行，words=[ab, abc, ac]，建树结果（ac 与 ab 共享前缀 a）：

```

root───a(A)───b(B,word=ab)───c(C,word=abc)

└────c(E,word=ac)

```

步骤格子树上位置动作与状态变化
1(0,0)=aroot→Aroot.children[a] 存在，进入 A，标记 (0,0)
2(0,1)=bA→BB.word=ab 非空，收集 ab 并把 B.word 置 null
3(0,2)=cB→CC.word=abc 命中收集；C 无孩子，开始回溯
4—A 的另一孩子 E(ac)树上说 ac 存在，但 (0,0) 的邻格里没有未访问的 c，走不出去，放弃
5(0,1)=brootroot 无 b 孩子，该起点秒退
6(0,2)=crootroot 无 c 孩子，同样秒退

输出 [ab, abc]。三个结论：词在字典存在不代表棋盘有路（步骤4）；字典没有的前缀连搜都不搜（步骤5、6）；B 命中后 children 未清空所以 abc 仍能继续深走收上来（前缀嵌套）。

## ④ 边界与细节

  • 1x1 棋盘 + 单字符词：起点循环与命中逻辑的最小闭环
  • 单元格不可复用（aba）：visited 漏撤销会让后续路径误判格子被占用
  • 多路径同词（aa）：两条路径先后到达同一词尾节点，第二次因 word 已置 null 不重复收录
  • 前缀嵌套（ab/abc）：命中短词不动 children，长词在同一路径上继续收
  • 竖条棋盘（ba/bab/bb）：bb 两字母不相邻，几何相邻性自然淘汰

## ⑤ 复杂度与下限论证

  • 时间：建树 O(ΣL)，ΣL ≤ 3×10^4×10 = 3×10^5；搜索上界 O(m·n·3^L)——144 个起点 × 每步至多 3 个新方向（不走回头格）× 深度 ≤ 10，约 8.5×10^6 量级，65 用例实测通过。
  • 空间：Trie 节点 O(ΣL) 主导，另加 visited O(m·n)、递归栈 O(L)。
  • 下限论证：任何正确算法都要读完 words（Ω(ΣL)），也必须允许每个格子作为起点候选（Ω(m·n)）。本解法两项均贴下限，是该题公认最优框架。（可选进阶：命中后若无剩余孩子可向上剪掉子树，缩小后续搜索的树，量级不变。）
