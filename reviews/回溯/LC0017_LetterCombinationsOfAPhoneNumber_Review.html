17. 电话号码的字母组合 (Letter Combinations of a Phone Number)

> https://leetcode.cn/problems/letter-combinations-of-a-phone-number/

难度：Medium ｜ 分类：回溯

标签：哈希表、字符串、回溯

题目描述

给定一个仅包含数字 2-9 的字符串，返回所有它能表示的字母组合。答案可以按 任意顺序 返回。

给出数字到字母的映射如下（与电话按键相同）。注意 1 不对应任何字母。

示例 1：

输入：digits = "23"

输出：["ad","ae","af","bd","be","bf","cd","ce","cf"]

示例 2：

输入：digits = "2"

输出：["a","b","c"]

提示：

1

digits[i] 是范围 ['2', '9'] 的一个数字。

    String[] map = {"", "", "abc", "def", "ghi", "jkl", "mno", "pqrs", "tuv", "wxyz"};
    List<String> ans;
    public List<String> letterCombinations(String digits) {
        ans = new ArrayList<>();
        if (digits.isEmpty()) {
            return ans;
        }
        dfs(digits, new StringBuilder(), 0);
        return ans;
    }

    private void dfs(String digits, StringBuilder path, int len) {
        if (len == digits.length()) {
            ans.add(path.toString());
            return;
        }

        for (char c : map[digits.charAt(len) - '0'].toCharArray()) {
            path.append(c);
            dfs(digits, path, len+1);
            path.deleteCharAt(path.length() - 1);
        }

    }

思路拆解

问题本质：给定数字串（每位是 2-9），每位映射到固定字母集（7/9 是 4 个字母，其余 3 个），求所有「每位置取一个字母」的组合串。本质是多路选择的枚举：每层递归决定一位选哪个字母，枚举所有路径。

解法选择理由：组合枚举的标准工具是回溯（递归 + 选择/撤销）。组合总数是指数级（最多 4^n），必须枚举全部，没有多项式捷径；回溯每次在一条路径上增量构造（StringBuilder），相比「每层复制整串」省内存，是本题最直接写法。

关键设计决策：

  • map 数组：下标 = 数字（0-9），值 = 该键字母串，map[digits.charAt(len)-'0'] 取当前位可选字母。
  • 终止条件 len == digits.length()：len 既是已选位数也是下一层的下标，走到末尾收集 path.toString()。
  • 选择/撤销：path.append(c) 进入下一层，返回后 deleteCharAt(last) 撤销，保证兄弟分支互不污染。
  • 空输入单独返回：len==0==digits.length() 会直接把空串当组合收集（得到 [""]），题目要求空输入返回空列表，故入口处提前 return。

边界与细节：空输入 → []；单数字 7/9（4 字母键）→ 4 个单字母；全相同数字（22）→ 3×3 笛卡尔积；混合四字母键（27）→ 3×4；多数字（234）→ 3×3×3。以上边界 1-6 已覆盖，且输入都在约束内（仅 2-9、长度 0-4）。

具体 case 推演（digits = "27"，期望 12 个组合）：

  1. dfs("27", path="", len=0)：map[2]="abc"，先选 'a' → path="a"，进入 len=1。
  2. dfs(..., path="a", len=1)：map[7]="pqrs"，依次选 'p','q','r','s' → 收集 "ap","aq","ar","as"，每选一个后 deleteCharAt 撤销。
  3. 回到 len=0，撤销 'a' → path=""，再选 'b' → 重复第 2 步收集 "bp"..."bs"；再选 'c' 同理。
  4. 共 3×4=12 条，与边界6 期望一致。

复杂度与下限论证：设每位字母数 c_i，组合总数 = ∏c_i，最坏全 4 字母键 = 4^n；每生成一个长度 n 的串要 O(n) 复制，总 O(4^n·n)。因为输出本身就有 4^n 个串，任何解法都至少 O(4^n·n)，时间达下界。空间 O(n)（递归栈深度 n + StringBuilder 长度 n），无额外结果存储（结果本身不算）。
