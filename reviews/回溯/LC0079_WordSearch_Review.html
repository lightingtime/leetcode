79. 单词搜索 (Word Search)

> https://leetcode.cn/problems/word-search/

难度：Medium ｜ 分类：回溯

标签：深度优先搜索、数组、字符串、回溯、矩阵

题目描述

给定一个 m x n 二维字符网格 board 和一个字符串单词 word 。如果 word 存在于网格中，返回 true ；否则，返回 false 。

单词必须按照字母顺序，通过相邻的单元格内的字母构成，其中“相邻”单元格是那些水平相邻或垂直相邻的单元格。同一个单元格内的字母不允许被重复使用。

示例 1：

输入：board = [['A','B','C','E'],['S','F','C','S'],['A','D','E','E']], word = "ABCCED"

输出：true

示例 2：

输入：board = [['A','B','C','E'],['S','F','C','S'],['A','D','E','E']], word = "SEE"

输出：true

示例 3：

输入：board = [['A','B','C','E'],['S','F','C','S'],['A','D','E','E']], word = "ABCB"

输出：false

提示：

m == board.length

n = board[i].length

1

1

board 和 word 仅由大小写英文字母组成

boolean[][] visited;
    public boolean exist(char[][] board, String word) {
        visited = new boolean[board.length][board[0].length];
        boolean ans = false;
        for (int i = 0; i < board.length; i++) {
            for (int j = 0; j < board[0].length; j++) {
                if (!visited[i][j]) {
                    ans = dfs(board, i, j, word, 0);
                }
                if (ans) {
                    return true;
                }
            }
        }
        return ans;
    }

    private boolean dfs(char[][] board, int i, int j, String word, int len) {
        if (len == word.length()) {
            return true;
        }
        if (i < 0 || j < 0 || i >= board.length || j >= board[0].length || visited[i][j]) {
            return false;
        }
        if (word.charAt(len) != board[i][j]) {
            return false;
        }
        visited[i][j] = true;
        boolean search;
        search = dfs(board, i + 1, j, word, len + 1);
        search = search || dfs(board, i - 1, j, word, len + 1);
        search = search || dfs(board, i, j + 1, word, len + 1);
        search = search || dfs(board, i, j - 1, word, len + 1);
        // visited 表示当前递归路径占用的格子，回退时必须释放。
        visited[i][j] = false;
        return search;
    }

boolean[][] visited;

    public boolean exist(char[][] board, String word) {
        int m = board.length;
        int n = board[0].length;
        visited = new boolean[m][n];
        boolean ans = false;
        int index = 0;
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                ans = ans || dfs(board, i, j, index, word);
            }
        }
        return ans;
    }

    private boolean dfs(char[][] board, int i, int j, int index, String word) {
        if (index == word.length()) {
            return true;
        }
        if (i < 0 || i >= board.length || j < 0 || j >= board[0].length) {
            return false;
        }
        if (visited[i][j]) {
            return false;
        }
        if (board[i][j] != word.charAt(index)) {
            return false;
        }
        visited[i][j] = true;
        int[][] dirs = new int[][]{{-1, 0}, {1, 0}, {0, -1}, {0, 1}};
        boolean ans = false;
        for (int[] dir : dirs) {
            int x = i + dir[0];
            int y = j + dir[1];
            ans = ans || dfs(board, x, y, index + 1, word);
        }
        visited[i][j] = false;
        return ans;
    }

思路拆解

问题本质：在 m×n 网格中判断单词是否存在——按字母顺序走水平/垂直相邻格，同一格不能重复使用。这是网格上的路径搜索，DFS（回溯）天然适配：沿一条路径深入匹配，走不通就撤销回退换方向。

关键设计：

  1. 状态：dfs(i, j, index) 表示当前站在 (i,j)、要匹配 word 的第 index 个字母；visited[i][j] 记录当前路径是否占用过该格；
  2. 终止条件：index == word.length() 时所有字母已匹配，返回 true——这个判断必须在访问 board 之前做，否则匹配完还会越界访问；
  3. 剪枝顺序：越界 → visited → 字母不相等，任一不满足直接返回 false；只有字母相等才继续深入；
  4. 主循环：word 第一个字母可能出现在任意格，遍历全部格子作为起点；
  5. 选择/撤销对称：匹配当前格后 visited[i][j]=true，向四个方向递归 index+1，全部方向结束后 visited[i][j]=false。

具体 case 推演：

  • 命中：board=[[A,B],[C,D]]，word=「AC」：从 (0,0) 的 A 匹配 index=0 → 标记 visited → 向下到 (1,0) 的 C 匹配 index=1 → 进入下一层时 index==2 返回 true；
  • 撤销的必要性：board=[[A,A]]，word=「AAA」：从 (0,0) 匹配后向右到 (0,1)，index=2 时已无路可走返回 false；若返回时未把 (0,1) 还原，其他起点的搜索会误以为该格被占用；
  • 成功路径依赖逐层还原：2×2 全 A 网格找「AAA」，(0,0)→(0,1)→(1,1) 能走通，前提是每层返回时都把上一格释放；
  • 同一格不可重复用（示例 3）：word=「ABCB」走 A(0,0)→B(0,1)→C(0,2) 后想再找 B 只能回到 (0,1)，但 visited 已标记 → false。

边界与细节：

  • 单词长度为 1：任意格字母相等即 true；
  • 词比格子总数还长时必然 false（路径长度上限 = 格子数）；
  • 斜对角不算相邻，只能上下左右；单行/单列网格由越界判断自然处理。

复杂度分析：

  • 时间 O(m·n·3^L)：m·n 个起点，每个起点最多探索 3^L 条路径（除回头方向外每步 3 个选择），L 为单词长度；
  • 空间 O(L + m·n)：递归栈深度 L + visited 数组。

为什么是可接受/最优：单词搜索没有多项式优化的一般算法（网格字符可任意重复），标准做法就是 DFS + 剪枝；O(m·n·3^L) 是本题标准复杂度，visited 与字母不匹配两层剪枝把实际搜索量压得很低。
