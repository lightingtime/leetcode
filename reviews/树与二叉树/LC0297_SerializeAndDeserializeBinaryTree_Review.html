297. 二叉树的序列化与反序列化 (Serialize and Deserialize Binary Tree)

> https://leetcode.cn/problems/serialize-and-deserialize-binary-tree/

难度：Hard ｜ 分类：树与二叉树

标签：树、深度优先搜索、广度优先搜索、设计、字符串、二叉树

题目描述

序列化是将一个数据结构或者对象转换为连续的比特位的操作，进而可以将转换后的数据存储在一个文件或者内存中，同时也可以通过网络传输到另一个计算机环境，采取相反方式重构得到原数据。

请设计一个算法来实现二叉树的序列化与反序列化。这里不限定你的序列 / 反序列化算法执行逻辑，你只需要保证一个二叉树可以被序列化为一个字符串并且将这个字符串反序列化为原始的树结构。

提示: 输入输出格式与 LeetCode 目前使用的方式一致，详情请参阅 LeetCode 序列化二叉树的格式。你并非必须采取这种方式，你也可以采用其他的方法解决这个问题。

LC0297_SerializeAndDeserializeBinaryTree.java · 层序 BFS + 占位符提交区
static class Codec {
    public String serialize(TreeNode root) {
        if (root == null) {
            return "[]";
        }
        Deque<TreeNode> queue = new LinkedList<>();
        List<String> list = new ArrayList<>();
        queue.offer(root);
        while (!queue.isEmpty()) {
            int size = queue.size();
            for (int i = 0; i < size; i++) {
                TreeNode node = queue.pollFirst();
                if (node != null) {
                    list.add(node.val + "");
                    queue.offerLast(node.left);
                    queue.offerLast(node.right);
                } else {
                    list.add("#");
                }
            }
        }
        return "[" + String.join(",", list) + "]";
    }

    public TreeNode deserialize(String data) {
        data = data.substring(1, data.length() - 1);
        if (data.isEmpty()) {
            return null;
        }
        String[] split = data.split(",");
        TreeNode root = new TreeNode(Integer.parseInt(split[0]));
        Deque<TreeNode> queue = new ArrayDeque<>();
        queue.offer(root);
        int i = 1;
        while (!queue.isEmpty()) {
            TreeNode node = queue.pollFirst();
            if (!Objects.equals(split[i], "#")) {
                node.left = new TreeNode(Integer.parseInt(split[i]));
                queue.offerLast(node.left);
            }
            i++;
            if (!Objects.equals(split[i], "#")) {
                node.right = new TreeNode(Integer.parseInt(split[i]));
                queue.offerLast(node.right);
            }
            i++;
        }
        return root;
    }
}

static class Codec {
        public String serialize(TreeNode root) {
            StringBuilder sb = new StringBuilder();
            if (root == null) {
                return sb.toString();
            }
            Deque<TreeNode> queue = new LinkedList<>();
            queue.offerLast(root);
            while (!queue.isEmpty()) {
                TreeNode cur = queue.pollFirst();
                if (cur != null) {
                    sb.append(cur.val + ",");
                    queue.offerLast(cur.left);
                    queue.offerLast(cur.right);
                } else {
                    sb.append("#,");
                }
            }
            sb.deleteCharAt(sb.length() - 1);
            return sb.toString();
        }

        public TreeNode deserialize(String data) {
            if (data == null || data.isEmpty()) {
                return null;
            }
            String[] vals = data.split(",");
            TreeNode root = new TreeNode(Integer.parseInt(vals[0]));
            Deque<TreeNode> queue = new LinkedList<>();
            queue.offerLast(root);
            int i = 1;
            while (!queue.isEmpty()) {
                TreeNode cur = queue.pollFirst();
                if (!vals[i].equals("#")) {
                    TreeNode node = new TreeNode(Integer.parseInt(vals[i]));
                    cur.left = node;
                    queue.offerLast(node);
                }
                i++;
                if (!vals[i].equals("#")) {
                    TreeNode node = new TreeNode(Integer.parseInt(vals[i]));
                    cur.right = node;
                    queue.offerLast(node);
                }
                i++;
            }
            return root;
        }

思路拆解

反序列化参数 i 的作用：为什么下标能自动对应左右子树

i 的语义：deserialize 中 i 是指向 vals（序列化数组）的「下一个待消费槽位」下标；每处理完一个父节点的左右孩子，i 前进 2。

为什么能对上：serialize 与 deserialize 是同一个 BFS 的「写」与「读」两个方向：

  • serialize：每个节点出队时，把它 left、right（含 null）紧接着写入序列化串——所以每个节点都「消耗」2 个输出槽位；null 只写出、不入队。
  • deserialize：每个非空父节点出队时，从 vals 连续读取 2 个槽位作为左右孩子——同样每节点消耗 2 个输入槽位；# 跳过不建节点。

两条 BFS 的「非空节点出队顺序」完全相同（都是层序），因此「读的位置」天然等于「写的位置」——i 不需要数学公式，它就是复刻 serialize 写入节奏的游标。

case 推演（树 [1,2,3,null,null,4,5]）：serialize 产出 1,2,3,#,#,4,5,#,#,#,#（每个非空节点后紧跟左右两槽位）。

deserialize 出队父节点消费 i槽位内容动作
11, 22, 3挂 left=2、right=3，2/3 入队
23, 4#, #左空、右空，不入队
35, 64, 5挂 left=4、right=5，4/5 入队
47, 8#, #左空、右空
59, 10#, #左空、右空

对照 serialize 的写入：1 出队时写 2,3；2 出队时写 #,#；3 出队时写 4,5……——读的顺序就是写的顺序，所以 i 每次 +2 就精确落在「当前父节点的左右孩子」上。

一句话：i 不是靠 2i/2i+1 公式定位（那要求完全二叉树连续数组），而是靠「读写同节奏」——BFS 队列保证非空节点按层序处理，每个节点固定消费两个槽位，指针 i 自然与左右子树一一对应。

套路沉淀

序列化/反序列化顺序一致性 + 队列栈进出配对

Deque 入队 offerLast 配出队 pollFirst 才是队列（FIFO）；offerLast 配 pollLast 实际是栈（LIFO）。序列化用哪种顺序生成字符串，反序列化就必须按同一种顺序消费：层序（先左后右）序列化就要层序重建，否则结构错位。
