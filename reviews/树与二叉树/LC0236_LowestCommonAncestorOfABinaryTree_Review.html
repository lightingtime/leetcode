public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
        if (root == null) {
            return null;
        }
        if (root == p || root == q) {
            return root;
        }
        TreeNode left = lowestCommonAncestor(root.left, p, q);
        TreeNode right = lowestCommonAncestor(root.right, p, q);
        if (left == null) {
            return right;
        }
        if (right == null) {
            return left;
        }
        return root;
    }

思路拆解

问题本质：p、q 的最近公共祖先 = 从根往下找第一个「自身是 p/q，或左右子树分别找到 p 和 q」的节点。

关键设计：后序递归：root 为 null 返回 null；root 是 p 或 q 直接返回 root（自己就是祖先，不必再往下找）；然后分别在左、右子树递归找；左空返回右、右空返回左、两边都非空说明 p、q 分居两侧，root 就是 LCA。

边界：题目保证 p、q 存在且互异；p 是 q 的祖先时递归在 p 处提前返回，另一侧不会误判；树只有单节点。

复杂度：O(n) 时间（每个节点访问一次）、O(h) 空间（递归栈），最优；不需要 parent 指针或路径记录。
