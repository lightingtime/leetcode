    public TreeNode sortedArrayToBST(int[] nums) {
        return buildBST(nums, 0, nums.length - 1);
    }

    private TreeNode buildBST(int[] nums, int l, int r) {
        if (l > r) {
            return null;
        }
        if (l == r) {
            return new TreeNode(nums[l]);
        }
        int mid = l + (r - l) / 2;
        TreeNode root = new TreeNode(nums[mid]);
        root.left = buildBST(nums, l, mid - 1);
        root.right = buildBST(nums, mid + 1, r);
        return root;
    }

思路拆解

问题本质：升序数组 → 高度平衡 BST。BST 的中序遍历就是升序序列，所以「数组中间」天然对应 BST 的根；递归切半能保证左右子树元素数量差 ≤ 1，从而整体平衡。

解法选择理由：递归分治，每次取区间中间元素为根，左半段建左子树、右半段建右子树。每个元素恰好当一次根 → O(n) 时间；递归深度 O(log n)。建树至少要为 n 个节点各分配一次，时间下界就是 O(n)，此解达到最优。

关键设计决策：

  1. 用下标区间 [l, r] 递归，不复制子数组（复制会让复杂度劣化）。
  2. 递归基：l > r 返回 null；左右子区间分别是 [l, mid-1]、[mid+1, r]。
  3. 取左中 (l+r)/2 或右中 (l+r+1)/2 都正确（答案不唯一），本解取左中。
  4. 严格递增保证 mid 值唯一，BST 性质天然成立。

具体 case 推演（nums=[-10,-3,0,5,9]）：

  1. 根：mid=(0+4)/2=2 → 值 0
  2. 左区间 [0,1]：mid=0 → 值 -10；再递归右 [1,1] → 值 -3，挂在 -10 的右子树
  3. 右区间 [3,4]：mid=3 → 值 5；再递归右 [4,4] → 值 9，挂在 5 的右子树
  4. 结果树：[0, -10, 5, null, -3, null, 9]，中序 = [-10,-3,0,5,9] ✓，左右高度差 ≤ 1 ✓

小 case（[1,3]，偶数长度）：mid=(0+1)/2=0 → 根 1，右子树 [1,1] → 3，树为 [1,null,3]，中序 [1,3] ✓。

边界与细节：

  • 单元素：mid 就是自身，左右区间为空 → 叶子节点。
  • 偶数长度：取左中时左子树少一个节点，高度差仍 ≤ 1，平衡。
  • 大输入（长度 10^4）：递归深度 O(log n) ≈ 14，无栈溢出风险。
  • 值域 ±10^4，无溢出。
  • 易错点：若取端点当根（如 nums[0]），会退化成链 → 不平衡；本地测试的「中序 + 高度平衡」双重校验能抓住。

复杂度与下限论证：每个节点创建一次 → O(n) 时间；递归栈深度 = 树高 O(log n) → 空间 O(log n)（不计返回树本身）。时间下界 O(n)（n 个节点至少要建 n 次），此解最优。
