public List<List<Integer>> levelOrder(TreeNode root) {
        List<List<Integer>> ans = new ArrayList<>();
        if (root == null) {
            return ans;
        }
        Deque<TreeNode> queue = new LinkedList<>();
        queue.offerLast(root);
        while (!queue.isEmpty()) {
            int size = queue.size();
            List<Integer> list = new ArrayList<>();
            for (int i = 0; i < size; i++) {
                TreeNode cur = queue.pollFirst();
                list.add(cur.val);
                if (cur.left != null) {
                    queue.offerLast(cur.left);
                }
                if (cur.right != null) {
                    queue.offerLast(cur.right);
                }
            }
            ans.add(list);
        }
        return ans;
    }

二叉树的层序遍历：BFS 队列按层弹出当前层再扩展下一层，一次 Accepted（35/35）

思路拆解

问题本质：按层输出二叉树 = BFS。关键是不能让层与层混在一起，所以每层先记录队列大小再一次性处理。

关键设计：while 队列非空：size=queue.size()，for size 次出队收集本层节点值、同时把下一层子节点入队；这样一轮恰好处理一层，ans 按层追加。空树直接返回空列表。

边界：空树；单节点一层；斜树每层一个节点；节点值重复不影响（按结构输出）；宽层（满二叉树最后一层 n/2 个节点）考验队列容量。

复杂度：O(n) 时间、O(w) 空间（w 为最大层宽，最坏 O(n)），最优。
