105. 从前序与中序遍历序列构造二叉树 (Construct Binary Tree from Preorder and Inorder Traversal)

> https://leetcode.cn/problems/construct-binary-tree-from-preorder-and-inorder-traversal/

难度：Medium ｜ 分类：树与二叉树

标签：树、数组、哈希表、分治、二叉树

题目描述

给定两个整数数组 preorder 和 inorder ，其中 preorder 是二叉树的先序遍历， inorder 是同一棵树的中序遍历，请构造二叉树并返回其根节点。

示例 1:

输入: preorder = [3,9,20,15,7], inorder = [9,3,15,20,7]

输出: [3,9,20,null,null,15,7]

示例 2:

输入: preorder = [-1], inorder = [-1]

输出: [-1]

提示:

1

inorder.length == preorder.length

-3000

preorder 和 inorder 均 无重复 元素

inorder 均出现在 preorder

preorder 保证 为二叉树的前序遍历序列

inorder 保证 为二叉树的中序遍历序列

示例

  1. 输入：preorder = [3,9,20,15,7]，inorder = [9,3,15,20,7]

输出：[3,9,20,null,null,15,7]

  1. 输入：preorder = [-1]，inorder = [-1]

输出：[-1]

关键点都处理对了：① 用 preorder[preStart] 取当前子树的根，靠哈希表拿到它在 inorder 中的下标 index；② 左子树大小 leftLen = index - inStart，前序左区间 [preStart+1, preStart+leftLen]、右区间 [preStart+1+leftLen, preEnd]，中序左右区间是 [inStart, index-1] 与 [index+1, inEnd]——两边的区间长度严格对应，所以不会切错；③ 递归出口判的是区间为空（preStart > preEnd），空输入与单节点都自然兜住。本地示例 2 + 边界 6（空输入/全左链/全右链/不平衡混合/极值/完全二叉树）全过，一次提交 Accepted（203/203）。

    Map<Integer, Integer> map;
    public TreeNode buildTree(int[] preorder, int[] inorder) {
        map = new HashMap<>();
        for (int i = 0; i < inorder.length; i++) {
            map.put(inorder[i], i);
        }
        TreeNode root = buildHelper(preorder, 0, preorder.length - 1, inorder, 0, inorder.length - 1);
        return root;
    }

    private TreeNode buildHelper(int[] preorder, int preStart, int preEnd, int[] inorder, int inStart, int inEnd) {
        if (preStart > preEnd) {
            return null;
        }

        TreeNode root = new TreeNode(preorder[preStart]);
        int index = map.get(root.val);
        int leftLen = index - inStart;
        root.left = buildHelper(preorder, preStart + 1, preStart + leftLen, inorder, inStart, index - 1);
        root.right = buildHelper(preorder, preStart + 1 + leftLen, preEnd, inorder, index + 1, inEnd);
        return root;
    }

Map<Integer, Integer> map;
    public TreeNode buildTree(int[] preorder, int[] inorder) {
        map = new HashMap<>();
        for (int i = 0; i < inorder.length; i++) {
            map.put(inorder[i], i);
        }
        return buildTreeHelper(preorder, 0, preorder.length - 1, inorder, 0, inorder.length);
    }

    private TreeNode buildTreeHelper(int[] preorder, int preStart, int preEnd, int[] inorder, int inStart, int inEnd) {
        if (preStart > preEnd) {
            return null;
        }
        TreeNode root = new TreeNode(preorder[preStart]);
        int index = map.get(preorder[preStart]);
        int leftLength = index - inStart;
        root.left = buildTreeHelper(preorder, preStart + 1, preStart + leftLength, inorder, inStart, index - 1);
        root.right = buildTreeHelper(preorder, preStart + leftLength + 1, preEnd, inorder, index + 1, inEnd);
        return root;
    }

思路拆解

问题本质：前序第一个元素是根，中序中根的位置把左右子树区间一分为二 → 递归分治重建整棵树。

关键设计：先用 HashMap 存中序值→下标，实现 O(1) 查根位置；递归参数是前序区间 [preStart, preEnd] 与中序区间 [inStart, inEnd)：根 = preorder[preStart]，rootIndex = map.get(根)，左子树长度 leftLength = rootIndex - inStart；左子树前序区间 [preStart+1, preStart+leftLength]，右子树 [preStart+leftLength+1, preEnd]。

边界：区间为空（preStart>preEnd）返回 null；单节点；只有左子树或只有右子树的斜树；题目保证节点值互异，map 不会冲突。

复杂度：O(n) 时间（每个节点一次、map 查询 O(1)）、O(n) 空间（map + 递归栈），最优。
