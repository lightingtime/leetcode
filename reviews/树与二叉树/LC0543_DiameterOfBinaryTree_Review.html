543. 二叉树的直径 (Diameter of Binary Tree)

> https://leetcode.cn/problems/diameter-of-binary-tree/

难度：Easy ｜ 分类：树与二叉树

标签：树、深度优先搜索、二叉树、树形 DP

题目描述

给你一棵二叉树的根节点，返回该树的 直径 。

二叉树的 直径 是指树中任意两个节点之间最长路径的 长度 。这条路径可能经过也可能不经过根节点 root 。

两节点之间路径的 长度 由它们之间边数表示。

示例 1：

输入：root = [1,2,3,4,5]

输出：3

解释：3 ，取路径 [4,2,1,3] 或 [5,2,1,3] 的长度。

示例 2：

输入：root = [1,2]

输出：1

提示：

树中节点数目在范围 [1, 104] 内

int max = 0;
    public int diameterOfBinaryTree(TreeNode root) {
        max = 0; // 重置：成员变量在多次调用间会残留上一次的答案
        dfs(root);
        return max;
    }

    private int dfs(TreeNode root) {
        if (root == null) {
            return 0;
        }
        int left = dfs(root.left);
        int right = dfs(root.right);
        max = Math.max(max, left + right);
        return 1 + Math.max(left, right);
    }

思路拆解

问题本质与解法选择

  • 题目：任意两个节点间最长路径的边数，路径可能不经过根。
  • 观察：任何一条路径都「向上走到某个最高点 LCA 再向下」，所以最长路径一定等于某个节点的 左子树高度 + 右子树高度（经过该节点的最深左叶子→该节点→最深右叶子）。
  • 解法选择：后序递归。每个节点返回自己的子树高度给父节点（max(左,右)+1），同时用左高+右高更新全局答案；这样一趟遍历同时算完所有候选。

关键设计决策

  • 递归函数 dfs(node) 返回以 node 为根的子树高度（边数口径：叶子返回 1，空返回 0）。
  • 全局答案 max 在每层更新：max(max, left + right)——left+right 恰为「经过当前节点的最长路径边数」。
  • 必须用成员变量/数组累计答案，不能用递归的局部变量（会随栈帧消失）。
  • 坑：成员变量多次调用同一实例时会残留上次答案，入口需重置为 0（本地多用例测试暴露；力扣虽单用例也建议重置）。

具体 case 推演

  • 示例1：[1,2,3,4,5] → 4、5 叶子各返回 1；节点2 左=1 右=1，max=2，返回 2；节点3 返回 1；根1 左=2 右=1，max=max(2,3)=3，返回 3 → 答案 3 ✓
  • 示例2：[1,2] → 节点2 返回 1；根1 左=1 右=0，max=1 → 答案 1 ✓
  • 链状 [1,2,3]（1-2-3）：节点3 返回1；节点2 左=1 右=0，max=1，返回2；根1 左=2 右=0，max=2 → 答案 2 ✓

边界与细节

  • 空节点返回 0；单节点：左=右=0，max=0 ✓
  • 只有一条链的树：答案 = 链长 - 1（边数）
  • 递归深度 = 树高 h，最坏 O(n)。

复杂度与下限论证

  • 时间 O(n)：每个节点恰好访问一次。
  • 空间 O(h)：递归栈深度为树高。
  • 下界论证：必须访问每个节点才能算出所有可能的路径候选，O(n) 达到下界。
