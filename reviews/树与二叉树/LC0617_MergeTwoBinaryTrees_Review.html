617. 合并二叉树 (Merge Two Binary Trees)

> https://leetcode.cn/problems/merge-two-binary-trees/

难度：Easy ｜ 分类：树与二叉树

标签：树、深度优先搜索、广度优先搜索、二叉树

题目描述

给你两棵二叉树： root1 和 root2 。

想象一下，当你将其中一棵覆盖到另一棵之上时，两棵树上的一些节点将会重叠（而另一些不会）。你需要将这两棵树合并成一棵新二叉树。合并的规则是：如果两个节点重叠，那么将这两个节点的值相加作为合并后节点的新值；否则，不为 null 的节点将直接作为新二叉树的节点。

返回合并后的二叉树。

注意: 合并过程必须从两个树的根节点开始。

示例 1：

输入：root1 = [1,3,2,5], root2 = [2,1,3,null,4,null,7]

输出：[3,4,5,5,4,null,7]

示例 2：

输入：root1 = [1], root2 = [1,2]

输出：[2,2]

提示：

两棵树中的节点数目在范围 [0, 2000] 内

        if (root1 == null && root2 == null) {
            return null;
        }
        if (root1 == null) {
            return root2;
        }
        if (root2 == null) {
            return root1;
        }
        root1.val += root2.val;
        TreeNode left = mergeTrees(root1.left, root2.left);
        TreeNode right = mergeTrees(root1.right, root2.right);
        root1.left = left;
        root1.right = right;
        return root1;
    }

思路拆解

问题本质与解法选择

  • 题目：两棵二叉树对应位置节点重叠则值相加，不重叠则保留非空节点，返回合并后的根。
  • 合并是逐节点同构操作：对每一对 (root1, root2) 决定当前节点的值和左右子树，天然适合递归。
  • 解法选择：递归。每个节点只处理一次，且只在两棵树都非空的位置继续递归（单空时整棵子树直接复用，无需下钻）。

关键设计决策

  • 递归出口三态：都空→null；root1 空→返回 root2；root2 空→返回 root1（子树原样保留）。
  • 都不为空：root1.val += root2.val，递归合并左右子树分别接到 root1 上，返回 root1（原地复用 root1，省空间）。
  • 复杂度只与两棵树重叠部分（较小的树）有关：min(m,n)。

具体 case 推演

  • 示例2：[1] 与 [1,2] → 根都非空：val=1+1=2；root1 左空、root2 左=2 → 返回节点 2；root1 右空、root2 右空 → null。结果 [2,2] ✓
  • 示例1：[1,3,2,5] 与 [2,1,3,null,4,null,7] → 根 1+2=3；左：3+1=4，再往下 5 与 null → 返回 5，null 与 4 → 返回 4；右：2+3=5，null 与 7 → 7。结果 [3,4,5,5,4,null,7] ✓
  • 单空树：root1=[] → 直接返回 root2（整棵原样）。

边界与细节

  • 两棵都为空树：返回 null。
  • 一边为空树时返回另一边，不产生新节点、不再递归。
  • 原地修改 root1：若题目要求不改原树则需新建节点；本题允许，返回合并后新树的根即可。

复杂度与下限论证

  • 时间 O(min(m,n))：只在两棵树都非空的节点递归，重叠节点数 ≤ min(m,n)。
  • 空间 O(min(m,n))：递归栈深度最坏为重叠部分高度（链状时 = min(m,n)）。
  • 下界论证：合并结果至少需要处理所有重叠节点，O(min(m,n)) 达到下界。
