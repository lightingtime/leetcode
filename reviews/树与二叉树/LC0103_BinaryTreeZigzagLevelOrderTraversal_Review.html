103. 二叉树的锯齿形层序遍历 (Binary Tree Zigzag Level Order Traversal)

> https://leetcode.cn/problems/binary-tree-zigzag-level-order-traversal/

难度：Medium ｜ 分类：树与二叉树

标签：树、广度优先搜索、二叉树

题目描述

给你二叉树的根节点 root ，返回其节点值的 锯齿形层序遍历 。（即先从左往右，再从右往左进行下一层遍历，以此类推，层与层之间交替进行）。

示例 1：

输入：root = [3,9,20,null,null,15,7]

输出：[[3],[20,9],[15,7]]

示例 2：

输入：root = [1]

输出：[[1]]

示例 3：

输入：root = []

输出：[]

提示：

树中节点数目在范围 [0, 2000] 内

我的解法

写法 1 · BFS 层序 + 方向标记（逆序层头插）

时间 O(n^2) 最坏空间 O(n)内存 ≈ 41.7 MB用例 33/33

LC0103_BinaryTreeZigzagLevelOrderTraversal.java · BFS 层序 + 方向标记（逆序层头插）提交区
    public List<List<Integer>> zigzagLevelOrder(TreeNode root) {
        List<List<Integer>> ans = new ArrayList<>();
        if (root == null) {
            return ans;
        }
        Deque<TreeNode> queue = new ArrayDeque<>();
        queue.offer(root);
        boolean left = true;
        while (!queue.isEmpty()) {
            int size = queue.size();
            List<Integer> list = new ArrayList<>();
            for (int i = 0; i < size; i++) {
                TreeNode cur = queue.removeFirst();
                if (left) {
                    list.add(cur.val);
                } else {
                    list.add(0, cur.val);
                }
                if (cur.left != null) {
                    queue.offerLast(cur.left);
                }
                if (cur.right != null) {
                    queue.offerLast(cur.right);
                }
            }
            ans.add(list);
            left = !left;
        }
        return ans;
    }

写法 2 · BFS 层序 + 方向标记（LinkedList 头插 O(1)）

时间 O(n)空间 O(n)内存 ≈ 42.0 MB用例 33/33

LC0103_BinaryTreeZigzagLevelOrderTraversal.java · BFS 层序 + 方向标记（LinkedList 头插 O(1)）提交区
    public List<List<Integer>> zigzagLevelOrder(TreeNode root) {
        List<List<Integer>> ans = new ArrayList<>();
        if (root == null) {
            return ans;
        }
        Deque<TreeNode> queue = new ArrayDeque<>();
        queue.offer(root);
        boolean left = true;
        while (!queue.isEmpty()) {
            int size = queue.size();
            List<Integer> list = new LinkedList<>();
            for (int i = 0; i < size; i++) {
                TreeNode cur = queue.removeFirst();
                if (left) {
                    list.add(cur.val);
                } else {
                    list.add(0, cur.val);
                }
                if (cur.left != null) {
                    queue.offerLast(cur.left);
                }
                if (cur.right != null) {
                    queue.offerLast(cur.right);
                }
            }
            ans.add(list);
            left = !left;
        }
        return ans;
    }

思路拆解

问题本质：层序遍历 + 每层方向交替。BFS 天然按「层」推进，锯齿只改变每层内部的方向，不改变遍历顺序——核心就是「先按层 BFS，再把奇数层倒过来输出」。

解法：队列逐层 BFS + boolean 方向标记。每层先记下 size，再循环处理正好 size 个节点；正序层 append 到链表尾部，逆序层在链表头部插入（LinkedList 头插 O(1)）。空树直接返回空列表。

关键设计决策：

  1. 每层先取 size 再循环：队列在处理过程中会不断入队新节点，若不固定 size 会把下一层混进当前层。
  2. 方向标记每层取反：第 0 层正序、第 1 层逆序、第 2 层正序……
  3. 逆序层用 LinkedList 头插：头插 O(1)，避免 ArrayList.add(0) 的 O(层大小) 移位（这是写法 1 到写法 2 的关键优化点）。
  4. BFS 队列用 ArrayDeque：队首出队、队尾入队均 O(1)。

具体 case 推演（[3,9,20,null,null,15,7]）：

  1. 层 0（正序）：队列 [3] → size=1 → 出 3，入 9、20 → list=[3] → 输出 [3]
  2. 层 1（逆序）：size=2 → 出 9（入 null 跳过）头插 9→[9]；出 20（入 15、7）头插 20→[20,9] → 输出 [20,9]
  3. 层 2（正序）：size=2 → 出 15→[15]；出 7→[15,7] → 输出 [15,7]

结果 [[3],[20,9],[15,7]] ✓

边界与细节：

  • 空树 → []；单节点 → [[1]]。
  • 单链（左/右链）：每层单节点，方向切换无影响 → [[1],[2],[3]]。
  • 满二叉树：第二层逆序 [3,2]，第三层正序 [4,5,6,7]。
  • 节点值含 0/负数：值不影响顺序。
  • 大输入 2000 节点：队列峰值 O(n)，迭代 BFS 无栈溢出。

复杂度与下限论证：每个节点入队/出队各一次，每层每个节点 O(1) 插入（LinkedList 头插/尾插均 O(1)）→ 总时间 O(n)；空间 O(n)（队列 + 结果）。时间下界 O(n)（每个节点至少访问一次），此写法达到最优。
