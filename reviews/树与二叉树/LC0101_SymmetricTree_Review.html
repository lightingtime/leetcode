写法 1 · 递归镜像比较

时间 O(n)空间 O(树高)内存 ≈ 41.9 MB用例 201/201

LC0101_SymmetricTree.java · 递归镜像比较提交区
public boolean isSymmetric(TreeNode root) {
    return isSymmetricHelper(root, root);
}

private boolean isSymmetricHelper(TreeNode left, TreeNode right) {
    if (left == null && right == null) {
        return true;
    }
    if (left == null || right == null) {
        return false;
    }
    if (left.val != right.val) {
        return false;
    }
    return isSymmetricHelper(left.left, right.right) && isSymmetricHelper(left.right, right.left);
}

递归镜像比较：helper(root,root) 出口先判双 null/单 null/值不同，再镜像递归 left.left vs right.right 且 left.right vs right.left；8 组本地一次全过，力扣 201/201 一次 Accepted

写法 2 · 迭代栈成对比较

时间 O(n)空间 O(树宽)内存 ≈ 41.8 MB用例 201/201

LC0101_SymmetricTree.java · 迭代栈成对比较提交区
    public boolean isSymmetric(TreeNode root) {
        Deque<TreeNode> stack = new LinkedList<>();
        stack.push(root);
        stack.push(root);
        while (!stack.isEmpty()) {
            TreeNode left = stack.pop(), right = stack.pop();
            if (left == null && right == null) {
                continue;
            }
            if (left == null || right == null) {
                return false;
            }
            if (left.val != right.val) {
                return false;
            }
            stack.push(left.left);
            stack.push(right.right);
            stack.push(left.right);
            stack.push(right.left);
        }
        return stack.isEmpty();
    }

    private boolean isSymmetricHelper(TreeNode left, TreeNode right) {
        if (left == null && right == null) {
            return true;
        }
        if (left == null || right == null) {
            return false;
        }
        if (left.val != right.val) {
            return false;
        }
        return isSymmetricHelper(left.left, right.right) && isSymmetricHelper(left.right, right.left);
    }

迭代栈（LinkedList 成对比较）：初始 push root 两次对应 helper(root,root)，每轮取一对做双 null/单 null/值判断，再把 (left.left,right.right) 与 (left.right,right.left) 两对入栈；曾用 ArrayDeque 不允许 null 入栈导致 NPE，换 LinkedList 后通过；力扣 201/201 Accepted

思路拆解

问题本质：树关于根镜像对称 ⟺ 左子树与右子树互为镜像。比较两棵子树时要交叉：p 的左对 q 的右、p 的右对 q 的左。

关键设计：递归 helper(left, right)：都空返回 true、一空返回 false、值不等返回 false，否则递归 (left.left, right.right) && (left.right, right.left)；入口调用 isSymmetricHelper(root, root)。代码里同时有迭代栈版本（成对压入再成对弹出比较）和递归版本，思路一致。

边界：空树 true；单节点 true；结构对称但值不对称；值对称但结构不对称（null 位置不同）——必须同时检查空与值。

复杂度：O(n) 时间（每个节点访问一次）、O(h) 空间（h 为树高），最优。
