题目描述

给你一棵二叉树的根节点 root ，翻转这棵二叉树，并返回其根节点。

示例 1：

输出：[4,7,2,9,6,3,1]

示例 2：

输入：root = [2,1,3]

输出：[2,3,1]

示例 3：

输入：root = []

输出：[]

public TreeNode invertTree(TreeNode root) {
        // TODO: 在这里实现你的解法
        if (root == null) {
            return null;
        }
        TreeNode left = invertTree(root.left);
        TreeNode right = invertTree(root.right);
        root.left = right;
        root.right = left;
        return root;
    }

思路拆解

问题本质与解法选择

  • 题目：把二叉树每个节点的左右子树交换，返回根。
  • 翻转是纯结构操作：每个节点都要交换 left/right，子树内部同样递归处理。
  • 解法选择：递归。二叉树题先想「对当前节点做什么 + 递归左右子树」；这里先递归再交换（后序）和先交换再递归（前序）都正确，因为交换是自反操作，选后序更直观：子树先翻好，当前节点直接换指针。

关键设计决策

  • 递归出口：root == null 返回 null（空子树无需翻转）。
  • 后序三步：left = invertTree(root.left)；right = invertTree(root.right)；root.left = right；root.right = left；返回 root。
  • 返回值是翻转后的子树根：翻转只换指针不换节点本身，根始终是原 root。

具体 case 推演

  • 示例2：[2,1,3] → 递归翻转左子树 1（null 子节点返回 null，1 的左右仍 null）得 1；右子树 3 同理；交换后 root 的左=3、右=1 → [2,3,1] ✓
  • 示例3：root=[] → 直接返回 null ✓
  • 单节点 [1]：左右都 null，交换后仍是 1 ✓

边界与细节

  • 空树（null 根）直接返回 null。
  • 只有左子/只有右子的节点：null 与子树交换后正确。
  • 递归深度 = 树高 h，最坏退化为链时 h = n，空间 O(h)。

复杂度与下限论证

  • 时间 O(n)：每个节点恰好访问一次（递归调用一次）。
  • 空间 O(h)：递归栈深度为树高 h；最坏链状 O(n)，平均 O(log n)。
  • 下界论证：每个节点都必须被访问才能交换指针，时间下界 O(n)；该解法达到下界。
