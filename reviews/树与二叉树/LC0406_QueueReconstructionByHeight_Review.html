406. 根据身高重建队列 (Queue Reconstruction by Height)

> https://leetcode.cn/problems/queue-reconstruction-by-height/

难度：Medium ｜ 分类：树与二叉树

标签：树状数组、线段树、数组、排序

题目描述

假设有打乱顺序的一群人站成一个队列，数组 people 表示队列中一些人的属性（不一定按顺序）。每个 people[i] = [hi, ki] 表示第 i 个人的身高为 hi ，前面 正好 有 ki 个身高大于或等于 hi 的人。

请你重新构造并返回输入数组 people 所表示的队列。返回的队列应该格式化为数组 queue ，其中 queue[j] = [hj, kj] 是队列中第 j 个人的属性（queue[0] 是排在队列前面的人）。

示例 1：

输入：people = [[7,0],[4,4],[7,1],[5,0],[6,1],[5,2]]

输出：[[5,0],[7,0],[5,2],[6,1],[4,4],[7,1]]

解释：

编号为 0 的人身高为 5 ，没有身高更高或者相同的人排在他前面。

编号为 1 的人身高为 7 ，没有身高更高或者相同的人排在他前面。

编号为 2 的人身高为 5 ，有 2 个身高更高或者相同的人排在他前面，即编号为 0 和 1 的人。

编号为 3 的人身高为 6 ，有 1 个身高更高或者相同的人排在他前面，即编号为 1 的人。

编号为 4 的人身高为 4 ，有 4 个身高更高或者相同的人排在他前面，即编号为 0、1、2、3 的人。

编号为 5 的人身高为 7 ，有 1 个身高更高或者相同的人排在他前面，即编号为 1 的人。

因此 [[5,0],[7,0],[5,2],[6,1],[4,4],[7,1]] 是重新构造后的队列。

示例 2：

输入：people = [[6,0],[5,0],[4,0],[3,2],[2,2],[1,4]]

输出：[[4,0],[5,0],[2,2],[3,2],[1,4],[6,0]]

public int[][] reconstructQueue(int[][] people) {
        List<int[]> ans = new ArrayList<>();
        Arrays.sort(people, (a, b) -> {
            if (a[0] == b[0]) {
                return a[1] - b[1];
            }
            return b[0] - a[0];
        });
        for (int[] p : people) {
            ans.add(p[1], p);
        }
        return ans.toArray(new int[0][]);
    }

思路拆解

问题本质：给定每个元素的两个属性 [h, k]，k = 前方身高 ≥ h 的人数，要求还原唯一合法排列。每个位置的 k 由前方所有「≥ 自己」的人共同决定，约束互相耦合，不能逐位置直接填，需要找到一种「先定住一批人、再插其他人不破坏它们」的处理顺序。

解法选择理由：k 只统计「前方身高 ≥ 我」的人，所以比我矮的人插到我前面不会改变我的 k。因此按身高从高到低处理：先放最高的人，他们之间只互相影响、可先定死；后面每放一个更矮的人，都不会破坏已放好的人的计数。这确定了「排序 + 按下标插入」的思路。

关键设计决策：

  1. 排序规则：身高降序；身高相同按 k 升序。同身高必须 k 升序——若先放 k 大的人，后面 k 小的人插到它前面，会让它的「≥ 人数」多算。用三个 [7,0],[7,1],[7,2] 验证：k 升序依次插入得到 [7,0],[7,1],[7,2]；若先放 [7,2]，它前方人数会变成 0，直接违背 k=2。
  2. 插入位置 = k：ans.add(p[1], p) 把当前人插到下标 k，ArrayList 会把下标 k 及之后整体右移，恰好让 k 个人留在他前面。插入时队列里已有的全是「不比他矮」的人（身高降序保证），所以前方恰好 k 个 ≥ 他的人。
  3. 返回：ans.toArray(new int[0][]) 转成 int[][]。

具体推演：以 [[7,0],[7,1],[6,1],[6,0]]（n=4）为例，排序后为 [7,0],[7,1],[6,0],[6,1]：

  • 插入 [7,0] 到下标 0 → 队列 [7,0]
  • 插入 [7,1] 到下标 1 → [7,0],[7,1]
  • 插入 [6,0] 到下标 0 → [6,0],[7,0],[7,1]
  • 插入 [6,1] 到下标 1 → [6,0],[6,1],[7,0],[7,1]

逐人验证：[6,1] 前方 [6,0] ≥6 共 1 个 ✓；[7,1] 前方 [6,0],[6,1],[7,0] 中 ≥7 只有 [7,0] 共 1 个 ✓；被挤到后面的 7 们前方多了 6，但 6<7 不计数，k 未被破坏 ✓。

边界与细节：

  • 单元素：直接返回自身。
  • 全相同身高：k 必须为 0..n-1 连续递增，升序插入即为答案。
  • 全 k=0：队列严格按身高升序（矮在前），因为没有任何人前方有 ≥ 自己的人。
  • 同身高与不同身高混合：验证「≥」语义，同身高也互相计入 k。
  • 身高可达 10^6：int 差值不超过 10^6，比较无溢出风险。

复杂度与下限：排序 O(n log n)；n 次 ArrayList 插入最坏每次右移 O(n)，总 O(n²)；空间 O(n)（ans 列表）。下限论证：还原任意排列至少需要比较身高，排序步骤 Ω(n log n) 不可省；插入的 O(n²) 在本题 n ≤ 2000 下最多约 4×10^6 次操作，完全可接受，是本题官方标准解法。进阶可用树状数组在空位中二分定位第 k+1 个空位，把插入优化到 O(n log n)，但实现复杂度高、本题无需。
