104. 二叉树的最大深度 (Maximum Depth of Binary Tree)

> https://leetcode.cn/problems/maximum-depth-of-binary-tree/

难度：Easy ｜ 分类：树与二叉树

标签：树、深度优先搜索、广度优先搜索、二叉树

题目描述

给定一个二叉树 root ，返回其最大深度。

二叉树的 最大深度 是指从根节点到最远叶子节点的最长路径上的节点数。

示例 1：

输入：root = [3,9,20,null,null,15,7]

输出：3

示例 2：

输入：root = [1,null,2]

输出：2

提示：

树中节点的数量在 [0, 104] 区间内。

public int maxDepth(TreeNode root) {
        if (root == null) {
            return 0;
        }
        int max = Math.max(maxDepth(root.left), maxDepth(root.right));
        return max + 1;
    }

LC0104_MaximumDepthOfBinaryTree.java · 递归 DFS · 上一版提交区
public int maxDepth(TreeNode root) {
        if (root == null) {
            return 0;
        }
        return 1 + Math.max(maxDepth(root.left), maxDepth(root.right));
    }

思路拆解

问题本质：二叉树最大深度 = 1 + max(左子树深度, 右子树深度)。树的分治结构让递归成为最自然的表达。

关键设计：递归终止条件为空节点返回 0；每深入一层加 1；取左右子树的较大者。也可以层序遍历计数，但递归最简洁。

边界：空树深度 0；单节点 1；斜树（退化成链）深度为 n，递归栈深度 O(n)，注意不要爆栈。

复杂度：O(n) 时间、O(h) 空间（h 为树高，最坏 O(n)），最优。
