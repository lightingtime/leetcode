581. 最短无序连续子数组 (Shortest Unsorted Continuous Subarray)

> https://leetcode.cn/problems/shortest-unsorted-continuous-subarray/

难度：Medium ｜ 分类：双指针与滑动窗口

标签：栈、贪心、数组、双指针、排序、单调栈

题目描述

给你一个整数数组 nums ，你需要找出一个 连续子数组 ，如果对这个子数组进行升序排序，那么整个数组都会变为升序排序。

请你找出符合题意的 最短 子数组，并输出它的长度。

示例 1：

输入：nums = [2,6,4,8,10,9,15]

输出：5

解释：你只需要对 [6, 4, 8, 10, 9] 进行升序排序，那么整个表都会变为升序排序。

示例 2：

输入：nums = [1,2,3,4]

输出：0

示例 3：

输入：nums = [1]

输出：0

我的解法

写法 1 · 排序对比找错位区间（朴素）

时间 O(n log n)空间 O(n)内存 —用例 307/307

LC0581_ShortestUnsortedContinuousSubarray.java · 排序对比找错位区间（朴素）提交区
    public int findUnsortedSubarray(int[] nums) {
        int[] copy = Arrays.copyOf(nums, nums.length);
        Arrays.sort(copy);
        int l = 0;
        while (l < nums.length) {
            if (copy[l] == nums[l]) {
                l++;
            } else {
                break;
            }
        }
        int r = nums.length - 1;
        while (r >= 0) {
            if (copy[r] == nums[r]) {
                r--;
            } else {
                break;
            }
        }
        if (r <= l) {
            return 0;
        }
        return r - l + 1;
    }

朴素写法（先实现）：复制排序 + 双端对比定位第一个/最后一个错位；本地测试全过，正确但 O(n log n)/O(n)。

写法 2 · 两趟扫描找左右边界

时间 O(n)空间 O(1)内存 ≈ 45.3 MB用例 307/307

LC0581_ShortestUnsortedContinuousSubarray.java · 两趟扫描找左右边界提交区
    public int findUnsortedSubarray(int[] nums) {
        int r = 0;
        int max = Integer.MIN_VALUE;
        for (int i = 0; i < nums.length; i++) {
            if (nums[i] < max) {
                r = i;
            }
            max = Math.max(max, nums[i]);
        }
        if (r == 0) {
            return 0;
        }
        int l = nums.length - 1;
        int min = Integer.MAX_VALUE;
        for (int i = nums.length - 1; i >= 0; i--) {
            if (nums[i] > min) {
                l = i;
            }
            min = Math.min(min, nums[i]);
        }
        return r - l + 1;
    }

最优写法：两趟扫描维护左右 max/min 找边界，O(n)/O(1)，一次 Accepted（307/307）。

思路拆解

写法 1：排序对比（朴素）——思路与复杂度

  • 复制一份数组排序得到目标有序序列 copy。
  • 从左到右找第一个 copy[i] != nums[i] 的位置 l（第一个错位）。
  • 从右到左找最后一个 copy[j] != nums[j] 的位置 r（最后一个错位）。
  • 若 r <= l（没有任何错位，数组已有序）返回 0；否则返回 r - l + 1。
  • 为什么对：排序后的数组就是最终目标状态；所有「不在最终位置」的元素必须被包含进重排区间，最短区间 = 第一个错位到最后一个错位（两端已就位的元素不动）。
  • 复杂度：时间 O(n log n)（排序主导），空间 O(n)（复制数组）。正确但没利用「只需找边界」的性质。

写法 2：两趟扫描（最优）——思路与复杂度

  • 核心判定：一个元素不需要重排 ⇔ 左边全 ≤ 它且右边全 ≥ 它；否则它不在最终位置，必须重排。
  • 右边界：从左到右维护 max（左侧已扫最大值），nums[i] < max 说明左侧有比它大的，更新 r = i；最终 r = 最靠右的逆序位置。
  • 左边界：从右到左维护 min（右侧已扫最小值），nums[i] > min 说明右侧有比它小的，更新 l = i；最终 l = 最靠左的逆序位置。
  • 哨兵：r 初始 0，若从未触发逆序则 r == 0，返回 0；长度 = r - l + 1。
  • 复杂度：时间 O(n)（两趟线性扫描，每趟每元素 O(1)），空间 O(1)（仅标量变量）。O(n) 是时间下界（必须至少看每个元素一次判断错位，否则可能漏边界），本写法已达最优。

具体 case 推演（两种写法都用 nums=[2,6,4,8,10,9,15]，期望 5）

写法 1（排序对比）：

  • copy = [2,4,6,8,9,10,15]
  • 左扫：i=0: 2==2 ✓；i=1: 6!=4 → l=1（第一个错位）
  • 右扫：i=6: 15==15 ✓；i=5: 9!=10 → r=5（最后一个错位）
  • 长度 = 5-1+1 = 5 ✓

写法 2（两趟扫描）：

  • 左→右（max 初始 MIN_VALUE）：2→max=2；6→max=6；4<6 → r=2；8→max=8；10→max=10；9<10 → r=5；15→max=15。结果 r=5
  • 右→左（min 初始 MAX_VALUE）：15→min=15；9<15→min=9；10>9 → l=4；8<9→min=8；4<8→min=4；6>4 → l=1；2<4→min=2。结果 l=1
  • 长度 = 5-1+1 = 5 ✓

边界与细节

  • 已升序 / 单元素 / 全相同：两写法都返回 0（写法 1 无错位 r<=l；写法 2 无逆序 r 保持 0）。
  • 严格降序：两写法都返回 n（整段重排）。
  • 中间连续相等 [1,3,2,2,2]：写法 2 右边界扫到最后一个 2（2<3 持续触发）得 r=4，左边界在 3 处得 l=1，长度 4，中间相等值不遗漏；写法 1 直接由错位端点给出 4。

最优性结论

时间 O(n)、空间 O(1) 均为该题下界：任何解法必须至少扫描每个元素一次判断错位；判断边界只需 O(1) 的 max/min 标量。写法 2 已达最优，写法 1 作为朴素基线用于理解「错位区间」的本质。
