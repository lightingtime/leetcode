public int findUnsortedSubarray(int[] nums) {
        int r = 0;
        int max = Integer.MIN_VALUE;
        for (int i = 0; i < nums.length; i++) {
            if (nums[i] < max) {
                r = i;
            }
            max = Math.max(max, nums[i]);
        }
        if (r == 0) {
            return 0;
        }
        int l = nums.length - 1;
        int min = Integer.MAX_VALUE;
        for (int i = nums.length - 1; i >= 0; i--) {
            if (nums[i] > min) {
                l = i;
            }
            min = Math.min(min, nums[i]);
        }
        return r - l + 1;
    }

最短无序连续子数组：两趟扫描维护左右 max/min 找边界，O(n)/O(1)，一次 Accepted（307/307）

思路拆解

1. 问题本质与解法选择理由

本质：找最短连续子数组，排序它之后整个数组变升序。等价于「找出所有不在最终位置的元素，取最左到最右的区间」。

  • 朴素做法：复制一份排序后双端对比，O(n log n)/O(n)，正确但没利用「只需找边界」的性质。
  • 最优做法：不排序直接扫描定位边界。一个元素不需要重排 ⇔ 左边全 ≤ 它且右边全 ≥ 它；因此「左边界 = 最靠左的存在右侧更小元素的逆序位」，「右边界 = 最靠右的存在左侧更大元素的逆序位」。两趟 O(n) 扫描即可。

2. 关键设计决策

  • 右边界：从左到右维护 max（左侧已扫最大值）；nums[i] < max 说明左侧有比它大的，它必须重排，更新 r = i。max 只增不减，代表左侧集合的最大值。
  • 左边界：从右到左维护 min（右侧已扫最小值）；nums[i] > min 说明右侧有比它小的，它必须重排，更新 l = i。
  • 哨兵：r 初始 0，若从未触发逆序则 r == 0 返回 0（位置 0 不可能成为右边界，因为第一个元素必然 ≥ 左侧最大值 MIN_VALUE）。
  • 长度 = r - l + 1。

3. 边界与细节

  • 已升序 / 单元素 / 全相同：两趟都不触发逆序，r 保持 0 → 返回 0。
  • 严格降序：r 更新到最后、l 更新到 0，长度 = n（整个数组）。
  • 中间连续相等 [1,3,2,2,2]：右边界扫到最后一个 2（因为 2<3 持续触发），左边界在 3 处，长度 4，中间的相等值不会被漏。
  • 哨兵安全性：nums[i] < max 中 max 初始 MIN_VALUE，位置 0 永远不会触发更新，r==0 等价于「无逆序」。

4. 具体 case 推演（nums=[2,6,4,8,10,9,15]）

第一趟（找 r，从左到右，max 初始 MIN_VALUE）：

  • i=0: 2 不小于 max，max=2
  • i=1: 6 ≥ 2，max=6
  • i=2: 4<6 → r=2，max 保持 6
  • i=3: 8 ≥ 6，max=8
  • i=4: 10 ≥ 8，max=10
  • i=5: 9<10 → r=5
  • i=6: 15 ≥ 10，max=15
  • 结果 r=5

第二趟（找 l，从右到左，min 初始 MAX_VALUE）：

  • i=6: 15 不大于 min，min=15
  • i=5: 9<15，min=9
  • i=4: 10>9 → l=4
  • i=3: 8<9，min=8
  • i=2: 4<8，min=4
  • i=1: 6>4 → l=1
  • i=0: 2<4，min=2
  • 结果 l=1

长度 = 5-1+1 = 5，与示例一致。

5. 复杂度与最优性

  • 时间 O(n)：两趟线性扫描，每趟每元素 O(1)。下限论证：必须至少看每个元素一次才能判断它是否错位，否则可能漏掉边界，因此 O(n) 是时间下界，本解已达。
  • 空间 O(1)：只用了几个标量变量。判断边界只需 O(1) 的 max/min 信息，空间下界已达。

6. 写法微调提示（已最优，仅风格/稳健性）

  • r = 0 哨兵依赖「位置 0 不可能成为右边界」这一隐含事实；改为 r = -1、结束时 if (r == -1) return 0; 更直观稳健（与左边界哨兵对称）。
  • max = Math.max(...) / min = Math.min(...) 可改为条件更新，性能无实质差别，属风格选择。
