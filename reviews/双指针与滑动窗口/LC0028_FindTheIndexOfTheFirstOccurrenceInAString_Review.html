28. 找出字符串中第一个匹配项的下标 (Find the Index of the First Occurrence in a String)

难度：Easy ｜ 分类：双指针与滑动窗口

标签：双指针、字符串、字符串匹配、KMP 算法、Boyer–Moore 算法、扩展 KMP

题目描述

给你两个字符串 haystack 和 needle ，请你在 haystack 字符串中找出 needle 字符串的第一个匹配项的下标（下标从 0 开始）。如果 needle 不是 haystack 的一部分，则返回 -1 。

示例 1：

输入：haystack = "sadbutsad", needle = "sad"

输出：0

解释："sad" 在下标 0 和 6 处匹配。

第一个匹配项的下标是 0 ，所以返回 0 。

示例 2：

输入：haystack = "leetcode", needle = "leeto"

输出：-1

解释："leeto" 没有在 "leetcode" 中出现，所以返回 -1 。

提示：

1 4

haystack 和 needle 仅由小写英文字符组成

src/双指针与滑动窗口/LC0028_FindTheIndexOfTheFirstOccurrenceInAString.java提交区
public int strStr(String haystack, String needle) {
        int[] pi = new int[needle.length()];
        int j = 0;
        for (int i = 1; i < needle.length(); i++) {
            while (j > 0 && needle.charAt(j) != needle.charAt(i)) {
                j = pi[j - 1];
            }
            if (needle.charAt(i) == needle.charAt(j)) {
                j++;
            }
            pi[i] = j;
        }
        j = 0;
        for (int i = 0; i < haystack.length(); i++) {
            while (j > 0 && haystack.charAt(i) != needle.charAt(j)) {
                j = pi[j - 1];
            }
            if (haystack.charAt(i) == needle.charAt(j)) {
                j++;
            }
            if (j == needle.length()) {
                return i - j + 1;
            }
        }
        return -1;
    }

思路拆解

① 问题本质与解法选择

  • 单模式字符串匹配：在 haystack 中找 needle 首次出现的下标，不存在返回 -1。
  • 暴力做法每次失配把 needle 指针直接归零、从头重比，最坏 O(n*m)；长度上限 10^4 时最坏 10^8 次比较，虽勉强可过但存在大量重复比对。
  • KMP 核心：失配时不归零，而是利用「已匹配前缀的最长相等前后缀」跳到合适位置，避免重新比对已经匹配过的字符。

② 关键设计决策

  • pi[i]（前缀函数）= needle[0..i] 的最长相等真前后缀长度，pi[0]=0。
  • 构建 pi：j 为上一轮留下的 pi[i-1]（即当前候选边界长度）；失配用 while (j>0 && needle[i]!=needle[j]) j=pi[j-1] 回退到更短边界；若 needle[i]==needle[j] 则 j++（边界加长）；迭代末尾 pi[i]=j。
  • 匹配：j 从 0 起；失配同样 j=pi[j-1]，匹配则 j++；当 j==needle.length() 时返回 i-j+1。
  • 易错点：构建完 pi 后必须把 j 重置为 0，因为构建循环结束后 j 停在 pi[m-1]，不一定是 0；直接沿用会把匹配窗口初始化错位。

③ 边界与细节

  • 约束 1 <= haystack.length, needle.length <= 10^4，两串仅小写字母；无空串，无需特判。
  • needle 比 haystack 长：匹配循环扫完 haystack 也达不到 j==m，自然返回 -1。
  • 全相同字符（如 "aaaaa" / "aa"）：pi 递增、支持重叠匹配，仍返回首个位置 0。
  • 命中起点 = i-j+1：窗口长 j、末尾在 i，起点需左移 j-1 格（末尾格自身占 1 个）。

④ 复杂度与最优性

  • 构建 pi：内层 while 的 j 回退总次数有界 O(m)（j 至多单调增到 m，回退总数被总增量封顶），故 O(m)；匹配同理 O(n)；总时间 O(n+m)。
  • 空间：pi 数组 O(m)。
  • 最优性：单模式串匹配在比较模型下界为 Ω(n+m)（至少要读入 haystack 与 needle 两个串），KMP 达到该下界，故为最优。

**⑤ 具体 case 推演：haystack="mississippi"、needle="issip"

  • needle 的 pi = [0,0,0,1,0]。
  • 逐行推演（j 为匹配阶段进入该 i 时的 needle 指针）：
ihay[i]进入时 j动作结束 j
0m0m vs i 不等0
