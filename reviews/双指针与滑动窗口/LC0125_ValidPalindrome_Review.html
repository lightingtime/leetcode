125. 验证回文串 (Valid Palindrome)

> https://leetcode.cn/problems/valid-palindrome/

难度：Easy ｜ 分类：双指针与滑动窗口

标签：双指针、字符串

题目描述

如果在将所有大写字符转换为小写字符、并移除所有非字母数字字符之后，短语正着读和反着读都一样。则可以认为该短语是一个 回文串 。

字母和数字都属于字母数字字符。

给你一个字符串 s，如果它是 回文串 ，返回 true ；否则，返回 false 。

示例 1：

输入: s = "A man, a plan, a canal: Panama"

输出：true

解释："amanaplanacanalpanama" 是回文串。

示例 2：

输入：s = "race a car"

输出：false

解释："raceacar" 不是回文串。

示例 3：

输入：s = " "

输出：true

解释：在移除非字母数字字符之后，s 是一个空字符串 "" 。

由于空字符串正着反着读都一样，所以是回文串。

s 仅由可打印的 ASCII 字符组成

public boolean isPalindrome(String s) {
        int l = 0, r = s.length() - 1;
        while (l < r) {
            if (!Character.isLetterOrDigit(s.charAt(l))) {
                l++;
            } else if (!Character.isLetterOrDigit(s.charAt(r))) {
                r--;
            } else {
                if (Character.toLowerCase(s.charAt(l)) != Character.toLowerCase(s.charAt(r))) {
                    return false;
                } else {
                    l++;
                    r--;
                }
            }
        }
        return true;
    }

思路拆解

① 问题本质与解法选择

  • 判断字符串是否回文，但只比较「字母或数字」字符，并忽略大小写，非字母数字一律跳过。
  • 两种思路：① 先过滤+转小写生成干净串，再双指针判断（O(n) 时间、O(n) 额外空间）；② 直接在原串上用双指针跳过非字母数字（O(n) 时间、O(1) 空间）。本题选后者更省空间。

② 关键设计决策

  • l=0、r=s.length()-1。
  • while (l<r)：
  • !isLetterOrDigit(s.charAt(l)) → l++（左端非法字符，跳过）；
  • 否则 !isLetterOrDigit(s.charAt(r)) → r--（右端非法字符，跳过）；
  • 否则 toLowerCase(s[l]) 与 toLowerCase(s[r]) 比较：不同 → return false；相同 → l++、r--。
  • 关键点：判「字母数字」要用 Character.isLetterOrDigit（含数字）。Character.isAlphabetic 只认字母，会把数字当非法字符误跳过——这被用例 "0P" 暴露过。

③ 边界与细节

  • 全部为非字母数字（如 ".,!"）：l 持续右移越过 r，循环退出，返回 true（等价于过滤后空串回文）。
  • 单字符（字母或数字）：l==r 不进入循环，返回 true。
  • 大小写：统一 toLowerCase 后再比较。
  • 数字参与比较：用 isLetterOrDigit 保留数字。
  • 上限 2*10^5：线性扫描，快。

④ 复杂度与最优性

  • 每个字符至多被左右指针各扫一次，O(n)；空间 O(1)。
  • 最优性：每个字符至少要读一次以决定忽略或比较，下界 Ω(n)；本题达到下界且无需额外数组，空间也为最优。

**⑤ 具体 case 推演：s="0P"

  • l=0 指向 '0'、r=1 指向 'P'。
  • isLetterOrDigit('0')=true、isLetterOrDigit('P')=true，二者都合法，进入比较。
  • toLowerCase('0')='0' vs toLowerCase('P')='p' → 不同 → return false。正确（核心 "0p" 非回文）。
  • 对比错误写法：若用 isAlphabetic，'0' 会被当非法跳过 → 只剩 'P' vs 'P' → 误返回 true。

**⑥ 正例推演：s="ab@ba"

  • l=0('a')、r=4('a') 都对，比较相等 → l=1、r=3。
  • l=1('b')、r=3('b') 相等 → l=2、r=2。
  • l=2('@') 非法 → l++ → l=3，l<r 不成立，退出。
  • 返回 true（过滤后 "abba" 回文），符号被正确跳过。
