我的解法

思路：双指针原地交换。unCheck 指向待处理的 0 位置，check 向前扫描： 当 unCheck 处是 0 时，把 check 位置的元素交换过来并让 check 前进； 当 unCheck 处已非 0，则 unCheck 前进并把 check 拉回对齐。 一趟完成，非零元素相对顺序保持不变。

时间 O(n) 空间 O(1) 原地操作 保持非零相对顺序

src/LC0283_MoveZeroes.java提交区
public void moveZeroes(int[] nums) {
    int unCheck = 0, check = 0;
    while (check < nums.length) {
        if (nums[unCheck] == 0) {
            int temp = nums[check];
            nums[check] = nums[unCheck];
            nums[unCheck] = temp;
            check++;
        } else {
            unCheck++;
            check = unCheck;
        }
    }
}

关键点：0 位置指针与扫描指针配合，每步只做一次交换或一次指针移动，不额外开数组。

分类提醒 · 双指针与滑动窗口

看到有序数组/子数组/子串问题，先想排序后双指针或滑动窗口，把 O(n²) 降到 O(n)。
