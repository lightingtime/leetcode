283. 移动零 (Move Zeroes)

> https://leetcode.cn/problems/move-zeroes/

难度：Easy ｜ 分类：双指针与滑动窗口

标签：数组、双指针

题目描述

给定一个数组 nums，编写一个函数将所有 0 移动到数组的末尾，同时保持非零元素的相对顺序。

请注意 ，必须在不复制数组的情况下原地对数组进行操作。

示例 1:

输入: nums = [0,1,0,3,12]

输出: [1,3,12,0,0]

示例 2:

输入: nums = [0]

输出: [0]

提示:

时间 O(n)空间 O(1)内存 ≈ 46.0 MB用例 —

LC0283_MoveZeroes.java · 双指针提交区
    public void moveZeroes(int[] nums) {
        int lt = 0, i = 0;
        while (i < nums.length) {
           if (nums[i] != 0) {
               swap(nums, lt, i);
               lt++;
               i++;
           } else {
               i++;
           }
        }
    }

    private void swap(int[] nums, int i, int j) {
        int temp = nums[i];
        nums[i] = nums[j];
        nums[j] = temp;
    }

public void moveZeroes(int[] nums) {
        int unCheck = 0, check = 0;
        while (check < nums.length) {
            if (nums[unCheck] == 0) {
                int temp = nums[check];
                nums[check] = nums[unCheck];
                nums[unCheck] = temp;
                check++;
            } else {
                unCheck++;
                check = unCheck;
            }
        }
    }

思路拆解

问题本质：原地把 0 全部移到末尾，同时保持非零元素相对顺序。双指针一趟完成，不额外开数组。

关键设计：一个扫描位负责找 0，一个交换位指向当前要放置非零元素的位置：扫描位是 0 时与交换位交换并把交换位前移；扫描位非 0 时扫描位继续前移。这样每个非零元素都会被逐步换到前面、0 被推到后面，相对顺序不变。

边界：全 0（交换后无变化但必须保证不越界）；全非 0（扫描位一路前移）；0 在开头或结尾；交换用临时变量避免覆盖。

复杂度：O(n) 时间、O(1) 空间，原地最优。
