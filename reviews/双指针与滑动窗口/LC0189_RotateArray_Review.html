189. 轮转数组 (Rotate Array)

> https://leetcode.cn/problems/rotate-array/

难度：Medium ｜ 分类：双指针与滑动窗口

标签：数组、数学、双指针

题目描述

给定一个整数数组 nums，将数组中的元素向右轮转 k 个位置，其中 k 是非负数。

示例 1:

输入: nums = [1,2,3,4,5,6,7], k = 3

输出: [5,6,7,1,2,3,4]

解释:

向右轮转 1 步: [7,1,2,3,4,5,6]

向右轮转 2 步: [6,7,1,2,3,4,5]

向右轮转 3 步: [5,6,7,1,2,3,4]

示例 2:

输入：nums = [-1,-100,3,99], k = 2

输出：[3,99,-1,-100]

解释:

向右轮转 1 步: [99,-1,-100,3]

向右轮转 2 步: [3,99,-1,-100]

提示：

0 5

public void rotate(int[] nums, int k) {
        int n = nums.length;
        k %= n;
        swap(nums, 0, n - 1);
        swap(nums, 0, k - 1);
        swap(nums, k, n - 1);
    }

    private void swap(int[] nums, int l, int r) {
        while (l < r) {
            int temp = nums[r];
            nums[r] = nums[l];
            nums[l] = temp;
            l++;
            r--;
        }
    }

思路拆解

① 问题本质与解法选择

  • 把数组原地右移 k 位，进阶要求 O(1) 空间。
  • 三种方法：① 额外数组复制（O(n) 空间）；② 环状替换（O(1) 空间，但下标取模循环易写错）；③ 三段反转（O(1) 空间、最直观）。本题选三段反转。
  • 关键前提：k 可能大于 n，必须先 k %= n 消掉整圈。

② 关键设计决策

  • k %= n 消除整圈。
  • swap(nums, 0, n-1)：整体反转。
  • swap(nums, 0, k-1)：反转前 k 段。
  • swap(nums, k, n-1)：反转剩余段。
  • 原理：整体反转后，原数组末尾 k 个元素到了最前面（但顺序颠倒）；把这两段各自再反转一次，就能把内部顺序恢复，得到「右移 k 位」的结果。

③ 边界与细节

  • k=0 或 k=n：取模后 k=0，第一次整体反转 + 第三次整体反转互相抵消，数组不变。
  • n=1：k%=n=0，swap(0,0) 因 l<r 不满足而不执行，安全。
  • 负数元素：反转只交换位置，与数值正负无关。
  • n=10^5、k=10^5：取模后最多 n-1，交换次数有界。

④ 复杂度与最优性

  • 三段各做约 n/2 次交换，总时间 O(n)；空间 O(1)。
  • 最优性：每个元素至少要移动一次，时间下界 Ω(n)，达到；O(1) 空间正是题目进阶要求，同样达到。

⑤ 具体 case 推演：nums=[1,2,3,4,5,6,7]、k=3

  • k %= 7 → 3。
  • 整体反转：[7,6,5,4,3,2,1]；
  • 反转前 3 段 [7,6,5] → [5,6,7]，数组变 [5,6,7,4,3,2,1]；
  • 反转后 4 段 [4,3,2,1] → [1,2,3,4]，结果 [5,6,7,1,2,3,4] ✓。
  • 为什么对：整体反转让末尾 k 个元素 [5,6,7] 到开头但顺序颠倒，两段各自再反转一次恢复正序。
