public boolean isPalindrome(ListNode head) {
        if (head == null) {
            return true;
        }

        ListNode firstEnd = fastSlow(head);
        ListNode secondStart = reverseLinkList(firstEnd.next);

        ListNode p1 = head;
        ListNode p2 = secondStart;
        while (p2 != null) {
            if (p1.val != p2.val) {
                return false;
            }
            p1 = p1.next;
            p2 = p2.next;
        }
        return true;
    }

	private ListNode reverseLinkList(ListNode head) {
        ListNode pre = null;
        ListNode cur = head;
        while (cur != null) {
            ListNode next = cur.next;
            cur.next = pre;
            pre = cur;
            cur = next;
        }
		return pre;
	}

    private ListNode fastSlow(ListNode head) {
        ListNode fast = head;
        ListNode slow = head;
        while (fast.next != null && fast.next.next != null) {
            fast = fast.next.next;
            slow = slow.next;
        }
        return slow;
    }

回文链表：快慢指针找中点 + 原地反转后半段，O(n)/O(1)，重写后再次 Accepted（93/93）达成进阶最优

思路拆解

问题本质：判断链表是否回文。复制到数组比较是 O(n) 空间；O(1) 空间做法：快慢指针找中点 → 反转后半段 → 逐节点对称比较。

关键设计：fastSlow 让 fast 走 2 步、slow 走 1 步，结束时 slow 停在（前半段的）末尾 firstEnd；反转 firstEnd.next 得到后半段头 secondStart；然后 p1 从头、p2 从 secondStart 同步比较。比较循环以 p2!=null 为条件，奇数长度时中间节点自然被跳过。

边界：空链表返回 true；偶数长度 slow 恰在中点前、奇数长度 slow 在前半段末尾，反转后半段长度 ≤ 前半段，比较不会越界；比较完不要求恢复链表结构。

复杂度：O(n) 时间、O(1) 额外空间（反转用迭代），最优。

套路沉淀

快慢指针找中点后的奇偶判定

快慢指针走完后：fast 为 null → 偶数长度（slow 正好是后半段开头，无需跳过）；fast 停在最后一个节点 → 奇数长度（slow 停在中点，需先跳过中点再比较后半段）

递归不算 O(1) 空间：调用栈计入空间复杂度

递归的调用栈深度随输入规模增长（如链表递归深度 n），辅助空间 O(递归深度)，不算 O(1)；O(1) 空间要求用迭代 + 常数个变量（如快慢指针 + 原地反转）。另注意递归深度大时有栈溢出风险。

反转链表三步的顺序与自环陷阱

标准三步：先保存后继 next=cur.next，再用旧 pre 改指向 cur.next=pre，最后才前移 pre=cur、cur=next。若先 pre=cur 再 cur.next=pre，pre 与 cur 同节点，cur.next 指向自己形成自环，链表被破坏。
