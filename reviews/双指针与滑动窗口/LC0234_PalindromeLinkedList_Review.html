我的解法

思路：快慢指针找中点 + 原地反转后半段。快指针每次走 2 步、慢指针走 1 步， 走完后 slow 停在链表中点附近；把 slow.next 起点的后半段原地反转， 再从头节点与反转后的后半段逐节点比较。全程只用了常数个指针变量，空间 O(1)。

时间 O(n) 空间 O(1)（原地反转） 快慢指针防越界 反转三步保序

public boolean isPalindrome(ListNode head) {
    if (head == null) {
        return true;
    }
    ListNode firstEnd = fastSlow(head);
    ListNode secondStart = reverseLinkList(firstEnd.next);
    ListNode p1 = head;
    ListNode p2 = secondStart;
    while (p2 != null) {
        if (p1.val != p2.val) {
            return false;
        }
        p1 = p1.next;
        p2 = p2.next;
    }
    return true;
}

private ListNode reverseLinkList(ListNode head) {
    ListNode pre = null;
    ListNode cur = head;
    while (cur != null) {
        ListNode next = cur.next;
        cur.next = pre;
        pre = cur;
        cur = next;
    }
    return pre;
}

private ListNode fastSlow(ListNode head) {
    ListNode fast = head;
    ListNode slow = head;
    while (fast.next != null && fast.next.next != null) {
        fast = fast.next.next;
        slow = slow.next;
    }
    return slow;
}

关键点：快慢指针找中点；反转后半段时「先保存后继 → 用旧 pre 改指向 → 再前移」，顺序不能换。

算法判定：快慢指针 + 原地反转，已是最优

  • 时间复杂度 O(n)：找中点、反转后半段、逐节点比较各一遍，每个节点至多访问常数次，O(n) 是下限。

分类提醒 · 双指针与滑动窗口

看到有序数组/子数组/子串问题，先想排序后双指针或滑动窗口，把 O(n²) 降到 O(n)。

链表双指针的经典组合是「快慢指针 + 反转」：快慢指针负责找中点/判环，反转负责「从尾部往回看」。 这题先用栈拿到正确解，再改用原地反转把空间从 O(n) 降到 O(1)，符合「先正确、再优化」的节奏。

套路沉淀

本轮涉及 4 条已入库套路（lc-analyze/references/patterns.md）：

链表指针判空取舍：p != null 允许指针走出链表；p.next != null 停在链内/提前看一步。快慢指针跳 2 步用 fast.next != null && fast.next.next != null 防越界。
快慢指针找中点后的奇偶判定：fast 为 null → 偶数，slow 即后半段开头；fast 停在最后节点 → 奇数，先跳过中点再比较。
递归不算 O(1) 空间：调用栈深度随输入规模增长，辅助空间 O(递归深度)；O(1) 只能靠迭代 + 常数变量。
反转链表三步的顺序与自环陷阱：先保存后继 → 用旧 pre 改指向 → 再前移；先 pre=cur 会形成 cur.next=cur 自环。
