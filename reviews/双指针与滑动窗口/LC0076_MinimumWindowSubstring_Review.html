我的解法

思路：滑动窗口 + 计数。need[c] 记录窗口还缺字符 c 多少个（>0 缺、==0 恰好、<0 多余）， count 记录总共还缺几个字符。右指针扩展、先判后减；count 归零后先收缩多余字符、 记录最短窗口，再还回关键字符让窗口整体前进。128 长度数组直接按字符下标存，大小写都安全。

时间 O(m+n) 空间 O(1)（固定 128 数组） 满足进阶要求

src/LC0076_MinimumWindowSubstring.java提交区
public String minWindow(String s, String t) {
    int[] need = new int[128];
    for (Character c : t.toCharArray()) {
        need[c]++;
    }
    int count = t.length();
    int start = 0;
    int i = 0;
    int min = Integer.MAX_VALUE;
    String ans = "";
    while (i < s.length()) {
        char c = s.charAt(i);
        if (need[c] > 0) {
            count--;
        }
        need[c]--;
        if (count == 0) {
            while (need[s.charAt(start)] < 0) {
                need[s.charAt(start)]++;
                start++;
            }
            if (i - start + 1 < min) {
                min = i - start + 1;
                ans = s.substring(start, i + 1);
            }
            need[s.charAt(start)]++;
            count++;
            start++;
        }
        i++;
    }
    return ans;
}

边界语义：need[c] == 0 表示恰好满足、不可删；need[c] < 0 表示多余、收缩时可删； 记录答案后必须把左边界关键字符还回（need++、count++、start++），窗口才能继续前进。

解题过程

01 · 独立实现：need 计数 + count 未满足数思路正确 ▸

滑动窗口 + 计数 + 覆盖判定的整体框架一次搭对：右扩、收缩、记录、前进四步齐全。

02 · 踩坑①：`c - 'a'` 大写越界AIOOBE ▸

c - 'a' 只对小写字母得到非负下标，大写 'A' 得到 -32，数组 int[52] 直接越界： 所有含大写字母的用例报 ArrayIndexOutOfBoundsException: Index -32。 改为 128 长度数组、直接 need[c] 按 ASCII 下标存取。

03 · 踩坑②：收缩误删恰好满足的字符状态失真 ▸

收缩条件写成 need <= 0，把恰好满足（need == 0）的必需字符也还回去， 却不移动 start、不更新 count——覆盖状态与 count 脱节，count 后续可能变负数，窗口全部失真。 收缩应只用 need < 0 删多余。

04 · 踩坑③：先减后判，count 永不更新全空答案 ▸

扩展写成 need[c]-- 后再判断 need[c] > 0：首次遇到的必需字符减完已是 0， count 一次都没减，恒等于 t 的长度，count == 0 永不成立，答案一直是空串。 判断必须用减之前的值（先判后减，或减后判断 >= 0）。

05 · 修正三处，本地全过已解决 ▸

128 数组直接下标 + 扩展先判后减 + 收缩只删多余 + 记录后三连前进。 3 示例 + 5 边界（s 比 t 短、窗口在开头/结尾、t 含重复字符、大小写敏感）全部通过。

分类提醒 · 双指针与滑动窗口

看到有序数组/子数组/子串问题，先想排序后双指针或滑动窗口，把 O(n²) 降到 O(n)。

覆盖类子串问题：右扩到「够」、左缩到「最小」、记录后整体前进，计数状态（count）与窗口内容必须严格同步。

套路沉淀

错误习惯复盘

  • 字符到数组下标映射错误：c - 'a' 只对小写有效，大写负下标越界。
  • 窗口收缩状态失真：need <= 0 误删恰好满足的字符，count 与覆盖脱节。
  • 先减后判导致计数失效：need[c]-- 后再判 > 0，count 永不更新。
