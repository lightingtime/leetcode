76. 最小覆盖子串 (Minimum Window Substring)

> https://leetcode.cn/problems/minimum-window-substring/

难度：Hard ｜ 分类：双指针与滑动窗口

标签：哈希表、字符串、滑动窗口

题目描述

给定两个字符串 s 和 t，长度分别是 m 和 n，返回 s 中的 最短窗口 子串，使得该子串包含 t 中的每一个字符（包括重复字符）。如果没有这样的子串，返回空字符串 ""。

测试用例保证答案唯一。

示例 1：

输入：s = "ADOBECODEBANC", t = "ABC"

输出："BANC"

解释：最小覆盖子串 "BANC" 包含来自字符串 t 的 'A'、'B' 和 'C'。

示例 2：

输入：s = "a", t = "a"

输出："a"

解释：整个字符串 s 是最小覆盖子串。

示例 3:

输入: s = "a", t = "aa"

输出: ""

解释: t 中两个字符 'a' 均应包含在 s 的子串中，

因此没有符合条件的子字符串，返回空字符串。

提示：

m == s.length

n == t.length

1 5

s 和 t 由英文字母组成

写法 1 · 滑动窗口+计数

LC0076_MinimumWindowSubstring.java · 滑动窗口+计数提交区
public String minWindow(String s, String t) {
        int[] need = new int[128];
        for (char c : t.toCharArray()) {
            need[c]++;
        }
        int count = t.length();
        int start = 0;
        int min = Integer.MAX_VALUE;
        String ans = "";
        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            // 先判后减：只有仍缺少的必需字符才减少 count
            if (need[c] > 0) {
                count--;
            }
            need[c]--;
            if (count == 0) {
                // 收缩左边界，跳过所有多余字符，直到窗口刚好覆盖 t
                while (need[s.charAt(start)] < 0) {
                    need[s.charAt(start)]++;
                    start++;
                }
                if (i - start + 1 < min) {
                    min = i - start + 1;
                    ans = s.substring(start, i + 1);
                }
                // 记录后移出最左必需字符，让窗口重新变为未覆盖
                need[s.charAt(start)]++;
                count++;
                start++;
            }

        }
        return ans;
    }

LC0076_MinimumWindowSubstring.java · 滑动窗口+计数 · 上一版提交区
public String minWindow(String s, String t) {
        int[] need = new int[128];
        for (Character c : t.toCharArray()) {
            need[c]++;
        }
        int count = t.length();
        int start = 0;
        int i = 0;
        int min = Integer.MAX_VALUE;
        String ans = "";
        while (i < s.length()) {
            char c = s.charAt(i);
            // 该字符进入窗口前若仍缺，则未满足数 -1（先判后减）
            if (need[c] > 0) {
                count--;
            }
            need[c]--;
            if (count == 0) {
                // 先收缩：删掉左边多余字符，记录以 i 结尾的最短覆盖窗口
                while (need[s.charAt(start)] < 0) {
                    need[s.charAt(start)]++;
                    start++;
                }
                // 记录答案
                if (i - start + 1 < min) {
                    min = i - start + 1;
                    ans = s.substring(start, i + 1);
                }
                // 还回左边界关键字符（need+1、count+1、start+1），覆盖被破坏，窗口继续右扩
                need[s.charAt(start)]++;
                count++;
                start++;
            }
            i++;
        }
        return ans;
    }

思路拆解

问题本质：找包含 t 全部字符（含重复次数）的最短连续子串。滑动窗口 + 计数：右端扩张到覆盖，再左端收缩找最短，如此往复。

关键设计：need[128] 记录各字符还差多少（t 初始化），count 记录还缺几个字符。右扩：need[c]>0 说明该字符是当前缺的，count--，然后 need[c]--（多余字符变负）；count==0 时收缩：while need[s[start]]<0 说明左端字符是多余的，need++ 并 start++，直到左端是关键字符，此时记录最短窗口；再把左端关键字符还回去（need++、count++、start++），窗口重新变成缺状态，继续右扩找下一个覆盖。

边界：s 中没有完整覆盖时返回空串；t 中重复字符（如 AABC 需要两个 A）靠 count 与 need 的正负区分「缺」与「多余」；字符范围按 128 覆盖 ASCII。

复杂度：O(n) 时间（每个字符进出窗口各一次）、O(1) 空间（固定数组），最优。

套路沉淀

滑动窗口覆盖子串：收缩只删多余、记录后整体前移

覆盖判定用计数 + 未满足数 count；收缩时只能删多余字符（need<0），need==0 表示恰好满足不能再删；记录答案后要把左边界关键字符还回（need[left]++、count++、left++）让窗口整体前进，否则覆盖状态与 count 脱节

维护最优值：比较与更新必须成对落在同一分支

凡是「取最小/取最优」的写法，先检查更新语句是否存在：只比较不更新会让条件恒真、答案被后续更差的解覆盖（LC0076 的 min 声明成 MAX_VALUE 后从未赋值，ans 每遇到一个合法窗口就覆盖一次，最后返回最后一个窗口而不是最短窗口）。排查手法：对着「声明最优变量的那一行」问三句——谁给它赋初值、哪一行更新它、这个更新语句和比较语句是否在同一分支里。

覆盖类滑动窗口：count 由判断决定，need 的减法必须无条件执行

覆盖型滑动窗口的扩展阶段有两行，门控位置极易写反：判断决定 count，减法无条件执行。正确顺序是先 if (need[c] > 0) count--; 再 need[c]--;（无条件）。写反成 if (need[c] > 0) need[c]--; count--; 会同时崩掉两处：① count 与 t 无关，扫满 t.length() 个字符就误判覆盖完成（XYZABC/ABC 记成 XYZ，最小复现 xa/a 得 x）；② need 永不为负，「多余字符」的负标记消失，收缩循环 while (need[start] < 0) 收不动左端（左端是无关字符时 need==0 也停），窗口收不到最短（xxabxxa/ab 给 xx 而非 ab）。口诀：判断管计数器，减法管状态；need 的负值就是「可以删」的凭证。
