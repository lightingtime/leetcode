438. 找到字符串中所有字母异位词 (Find All Anagrams in a String)

> https://leetcode.cn/problems/find-all-anagrams-in-a-string/

难度：Medium ｜ 分类：双指针与滑动窗口

标签：哈希表、字符串、滑动窗口

题目描述

给定两个字符串 s 和 p，找到 s 中所有 p 的 异位词 的子串，返回这些子串的起始索引。不考虑答案输出的顺序。

示例 1:

输入: s = "cbaebabacd", p = "abc"

输出: [0,6]

解释:

起始索引等于 0 的子串是 "cba", 它是 "abc" 的异位词。

起始索引等于 6 的子串是 "bac", 它是 "abc" 的异位词。

示例 2:

输入: s = "abab", p = "ab"

输出: [0,1,2]

解释:

起始索引等于 0 的子串是 "ab", 它是 "ab" 的异位词。

起始索引等于 1 的子串是 "ba", 它是 "ab" 的异位词。

起始索引等于 2 的子串是 "ab", 它是 "ab" 的异位词。

提示:

1 4

s 和 p 仅包含小写字母

我的解法

写法 1 · 定长滑动窗口+双计数数组

时间 O(n)空间 O(1)内存 ≈ 44.8 MB用例 65/65

src/双指针与滑动窗口/LC0438_FindAllAnagramsInAString.java提交区
public List<Integer> findAnagrams(String s, String p) {
        List<Integer> ans = new ArrayList<>();
        if (s.isEmpty() || s.length() < p.length()) {
            return ans;
        }
        int[] array = new int[26];
        int[] target = new int[26];
        for (char c : p.toCharArray()) {
            target[c - 'a']++;
        }
        int l = 0, r = 0;
        while (r < s.length()) {
            if (r - l < p.length()) {
                array[s.charAt(r) - 'a']++;
                r++;
            } else {
                array[s.charAt(l) - 'a']--;
                array[s.charAt(r) - 'a']++;
                r++;
                l++;
            }
            if (Arrays.equals(array, target)) {
                ans.add(l);
            }
        }
        return ans;
    }

    private boolean arrayEquals(int[] array, int[] target) {
        for (int i = 0; i < target.length; i++) {
            if (target[i] != array[i]) {
                return false;
            }
        }
        return true;
    }

思路拆解

1. 问题本质与解法选择理由

问题是找 s 中所有与 p 构成字母异位词的连续子串：长度必须等于 |p|，且每个字符出现次数与 p 完全一致。核心难点是「怎么快速判断一个子串与 p 频次相同」。

  • 朴素做法：枚举每个长度为 m=|p| 的子串重新统计频次再比较，O(n*m)，n、m 最大 3e4 会超时。
  • 选滑动窗口：窗口长度固定为 m，向右滑一格只需「移出左字符、移入右字符」两次 O(1) 更新，配合 26 个字母的计数数组比较，整体降到 O(n)。这是「定长子串 + 频次比较」类题的经典最优框架。

2. 关键设计决策

  • 两个 int[26]：target 存 p 的频次（只初始化一次），array 存当前窗口 [l, r) 的频次。
  • 半开区间窗口：r - l < m 时只扩右边界；窗口满后每次先移出 s[l] 再移入 s[r]，然后 l++、r++，窗口长度恒为 m。
  • 每步滑动后调用 arrayEquals 逐项比较 26 项，相等即记录左端点 l。
  • 剪枝：s.length() < p.length() 直接返回空列表。

3. 边界与细节

  • 窗口首次填满发生在某次「只扩右」的迭代内，那次迭代就会比较并可能记录（如 "abab"/"ab" 第 2 次迭代窗口 [0,2) 满时记录索引 0），不会漏掉第一个窗口。
  • 全重复串 "aaaa"/"aa"：array 恒为 {a:2}，每次滑动都匹配，得 [0,1,2]。
  • 单字符、p 比 s 长、无匹配等边界测试均已覆盖。

4. 具体 case 推演（s="cbaebabacd", p="abc", m=3，target={a:1,b:1,c:1}）

  • 迭代1：扩右，array={c:1}，不等
  • 迭代2：扩右，array={b:1,c:1}，不等
  • 迭代3：扩右，array={a:1,b:1,c:1}，相等 → ans=[0]
  • 迭代4：移出 c、移入 e，array={a:1,b:1,e:1}，不等
  • 迭代5：移出 b、移入 b，array={a:1,b:1,e:1}，不等
  • 迭代6：移出 a、移入 a，array={a:1,b:1,e:1}，不等
  • 迭代7：移出 e、移入 b，array={a:1,b:2}，不等
  • 迭代8：移出 b、移入 a，array={a:2,b:1}，不等
  • 迭代9：移出 a、移入 c，array={a:1,b:1,c:1}，相等 → ans=[0,6]
  • 最终 [0,6] 与示例一致。

5. 复杂度与最优性

  • 时间 O(26n)=O(n)：每个字符进、出窗口各一次；每步滑动后比较 26 项是常数。下限论证：s 中每个可能起点都要被检查，共 n-m+1 个长度为 m 的窗口，任何解法都必须扫过这些窗口，因此 O(n) 是时间下界，本解已达。
  • 空间 O(1)：两个固定 26 长度数组。判断字母异位词至少要保存 26 种字符的频次，O(1) 已是空间下界。

6. 可继续优化（仅提示，非必须）

每次滑动后都做 O(26) 全量比较，可改用「差异计数 diff」：只根据移出、移入的两个字符更新差异数，相等判断降为 O(1)。复杂度仍是 O(n)/O(1)，只是常数更小。
