15. 三数之和 (3Sum)

> https://leetcode.cn/problems/3sum/

难度：Medium ｜ 分类：双指针与滑动窗口

标签：数组、双指针、排序

题目描述

给你一个整数数组 nums ，判断是否存在三元组 [nums[i], nums[j], nums[k]] 满足 i != j、i != k 且 j != k ，同时还满足 nums[i] + nums[j] + nums[k] == 0 。请你返回所有和为 0 且不重复的三元组。

注意：答案中不可以包含重复的三元组。

示例 1：

输入：nums = [-1,0,1,2,-1,-4]

输出：[[-1,-1,2],[-1,0,1]]

解释：

nums[0] + nums[1] + nums[2] = (-1) + 0 + 1 = 0 。

nums[1] + nums[2] + nums[4] = 0 + 1 + (-1) = 0 。

nums[0] + nums[3] + nums[4] = (-1) + 2 + (-1) = 0 。

不同的三元组是 [-1,0,1] 和 [-1,-1,2] 。

注意，输出的顺序和三元组的顺序并不重要。

示例 2：

输入：nums = [0,1,1]

输出：[]

解释：唯一可能的三元组和不为 0 。

示例 3：

输入：nums = [0,0,0]

输出：[[0,0,0]]

解释：唯一可能的三元组和为 0 。

① 与上一轮对比

  • 同一思路：排序 + 固定 i 后双指针夹逼（k 从左、j 从右向中间收），O(n²) 时间 / O(1) 额外空间。写法上有两处结构差异：
  • 外层：一刷是 while (i < j) { … i++; }，本轮改成 for (int i = 0; i < nums.length - 2; i++)——循环上界直接把「后面至少还要留两个位置」写进条件，比在体内手动 i++ 更难写漏；
  • 内层 j：一刷在外层末尾手动 j = nums.length - 1 重置，本轮把 int j = nums.length - 1 放进 i 循环内部，作用域更小、不会跨轮串味。
  • 相同之处：i 与 k 都做「保留第一次出现、跳过后续重复」，k 的去重带 k > i + 1 保护，相等时只 k++。

② 这次为什么能一次写对

  • 一刷记下的两个坑一个都没复现：
  • 去重方向：if (i > 0 && nums[i] == nums[i - 1]) continue; 与 if (k > i + 1 && nums[k] == nums[k - 1]) 都是跳「后续重复」，-1,-1,2 这种需要两个相同值的组合不会被误杀（示例1 覆盖）；
  • 移动依据引用跑飞变量：内层 j 每轮重新初始化，判断用的是当轮的 nums[i] + nums[j] + nums[k]，不会像一刷那样在 k == j 之后还拿同一个元素凑两次。
  • j 不做显式去重也不会重复输出：i、k 固定后第三个数被和为 0 唯一确定，边界6/7/8 的超多重复用例都通过。

③ 掌握度判定

  • 一次提交即 Accepted（316/316），全程无提示、无探讨 → 较强。

④ 下一步提醒

  • 去重三件套可以固化成模板背下来：i 去重（与前一个比）、k 去重（且必须带 k > i + 1）、j 无需去重。

    public List<List<Integer>> threeSum(int[] nums) {
        List<List<Integer>> ans = new ArrayList<>();
        Arrays.sort(nums);
        for (int i = 0; i < nums.length - 2; i++) {
            if (i > 0 && nums[i] == nums[i - 1]) {
                continue;
            }
            int j = nums.length - 1;
            int k = i + 1;
            while (k < j) {
                if (k > i + 1 && nums[k] == nums[k - 1]) {
                    k++;
                    continue;
                }
                if (nums[i] + nums[j] + nums[k] == 0) {
                    List<Integer> list = new ArrayList<>();
                    list.add(nums[i]);
                    list.add(nums[k]);
                    list.add(nums[j]);
                    ans.add(list);
                    k++;
                } else if (nums[i] + nums[j] + nums[k] < 0) {
                    k++;
                } else {
                    j--;
                }
            }
        }
        return ans;
    }

思路拆解

问题本质：找出所有和为 0 且不重复的三元组。排序 + 双指针把三数问题降维为「固定一个数 + 剩余区间内两数之和」。

关键设计：排序后外层 i 固定第一个数，内层 k（左）、j（右）双指针：三数和 <0 左移 k，>0 右移 j，==0 记录三元组并把 k 前移。去重是关键：i 与 k 都跳过和前一位置相同的值（k 还要满足 k>i+1 防止与 i 混淆），j 不用显式去重——与 i、k 去重配合即可保证三元组不重复不遗漏。

边界：长度不足 3 无解；全零数组只输出一个 [0,0,0]；每轮外层结束 j 必须重新置为末尾；负数与正数混合时双指针方向判断要仔细。

复杂度：O(n²) 时间（排序 O(n log n) + 双指针 O(n²)）、O(1) 额外空间（忽略排序栈），最优。

套路沉淀

排序后去重：保留重复值第一次出现，跳过后续重复

去重方向是跳过已经用过的值（nums[i]==nums[i-1] 时跳过 i），而不是跳过重复组里靠前的第一个（nums[i]==nums[i+1]）；三数之和允许两个位置取相同值，所以第一次出现必须保留；双指针夹逼找到答案后还需跳过两端重复值

去重方向写反：跳过重复值中靠前的第一个，而不是跳过后续重复，导致需要两个相同值的合法组合（如 -1,-1,2）被丢弃，或同一组合重复输出（累计 1 次）

复习提醒

★ `nums[i] + nums[j] + nums[k]` 在本次代码里算了两遍（判等 + 判小于），提成局部变量 `sum` 更快也更易读——顺带避免你上次踩过的「移动依据引用跑飞变量」。
★ 构造三元组可以一行 `Arrays.asList(nums[i], nums[k], nums[j])`（`java.util.Arrays` 已经 import）。
★ 相等分支只 `k++`、不 `j--` 是正确的（下一轮 k 去重会把重复值跳掉），但与常见写法不同，建议补一行注释说明。
