295. 数据流的中位数 (Find Median from Data Stream)

> https://leetcode.cn/problems/find-median-from-data-stream/

难度：Hard ｜ 分类：双指针与滑动窗口

标签：设计、双指针、数据流、排序、堆（优先队列）

题目描述

中位数是有序整数列表中的中间值。如果列表的大小是偶数，则没有中间值，中位数是两个中间值的平均值。

例如 arr = [2,3,4] 的中位数是 3 。

例如 arr = [2,3] 的中位数是 (2 + 3) / 2 = 2.5 。

实现 MedianFinder 类:

MedianFinder() 初始化 MedianFinder 对象。

void addNum(int num) 将数据流中的整数 num 添加到数据结构中。

double findMedian() 返回到目前为止所有元素的中位数。与实际答案相差 10-5 以内的答案将被接受。

示例 1：

输入

["MedianFinder", "addNum", "addNum", "findMedian", "addNum", "findMedian"]

[[], [1], [2], [], [3], []]

输出

[null, null, null, 1.5, null, 2.0]

解释

MedianFinder medianFinder = new MedianFinder();

medianFinder.addNum(1); // arr = [1]

medianFinder.addNum(2); // arr = [1, 2]

medianFinder.findMedian(); // 返回 1.5 ((1 + 2) / 2)

medianFinder.addNum(3); // arr[1, 2, 3]

medianFinder.findMedian(); // return 2.0

在调用 findMedian 之前，数据结构中至少有一个元素

我的解法

写法 1 · 对顶堆（大顶堆存较小一半 + 小顶堆存较大一半）

时间 O(log n)空间 O(n)内存 ≈ 107.4 MB用例 22/22

src/双指针与滑动窗口/LC0295_FindMedianFromDataStream.java提交区
static class MedianFinder {
        PriorityQueue<Integer> firstHeap;
        PriorityQueue<Integer> secondHeap;
        public MedianFinder() {
            secondHeap = new PriorityQueue<>();
            firstHeap = new PriorityQueue<>(Comparator.reverseOrder());
        }
        public void addNum(int num) {
            if (firstHeap.isEmpty() || num < firstHeap.peek()) {
                firstHeap.offer(num);
                if (secondHeap.size() + 1 < firstHeap.size()) {
                    secondHeap.offer(firstHeap.poll());
                }
            } else {
                secondHeap.offer(num);
                if (firstHeap.size() < secondHeap.size()) {
                    firstHeap.offer(secondHeap.poll());
                }
            }
        }
        public double findMedian() {
            if (firstHeap.size() > secondHeap.size()) {
                return firstHeap.peek();
            }
            return (firstHeap.peek() + secondHeap.peek()) / 2.0;
        }
    }

思路拆解

① 问题本质与解法选择

  • 数据流不断追加整数，随时要回答「当前已插入元素的中位数」：本质是动态集合的中间值查询，需要一种既能快速插入、又能快速取中间值的结构。
  • 朴素思路：每次插入后重排，findMedian 取中间，插入 O(n log n)；或维护有序数组二分插入，插入 O(n)（数组搬移）。对 5*10^4 次调用都太慢。
  • 关键观察：中位数只依赖「较小的一半最大值」和「较大的一半最小值」。把数据分成两半，各用一个堆维护极值：大顶堆（max-heap）存较小的一半，小顶堆（min-heap）存较大的一半，中位数就是两个堆顶的组合——这就是「对顶堆」思路，插入 O(log n)、查询 O(1)。
  • 为什么选堆而不是平衡树/有序数组：堆只关心「顶」，插入 O(log n) 且无需搬移，完美匹配「只取中间两个数」的需求。

② 关键设计决策

  • 两个堆：firstHeap（大顶堆，存较小一半）、secondHeap（小顶堆，存较大一半）。
  • 平衡不变式：secondHeap.size() <= firstHeap.size() <= secondHeap.size() + 1，且 firstHeap 内所有元素 <= secondHeap 内所有元素。
  • addNum(num)：
  1. 若 firstHeap 为空或 num < firstHeap.peek() → 进 firstHeap（比当前中位数小，进下半区）；否则进 secondHeap。
  2. 平衡修正：若 secondHeap.size() + 1 < firstHeap.size() → 把 firstHeap 顶搬给 secondHeap；若 firstHeap.size() < secondHeap.size() → 把 secondHeap 顶搬给 firstHeap。
  • findMedian()：firstHeap.size() > secondHeap.size()（总数奇数）→ 返回 firstHeap.peek()；否则（偶数）→ 返回 (firstHeap.peek() + secondHeap.peek()) / 2.0。
  • 相等元素走 else 进 secondHeap：相等时进哪边都不破坏极值关系，平衡规则会把数量拉回合法区间，中位数不变。

③ 边界与细节

  • 单元素：firstHeap 1 个、secondHeap 空，奇数分支返回堆顶。
  • 偶数个：两堆各一半，取两堆顶平均（必须 / 2.0，/ 2 会整除丢精度）。
  • 全相同：相等元素交替进堆，两堆大小始终合法，中位数恒为该值。
  • 数值范围 -10^5 ~ 10^5：堆比较无溢出问题，中位数最大 (100000+100000)/2 = 100000，int 内。
  • 大流量递增插入：元素不断进 secondHeap，平衡规则每次把 secondHeap 顶搬回 firstHeap，两堆交替增长。

④ 复杂度与最优性

  • addNum：单次堆插入 + 至多一次堆顶搬移，O(log n)；findMedian：只看堆顶，O(1)。空间 O(n) 存全部元素。
  • 最优性论证（下限）：若 addNum 能 O(1)，则插入 n 个数后 findMedian 若也 O(1)，就得到 O(n) 的比较排序，与比较排序下界 Ω(n log n) 矛盾 → 插入至少 Ω(log n)。本解法达到 O(log n)；且任何解法都必须存全部数据（Ω(n) 空间），时间空间均为最优。

⑥ 具体 case 推演：逆序 30,20,10（中位应为 20）

  • addNum(30)：左空进左 → firstHeap=[30]，secondHeap=[]。
  • addNum(20)：20<30 进左 → firstHeap=[20,30]，secondHeap=[]；平衡 0+1<2 成立 → 左顶 30 搬右 → firstHeap=[20]，secondHeap=[30]。
  • addNum(10)：10<20 进左 → firstHeap=[10,20]，secondHeap=[30]；平衡 1+1<2 否、2<1 否 → 保持。
  • findMedian()：左 2 > 右 1 → 返回 firstHeap 顶 20。正确（排序后 [10,20,30] 中位 20）。
  • 中途校验：[20,30] 时 findMedian = (20+30)/2 = 25.0，与排序结果一致。

套路沉淀

对顶堆维护动态中位数

数据流动态取中位数：大顶堆存较小一半、小顶堆存较大一半，保持 second<=first<=second+1；addNum 先按与 firstHeap 顶比较决定进哪堆，再单向搬堆顶平衡，findMedian 看两堆大小取堆顶或平均。O(log n) 插入 / O(1) 查询。
