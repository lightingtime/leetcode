876. 链表的中间结点 (Middle of the Linked List)

> https://leetcode.cn/problems/middle-of-the-linked-list/

难度：Easy ｜ 分类：双指针与滑动窗口

标签：链表、双指针

题目描述

给你单链表的头结点 head ，请你找出并返回链表的中间结点。

如果有两个中间结点，则返回第二个中间结点。

示例 1：

输入：head = [1,2,3,4,5]

输出：[3,4,5]

解释：链表只有一个中间结点，值为 3 。

示例 2：

输入：head = [1,2,3,4,5,6]

输出：[4,5,6]

解释：该链表有两个中间结点，值分别为 3 和 4 ，返回第二个结点。

提示：

链表的结点数范围是 [1, 100]

LC0876_MiddleOfTheLinkedList.java · 快慢指针提交区
public ListNode middleNode(ListNode head) {
        ListNode dummy = new ListNode(-1, head);
        ListNode slow = dummy, fast = dummy;
        while (fast != null) {
            fast = fast.next;
            slow = slow.next;
            if (fast != null) {
                fast = fast.next;
            }
        }
        return slow;
    }

思路拆解

问题本质与解法选择理由

单链表不能从尾部反向定位中点。让两个指针从同一起点按 1:2 的速度同步前进，快指针到达末尾时慢指针走过约一半，因此只需一次遍历。

关键设计决策

  • 两个指针从 dummy 节点开始。每轮慢指针前进一步，快指针先前进一步；快指针非空时再前进一步。
  • 循环条件检查快指针是否为空。偶数长度时快指针第一步到 null，慢指针落在两个中点中的后一个；奇数长度时快指针第二步到 null，慢指针落在唯一中点。

具体推演

输入 1 → 2 → 3 → 4 → 5，初始两个指针都在 dummy：

  1. 第 1 轮后 slow 在 1，fast 在 2。
  2. 第 2 轮后 slow 在 2，fast 在 4。
  3. 第 3 轮后 slow 在 3，fast 为 null；返回从节点 3 开始的后缀。

输入 1 → 2 → 3 → 4 → 5 → 6 时，第 4 轮快指针到 null，慢指针同步到节点 4，符合返回第二个中点的要求。单节点用例确认最短合法输入；100 个节点的用例确认最大约束长度。

边界与复杂度

结点数约束为 1 到 100，因此无需处理空链表。每轮快指针最多走两步、慢指针走一步，整体时间 O(n)，额外空间 O(1)。定位中点前需要走到链表末尾附近，时间下界为 O(n)，所以时间复杂度最优。
