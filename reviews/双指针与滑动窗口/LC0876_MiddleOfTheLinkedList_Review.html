876. 链表的中间结点 (Middle of the Linked List)

> https://leetcode.cn/problems/middle-of-the-linked-list/

难度：Easy ｜ 分类：双指针与滑动窗口

标签：链表、双指针

题目描述

给你单链表的头结点 head ，请你找出并返回链表的中间结点。

如果有两个中间结点，则返回第二个中间结点。

示例 1：

输入：head = [1,2,3,4,5]

输出：[3,4,5]

解释：链表只有一个中间结点，值为 3 。

示例 2：

输入：head = [1,2,3,4,5,6]

输出：[4,5,6]

解释：该链表有两个中间结点，值分别为 3 和 4 ，返回第二个结点。

提示：

链表的结点数范围是 [1, 100]

LC0876_MiddleOfTheLinkedList.java · 快慢指针提交区
public ListNode middleNode(ListNode head) {
        ListNode dummy = new ListNode(-1, head);
        ListNode slow = dummy, fast = dummy;
        while (fast != null) {
            fast = fast.next;
            slow = slow.next;
            if (fast != null) {
                fast = fast.next;
            }
        }
        return slow;
    }

思路拆解

问题本质与解法选择理由

单链表无法从尾部反向定位中点；让两个指针按 1:2 的步幅同步前进，可在快指针到尾时用慢指针定位中点，单次遍历完成。

关键设计决策

  • 与 从 dummy 节点开始。每轮先让 前进一步，再让 前进一步；若 仍非空，再前进第二步。
  • 循环以 为条件。奇数长度时快指针第二步后到 null；偶数长度时快指针第一步就可能到 null，此时慢指针正好落在两个中点中的后一个。

具体推演

输入链表 ，dummy 记作 ：

  1. 初始 。
  2. 第 1 轮后 、。
  3. 第 2 轮后 、。
  4. 第 3 轮后 、，停止并返回从节点 3 开始的后缀。

输入 时，快指针第 4 轮前进一步到 null，慢指针同步到节点 4，因此返回第二个中点。单节点时首轮后慢指针仍为该节点；最大长度 100 的用例验证遍历能到达中部。

边界与复杂度

题目节点数范围为 ，无需处理空链表。每个节点被快指针至多经过一次、慢指针至多经过一次，时间 O(n)，额外空间 O(1)。定位中点需要确认链表后半段的边界，因此 O(n) 时间已达渐进下限。

套路沉淀

快慢指针按比例推进定位链表中点

两个指针从同一起点出发，按 1:2 的速度推进。快指针到达末尾时，慢指针走过约一半；循环终止条件与每轮快指针的空值检查共同决定偶数长度时返回第二个中点。
