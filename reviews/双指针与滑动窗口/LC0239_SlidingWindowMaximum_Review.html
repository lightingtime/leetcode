public int[] maxSlidingWindow(int[] nums, int k) {
        LinkedList<Integer> queue = new LinkedList<>();
        int[] ans = new int[nums.length - k + 1];
        int start = 0;
        int i = 0;
        while (i < nums.length) {
            // 入队前弹掉队尾比新元素小的：新元素更大且更晚，被弹者永远当不了最大值
            while (!queue.isEmpty() && nums[queue.peekLast()] < nums[i]) {
                queue.pollLast();
            }
            queue.offerLast(i);
            // 弹出过期队头：窗口是闭区间 [i-k+1, i]，队头下标 <= i-k 说明已滑出窗口
            while (!queue.isEmpty() && queue.peekFirst() <= i - k) {
                queue.pollFirst();
            }
            if (i - start + 1 == k) {
                ans[start] = nums[queue.peekFirst()];
                start++;
            }
            i++;
        }
        return ans;
    }

单调队列存下标：入队前弹队尾小值、读答案前弹过期队头（<= i-k），O(n)/O(k) 一次 Accepted（53/53）

思路拆解

问题本质：每个固定长度 k 窗口的最大值。暴力 O(nk)；单调队列把每个窗口取最大值摊到 O(1)。

关键设计：双端队列存下标，从队头到队尾保持数值单调递减。新元素入队前弹掉队尾所有比它小的——那些元素比新元素更小且更早过期，永远不可能再成为最大值；入队后弹掉队头中已滑出窗口的下标（≤ i-k）；此时队头就是当前窗口最大值。窗口形成后（i≥k-1）每次记录。

边界：k=1 时每个窗口即单元素；k=n 只有一个窗口；形成窗口前的阶段只入队不记录；过期判断基于闭区间 [i-k+1, i]。

复杂度：O(n) 时间（每个下标至多入队出队一次）、O(k) 空间，最优。
