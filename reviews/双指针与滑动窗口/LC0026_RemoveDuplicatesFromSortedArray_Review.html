题目描述

给你一个 非严格递增排列 的数组 nums ，请你 原地 删除重复出现的元素，使每个元素 只出现一次 ，返回删除后数组的新长度。元素的 相对顺序 应该保持 一致 。然后返回 nums 中唯一元素的个数。

考虑 nums 的唯一元素的数量为 k。去重后，返回唯一元素的数量 k。

nums 的前 k 个元素应包含 排序后 的唯一数字。下标 k - 1 之后的剩余元素可以忽略。

src/双指针与滑动窗口/LC0026_RemoveDuplicatesFromSortedArray.java提交区
public int removeDuplicates(int[] nums) {
        int l = 0;
        for (int num : nums) {
            if (l == 0 || nums[l - 1] != num) nums[l++] = num;
        }
        return l;
    }

思路拆解

问题本质与解法选择

数组是非递减排列，所以重复元素一定相邻。要「原地去重」并返回新长度，无法真正删除元素，只能用指针标记有效区：nums[0..l-1] 为去重后的唯一值，返回 l。

为什么用双指针：暴力做法是每个元素都与之前所有元素比较，O(n²)；而数组有序 + 只保留唯一值，一趟扫描即可 O(n) 解决。

关键设计决策

变量语义
l已确认放入有效区的唯一值个数，也等于下一个写入下标
  • nums[l-1]：有效区最后一个唯一值；当 l==0 时尚未放任何元素，需特判以免取 nums[-1] 越界。
  • 遍历到 num 时：
  • 若 l==0（第一个元素）或 num != nums[l-1]（发现新唯一值）：nums[l++] = num，先写入有效区末尾再让 l 加 1；
  • 若相等：说明是重复值，直接跳过，l 不动。
  • 返回 l：因为 l 恰好就是有效区长度（唯一值个数）。

具体 case 推演（nums = [1,1,2]）

步num条件判断动作l
初始---0
1nums[0] = 1l==0 成立nums[0]=11
2nums[1] = 1nums[l-1]=nums[0]=1，与 1 相等跳过1
3nums[2] = 2nums[0]=1，与 2 不等nums[1]=22

结果 nums 前 2 位为 [1,2]，返回 2。

边界与细节

  • 单元素：l==0 成立，写入后 l=1，返回 1；
  • 全相同：只写入第一个，l 恒为 1；
  • 无重复：每个元素都写入有效区，l 递增到数组长度；
  • 值域 [-100,100]、长度上限 3e4：本地大输入测试已覆盖；
  • 增强 for 中往前覆盖 nums[l] 安全：l 始终不大于当前扫描位置，不会覆盖尚未遍历到的元素。

复杂度分析

  • 时间 O(n)：一趟扫描；
  • 空间 O(1)：仅一个计数指针 l。

为什么是最优：每个元素至少要读一次才能判断是否重复，时间 O(n) 是下限；只需一个计数指针，空间 O(1) 也是下限。

套路沉淀

双指针原地去重/覆盖

有序数组原地去重：慢指针同时充当写入位与计数，遇到与有效区最后一个不同的值就覆盖到有效区末尾；扫描用增强 for 或快指针。可迁移到移动零、移除元素、合并数组等原地重排题。
