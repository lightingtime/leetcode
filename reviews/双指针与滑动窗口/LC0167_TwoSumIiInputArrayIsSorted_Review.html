167. 两数之和 II - 输入有序数组 (Two Sum II - Input Array Is Sorted)

> https://leetcode.cn/problems/two-sum-ii-input-array-is-sorted/

难度：Medium ｜ 分类：双指针与滑动窗口

标签：数组、双指针、二分查找

题目描述

给你一个下标从 1 开始的整数数组 numbers ，该数组已按 非递减顺序排列。

请你从数组中找出满足相加之和等于目标数 target 的 两个 数。令这两个数分别是 numbers[index1] 和 numbers[index2] ，其中 1 1 2 。

以长度为 2 的整数数组 [index1, index2] 的形式返回这两个整数的下标 index1 和 index2。

你可以假设每个输入 只对应唯一的答案 ，而且你 不可以 重复使用相同的元素。

你所设计的解决方案必须只使用常数级的额外空间。

示例 1：

输入：numbers = [2,7,11,15], target = 9

输出：[1,2]

解释：2 与 7 之和等于目标数 9 。因此 index1 = 1, index2 = 2 。返回 [1, 2] 。

示例 2：

输入：numbers = [2,3,4], target = 6

输出：[1,3]

解释：2 与 4 之和等于目标数 6 。因此 index1 = 1, index2 = 3 。返回 [1, 3] 。

示例 3：

输入：numbers = [-1,0], target = -1

输出：[1,2]

解释：-1 与 0 之和等于目标数 -1 。因此 index1 = 1, index2 = 2 。返回 [1, 2] 。

我的解法

写法 1 · 有序数组相向双指针（左右指针单调移动）

时间 O(n)空间 O(1)内存 ≈ 46.3 MB用例 26/26

LC0167_TwoSumIiInputArrayIsSorted.java · 有序数组相向双指针（左右指针单调移动）提交区
public int[] twoSum(int[] numbers, int target) {
        int i = 0;
        int j = numbers.length - 1;
        while (i < j) {
            if (i > 0 && numbers[i] == numbers[i - 1]) {
                i++;
                continue;
            }
                int sum  = numbers[i] + numbers[j];
                if (sum == target) {
                    return new int[]{i + 1, j + 1};
                } else if (sum < target) {
                    i++;
                } else {
                    j--;
                }
        }
        return new int[] {-1, -1};
    }

写法 2 · 固定左端点，重置右端点向左扫描

时间 O(n²)空间 O(1)内存 ≈ 46.7 MB用例 26/26

LC0167_TwoSumIiInputArrayIsSorted.java · 固定左端点，重置右端点向左扫描提交区
public int[] twoSum(int[] numbers, int target) {
    for (int i = 0; i < numbers.length - 1; i++) {
        if (i > 0 && numbers[i] == numbers[i - 1]) {
            continue;
        }
        int j = numbers.length - 1;
        while (i < j) {
            int sum  = numbers[i] + numbers[j];
            if (sum == target) {
                return new int[]{i + 1, j + 1};
            } else if (sum < target) {
                break;
            } else {
                j--;
            }
        }
    }
    return new int[] {-1, -1};
}

思路拆解

问题本质与解法选择

数组非递减，每次比较两端之和，可以排除一个端点参与的全部剩余组合。保留两个单调移动的指针，避免旧写法每轮重置右端点而重复扫描。

关键设计决策

变量语义
i剩余候选区间的左端下标，初值 0
j剩余候选区间的右端下标，初值 n-1
sumnumbers[i]+numbers[j]

保持 i<j，禁止同一下标使用两次。sum 小于目标时，固定 i 与任何更小的右端值相加仍小于目标，因此排除 i；sum 大于目标时，固定 j 与任何更大的左端值相加仍大于目标，因此排除 j。

具体推演：numbers=[1,2,4]、target=6。

  1. i=0、j=2，sum=1+4=5；1 与剩余更小值 2 相加也不足 6，排除左端 1。
  2. i=1、j=2，sum=2+4=6，返回从 1 开始的下标 [2,3]。

边界与细节

[0,0]、target=0：i=0、j=1，两个不同位置可有相同数值，返回 [1,2]。[1,2,3]、target=4：先比较 1+3，返回 [1,3]，不能把中间的 2 使用两次。题目保证唯一答案，长度至少 2，无须处理空数组或无解输入。值和目标均在 [-1000,1000]，两数之和不会溢出 int。跳过重复左端值仅在此前左端被排除后发生，不影响正确性，但该分支并非必需，可删除以精简代码。

复杂度与最优性

i 只增加、j 只减少，每轮至少移动一个指针，二者相遇前总移动次数至多 n-1；时间 O(n)、额外空间 O(1)。一般有序数组比较模型下，最坏情况需要排除线性数量的候选位置，线性扫描达到该模型的最优量级。当前题值域固定为 2001 种整数；旧写法跳过重复左端值后，更精确的上界是 O(n*min(n,2001))，通常按可变值域分析记作 O(n²)。新版无需依赖值域限制来保证线性。

套路沉淀

有序数组相向双指针：按和的大小排除端点

非递减数组中，和偏小则排除左端点，和偏大则排除右端点；每次排除需证明该端点与区间内其他元素均不可能组成目标。左右指针只向内移动，不要每轮重置右端。
