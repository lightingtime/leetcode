我的解法

思路：快慢指针

时间 O(n)空间 O(1)

快慢指针提交区
public boolean hasCycle(ListNode head) {
        if (head == null || head.next == null) {
            return false;
        }
        ListNode fast = head;
        ListNode slow = head;
        while (fast.next != null && fast.next.next != null) {
            fast = fast.next.next;
            slow = slow.next;
            if (fast == slow) {
                return true;
            }
        }
        return false;
    }

思路拆解

问题本质：判断链表是否有环。哈希表记录访问过的节点可行但 O(n) 空间；快慢指针让 fast 每次走 2 步、slow 走 1 步，只花 O(1) 空间。

关键设计：若有环，fast 相对 slow 每轮靠近 1 步，必在环内相遇；无环则 fast 先走到 null。判断相遇要在移动之后立刻比较（代码在 fast 前进后检查 fast==slow）。

边界：空链表或单节点直接返回 false；循环条件 fast.next!=null && fast.next.next!=null 保证 fast 前进前已有两个后继，不会空指针；自环节点也能正确检测（fast 先入环，slow 随后在环内被追上）。

复杂度：O(n) 时间（无环走 n/2 步；有环不超过 n+环长）、O(1) 空间，最优。
