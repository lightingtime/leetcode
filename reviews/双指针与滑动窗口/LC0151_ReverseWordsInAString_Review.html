151. 反转字符串中的单词 (Reverse Words in a String)

> https://leetcode.cn/problems/reverse-words-in-a-string/

难度：Medium ｜ 分类：双指针与滑动窗口

标签：双指针、字符串

题目描述

给你一个字符串 s ，请你反转字符串中 单词 的顺序。

单词 是由非空格字符组成的字符串。s 中使用至少一个空格将字符串中的 单词 分隔开。

返回 单词 顺序颠倒且 单词 之间用单个空格连接的结果字符串。

注意：输入字符串 s中可能会存在前导空格、尾随空格或者单词间的多个空格。返回的结果字符串中，单词间应当仅用单个空格分隔，且不包含任何额外的空格。

示例 1：

输入：s = "the sky is blue"

输出："blue is sky the"

示例 2：

输入：s = " hello world "

输出："world hello"

解释：反转后的字符串中不能存在前导空格和尾随空格。

示例 3：

输入：s = "a good example"

输出："example good a"

解释：如果两个单词间有多余的空格，反转后的字符串需要将单词间的空格减少到仅有一个。

我的解法

写法 1 · 整体反转后逐单词恢复字符顺序

时间 O(n)空间 O(n)内存 ≈ 42.3 MB用例 62/62

LC0151_ReverseWordsInAString.java · 整体反转后逐单词恢复字符顺序提交区
public String reverseWords(String s) {
        s = new StringBuilder(s.trim()).reverse().toString();
        int n = s.length();
        StringBuilder ans = new StringBuilder();
        int index = 0;
        while (index < n) {
            if (s.charAt(index) == ' ') {
                ans.append(' ');
            }
            while (index < n && s.charAt(index) == ' ') {
                index++;
            }
            int start = index;
            while (index < n && Character.isLetterOrDigit(s.charAt(index))) {
                index++;
            }
            for (int i = index - 1; i >= start; i--) {
                ans.append(s.charAt(i));
            }
        }
        return ans.toString();
    }

思路拆解

问题本质与解法选择

目标是改变单词的排列顺序，保留每个单词内部的字符顺序，并规范空格。整体反转会同时翻转单词顺序和单词内部字符；再把每个单词反转一次，就只改变单词顺序。

关键设计决策

先 trim 去掉首尾空格，再整体反转。用 index 从左向右扫描，ans 保存已恢复字符顺序的单词。

变量语义
n去除首尾空格并反转后字符串的长度
index下一待处理字符的位置，始终单调增加
start当前单词在反转字符串中的起点
[start,index)当前单词的字符区间
ans已处理单词按目标顺序连接的结果

每次遇到空格段时先向 ans 追加一个空格，再跳过整个连续空格段；遇到单词时确定半开区间 [start,index)，然后逆序追加该区间的字符。首尾空格已去掉，因此不会产生输出首尾空格。

具体推演输入 " ab cd "：

  1. trim 后为 "ab cd"，整体反转得到 "dc ba"，index=0、ans=""。
  2. 扫描 dc 得到 start=0、index=2；逆序追加得到 ans="cd"。
  3. index=2 遇到空格，追加一次空格，跳过连续空格后 index=5、ans="cd "。
  4. 扫描 ba 得到 start=5、index=7，逆序追加得到 ans="cd ab"；index=n，循环结束。

边界与细节

单字符 "a" 整体及局部反转后仍为 "a"。输入 "a b" 反转为 "b a"，先输出 b，再处理一个空格，最后输出 a。连续空格只追加一次，重复单词不去重。大小写与数字作为单词字符保留。输入只含英文字母、数字及普通空格，Character.isLetterOrDigit 在该范围内能识别全部非空格字符；也可用不等于普通空格的判断精简。题目保证至少一个单词，不需补充空字符串或全空格输入。长度上限为 10000，已覆盖单个长单词、长前导空格及大量短单词。

复杂度与最优性

trim、整体反转、扫描、逐单词逆序追加和构造结果均为线性；index 总共前进 n 次，所有单词的内部循环合计不超过 n 次，因此时间 O(n)。中间反转字符串与 StringBuilder 占用 O(n) 空间。最坏情况需读取并输出线性数量的字符，O(n) 时间达到下限；Java String 不可变，计入返回字符串及构造结果的空间时 O(n) 为最优量级。题目针对可变字符串提出的原地进阶不直接适用于本方法签名。

套路沉淀

整体反转与局部反转的组合

反转单词顺序时，先整体反转改变单词次序，再逐单词反转恢复内部字符顺序。例：ab cd → dc ba → cd ab。用单调扫描划分单词区间，连续分隔符统一输出一次；所有局部扫描总长度为 O(n)。
