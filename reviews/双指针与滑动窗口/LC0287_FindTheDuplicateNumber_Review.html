public int findDuplicate(int[] nums) {
        int fast = 0, slow = 0;
        do {
            fast = nums[nums[fast]];
            slow = nums[slow];
        } while ( fast != slow);
        slow = 0;
        while (fast != slow) {
            fast = nums[fast];
            slow = nums[slow];
        }
        return fast;
    }

数组当下标链，Floyd 判圈找环入口：相遇阶段 do-while 先移动后比较、入口阶段同速，O(n)/O(1) 一次 Accepted（59/59）

思路拆解

问题本质：n+1 个数取值 1..n，必有一个重复。限制不能改数组、O(1) 空间，于是把数组看作链：下标 i → nums[i]。重复值意味着有多个前驱指向同一节点 → 链成环，环入口就是重复值。

关键设计：快慢指针在值上跳：slow=nums[slow]、fast=nums[nums[fast]]，相遇后把 slow 重置为 0，再同速走，再次相遇处即环入口（重复值）。原理：入环前的路径长度与相遇点到入口的距离存在固定的映射关系。

边界：下标 0 一定不在环内（值域 1..n 没有任何元素指向 0），所以从 0 出发必能进入环；重复可能多个，返回任一即可；题目保证至少一个重复。

复杂度：O(n) 时间、O(1) 空间，且不修改数组，完全满足题目全部约束，最优。
