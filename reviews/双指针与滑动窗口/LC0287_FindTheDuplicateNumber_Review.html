我的解法

思路：Floyd 判圈。把数组当跳跳链：站在下标 i 下一步跳 nums[i]， 因为值都在 [1, n] 且有两个位置指向同一个值，这条链必然成环，重复数 = 环的入口。 第一阶段快慢指针相遇（slow 一步、fast 两步）；第二阶段 slow 回起点、两者同速，再次相遇即答案。

时间 O(n) 空间 O(1) 不修改数组

src/LC0287_FindTheDuplicateNumber.java提交区
public int findDuplicate(int[] nums) {
    int fast = 0, slow = 0;
    do {
        fast = nums[nums[fast]];
        slow = nums[slow];
    } while (fast != slow);
    slow = 0;
    while (fast != slow) {
        fast = nums[fast];
        slow = nums[slow];
    }
    return fast;
}

边界语义：第一阶段两指针从同一起点出发，必须先移动再比较（do-while）， 否则 fast != slow 初始为 false、循环体一次不执行；第二阶段 slow 回起点、fast 留在相遇点， 两者每次走一步，相遇点即环入口（重复数）。

解题过程

01 · 独立实现：数组当下标链 + Floyd 判圈思路正确 ▸

按「跳跳链」视角：i → nums[i]，重复数有两个位置指向它，所以它是环入口。 Floyd 两阶段：先相遇，再找回起点，思路一次到位。

02 · 踩坑：相遇检测先判后走全错 ▸

第一阶段用了 while (fast != slow)，而两指针都从 0 出发， 初始即相等，循环体一次不执行，fast/slow 从未移动，最后直接返回初始值 0——全部用例输出 0。

03 · 修正：do-while 先移动后比较，本地全过已解决 ▸

换成 do { ... } while (fast != slow)，保证至少先移动一次再比较。 3 示例 + 4 边界（最小规模、重复最小值、重复值在中间、n=10⁵ 大数组）全部通过。

分类提醒 · 双指针与滑动窗口

看到有序数组/子数组/子串问题，先想排序后双指针或滑动窗口，把 O(n²) 降到 O(n)。

当题目限制「不修改数组 + O(1) 空间」时，快慢指针判圈（Floyd）是绕开哈希表/排序的经典手段。
