题目描述

给你链表的头结点 head ，请将其按 升序 排列并返回 排序后的链表 。

示例 1：

输入：head = [4,2,1,3]

输出：[1,2,3,4]

示例 2：

输入：head = [-1,5,3,4,0]

输出：[-1,0,3,4,5]

示例 3：

输入：head = []

输出：[]

写法 1 · 自顶向下归并排序

public ListNode sortList(ListNode head) {
        return sortList(head, null);
    }

	private ListNode sortList(ListNode head, ListNode tail) {
        if (head == null) {
            return head;
        }
        if (head.next == tail) {
            head.next = null;
            return head;
        }
        ListNode fast = head, slow = head;
        while (fast != tail) {
            slow = slow.next;
            fast = fast.next;
            if (fast != tail) {
                fast = fast.next;
            }
        }
        ListNode mid = slow;
        ListNode p1 = sortList(head, mid);
        ListNode p2 = sortList(mid, tail);
        return merge(p1, p2);
	}

	private ListNode merge(ListNode p1, ListNode p2) {
        ListNode head = new ListNode(0);
        ListNode dummy = head;
        while (p1 != null && p2 != null) {
            if (p1.val <= p2.val) {
                dummy.next = p1;
                p1 = p1.next;
            } else {
                dummy.next = p2;
                p2 = p2.next;
            }
            dummy = dummy.next;
        }
        if (p1 == null) {
            dummy.next = p2;
        } else if (p2 == null) {
            dummy.next = p1;
        }
		return head.next;
	}

自顶向下归并排序：快慢指针找中点 + 递归合并，时间 O(n log n) 最优；递归栈 O(log n) 未达进阶常数空间，可改迭代自底向上归并

思路拆解

问题本质：O(n log n) 排序链表。数组排序需要随机访问，归并排序只需要 next 指针，天然适配链表。

关键设计：递归分治——快慢指针找中点（fast 走 2 步、slow 走 1 步，fast 到区间尾时 slow 是中点）；区间写成 [head, tail)，当 head.next==tail 时断开为单节点；两半分别排序后 merge 有序合并（dummy 节点串接，每次取较小者，一方走完直接续接剩余链）。

边界：空链表和单节点直接返回；奇数/偶数长度切分都正确；[head,tail) 左闭右开让切分不重不漏；merge 时一方为 null 要处理。

复杂度：时间 O(n log n)；空间 O(log n) 递归栈（若题目严格要求 O(1) 空间，可改自底向上归并，但递归版已通过判题）。
