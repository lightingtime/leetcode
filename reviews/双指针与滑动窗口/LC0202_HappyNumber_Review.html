public boolean isHappy(int n) {
        int slow = n;
        int fast = getNext(n);
        while (fast != 1 && slow != fast) {
            slow = getNext(slow);
            fast = getNext(getNext(fast));
        }
        return fast == 1;
    }

    private int getNext(int n) {
        int sum = 0;
        while (n != 0) {
            int x = n % 10;
            sum += (x * x);
            n /= 10;
        }
        return sum;
    }

思路拆解

① 问题本质与解法选择

  • 快乐数 = 反复把数替换成各位数字平方和，若能到 1 则快乐；否则必然陷入无限循环（数学上已知非快乐数都会进入 4→16→37→58→89→145→42→20→4 这个环）。
  • 判循环两种思路：① HashSet 记录出现过的数，重复即非快乐（空间 O(logn)）；② Floyd 快慢指针：slow 走一步、fast 走两步，相遇即说明入环（空间 O(1)）。本题选 Floyd，空间更省。

② 关键设计决策

  • getNext(n)：对每个十进制位取平方并累加；n 最大 2^31-1 只有 10 位，平方和上限 10*81=810，中间值很小、不会溢出。
  • slow=n、fast=getNext(n)；while (fast!=1 && slow!=fast) 内 slow 走一步、fast 走两步；退出后 return fast==1。
  • 相遇有两种：fast 先到 1（快乐），或 slow==fast 落在环上（不快乐）。

③ 边界与细节

  • n=1：fast=getNext(1)=1，循环不进入，直接返回 true。
  • 直接到 1（如 10）：fast 首步即 1，返回 true。
  • 不快乐数（如 2）：slow/fast 最终在 4 的环上相遇，slow==fast 退出，返回 false。
  • 上限 2^31-1：getNext 处理 10 位数字，平方和 ≤ 810，无溢出风险。

④ 复杂度与最优性

  • 每次 getNext 为 O(logn)（位数）；快乐过程存在有限上界（平方和 ≤ 810 后进入小状态空间），循环次数有常数界；总时间 O(logn) 量级。
  • 空间 O(1)（只用两个指针）。
  • 最优性：HashSet 法需要 O(logn) 空间；Floyd 把空间降到常数，是判环问题的空间最优解。

⑤ 具体 case 推演：n=19（快乐）

  • 序列：19 → 82 → 68 → 100 → 1。
  • slow=19、fast=82：
  • iter1：slow=82，fast=getNext(getNext(82))=getNext(68)=100；
  • iter2：slow=68，fast=getNext(getNext(100))=getNext(1)=1；
  • fast==1 退出 → return true。

⑥ 具体 case 推演：n=2（不快乐）

  • slow=2、fast=4：
  • iter1：slow=4，fast=getNext(getNext(4))=getNext(16)=37；
  • iter2：slow=16，fast=getNext(getNext(37))=getNext(58)=89；
  • iter3：slow=37，fast=getNext(getNext(89))=getNext(145)=42；
  • iter4：slow=58，fast=getNext(getNext(42))=getNext(20)=4；
  • 继续后 slow/fast 在环 4→16→37→58→89→145→42→20→4 上相遇 → return false。
