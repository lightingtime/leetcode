LC0019_RemoveNthNodeFromEndOfList.java · 哨兵+快慢指针提交区
    public ListNode removeNthFromEnd(ListNode head, int n) {
        ListNode fast = head, slow = head, dummy = new ListNode(0, head);
        ListNode p = dummy;
        for (int i = 0; i < n; i++) {
            fast = fast.next;
        }
        while (fast != null) {
            p = p.next;
            slow = slow.next;
            fast = fast.next;
        }
        p.next = p.next.next;
        return dummy.next;
    }

public ListNode removeNthFromEnd(ListNode head, int n) {
        ListNode dummy = new ListNode(0, head);
        ListNode fast = head;
        int i = 0;
        while (i < n) {
            fast = fast.next;
            i++;
        }
        ListNode slow = head;
        ListNode pre = dummy;
        while (fast != null) {
            fast = fast.next;
            slow = slow.next;
            pre = pre.next;
        }
        pre.next = slow.next;
        return dummy.next;
    }

思路拆解

问题本质：单链表无法回溯，倒数第 n 个节点需要一趟定位。快慢指针：fast 先走 n 步，然后 fast 与 slow 同步走，fast 到末尾时 slow 正好指向待删节点。

关键设计：dummy 哑节点挂在 head 前，解决删除头节点的特判；pre 记录 slow 的前驱，删除时 pre.next=slow.next 跳过 slow。fast 先走 n 步保持与 slow 的固定间距，保证一趟内完成。

边界：n 等于链表长度时删除的是头节点，dummy.next 依然正确返回新头；链表只有 1 个节点；题目保证 n 在 1..len 内合法。

复杂度：O(n) 时间、O(1) 空间；比先求长度再走两趟更简洁，最优。
