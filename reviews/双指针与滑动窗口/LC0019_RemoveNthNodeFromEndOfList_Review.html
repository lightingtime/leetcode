我的解法

思路：哨兵节点 + 快慢指针拉开 N 步，一趟扫描。快指针先走 N 步， 随后慢指针（记录待删节点）和 pre（记录前驱）与快指针同步前进； 快指针走到 null 时，慢指针正好指向倒数第 N 个节点，直接 pre.next = slow.next 删除。 dummy 哨兵让「删头结点」与普通删除共用同一段逻辑，无需特判。

时间 O(n) 空间 O(1) 一趟扫描（满足进阶要求）

src/LC0019_RemoveNthNodeFromEndOfList.java提交区
public ListNode removeNthFromEnd(ListNode head, int n) {
    ListNode dummy = new ListNode(0, head);
    ListNode fast = head;
    int i = 0;
    while (i < n) {
        fast = fast.next;
        i++;
    }
    ListNode slow = head;
    ListNode pre = dummy;
    while (fast != null) {
        fast = fast.next;
        slow = slow.next;
        pre = pre.next;
    }
    pre.next = slow.next;
    return dummy.next;
}

当 n 等于链表长度时，快指针先走 N 步后即为 null，内层循环不执行， pre 停在 dummy、slow 停在 head，dummy.next = head.next 直接完成删头，无需单独分支。

思路已最优 · 代码写法可再精简两处

① 去掉 slow 指针：循环中始终满足 pre.next == slow（pre 就是待删节点的前驱）， 删除时直接用 pre.next = pre.next.next，不需要 slow 变量。

② 计数器换成 for 循环：快指针先走 N 步的 while + i++ 可以写成 for (int i = 0; i < n; i++) fast = fast.next;，少一个外部变量。

ListNode pre = dummy;
while (fast != null) {
    fast = fast.next;
    pre = pre.next;
}
pre.next = pre.next.next;

分类提醒 · 双指针与滑动窗口

看到有序数组/子数组/子串问题，先想排序后双指针或滑动窗口，把 O(n²) 降到 O(n)。

链表版的「双指针」是快慢指针：一个指针先出发或走得更快，拉开固定距离后同步前进，常用于找中点、判环、删倒数第 N 个。
