392. 判断子序列 (Is Subsequence)

> https://leetcode.cn/problems/is-subsequence/

难度：Easy ｜ 分类：动态规划

标签：双指针、字符串、动态规划

题目描述

给定字符串 s 和 t ，判断 s 是否为 t 的子序列。

字符串的一个子序列是原始字符串删除一些（也可以不删除）字符而不改变剩余字符相对位置形成的新字符串。（例如，"ace"是"abcde"的一个子序列，而"aec"不是）。

LC0392_IsSubsequence.java · 双指针线性扫描提交区
public boolean isSubsequence(String s, String t) {
        int i = 0, j = 0;
        while (j < t.length()) {
            if (i == s.length()) {
                return true;
            }
            if (s.charAt(i) == t.charAt(j)) {
                i++;
                j++;
            } else {
                j++;
            }
        }
        return i == s.length();
    }

思路拆解

问题本质与解法选择理由：判断 s 能否按原顺序从 t 中选出字符。扫描 t 时，匹配到 s 当前需要的字符就立即确认它；越早匹配，留给 s 后续字符的 t 后缀越长，因此贪心选择不会减少后续匹配机会。

关键设计决策：i 指向 s 中下一个待匹配字符，j 指向 t 当前字符。相等时 i、j 都前进；不相等时只让 j 前进。扫描结束后，i 到达 s.length() 才表示全部匹配。对于 s="ab"、t="acb"，状态依次为 (i,j)=(0,0)，匹配 a 后为 (1,1)，跳过 c 后为 (1,2)，匹配 b 后为 (2,3)，结果为 true。

边界与细节：s 为空时 i 已等于 s.length()，应返回 true；t 为空而 s 非空时循环不执行，返回 false。重复字符必须保持先后顺序，例如 s="aab"、t="aaab" 可以匹配；s="aba"、t="baa" 不能匹配。

复杂度与下限：最坏情况下需要检查 t 的每个字符，时间 O(|t|)，额外空间 O(1)。判定任意输入都可能依赖 t 的末尾字符，因此线性扫描符合输入规模下的紧确上界。
