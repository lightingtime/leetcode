344. 反转字符串 (Reverse String)

> https://leetcode.cn/problems/reverse-string/

难度：Easy ｜ 分类：双指针与滑动窗口

标签：双指针、字符串

题目描述

编写一个函数，其作用是将输入的字符串反转过来。输入字符串以字符数组 s 的形式给出。

不要给另外的数组分配额外的空间，你必须原地修改输入数组、使用 O(1) 的额外空间解决这一问题。

示例 1：

输入：s = ["h","e","l","l","o"]

输出：["o","l","l","e","h"]

示例 2：

输入：s = ["H","a","n","n","a","h"]

输出：["h","a","n","n","a","H"]

提示：

1 5

s[i] 都是 ASCII 码表中的可打印字符

public void reverseString(char[] s) {
        for (int i = 0; i < s.length /2; i++) {
            char c = s[s.length - i - 1];
            s[s.length - i - 1] = s[i];
            s[i] = c;
        }
    }

思路拆解

① 问题本质与解法选择

  • 反转字符数组，题目硬性要求原地、O(1) 额外空间，不能开新数组。
  • 最直观做法：用首尾两个下标从两端向中间推进，每步交换一对字符，走到中点即完成。

② 关键设计决策

  • 下标 i 从 0 到 s.length/2 - 1（即 i < s.length/2）。
  • 每次交换 s[i] 与 s[s.length-1-i]。
  • 中点处理：奇数长度时正中间那个字符位置恰好不变，无需特殊处理；i < length/2 天然不会碰它。

③ 边界与细节

  • 单字符：length/2 = 0，循环不进，数组不变，结果正确。
  • 偶数长度：所有字符成对交换。
  • 奇数长度：中间一个字符不参与交换，位置天然正确。
  • 全相同 / 回文：交换后数组不变，结果仍正确。
  • 上限 10^5：线性时间，快。

④ 复杂度与最优性

  • 每个元素至多参与一次交换（共 n/2 对），时间 O(n)；空间 O(1)（临时变量 c）。
  • 最优性：反转必须移动 n/2 对元素，下界 Ω(n)；空间上题目要求 O(1)，二者均达到，故最优。

⑤ 具体 case 推演：s=['h','e','l','l','o']（长度 5）

  • i=0：交换 s[0]='h' 与 s[4]='o' → ['o','e','l','l','h']；
  • i=1：交换 s[1]='e' 与 s[3]='l' → ['o','l','l','e','h']；
  • i=2 等于 length/2=2，循环停止；中间 s[2]='l' 未动。
  • 结果 ['o','l','l','e','h']，与示例一致。
