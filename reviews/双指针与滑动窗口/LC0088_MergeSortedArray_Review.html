88. 合并两个有序数组 (Merge Sorted Array)

> https://leetcode.cn/problems/merge-sorted-array/

难度：Easy ｜ 分类：双指针与滑动窗口

标签：数组、双指针、排序

题目描述

给你两个按 非递减顺序 排列的整数数组 nums1 和 nums2，另有两个整数 m 和 n ，分别表示 nums1 和 nums2 中的元素数目。

请你 合并 nums2 到 nums1 中，使合并后的数组同样按 非递减顺序 排列。

注意：最终，合并后数组不应由函数返回，而是存储在数组 nums1 中。为了应对这种情况，nums1 的初始长度为 m + n，其中前 m 个元素表示应合并的元素，后 n 个元素为 0 ，应忽略。nums2 的长度为 n 。

示例 1：

输入：nums1 = [1,2,3,0,0,0], m = 3, nums2 = [2,5,6], n = 3

输出：[1,2,2,3,5,6]

解释：需要合并 [1,2,3] 和 [2,5,6] 。

合并结果是 [1,2,2,3,5,6] ，其中斜体加粗标注的为 nums1 中的元素。

示例 2：

输入：nums1 = [1], m = 1, nums2 = [], n = 0

输出：[1]

解释：需要合并 [1] 和 [] 。

合并结果是 [1] 。

示例 3：

输入：nums1 = [0], m = 0, nums2 = [1], n = 1

输出：[1]

解释：需要合并的数组是 [] 和 [1] 。

合并结果是 [1] 。

注意，因为 m = 0 ，所以 nums1 中没有元素。nums1 中仅存的 0 仅仅是为了确保合并结果可以顺利存放到 nums1 中。

提示：

nums1.length == m + n

nums2.length == n

src/双指针与滑动窗口/LC0088_MergeSortedArray.java提交区
public void merge(int[] nums1, int m, int[] nums2, int n) {
        int p1 = m - 1, p2 = n - 1;
        int p = m + n - 1;
        while (p1 >= 0 || p2 >= 0) {
            if (p1 < 0) {
                nums1[p--] = nums2[p2];
                p2--;
            } else if (p2 < 0) {
                nums1[p--] = nums1[p1--];
            } else {
                if (nums1[p1] > nums2[p2]) {
                    nums1[p] = nums1[p1];
                    p1--;
                } else {
                    nums1[p] = nums2[p2];
                    p2--;
                }
                p--;
            }
        }

    }

思路拆解

① 问题本质与解法选择

  • 把两个非递减数组合并进 nums1（原地），结果仍非递减。nums1 长度 m+n，前 m 个有效、后 n 个占位 0。
  • 若从前往后写，会用到未动过的 nums1 前段，需要额外数组或 O(m) 空间暂存；而 nums1 尾部恰好有 n 个空位，从后往前写可完全就地完成。

② 关键设计决策

  • 三指针：p1=m-1（指向 nums1 有效末尾）、p2=n-1（指向 nums2 末尾）、p=m+n-1（指向 nums1 写入位）。
  • while (p1>=0 || p2>=0)：
  • p1<0：nums1 已取完，只搬 nums2：nums1[p--]=nums2[p2--]。
  • p2<0：nums2 已取完，把剩余 nums1 从后往前搬回原位：nums1[p--]=nums1[p1--]。
  • 否则比较 nums1[p1] 与 nums2[p2]，把较大者放到 p，对应指针左移。
  • 关键点：写入位 p 总是当前未填的最大下标，而 p1 是还没搬的最右有效元素，二者不会覆盖到未处理数据，所以原地安全。

③ 边界与细节

  • n=0：nums2 空，走 p2<0 分支把 nums1 原样搬回，结果不变。
  • m=0：nums1 全占位 0，走 p1<0 分支直接拷入 nums2。
  • m,n 可为 0，但 m+n>=1，nums1 长度至少 1。
  • 相等元素：用 nums1[p1] > nums2[p2]（严格大于），相等时取 nums2，合并后仍非递减。
  • 已覆盖负数值、全相同、上限 200 等。

④ 复杂度与最优性

  • 每个写入位只被写一次，p1/p2 各自只左移，总时间 O(m+n)；空间 O(1)（原地）。
  • 最优性：结果需把 m+n 个元素全部归位且每个元素至少被读一次，下界 Ω(m+n)；本题达到下界且无需额外数组，空间也为最优。

套路沉淀

从后往前双指针原地合并

原地合并有序数组：nums1 尾部有 n 个空位时，用 p1/p2/p 从大到小填，每次取较大者放到写位，避免覆盖未处理元素；O(m+n)、O(1)。
