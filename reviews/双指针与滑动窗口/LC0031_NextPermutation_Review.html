public void nextPermutation(int[] nums) {
        int firstIndex = nums.length - 2;
        while (firstIndex >= 0) {
            if (nums[firstIndex] < nums[firstIndex + 1]) {
                break;
            } else {
                firstIndex--;
            }
        }
        if (firstIndex == -1) {
            reverse(nums, 0, nums.length - 1);
            return;
        }
        int secondIndex = nums.length - 1;
        while (secondIndex > firstIndex) {
            if (nums[firstIndex] < nums[secondIndex]) {
                break;
            } else {
                secondIndex--;
            }
        }
        swap(nums, firstIndex, secondIndex);

        reverse(nums, firstIndex + 1, nums.length - 1);
    }

    private void swap(int[] nums, int firstIndex, int secondIndex) {
        int temp = nums[firstIndex];
        nums[firstIndex] = nums[secondIndex];
        nums[secondIndex] = temp;
    }

    private void reverse(int[] nums, int begin, int end) {
        while (begin < end) {
            swap(nums, begin, end);
            begin++;
            end--;
        }
    }

下一个排列：从右向左找升序转折点，后缀取最小较大值交换并反转，无转折点整体反转，O(n)/O(1)，一次 Accepted（268/268）

思路拆解

### 问题本质与解法选择

  • 字典序下「下一个排列」= 比当前刚好大一点的排列：前缀变动的位置尽量靠右、增量尽量小。
  • 降序后缀是局部最大形态，内部涨不动；必须从右往左找到第一个 nums[i] < nums[i+1]（升序转折点），把 i 处换成「后缀中大于它的最小值」，再把后缀反转为升序（局部最小形态）。
  • 全程原地交换/反转，O(1) 额外空间，满足题目硬性要求；暴力枚举所有排列不可行且不满足常数空间。

### 关键设计决策

  • 找转折点：从右往左扫，第一个满足 nums[i] < nums[i+1] 的位置。
  • 找交换对象：后缀此时是降序，从右往左第一个大于 nums[i] 的数就是「最接近 nums[i] 的较大值」。
  • 交换后反转后缀（firstIndex+1 到末尾）：降序变升序，后缀取最小形态。
  • 无转折点：整个数组已是降序（最大排列），整体反转得到字典序最小排列。

### 具体 case 推演

[1,3,5,4,2] → [1,4,2,3,5]：

  1. 从右往左找转折点：i=3 时 4<2 否；i=2 时 5<4 否；i=1 时 3<5 成立 → firstIndex=1。
  2. 从右往左找大于 3 的数：2 否，4 是 → secondIndex=3。
  3. 交换 → [1,4,5,3,2]。
  4. 反转下标 2..4 的 [5,3,2] → [2,3,5]，得到 [1,4,2,3,5] ✓

[1,2,3,5,4] → [1,2,4,3,5]：

  1. 转折点：i=3 时 5<4 否；i=2 时 3<5 成立 → firstIndex=2。
  2. 后缀 [5,4] 中从右往左第一个大于 3 的是 4 → secondIndex=4。
  3. 交换 → [1,2,4,5,3]。
  4. 反转 [5,3] → [3,5]，得到 [1,2,4,3,5] ✓

[3,2,1]：无转折点 → 整体反转 → [1,2,3] ✓

重复值 [1,3,2,2] → [2,1,2,3]：

  1. 转折点 i=0（1<3）。
  2. 后缀 [3,2,2] 从右往左第一个大于 1 的是最右的 2（下标 3）→ 交换得 [2,3,2,1]。
  3. 反转 [3,2,1] → [1,2,3]，得到 [2,1,2,3] ✓（取重复值最右一个交换，保证交换后后缀仍能反转为最小）。

### 边界与细节

  • 单元素或全相同：找不到转折点 → 整体反转（全相同反转结果不变）。
  • 重复值：交换对象取「从右往左第一个大于 pivot 的」，含重复值的最右一个，保证后缀反转正确。
  • 无更大排列时整体反转成最小排列。

### 复杂度分析与最优性论证

  • 时间 O(n)：找转折点、找交换对象、反转三段各 O(n)，总 O(n)；下界 Ω(n)，必须扫描数组，故最优。
  • 空间 O(1)：原地交换，常数变量，满足题目「只允许常数额外空间」硬性约束。
