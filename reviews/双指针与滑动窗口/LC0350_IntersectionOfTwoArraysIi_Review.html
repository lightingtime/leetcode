public int[] intersect(int[] nums1, int[] nums2) {
        List<Integer> ans = new ArrayList<>();
        int[] a = new int[1001];
        int[] b = new int[1001];
        for (int num : nums1) {
            a[num]++;
        }
        for (int num : nums2) {
            b[num]++;
        }
        for (int i = 0; i < 1001; i++) {
            if (a[i] > 0 && b[i] > 0) {
                int min = Math.min(a[i], b[i]);
                for (int j = 0; j < min; j++) {
                    ans.add(i);
                }
            }
        }
        return ans.stream().mapToInt(Integer::intValue).toArray();
    }

思路拆解

① 问题本质与解法选择

  • 求两数组交集，且每个元素保留重复次数（出现次数取 min），输出顺序任意。
  • 一般化解法：哈希表统计较小数组（O(m+n) / O(min(m,n))）或排序+双指针（O(m log m + n log n) / O(1)）。
  • 本题值域被限制在 0..1000，可以用固定大小 1001 的计数数组：O(m+n) 时间 + O(1) 空间，时间空间双维度最优。

② 关键设计决策

  • a[1001]、b[1001] 分别统计 nums1、nums2 中各值出现次数。
  • 遍历 i=0..1000：若 a[i]>0 && b[i]>0，往答案里追加 min(a[i], b[i]) 个 i。
  • 答案先用 List<Integer> 收集再转 int[]。

③ 边界与细节

  • 无交集 → 返回空数组。
  • 重复次数不等 → 取较小值（如 [1,1,1,1] ∩ [1,1] = [1,1]，不是 4 个 1）。
  • 0 与 1000 都在数组下标范围内，不漏边界值。
  • 长度上限 1000：两次线性统计 + 1001 次扫描，快。
  • 输出顺序任意，按升序输出也满足要求。

④ 复杂度与最优性

  • 时间 O(m+n+1001) = O(m+n)；空间 O(1001) = O(1)（固定常数）。
  • 最优性：每个元素至少被读一次，时间下界 Ω(m+n)，达到；值域固定时用常数数组即可，比哈希表（O(min(m,n)) 空间）更省。在本题约束下时间与空间均为最优。

⑤ 具体 case 推演：nums1=[1,2,2,1]、nums2=[2,2]

  • 统计后 a[1]=2、a[2]=2；b[2]=2。
  • i=1：a[1]=2>0 但 b[1]=0 → 跳过。
  • i=2：a[2]=2>0 且 b[2]=2>0 → min=2，追加两个 2。
  • 结果 [2,2]，与示例一致。
