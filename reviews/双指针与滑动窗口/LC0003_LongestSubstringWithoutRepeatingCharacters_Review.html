3. 无重复字符的最长子串 (Longest Substring Without Repeating Characters)

> https://leetcode.cn/problems/longest-substring-without-repeating-characters/

难度：Medium ｜ 分类：双指针与滑动窗口

标签：哈希表、字符串、滑动窗口

题目描述

给定一个字符串 s ，请你找出其中不含有重复字符的 最长 子串 的长度。

示例 1:

输入: s = "abcabcbb"

输出: 3

解释: 因为无重复字符的最长子串是 "abc"，所以其长度为 3。注意 "bca" 和 "cab" 也是正确答案。

示例 2:

输入: s = "bbbbb"

输出: 1

解释: 因为无重复字符的最长子串是 "b"，所以其长度为 1。

示例 3:

输入: s = "pwwkew"

输出: 3

解释: 因为无重复字符的最长子串是 "wke"，所以其长度为 3。

请注意，你的答案必须是 子串 的长度，"pwke" 是一个子序列，不是子串。

s 由英文字母、数字、符号和空格组成

public int lengthOfLongestSubstring(String s) {
        Map<Character, Integer> map = new HashMap<>();
        int max = 0;
        int start = 0;
        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            if (!map.containsKey(c) || map.get(c) < start) {
                map.put(c, i);
            } else {
                max = Math.max(max, i - start);
                start = map.get(c) + 1;
                map.put(c, i);
            }
        }
        max = Math.max(max, s.length() - start);
        return max;
    }

思路拆解

问题本质：找不含重复字符的最长连续子串长度。滑动窗口：窗口 [start, i] 内保持无重复，右端逐个扩张，遇重复就把左端跳到重复位置之后。

关键设计：HashMap 记录每个字符最近一次出现的下标。遇到 c 时若 c 出现过且位置 ≥ start（即在当前窗口内），窗口左端 start 跳到上次出现位置 +1；若旧位置 < start，说明在窗口外，不构成重复。每次更新 max = max(max, i-start+1)。

边界：空串返回 0；整个串无重复时最后一次比较 s.length()-start 不能漏；重复字符恰在窗口左边界（如 abca）时 start 正确右移；「出现过」和「位置在窗口内」两个条件缺一不可。

复杂度：O(n) 时间（每个字符至多进出窗口一次）、O(字符集大小) 空间，最优。

套路沉淀

闭区间计数：元素个数 = 间隔数 + 1

闭区间 [l, r] 的元素个数 = r - l + 1（两端下标都算）；用「间隔数 + 1」理解可防 off-by-one。滑动窗口/子数组/遍历题的长度计算都适用，最常错在多减 1 或少加 1。

滑动窗口结算时机与公式绑定

两种合法写法：每步结算（先跳 start 再算 i-start+1）；或延迟结算（if 只扩展不结算，else 里窗口到 i-1 算 i-start，循环后补 n-start）。公式必须匹配结算时窗口的合法性：含 i 且无重复才用 i-start+1。
