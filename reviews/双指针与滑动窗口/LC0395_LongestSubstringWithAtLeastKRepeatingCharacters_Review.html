395. 至少有 K 个重复字符的最长子串 (Longest Substring with At Least K Repeating Characters)

> https://leetcode.cn/problems/longest-substring-with-at-least-k-repeating-characters/

难度：Medium ｜ 分类：双指针与滑动窗口

标签：哈希表、字符串、分治、滑动窗口

题目描述

给你一个字符串 s 和一个整数 k ，请你找出 s 中的最长子串， 要求该子串中的每一字符出现次数都不少于 k 。返回这一子串的长度。

如果不存在这样的子字符串，则返回 0。

示例 1：

输入：s = "aaabb", k = 3

输出：3

解释：最长子串为 "aaa" ，其中 'a' 重复了 3 次。

示例 2：

输入：s = "ababbc", k = 2

输出：5

解释：最长子串为 "ababb" ，其中 'a' 重复了 2 次， 'b' 重复了 3 次。

提示：

1 4

s 仅由小写英文字母组成

① 与上一轮对比

  • 上一轮（09-12）同为主思路分治但非一次 AC、判较弱；本轮把主方法拆成 longestSubstring + 私有 dfs(l, r)，思路与上次一致：先统计当前区间频率 → 找第一堵墙（区间内频率 < k 的字符）→ 跳过整段连续墙 → 只递归墙体左右两侧。
  • 关键差异是历史坑这次都填上了：① 频率每层区间内重新统计，不再拿整串频率判区间内部（坑：全局够 ≠ 段内够）；② 找到墙后先跳过连续墙再递归，墙段本身不能进任何合法子串，所以左右两侧不重不漏（不会拿「两个切点之间的原始长度」当答案）。

② 这次为什么一次过

  • 正确性推理是「合法子串不含任何频率 < k 的字符」——这是单调的性质：墙字符在任何包含它的子串里都不合法，因此递归只保留左右两侧就覆盖全部候选，不需要再对段内做二次校验。
  • 边界都交给了「重扫 + 空区间返回 0」：k=1（所有字符都合法，直接返回整段）、k 大于串长（第一个墙就是 0 号位，两侧皆空）、连续墙（while 跳过整段）、答案在尾段（右递归负责）。

③ 掌握度判定

  • strong：本轮无任何解法提示，一次提交 Accepted（38/38）；本地 17 组用例全绿，另跑 30 万组随机小串（字母表 1–3 个字符、k=1–4）与暴力枚举全部子串对拍零差异。

④ 下一步提醒

  • 若想拿线性：本题可以枚举「窗口里恰好含 t 种字符」（t = 1..26），每种 t 用滑动窗口 O(n) 维护 题目要求的每种字符都 ≥ k，总计 O(26n)；或把分治改成「一次按所有墙字符切分」，每层至少消掉一种字符 → 深度 ≤ 26。

public int longestSubstring(String s, int k) {
        return dfs(s, 0, s.length() - 1, k);
    }

    private int dfs(String s, int l, int r, int k) {
        if (l > r) {
            return 0;
        }
        int[] counts = new int[26];
        for (int i = l; i <= r; i++) {
            counts[s.charAt(i) - 'a']++;
        }
        int p = -1;
        for (int i = l; i <= r; i++) {
            if (counts[s.charAt(i) - 'a'] < k) {
                p = i;
                break;
            }
        }
        if (p == -1) {
            return r - l + 1;
        }
        int q = p;
        while (q <= r && counts[s.charAt(q) - 'a'] < k) {
            q++;
        }

        return Math.max(dfs(s, l, p - 1, k), dfs(s, q, r, k));
    }

public int longestSubstring(String s, int k) {
        return dfs(s, 0, s.length() - 1, k);
    }

    private int dfs(String s, int l, int r, int k) {
        if (l > r) {
            return 0;
        }
        int[] counts = new int[26];
        for (int i = l; i <= r; i++) {
            counts[s.charAt(i) - 'a']++;
        }
        int end = -1;
        for (int i = l; i <= r; i++) {
            if (counts[s.charAt(i) - 'a'] < k) {
                end = i;
                break;
            }
        }
        if (end == -1) {
            return r - l + 1;
        }
        int start = end;
        while (start <= r && counts[s.charAt(start) - 'a'] < k) {
            start++;
        }
        return Math.max(dfs(s, l, end - 1, k), dfs(s, start, r, k));
    }

思路拆解

① 问题本质与解法选择

  • 找最长子串，使其中每个字符出现次数 ≥ k。
  • 关键观察：若某字符在当前串（区间）中总出现次数 < k，它不可能出现在任何合法子串里 → 它把区间切成若干互不相交的段，原问题变成子段上的同构子问题 → 分治。
  • 分治写法直观、可接受；本题更优做法是「按窗口内不同字符数枚举的滑动窗口」，时间复杂度 O(26n)。

② 关键设计决策

  • dfs(ch, start, end, k)：处理 s[start..end)，返回该区间内满足条件的最长合法子串长度。
  • 每次进入先统计区间频次 count[26]。
  • 找到第一个频次 < k 的字符（墙）；用 j 跳过连续墙，保证左右子区间都不含墙。
  • 返回 max(dfs(start, i), dfs(j, end))——只切这一刀，避免对每个墙都递归导致指数膨胀（之前版本的教训）。
  • 区间内无墙 → 整段合法 → 返回 end - start。
  • 剪枝：end - start < k → 0。

③ 边界与细节

  • k > s.length：end-start < k 直接返回 0。
  • 无墙（所有字符全局 ≥ k）：整串合法，返回串长。
  • 墙在开头/结尾：左/右子区间为空，递归返回 0。
  • 连续墙：while 跳过，避免把墙段传进递归。
  • 最后一个墙之后的段由「右递归」覆盖（这正是上一版漏掉、后被边界 11/12 抓住的洞）。

④ 复杂度与最优性

  • 每层最多 2 个互不重叠的子问题；最坏 O(n²)（斜切形态），一般接近 O(n log n)；空间 O(n) 递归栈。
  • 更优方向：枚举窗口内不同字符数 t=1..26，对每个 t 用滑动窗口找「恰好 t 种不同字符且每种 ≥ k」的最长窗口，总 O(26n)。当前实现不是时间最优（最优性标为否）。

⑤ 具体 case 推演：s="baaac"、k=3

  • dfs(0,5)：统计 b=1, a=3, c=1。第一个墙在 i=0（b 出现 1 < 3），j 到 1（a 非墙）。
  • 返回 max(dfs(0,0), dfs(1,5))。
  • dfs(1,5)="aaac"：统计 a=3, c=1。墙在 i=4（c），j=5。
  • 返回 max(dfs(1,4), dfs(5,5))；dfs(1,4)="aaa" 无墙 → 3；dfs(5,5) 空 → 0。
  • 答案 3 ✓（"aaa" 段在墙 b 与 c 之间，由左右递归覆盖）。

套路沉淀

分治：<k 字符当墙切左右

子串条件类分治：频次<k 的字符不可能在合法子串中，找到第一堵墙、跳过连续墙、递归左右取 max；每层只切一刀避免指数膨胀。

墙的合法性单调：含墙必不合法 → 只递归墙两侧

频率 < k 的字符是「墙」，任何包含它的子串都不合法，因此答案只可能在墙的左侧或右侧，递归两侧即可不重不漏；每层必须重扫当前区间统计频率（全局够≠段内够），找到第一堵墙后要跳过整段连续墙再递归（墙段本身不可能进答案）。找不到墙即整段合法，返回长度；l>r 返回 0。每层只剥第一段墙时最坏 O(n²)，改成一次按所有墙字符切分则深度 ≤ 26。
