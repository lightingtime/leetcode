public int longestSubstring(String s, int k) {
        return dfs(s.toCharArray(), 0, s.length(), k);
    }

    private int dfs(char[] ch, int start, int end, int k) {
        if (end - start < k) {
            return 0;
        }
        int[] count = new int[26];
        for (int i = start; i < end; i++) {
            count[ch[i] - 'a']++;
        }
        for (int i = start; i < end; i++) {
            if (count[ch[i] - 'a'] < k) {
                int j = i + 1;
                while (j < end && count[ch[j] - 'a'] < k) {
                    j++;
                }
                return Math.max(dfs(ch, start, i, k), dfs(ch, j, end, k));
            }
        }
        return end - start;
    }

思路拆解

① 问题本质与解法选择

  • 找最长子串，使其中每个字符出现次数 ≥ k。
  • 关键观察：若某字符在当前串（区间）中总出现次数 < k，它不可能出现在任何合法子串里 → 它把区间切成若干互不相交的段，原问题变成子段上的同构子问题 → 分治。
  • 分治写法直观、可接受；本题更优做法是「按窗口内不同字符数枚举的滑动窗口」，时间复杂度 O(26n)。

② 关键设计决策

  • dfs(ch, start, end, k)：处理 s[start..end)，返回该区间内满足条件的最长合法子串长度。
  • 每次进入先统计区间频次 count[26]。
  • 找到第一个频次 < k 的字符（墙）；用 j 跳过连续墙，保证左右子区间都不含墙。
  • 返回 max(dfs(start, i), dfs(j, end))——只切这一刀，避免对每个墙都递归导致指数膨胀（之前版本的教训）。
  • 区间内无墙 → 整段合法 → 返回 end - start。
  • 剪枝：end - start < k → 0。

③ 边界与细节

  • k > s.length：end-start < k 直接返回 0。
  • 无墙（所有字符全局 ≥ k）：整串合法，返回串长。
  • 墙在开头/结尾：左/右子区间为空，递归返回 0。
  • 连续墙：while 跳过，避免把墙段传进递归。
  • 最后一个墙之后的段由「右递归」覆盖（这正是上一版漏掉、后被边界 11/12 抓住的洞）。

④ 复杂度与最优性

  • 每层最多 2 个互不重叠的子问题；最坏 O(n²)（斜切形态），一般接近 O(n log n)；空间 O(n) 递归栈。
  • 更优方向：枚举窗口内不同字符数 t=1..26，对每个 t 用滑动窗口找「恰好 t 种不同字符且每种 ≥ k」的最长窗口，总 O(26n)。当前实现不是时间最优（最优性标为否）。

⑤ 具体 case 推演：s="baaac"、k=3

  • dfs(0,5)：统计 b=1, a=3, c=1。第一个墙在 i=0（b 出现 1 < 3），j 到 1（a 非墙）。
  • 返回 max(dfs(0,0), dfs(1,5))。
  • dfs(1,5)="aaac"：统计 a=3, c=1。墙在 i=4（c），j=5。
  • 返回 max(dfs(1,4), dfs(5,5))；dfs(1,4)="aaa" 无墙 → 3；dfs(5,5) 空 → 0。
  • 答案 3 ✓（"aaa" 段在墙 b 与 c 之间，由左右递归覆盖）。

套路沉淀

分治：<k 字符当墙切左右

子串条件类分治：频次<k 的字符不可能在合法子串中，找到第一堵墙、跳过连续墙、递归左右取 max；每层只切一刀避免指数膨胀。
