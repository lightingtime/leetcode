public int maxArea(int[] height) {
        int left = 0, right = height.length - 1;
        int max = 0;
        while (left < right) {
            max = Math.max(max, Math.min(height[left], height[right]) * (right - left));
            if (height[left] < height[right]) {
                left++;
            } else {
                right--;
            }
        }
        return max;
    }

盛最多水的容器：相向双指针，移动较矮一侧，O(n)/O(1)，一次 Accepted（65/65）

思路拆解

问题本质：选两条竖线使面积 min(h[l],h[r])×(r-l) 最大。暴力枚举 O(n²)；双指针从两端向中间收拢 O(n)。

关键设计：每步计算当前左右两线的面积并更新最大值，然后移动较矮的那条。理由：移动较矮的一侧可能遇到更高边从而增大面积；移动较高的一侧，宽度一定变小、高度又被较矮的钳制，面积不可能变大，所以可以安全排除以矮边为界的全部候选。

边界：只有两根线时即唯一候选；高度相等时移动任一侧都不漏最优（代码里 <= 时动右指针）；数组长度至少为 2。

复杂度：O(n) 时间、O(1) 空间；正确性来自每步排除的候选不可能超过当前最优，最优。

套路沉淀

相向双指针：两端向中间收，移动条件更差的一侧

左右指针从数组两端出发，每次计算当前答案后移动「条件更差」的一侧（如容器题移动较矮的边），把 O(n²) 降到 O(n)。适用：盛水容器、接雨水、回文验证等两端夹逼题。
