public void wiggleSort(int[] nums) {
        int mid = quickSort(nums, 0, nums.length - 1);
        int lt = 0, i = 0, gt = nums.length - 1;
        while (i <= gt) {
            int fi = (1 + 2 * i) % (nums.length | 1);
            int flt = (1 + 2 * lt) % (nums.length | 1);
            int fgt = (1 + 2 * gt) % (nums.length | 1);
            if (nums[fi] > mid) {
                swap(nums, fi, flt);
                i++;
                lt++;
            } else if (nums[fi] == mid) {
                i++;
            } else {
                swap(nums, fi, fgt);
                gt--;
            }
        }

    }

    private int quickSort(int[] nums, int l, int r) {
        if (l == r) {
            return nums[l];
        }
        int x = nums[l], i = l - 1, j = r + 1;
        while (i < j) {
            do {
                i++;
            } while (nums[i] < x);
            do {
                j--;
            } while (nums[j] > x);
            if (i < j) {
                swap(nums, i, j);
            }
        }
        int k = nums.length / 2;
        if (k <= j) {
            return quickSort(nums, l, j);
        } else {
            return quickSort(nums, j + 1, r);
        }
    }

    private void swap(int[] nums, int i, int j) {
        int temp = nums[i];
        nums[i] = nums[j];
        nums[j] = temp;
    }

思路拆解

问题本质与解法选择理由

目标是把数组原地重排成 nums[0] < nums[1] > nums[2] < ... 的摆动序列，要求 O(n) 时间、O(1) 空间。

直接想法是「排序后小的半段填谷位、大的半段填峰位」，但完整排序是 O(n log n) 且要 O(n) 辅助数组。两条路径都优化：

  • 时间：只需中位数（而非全序），用快速选择 O(n) 平均；
  • 空间：不复制排序结果，用虚拟下标把「排序 + 奇偶分开」折叠成一次原地三路划分。

关键设计决策

决策写法理由
求中位数Hoare 快速选择，k=n/2，返回 nums[k]摆动只需中位数值作为三路划分基准
虚拟下标映射`f(i) = (1+2i) % (n\1)`把真实下标重排成「峰位在前、谷位在后」的虚拟顺序
三路划分在虚拟空间上荷兰国旗：>mid 换到左(峰)、==mid 留中、<mid 换到右(谷)峰位恒 > 相邻谷位，摆动自动成立

虚拟下标为什么这么算

映射 f(i)=(1+2i)%(n\|1) 的设计动机：

  • 摆动要求奇数位(1,3,5…)是峰放大值、偶数位(0,2,4…)是谷放小值；
  • 1+2i 恰好按步长 2 枚举峰位，但只有奇数时才能覆盖全下标，所以模数取 n\|1（n 偶时 = n+1）使步长 2 与模数互质，保证 f 是 0..n-1 上的单射（满覆盖、不重复）。

n=6 时 n\|1=7：f = [1,3,5,0,2,4]，虚拟下标 0..2 对应峰位、3..5 对应谷位。

具体 case 逐层推演

[1,5,1,1,6,4]，快速选择得 mid=1，n=6：

  1. 三路划分指针 lt=0, i=0, gt=5，每次读写真实下标 nums[f(x)]：
  • i=0，nums[f(0)]=nums[1]=5 > 1 → 与 flt(=f(0)=1) 自换，lt=1, i=1
  • i=1，nums[f(1)]=nums[3]=1 == mid → i=2
  • i=2，nums[f(2)]=nums[5]=4 > 1 → swap(f(2)=5, f(1)=3)，lt=2, i=3
  • i=3，nums[f(3)]=nums[0]=1 == mid → i=4
  • i=4，nums[f(4)]=nums[2]=1 == mid → i=5
  • i=5，nums[f(5)]=nums[4]=6 > 1 → swap(f(5)=4, f(2)=5)，lt=3, i=6
  1. 结束 i>gt，结果 [1,5,1,4,1,6]：1<5>1<4>1<6 ✓

踩坑与修复

  1. 虚拟下标定义域越界：gt 初始化为 n 时 f(gt) 越界（n 偶时 f(n)=n）。修复：gt = n-1，保证 f 的参数始终在 0..n-1。
  2. Hoare 分区点用错：partition 退出后 i>=j，正确分界是 j（nums[l..j]<=x），用 i 会在 i==r 时递归区间不缩小 → 栈溢出。修复：k<=j 递归左半 [l,j]，否则右半 [j+1,r]。

复杂度与下限论证

  • 时间 O(n)：快速选择平均每次区间减半（n + n/2 + … = O(n)），三路划分单趟 O(n)。比较排序下限是 Ω(n log n)，但本题只要求中位数而非全序，快速选择能达到 Ω(n) 下界。
  • 空间 O(1)：只用几个整型变量，原地交换，无辅助数组；相比「排序+拷贝」的 O(n) 空间，这是理论下限。
