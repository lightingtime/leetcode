题目描述

给你一个整数数组 nums，将它重新排列成 nums[0] nums[2]  的顺序。

你可以假设所有输入数组都可以得到满足题目要求的结果。

示例 1：

输入：nums = [1,5,1,1,6,4]

输出：[1,6,1,5,1,4]

解释：[1,4,1,5,1,6] 同样是符合题目要求的结果，可以被判题程序接受。

示例 2：

输入：nums = [1,3,2,2,3,1]

输出：[2,3,1,3,1,2]

写法 1 · 快速选择中位数 + 虚拟下标三路划分

时间 平均 O(n)，最坏 O(n²)空间 平均 O(log n) 递归栈，最坏 O(n)内存 ≈ 47.5 MB用例 52/52

LC0324_WiggleSortIi.java · 快速选择中位数 + 虚拟下标三路划分提交区
public void wiggleSort(int[] nums) {
        int n = nums.length;
        int mid = quickSort(nums, 0, n - 1, n / 2);
        int lt = 0, i = 0, gt = n - 1;
        while (i <= gt) {
            if (nums[f(n, i)] < mid) {
                swap(nums, f(n, i), f(n, gt));
                gt--;
            } else if (nums[f(n, i)] > mid) {
                swap(nums, f(n, i), f(n, lt));
                lt++;
                i++;
            } else {
                i++;
            }
        }
    }

    private int f(int n, int i) {
        return (1 + 2 * i) % (n | 1);
    }

    private int quickSort(int[] nums, int l, int r, int k) {
        if (l == r) {
            return nums[l];
        }
        int p = nums[r];
        int i = l, j = l;
        while (j < r) {
            if (nums[j] < p) {
                swap(nums, i, j);
                i++;
            }
            j++;
        }
        swap(nums, i, r);
        if (i == k) {
            return nums[i];
        } else if (i < k) {
            return quickSort(nums, i + 1, r, k);
        } else {
            return quickSort(nums, l, i - 1, k);
        }
    }

    private void swap(int[] nums, int i, int j) {
        int temp = nums[i];
        nums[i] = nums[j];
        nums[j] = temp;
    }

public void wiggleSort(int[] nums) {
        int mid = quickSort(nums, 0, nums.length - 1);
        int lt = 0, i = 0, gt = nums.length - 1;
        while (i <= gt) {
            int fi = (1 + 2 * i) % (nums.length | 1);
            int flt = (1 + 2 * lt) % (nums.length | 1);
            int fgt = (1 + 2 * gt) % (nums.length | 1);
            if (nums[fi] > mid) {
                swap(nums, fi, flt);
                i++;
                lt++;
            } else if (nums[fi] == mid) {
                i++;
            } else {
                swap(nums, fi, fgt);
                gt--;
            }
        }

    }

    private int quickSort(int[] nums, int l, int r) {
        if (l == r) {
            return nums[l];
        }
        int x = nums[l], i = l - 1, j = r + 1;
        while (i < j) {
            do {
                i++;
            } while (nums[i] < x);
            do {
                j--;
            } while (nums[j] > x);
            if (i < j) {
                swap(nums, i, j);
            }
        }
        int k = nums.length / 2;
        if (k <= j) {
            return quickSort(nums, l, j);
        } else {
            return quickSort(nums, j + 1, r);
        }
    }

    private void swap(int[] nums, int i, int j) {
        int temp = nums[i];
        nums[i] = nums[j];
        nums[j] = temp;
    }

思路拆解

问题本质与解法选择理由

目标是把数组原地重排成 nums[0] < nums[1] > nums[2] < ...，要求 O(n) 时间、O(1) 空间。

朴素做法是「排序 → 前半填谷位、后半填峰位，两边都从末尾倒着取」，正确但 O(n log n) 且需要辅助数组。两条路都能省掉：

  • 时间：摆动只需要「谁小于中位数 / 谁大于中位数」，不需要完整顺序 → 用快速选择平均 O(n) 拿到中位数；
  • 空间：用虚拟下标把「交错摆位」折叠成「按虚拟顺序填」，于是能在原数组上直接做三路划分。

关键设计决策

决策写法理由
求中位数快速选择（Lomuto 分区，pivot 取 nums[r]），k = n/2，返回 nums[k]摆动只用到中位数值，作为三路划分的基准
虚拟下标`f(i) = (1 + 2i) % (n \1)`把虚拟顺序折回真实下标，使虚拟前段恰好是全部峰位、后段是全部谷位
三路划分在虚拟空间上荷兰国旗：> mid 换到 lt（峰位侧）、< mid 换到 gt（谷位侧）、== mid 留中一趟同时完成「按中位数分区」与「按峰谷摆位」

为什么虚拟下标是 (1+2i) % (n|1)

  • 1 + 2i 是步长 2 的数列，天然只命中奇数下标（峰位），「先把峰位走完」正是我们要的填充顺序；
  • 取模数必须是奇数才能与步长 2 互质，保证 f 是 0..n-1 上的单射；n 为偶数时用 n | 1 = n+1 把它变成奇数。
  • n=6：1+2i = 1,3,5,7,9,11 mod 7 → 1,3,5,0,2,4；虚拟 0..2 落在峰位 1,3,5，虚拟 3..5 落在谷位 0,2,4 ✓
  • 反例：写成 % n 时 n=6 得 1,3,5,1,3,5，撞车且永远取不到 0,2,4，谷位会留着旧数据。

具体 case 逐层推演

case 1：[1, 1, 2, 2]（n=4，最容易暴露重复值撞车）

  • 快速选择 k = 4/2 = 2，Lomuto 一趟后 i = 2 == k，返回 mid = nums[2] = 2；
  • f = [1,3,0,2]，初始 lt=0, i=0, gt=3：
  1. i=0，nums[f(0)] = nums[1] = 1 < 2 → 与 f(gt=3) = 2 交换 → 数组变 [1,2,1,2]，gt=2，i 不动
  2. i=0，nums[f(0)] = nums[1] = 2 == mid → i=1
  3. i=1，nums[f(1)] = nums[3] = 2 == mid → i=2
  4. i=2，nums[f(2)] = nums[0] = 1 < 2 → 与 f(gt=2) = 0 自换，gt=1，i 不动，此时 i=2 > gt=1 退出
  • 结果 [1,2,1,2]：1 < 2 > 1 < 2 ✓（两个 2 被分到真实下标 1、3，不相邻）

case 2：[1, 5, 1, 1, 6, 4]（n=6，官方示例）

  • 快速选择 k = 6/2 = 3，Lomuto 后 mid = nums[3] = 4，数组被搅成 [1,1,1,4,6,5]；
  • f = [1,3,5,0,2,4]，初始 lt=0, i=0, gt=5：
  1. i=0，nums[f(0)] = nums[1] = 1 < 4 → 与 f(5) = 4 交换 → [1,6,1,4,1,5]，gt=4
  2. i=0，nums[f(0)] = nums[1] = 6 > 4 → 与 f(lt=0) = 1 自换，lt=1, i=1
  3. i=1，nums[f(1)] = nums[3] = 4 == mid → i=2
  4. i=2，nums[f(2)] = nums[5] = 5 > 4 → 与 f(lt=1) = 3 交换 → [1,6,1,5,1,4]，lt=2, i=3
  5. i=3，nums[f(3)] = nums[0] = 1 < 4 → 与 f(gt=4) = 2 交换（两个 1 互换）→ gt=3，i 不动
  6. i=3，nums[f(3)] = nums[0] = 1 < 4 → 与 f(gt=3) = 0 自换 → gt=2，i=3 > gt=2 退出
  • 结果 [1,6,1,5,1,4]：1 < 6 > 1 < 5 > 1 < 4 ✓，正是官方示例给出的答案之一

边界与细节

  • gt 必须初始化为 n-1，不能是 n：f 的定义域只有 0..n-1，n 为偶时 f(n) = (1+2n) % (n+1) = n 直接越界（一刷踩过）。
  • 循环条件取 i <= gt：未处理区是闭区间 [i, gt]，i == gt 时还剩最后一个元素必须处理。
  • < mid 分支交换后 i 不能前进（从 gt 换过来的元素尚未检查）；> mid 分支换到 lt 后可以前进，因为 [0, lt) 已确认全是大于 mid 的元素。
  • 划分方向不能反：虚拟前段是峰位（该放大值），把 < mid 送进虚拟左段会让峰位拿到小数、谷位拿到大数，除单元素外全部用例失败（二刷踩过）。
  • n 为奇数时谷位比峰位多一个，虚拟分界点 n/2 恰好覆盖，不需要额外特判。
  • 小规模：n=1 没有相邻对，任何排列都合法；n=2 只需比较一次。

复杂度与下限论证

  • 时间 O(n)：快速选择每层区间平均减半（n + n/2 + n/4 + ... = O(n)），三路划分一趟 O(n)。
  • 空间 O(1)：只用常数个整型变量 + 原地 swap；递归写法的调用栈平均 O(log n)，若严格计入栈则是 O(log n)。
  • 下限：比较排序的 Ω(n log n) 下界只针对「求全序」，本题只需要中位数，而求中位数必须先看每个元素，Ω(n) 下界不可绕过，所以 O(n) 已是理论最优；空间上不需要任何副本，O(1) 同样是下限。

套路沉淀

虚拟下标 + 三路划分

原地重排成摆动/奇偶交错序列：构造映射 f(i)=(1+2i)%(n|1) 把峰位排前谷位排后（步长 2 与模数互质保证单射），三路划分在虚拟空间上按 mid 归位即同时完成分区与摆位，O(n)时间O(1)空间；Hoare 分区必须用 j 分界保证递归收敛

虚拟下标映射：划分方向必须与虚拟分段的角色对齐

映射 f(i)=(1+2i)%(n|1) 的虚拟前段 [0,n/2) 全部落在真实峰位（奇数下标）、后段 [n/2,n) 全部落在谷位；虚拟空间因此带角色语义，三路划分必须让 >mid 进虚拟左段（峰位）、<mid 进右段（谷位）。若反向（小的进左段），峰位会拿到小数、谷位拿到大数，输出呈「正确排列整体颠倒」，症状是除单元素外几乎全部用例失败——单元素永远通过，会掩盖问题。另注意方向反了也要保证分支自洽：换到 gt 的那支 i 不前进（换来的元素未检查）
