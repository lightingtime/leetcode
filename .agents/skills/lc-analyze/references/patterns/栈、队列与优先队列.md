## 20. 递归收集结果：用局部列表+helper 参数，避免实例字段跨调用累积

出处：LC0094 二叉树的中序遍历（递归写法）

递归/回溯需要一个收集结果的列表时，两种安全做法：

- 入口方法内 `new` 列表，传给递归 helper 作为参数累加（推荐）；
- 用实例字段收集，但**入口每次先 `clear()`**。

坑：实例字段且不重置时，本地 main 多次调用同一实例，上一次的结果会残留串到下一次（例：第二个测试期望 `[]`，实际拿到第一个测试的结果）；
同时该字段若声明在提交标记区之外，提交包装后 `dfs` 引用它直接编译失败（找不到符号）。

要点：凡是「一次调用产生一份结果」的方法，收集容器的作用域要么限定在调用内（局部变量+参数传递），要么入口显式重置；声明位置也要放进提交区。

## 21. 迭代中序：cur 指针驱动 + 左链一次压栈，访问后 cur=cur.right

出处：LC0094 二叉树的中序遍历（迭代写法）

迭代中序遍历的骨架：

- 外层 `while (cur != null || !stack.isEmpty())`，用 `cur` 指针驱动；
- 内层**先把 cur 自己压栈**，再 `cur = cur.left` 直到 cur 为 null（只压左孩子、当前节点不入栈，首次弹栈就是 null → NPE）；
- 弹栈访问节点，然后 `cur = cur.right` 继续下一轮。

错误写法：每次循环从栈顶重新检查 `node.left` 并压栈——左孩子指针从未改变，同一个左子节点会被反复压入，死循环直至 OOM；
访问后若不把 `cur` 移到右孩子（而是把右孩子 push 进栈后继续看栈顶），同样会重蹈重复压栈；
另外空树（root 为 null）不能直接入栈，否则 peek 后取 `node.left` 直接 NPE。

要点：保证「每个节点只压一次」的关键是访问后把 `cur` 移到右孩子，而不是回到栈顶重新走左链；
节点本身入栈与 `cur = cur.right` 两步缺一不可。

## 53. ArrayDeque 当栈用：push/pop 同侧，禁止混 offerLast

出处：LC0150 逆波兰表达式求值

`ArrayDeque` 作栈用时 push=addFirst、pop=removeFirst，都在队头；`offerLast` 是队尾操作：

- 数字/元素入栈必须也用 `push`，混用 `offerLast` 会让后入的元素跑到队尾、pop 却从队头取，栈序错乱（后入反而最后被取）。
- 后缀表达式求值：遇数字 push、遇算符 pop 两个算完再 push；减/除时先弹的是后操作数，用 `b - a`、`b / a`。
- 除法向零截断：Java int 除法本身向零截断（-7/2 = -3），无需额外处理。

要点：用 Deque 当栈前先想清楚操作的是 first 还是 last，push/pop/peek 必须同一侧。

## 54. 惰性栈展开嵌套结构：逆序压栈 + hasNext 循环展开栈顶

出处：LC0341 扁平化嵌套列表迭代器

嵌套结构（列表/树）按先序展开为迭代器：

- 构造：把元素**逆序压栈**（后进先出，让最左元素在栈顶先出）。
- hasNext：`while (!stack.isEmpty() && !stack.peek().isInteger())` 持续弹出栈顶列表、**逆序压回其元素**，直到栈顶是整数或栈空，最后 `return !stack.isEmpty()`。
- next：直接 `pop().getInteger()`（hasNext 已保证栈顶是整数）。
- 三坑：展开循环起点用 `size()-1`（`size()` 越界）；hasNext 必须循环展开（只展开一次，深层嵌套栈顶仍是列表）；展开后栈可能已空（空列表），返回 `!isEmpty()` 而非无条件 true。

要点：迭代器「惰性」= 按需展开栈顶，hasNext 负责把栈顶整理成「可用」状态。

## 56. 频次作下标建桶求 Top-K

出处：LC0347 前 K 个高频元素

- 适用信号：要「按频次取前 k 个」且**答案不要求有序**——先把「排序/堆」的 log 因子去掉。
- 关键观察：频次天然落在 `[1, n]` 有界区间，可以当**数组下标**用；`bucket[f]` 装所有出现 f 次的元素。
- 构造：统计时顺手维护 `max`（最大频次），桶数组开 `max + 1`；装桶先 `if (bucket[f] == null) bucket[f] = new ArrayList<>()`
  **再无条件 add**——写成 if/else 会把每个频次桶的第一个元素丢掉。
- 收集：从 `max` 递减扫到 0，`index++` 后立刻判 `index == k` 返回；只在**内层** break 而继续外层扫桶，会越界。
- 复杂度：时间 O(n)，空间 O(m)（m 为不同元素个数）；无快选最坏 O(n²)、无堆 O(n log k)，是这个题型的最优线性写法。

要点：Top-K 不要求有序 + 频次有界 → 计数数组当桶；下标是频次、桶里是元素，方向别搞反。
