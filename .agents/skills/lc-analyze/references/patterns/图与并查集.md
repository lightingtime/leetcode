## 24. 记忆化/哈希表：先定死 map 的 value 语义，value 必须是最终要比较的量

出处：LC0128 最长连续序列

用 map 做记忆化或统计前，先明确 key→value 存什么：

- 最终要比较的量（连续长度、最大值、次数）就必须直接存这个量本身；
- 中间定位值（链起点、前驱位置、偏移量）不能当最终量用。

错误示范：把「链起点再往前的数（`left - 1`）」存进 map，再拿它和 `max` 比较，结果是无意义数值；
跳链循环 `left -= map.get(left)` 用存储值当步长，存了负值时 `left` 会前后振荡，死循环。

要点：写 map 方案先回答一个问题——「key 查出来这个 value，我要用它做什么？」如果它最终要被比较/求和，
那它就该直接是那个数；如果只是定位用的中间值，就另存一份真正的结果。
无前驱的孤立数，长度基础值必须是 1；若公式里恒多 +1（如 `num - left + 1` 对孤立点算出 2），单元素/断开序列就会全错。

## 25. 链式记忆化：存在性判断基于全集，不能基于已处理集合

出处：LC0128 最长连续序列

算 `f(x) = 1 + f(x-1)` 时，`x-1`「在不在」必须问**全集**（所有输入先去重放入），
不能问「处理到当前为止见过没有」。否则输入乱序时前驱后到，`x` 被过早判定为孤立点，缓存值过期；
后面前驱进来了也没人回头重算 `x`（示例：`[100,4,200,1,3,2]` 得 2 而非 4，因为 3 先于 2、4 先于 3 到达）。

两种可行结构：

- 一个 map 全量放入（值标记「存在但未算」），按需递归/循环算长度，算过的直接返回；
- 一个 HashSet 存全集（只做存在性判断）+ 一个 HashMap 只做记忆化。

要点：记忆化缓存的值只在「查询依据稳定」时才不会过期；存在性依据必须是输入集合本身，而不是遍历进度。

## 26. 网格连通分量 DFS：四方向偏移 + 越界守卫 + 发现即计数

出处：LC0200 岛屿数量

网格连通题（岛屿、被围绕区域、填海造陆等）的统一骨架：

- 方向偏移只放**上下左右**四组（`{-1,0},{1,0},{0,-1},{0,1}`）；放成 8 组会把斜对角误连成同一块。
- `dfs` 开头先判越界，**出界才返回**；守卫写反（在界内却 return）会让所有在界调用直接返回。
- 主循环遇到「未访问的陆地」就计数 +1，并让 dfs 把整块标记完；dfs 不需要返回值参与计数。
- 空网格：先判 `m == 0`，再取 `grid[0].length`，顺序反了直接 AIOOBE。

要点：连通分量计数 = 「发现新块」时 +1，而不是对每个元素累加或取最大块大小；
越界守卫先写「什么情况安全退出」，再写「正常处理」。
