## 37. 值域 [1,n] 数组原地归位（cyclic sort）

出处：LC0448 找到所有数组中消失的数字

- 值 x 应放下标 x-1，就位判断用 `nums[i] == i+1`（不是 `i-1`）；
- 把 `nums[i]` 换到目标位前先检查目标位是否已有同值：已有说明该值是重复的，跳过当前下标；否则交换可能无变化、扫描指针不前进而死循环；
- 扫描指针每轮要么就位、要么前进，保证每轮必有进展，整趟 O(n)；第二次扫描时 `nums[i] != i+1` 的位置 i+1 即缺失数字。
- 具体 case：`[1,2,3]` 用错条件 `nums[i] != i-1` 会在 index=0 处自我交换死循环；`[1,1]` 在 index=1 时目标位 nums[0] 已有 1，无重复守卫则交换不变死循环。

要点：写「值放回位置」的原地算法时，先写清「值 x → 下标 x-1」的映射，再核对就位判断与重复/已占位分支，确保指针每轮必前进或就位。

## 38. 子数组和=前缀和之差：map 计已见前缀，先查后登记

出处：LC0560 和为 K 的子数组

- map 存「已出现的前缀和 → 次数」；单层循环里先查 `prefix[j]-k` 累加答案，再登记当前 `prefix[j]`，顺序不能反（反了会把空子数组/当前前缀算进去）；
- 初始 map 放入空前缀 0：约定 A（prefix[i]=nums[0..i]，虚拟 prefix[-1]=0）与约定 B（prefix 长度 n+1，prefix[0]=0）都要放，否则漏掉所有从下标 0 开始的子数组；
- 查询目标是 `prefix[j]-k`，登记键永远是当前 `prefix[j]`，两者不可混；
- 必须是单层循环：map 随 j 前进累积「j 之前出现过的前缀」；双层循环会把同一批前缀重复配对，导致重复计数。

要点：前缀和计数题的 map 语义是「已见过的前缀和频次」，每一轮固定「先查目标、再登记自己」，循环层数与 map 累积方向一一对应。

## 42. 取负标记法：0 是盲区，标记与判断都要避开「-0 仍是 0」

出处：LC0268 丢失的数字

把「出现过的数 v」映射到「下标 v 处取负」，扫描时第一个仍为正的下标即缺失值
（值域 [0,n] 内 n 个数缺一个）：

- 标记：`nums[|nums[i]|] *= -1`（先判目标 >0 防重复取负；值为 n 时越界需跳过）。
- 判断：`nums[i] > 0` = 从未被标记。
- 盲区：`-0 == 0`，值为 0 的格子永远变不成负数。若缺失值 m 的位置恰好存着 0
  （`nums[m] == 0`），该位置既无 `v=m` 来标记它、本身又无法取负，扫描时显示 0
  被当成「已标记」跳过，最后误返回 n。反例 `[4,3,0,1]`（缺 2）→ 返回 4。
- 对策：把值统一平移后再标记（如 v+1），让 0 也有可取的负；或换不依赖正负号的
  记录（cyclic sort 归位、异或、求和）。

要点：取负标记法的前提是「每个可标记位置的值都非 0」或「0 能表达已标记」；
设计标记方案时先问自己：值 0 会不会出现在需要标记的位置上。
