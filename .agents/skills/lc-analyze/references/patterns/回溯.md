## 27. 回溯枚举组合：空输入要提前返回，终止条件对空串直接成立

出处：LC0017 电话号码的字母组合

回溯枚举（字母组合、子集、排列等）里，终止条件 `len == 目标长度` 对空输入**一开始就成立**，
会把空串当成一个合法组合加入答案（`""` → `[""]`）；题目要求空输入返回空列表时，需在进入递归前单独返回。

另注意测试工具盲区：若规范化时把空串转成空内容，`[]` 与 `[""]` 无法区分（都显示 `[]`），
这类边界要用 `size() != 0` 之类的显式断言兜底，否则本地全绿、力扣 WA。

要点：先想清楚「长度为 0 是不是题目要的输出」；递归枚举类题目在入口处统一处理空输入。

## 28. 回溯枚举子集：两种框架不可混用，递归起点必须前进

出处：LC0078 子集

子集/组合类枚举有两种等价回溯框架，一次只能选一种：

- 框架 A（每个下标选/不选）：递归参数传下一个下标，分支是「加入」与「不加入」，不需要 for 循环；
- 框架 B（起点推进）：for i 从 start 起，只走「加入」分支并递归 (i+1)，「不加入」由循环自然推进，循环体内只有一个递归调用；
- 共性：下一层起点必须基于当前选择前进（i+1），传旧 index 会让同一元素重复入选（如 [1,3,3]）、子集重复、递归树超过 2^n 爆炸；
- 每次进入递归就把当前列表副本加入答案，空集由根节点自然产生。

要点：把两种框架叠用（for 循环里同时写「加完递归」和「删完递归」）会让每个状态被重复展开；
递归起点传错（index+1 而非 i+1）是这类题最隐蔽的爆炸源——本地跑小样例靠运气能过，跑满长度直接 OOM。

「不选」的位置要具体到 case：起点推进里 i 从 start 推进到 start+1 就是放弃 start——nums=[1,2,3] 时 i=1 分支的 list 从未包含 1，
跳过 1 的动作就是循环推进本身；讲解时禁止用「隐含/显然」带过，必须配这种逐层 case。

## 29. 递归枚举必须显式终止：决策下标越界即返回，不能访问越界元素

出处：LC0078 子集

选/不选框架没有 for 循环，终止条件必须显式：

- 递归参数是下一个待决策下标，当 index == 数组长度时，没有元素可决策，先返回；
- 子集题每个节点都是答案，越界前那层加入即可，但访问 nums[index] 前必须保证在界内；
- 从「起点推进」改成「选/不选」时，for 循环隐式的越界保护会消失，必须补上显式 base case，否则 AIOOBE。

要点：换框架时检查边界出口是否仍然存在；递归访问数组下标前，先保证下标在界内。

## 30. 答案收集时机绑定框架：选/不选只在叶子加答案，起点推进每节点加

出处：LC0078 子集

答案收集时机绑定回溯框架：

- 起点推进框架：每个节点形成的列表互不相同，进入 dfs 即可加答案；
- 选/不选框架：每个子集唯一对应一棵「叶子」，内部节点的列表与某个叶子重复，只能在叶子（所有元素决策完）加答案；
- 判断标准：同一个列表是否会被多条路径重复到达。

要点：换框架后，除了递归参数和终止条件，答案收集时机也要一起检查。

## 40. 回溯删除最小化：先算最小删除预算，连续相同只删第一个

出处：LC0301 删除无效的括号（Hard，回溯）

- 一遍扫描算出必须删的数量：`)` 在 balance=0 时出现 → 多余右括号 +1；扫完 balance 剩余 → 多余左括号数。最小删除总数 = 两者之和，之后 DFS 以此为预算，超过即剪枝。
- 枚举「保留/删除」两分支时，共享容器（StringBuilder/List）必须递归后撤销（deleteCharAt/remove），否则兄弟分支拿到被污染的现场。
- 去重：连续相同的括号删任意一个结果相同，只在「连续段第一个」上触发删除分支，同一结果只生成一次。
- 条件判断警惕恒真陷阱：`c != '(' || c != ')'` 对所有字符恒 true（'非A或非B' ≠ '非(A且B)'），导致删除分支永远不可达。

要点：删除类回溯三件套 = 预算（先算最小删除数）+ 撤销（共享容器还原）+ 去重（连续相同只删第一个）；叶子收集时校验合法性（balance==0）。
## 66. 括号生成回溯：剩余计数 + 前缀合法性剪枝

出处：LC0022 括号生成

适用信号：列出所有受前缀约束的串（括号、表达式、路径），答案数本身指数级。用「还剩多少」代替「已用多少」：l/r 为剩余左/右括号数，剪枝条件就写成 l > r（已放下的 ) 已多于 (，前缀非法）。两种分支各带前提：放 ( 需 l>0，放 ) 需 r>l；共享 StringBuilder 在递归返回后立刻撤销末字符。终止在 l==r==0 收结果，剪枝放在终止判断之后，已完整的合法串不会被误剪。复杂度下限：答案 C_n 个、每个长 2n，输出开销本身 Ω(C_n·n)。对照 LC0301：那题先算最小删除预算再删，本题构造时维护剩余计数，共同点是把非法前缀的整棵子树砍掉。
