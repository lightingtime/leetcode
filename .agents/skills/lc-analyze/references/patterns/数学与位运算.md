## 42. 翻倍减法模拟的溢出防护

出处：LC0029 两数相除（负数域翻倍减）

| 场景 | 正确做法 |
| --- | --- |
| 负数域翻倍（num 为负，num<<1 即 ×2） | 翻倍前先确认 `num*2` 不会越界（安全底线 `num >= MIN/2`），且翻倍后仍减得起，才翻 |
| 溢出后的错误信号 | `num<<1` 溢出成正数/0 后，`负 < 正` 恒真，内层循环会把 num 翻成非法值，减数和商全错 |
| 商本身超 int | `MIN/1` 的商绝对值 = 2^31，累计商的变量也要 32 位兜底，不能裸 `ans += time` |

要点：翻倍/移位的每一步都要先问「这次移位会不会越界」；32 位边界题里，越界不是「结果差一点」，而是让后续所有比较/减法失去意义。
