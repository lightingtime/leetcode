## 45. 纵向逐列扫描求公共前缀

出处：LC0014 最长公共前缀

多串最长公共前缀：以 `strs[0]` 为基准逐列比较，所有串同一位置字符相等才 append，
遇到某串到头（`index >= str.length()`，需先于 charAt 判断防越界）或字符不等即停；
`strs[0]` 为空串时 while 不执行直接返回 ""。

- 横向（两两取前缀逐步缩短）与纵向（逐列对齐）等价，纵向更直观、天然处理长短不齐。
- 复杂度：最坏 O(S)（S 为所有串长度和）、辅助 O(1)。

要点：多串公共前缀的终点 = 第一个「某串到头或字符不等」的位置，比较时先判越界再取值。

## 46. 无 0 的 26 进制转十进制

出处：LC0171 Excel 表列序号

Excel 列名转序号：`A=1..Z=26`，每一位取值 1~26（无 0 字符），是「无 0 的 26 进制」：

- 从右往左：`ans += k * mul`，其中 `k = char - 'A' + 1`，`mul` 从 1 起每步 `*26`；
  或等价从左往右：`ans = ans * 26 + k`。
- 上限 `FXSHRXW = 2^31-1`：int 累加中间值不溢出；避免用 `Math.pow` 浮点（丢精度）。
- 注意与普通 26 进制区别：`A=1` 而非 0，`Z=26` 而非 25，所以进位发生在 `Z -> AA`。

要点：带字母映射的进制题，先确认每一位的取值范围（0-based 还是 1-based），
再决定权重公式；1-based 时 `k = char - 'A' + 1`。

## 47. 多取模条件分类：交叠条件优先

出处：LC0412 Fizz Buzz

多条件 if/else 分类且条件有交叠（如「同时是 3 和 5 的倍数」）时：

- 交叠条件（公倍数，`i % 15 == 0`）必须放最前，否则 15 会被 `i % 3 == 0` 抢先判成 Fizz。
- 用 `if / else if` 链保证每个元素只命中一个分支。
- 通用化：多个除数的交叠倍数 = 最小公倍数，优先于单一除数条件。

要点：写多条件分类前先列出「条件之间的包含/交叠关系」，把最严格的（交叠）条件放最前面。

## 48. atoi/数字累加防溢出：累加前用 (上限-digit)/10 预判

出处：LC0008 字符串转换整数 (atoi)

逐字符累加整数（如 atoi、字符串转数字）防溢出：

- 每次累加前检查 `temp > (上限 - digit) / 10`，为真则截断到上限——避免 `temp*10 + digit` 本身爆 int
  （反例：`2147483640 + 8` 溢出成 -2147483648，乘后 `== MAX/10` 的检查拦不住）。
- 溢出标志不能只靠 `temp == MAX`：对负数不对称——`-2147483647` 的绝对值恰为 MAX 但完全合法，
  会被误截成 MIN；负数应按 `[-2^31, 0]` 方向判断（或换 long 累加）。
- 前导零无需特判：`temp*10 + 0` 累加 0 无影响，'0' 走统一数字分支；只有非数字字符才停止读取。

要点：任何 `ans = ans*10 + digit` 的累加，先想「ans 已经接近上限时加这一位会不会爆」；
溢出判断要和符号方向一致，不能拿正数 MAX 对称套负数。
