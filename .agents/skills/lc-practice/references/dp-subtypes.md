# DP 子类型速查表

「动态规划」只是大类，做题前必须先识别**子类型**，因为子类型决定三件套：状态定义、转移方程、填表顺序。
识别依据 = 题目输入形态 + 操作特征，不是难度。

## 快速识别表

| 子类型 | 输入/操作特征 | 状态套路 | 转移套路 | 填表顺序 |
| --- | --- | --- | --- | --- |
| 线性 DP | 数组/字符串按顺序扫描，问以某位置结尾或前 i 个的最优 | `dp[i]` = 以 i 结尾 / 前 i 个 | 当前决策 + 上一个状态（直接配对/跳段/选不选） | 从左到右 |
| 区间 DP | 对一段连续区间做操作，操作改变相邻关系（合并、戳破、切分、两端取值） | `dp[i][j]` = 区间 [i,j] 的最优 | 枚举最后一步/分界点 k，`dp[i][j] = max(dp[i][k] + dp[k][j] + cost)` | 按区间长度从小到大 |
| 树形 DP | 输入是树/二叉树，需要子节点信息汇总 | 每个节点返回若干状态值（如偷/不偷） | 后序遍历，子节点结果向上合并 | 自底向上（后序） |
| 背包 DP | 有容量限制 + 每个物品选/不选（或选几个），求最值/计数 | `dp[容量]` 或 `dp[i][容量]` | `dp[c] = opt(dp[c], dp[c-w] + v)` | 0-1 倒序、完全正序 |
| 状态机 DP | 同一时刻有多个状态，按动作互相转移（持有/卖出/冻结） | `dp[i][状态]`，状态数固定 | 每个状态从合法前驱转移 | 从左到右 |
| 数位 DP | 输入是一个大整数，按位统计满足条件的数 | `dp[pos][state][tight]` | 按位枚举数字 | 从高位到低位（记忆化） |
| 状压 DP | n 很小（≤20），状态是集合 | `dp[mask]`，mask 二进制位表示集合 | 枚举集合内元素转移 | mask 从小到大 |

## 各子类型宽泛提示（讲给用户用）

### 线性 DP
先问「状态以哪个位置结尾，还是前 i 个」；转移只写「当前一步怎么接上一步」，不要写生成式递推。例：32 题状态 = 以 i 结尾的最长有效长度。

### 区间 DP
**关键反直觉点**：正着做（先操作谁）会破坏相邻关系，要倒过来想「最后一步/最后一个处理的是谁」；最后处理的对象把区间切成左右两个独立子问题。
- 状态：`dp[i][j]` 表示区间 [i,j] 内做完所有操作的最优值；
- 转移：枚举最后处理的 k（分界点），`dp[i][j] = max(dp[i][k] + dp[k][j] + 最后一步代价)`；
- 填表：按区间长度从小到大，保证子区间先算完。
- 识别信号：合并石子/气球、戳破、括号配对、切绳子、两端取数。
- 注意边界补丁：常给原数组两端补哨兵（如补 1）简化越界。

### 树形 DP
后序遍历自底向上，每个节点返回一个或多个值（例：偷/不偷两个值）；子问题不重叠时 O(n)。

### 背包 DP
先分清 0-1（每件最多一次，倒序）还是完全（无限次，正序）；容量维度循环方向是最大坑点。

### 状态机 DP
先把所有「状态」列全（例：持有/空仓/冷冻），再画状态转移图，最后写成多维数组；每个状态只从合法前驱转移。

## 使用时机

- lc-practice 建题/展示：分类是「动态规划」时，必须先识别子类型并告诉用户，再给该子类型宽泛提示；
- lc-guide 引导：识别子类型后，用对应行的「状态套路/转移套路/填表顺序」分块引导；讲任何 DP 状态必须说清 5 件事（下标含义、端点含不含、值存什么、转移来源、答案取哪个格子），禁止只给公式；
- lc-submit 复盘：`done --dpSubtype <子类型>` 记录到 analysis.json，复盘页展示；类似题型提醒用子类型提示。
