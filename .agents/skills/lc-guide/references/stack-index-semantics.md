# 栈存下标时的语义解释模板

适用于括号匹配、单调栈、迭代器、滑动窗口等「栈里保存下标」的题。用户问“栈里存的是什么、栈顶有什么作用”时，不要只回答“存下标”，要讲清下标在本题中的角色。

## 按顺序解释

1. **元素类型**：栈中不是字符或对象，而是位置下标。
2. **每个元素的语义**：下标本身没有固定含义，必须结合不变量说明“它代表哪个尚未处理/尚未匹配的位置”。
3. **栈底与栈顶的区分**：栈底通常是边界或最早未处理位置，栈顶通常是最近一个未匹配/待处理位置。
4. **操作前后的栈顶语义**：
   - 入栈前，什么条件会把当前下标压入；
   - 出栈时，谁与谁完成配对/抵消；
   - 出栈后，新栈顶为什么能作为下一段计算的基准。
5. **长度或答案公式的来源**：用“当前下标 − 基准下标”解释，而不是只给公式。
6. **用 2～5 个元素的具体输入逐轮列出栈状态**。

## 示例：LC32 最长有效括号

栈的不变量：

```text
栈底 = 边界下标（-1 或最近一个无法匹配的 ')'）
栈底之上 = 边界之后所有尚未匹配的 '(' 下标
```

因此栈中存的是**位置**：

- 初始 `-1`：数组开始前的虚拟边界；
- 未匹配的 `(` 下标：未来遇到 `)` 时可以和它配对；
- 新出现的未匹配 `)` 下标：栈弹空后压入，成为当前有效段的左边界。

遇到可匹配的 `)` 时，先弹出它配对的 `(`。弹出后：

```text
新栈顶 = 当前有效子串开始位置的前一个下标
当前长度 = 当前下标 - 新栈顶
```

以 `")()())"` 为例：

| `i` | 字符 | 操作 | 栈 | 有效长度 |
| --- | --- | --- | --- | --- |
| 初始 | — | — | `[-1]` | 0 |
| 0 | `)` | 弹出 `-1` 后为空，压入 0 | `[0]` | 0 |
| 1 | `(` | 压入 1 | `[0, 1]` | 0 |
| 2 | `)` | 弹出 1，栈顶为 0 | `[0]` | `2 - 0 = 2` |
| 3 | `(` | 压入 3 | `[0, 3]` | 2 |
| 4 | `)` | 弹出 3，栈顶为 0 | `[0]` | `4 - 0 = 4` |
| 5 | `)` | 弹出 0 后为空，压入 5 | `[5]` | 4 |

这里：

- `0`、`5` 是边界下标；
- `1`、`3` 是未匹配的 `(` 下标；
- 栈顶在遇到 `)` 时负责找到“可配对的最近未匹配位置”，弹出后负责给出有效段左边界。

## 引导话术

不要问“栈里存什么”，而要追问：

```text
每个下标代表哪个尚未消除的位置？
什么时候把它压入？
弹出它意味着什么已经完成？
弹出后的新栈顶为什么可以作为长度计算的基准？
```
