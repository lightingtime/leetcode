# 引导实例：LC0004 两数组第 k 小

## 名词表（先讲，配数字例子）

| 名词 | 含义 | 例子（nums1=[10,20,50,60]） |
| --- | --- | --- |
| 下标 | 数组位置，从 0 数 | 20 的下标是 1 |
| 排名（第 k 小） | 从小到大数，从 1 数 | 20 是第 2 小 |
| 有效起点 p1/p2 | 指针，标记「从哪开始还算数」，只会右移 | p1=2 时 nums1 只剩 [50,60] |
| 候选下标 | 有效部分里第 k/2 个元素的下标 = 起点 + k/2 − 1 | k=5 时候选下标 = 0+2−1 = 1（20） |
| 封顶 | 数组不够长时候选取最后一个：min(len−1, 起点+k/2−1) | nums1=[1,2]、k=6 时候选下标 = min(1,2) = 1 |
| 排除数量 | 旧起点到候选下标（含候选）的元素个数 = 候选下标 − 旧起点 + 1 | 排除下标 0..1 → 数量 = 1−0+1 = 2 |

## 变量规划（写代码前先讲）

- `p1` / `p2`：两个数组当前有效起点，从 0 开始，排除一批就右移一批；
- `k`：1 基排名（第 k 小），随排除递减；
- `cand1` / `cand2`：两边候选下标（含封顶）；
- `removed`：本轮实际排除的元素个数（含候选）。

## 分块清单（一次一块）

1. 出口检查：`p1 >= len1` / `p2 >= len2` / `k == 1`（顺序：先判空再判 k==1，防越界）；
2. 候选下标：`min(len-1, p + k/2 - 1)`；
3. 比较排除：较小侧 `p = cand + 1`、`k -= cand - p(旧) + 1`；
4. main 换算：0 基下标 → 第 k 小，奇数 `totLen/2 + 1`，偶数 `totLen/2` 与 `totLen/2 + 1`。

## 踩坑案例（供检查片段时对照）

main 按 0 基下标算中间位置直接传给 1 基语义的辅助函数：totLen=3 时 `totLen/2 = 1` 是下标（对应第 2 小），
传给 k=1 会取到第 1 小；totLen=1 时 k=0 触发 `nums[p + k - 1] = nums[-1]` 越界。
修复方向：排名 = 下标 + 1。
